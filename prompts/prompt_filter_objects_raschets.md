## ЗАДАЧА

Доработать `Справочник.ОбъектыРасчетов.Форма.ФормаВыбора`:

### ШАГ 1: Анализ существующей формы
1. Найди файлы: `C:\Configuration_downloads\BASERP25\Catalogs\ОбъектыРасчетов\Forms\ФормаВыбора\`
2. Прочитай Module.bsl ПОЛНОСТЬЮ
3. Прочитай Form.xml — параметры формы, фильтры при открытии
4. Определи механизм отбора (ПараметрыВыбора, Отбор, ПараметрыФормы)

### ШАГ 2: Определить механизм передачи параметров
- Изучи откуда вызывается ФормаВыбора (из РКО при выборе ОбъектРасчетов в ТЧ)
- Определи можно ли передать доп. параметры через ПараметрыФормы

### ШАГ 3: Фильтр по СтатьеДДС (АВТОМАТИЧЕСКИЙ)
При открытии ФормаВыбора из РКО:
1. Получить `СтатьяДвиженияДенежныхСредств` из текущей строки ТЧ РасшифровкаПлатежа
2. Фильтровать ОбъектыРасчетов: показывать только те, чей Договор (ДоговорыКонтрагентов) имеет `А_СтатьяДвиженияДенежныхСредствОказаниеУслугПодразделению` = переданной СтатьяДДС
3. **Фильтр ТОЛЬКО когда передана СтатьяДДС!** Иначе — стандартный режим

### ШАГ 4: Фильтр по Подразделению (ОПЦИОНАЛЬНЫЙ)
1. Добавить поле "Подразделение (услуги)" типа Справочник.СтруктураПредприятия
2. При открытии НЕ заполнять
3. При изменении — фильтровать по `Договор.А_ПодразделениеОказаниеУслугПодразделению`
4. При очистке — убирать фильтр

### ШАГ 5: Тестирование
```sql
ВЫБРАТЬ
    ОР.Наименование, ОР.Договор,
    Д.А_СтатьяДвиженияДенежныхСредствОказаниеУслугПодразделению,
    Д.А_ПодразделениеОказаниеУслугПодразделению
ИЗ Справочник.ОбъектыРасчетов КАК ОР
ЛЕВОЕ СОЕДИНЕНИЕ Справочник.ДоговорыКонтрагентов КАК Д ПО ОР.Договор = Д.Ссылка
ГДЕ Д.А_СтатьяДвиженияДенежныхСредствОказаниеУслугПодразделению.Наименование
    ПОДОБНО "%Прочие услуги банка%"
```
