## Зачем

В «Сводной ведомости расчётов» по контрагенту **Воронцов Олександр Володимирович** тело всех кредитов проектам лежит
одним договором «Кредитование от кредитора -- Строительство (Закупка)» (остаток 7 000 370,10 на 30.09.2026).
Из оборотки не видно, **какому подразделению выдан кредит и кто его вернул**. Финансист и главбух хотят видеть это
прямо в строке договора.

Принцип (решение пользователя 16.10.2026): **один договор Воронцова = одна пара «откуда деньги → кому дали»**.
- `Подразделение` договора = ЦО, с чьего счёта ушли деньги (Строительство) — так договор остаётся в балансе ЦО;
- `А_ПодразделениеОказаниеУслугПодразделению` = подразделение-заёмщик (кому дали);
- наименование: `Кредит: Строительство → Глобино-2`.

Кредиты выдаёт ТОЛЬКО Воронцов. ЦО — не кредитор, а подразделение, через счёт которого идут его деньги.

## Что сделать

### 1. Справочник `ДоговорыКонтрагентов`

- Реквизит `А_ПодразделениеОказаниеУслугПодразделению` уже есть (тип `СправочникСсылка.СтруктураПредприятия`),
  поле на `ФормаЭлемента` уже выведено (id 1062, закладка «Основное», группа «Стороны договора / Организация»).
- Поменять синоним и подсказку (ru и uk, украинский текст в обоих, см. память «отчёты только на украинском»):
  синоним «Підрозділ-отримувач», подсказка «Кому надано послугу або видано кредит. Для кредитних договорів
  Воронцова — підрозділ-позичальник; підрозділ договору — ЦО, з рахунку якого пішли гроші».
- Это изменение метаданных: перед загрузкой — `db-dump-xml -Mode Partial -Objects "Справочник.ДоговорыКонтрагентов"`
  (в базе могут быть правки пользователя, LESSONS 11), потом правка, `db-load-xml -Mode Partial`, `db-update`.
  Если синоним не критичен — этот пункт можно отложить, логика от него не зависит.

### 2. Документ `А_ОказаниеУслугМеждуПодразделениями` — модуль объекта (область `КредитныеДоговоры`)

Файл `Documents/А_ОказаниеУслугМеждуПодразделениями/Ext/ObjectModule.bsl`.

1. `А_КредитнаяСторона(СтрокаДеньги, ЭтоРасход, ТипДоговора)` (≈ стр. 2656):
   - если статья ДДС стороны — статья кредитора (`А_ЭтоСтатьяКредитора(...)`, задан `А_ПартнерРасчетов`), то
     `ПодразделениеПолучатель` = подразделение ДРУГОЙ стороны строки
     (`ЭтоРасход ? ПодразделениеПриход : ПодразделениеРасход`); иначе — пустая ссылка;
   - передать его в поиск договора. Для выдачи (кредитор — расход ЦО) и для возврата (кредитор — приход ЦО)
     получается один и тот же договор пары, тип у обеих операций «Закупка».
2. `А_НайтиИлиСоздатьКредитныйДоговор(Контрагент, Организация, Подразделение, ВидДоговора, ТипДоговора,
   ПодразделениеПолучатель = Неопределено)` (≈ стр. 2545):
   - в ключ поиска добавить `И Дог.А_ПодразделениеОказаниеУслугПодразделению = &ПодразделениеПолучатель`
     (Неопределено → `Справочники.СтруктураПредприятия.ПустаяСсылка()`), чтобы договоры заёмщиков, процентов и НП
     (у них реквизит пуст) не путались с договорами пар;
   - при создании заполнить `А_ПодразделениеОказаниеУслугПодразделению`; остальные реквизиты — как сейчас
     (вид, «Собственники», «Задолженность по кредитам», грн, «По договорам», ГФУ по типу).
3. `А_ИмяКредитногоДоговора(ВидДоговора, Подразделение, ТипДоговора, ПодразделениеПолучатель = Неопределено)`
   (≈ стр. 2521): для «Тело кредита» с заполненным получателем — `"Кредит: " + Подр + " → " + Получатель`,
   суффикс « (Реализация)» только если тип не «Закупка»; ≤ 150 символов. Остальные серии — без изменений.
4. Больше ничего в `СоздатьОплатыНаСервере` не менять: кредитная сторона уже перезаписывает контрагента, партнёра,
   договор, ГФУ, направление и валюту из результата `А_КредитнаяСторона`.

Проверено по коду 16.10.2026 (перепроверить перед правкой):
- подписка `А_СобытияОбъектов` (≈ стр. 283) переименовывает договор в «X внутр.(…)» только если **у партнёра
  договора** заполнен `А_Подразделение`; у Воронцова он пуст — договоры пар не переименуются. Подписка ставит
  `А_НаправлениеОказаниеУслуг` = направление получателя (это нормально), `А_ВидКонтрагента` = «Собственники» сохраняется;
- прежний подбор ОУМП (стр. ≈188, 215, 398, 536, 877, 933, 980, 1019) ищет договоры по `А_ПодразделениеОказаниеУслугПодразделению`
  только у внутренних контрагентов (партнёр с `А_Подразделение`) — договоры Воронцова туда не попадут;
- **на стороне заёмщика реквизит НЕ заполнять**: там партнёр — подразделение, подписка переименует договор и его
  подхватит обычный подбор внутренних услуг.
