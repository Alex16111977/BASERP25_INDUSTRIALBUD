Акт о приемке выполненных работ

Документ Акт о приемке выполненных работ предназначен для отражения принятых работ от Субподрядчика.

На форме элемента вводятся следующие данные:     

  • Организация - организация, которая ведет строительство.
  • Субподрядчик - субподрядчик из справочника Партнеры.
  • Поставщик - поставщик строительства из справочника Контрагенты.
  • Договор - договор контрагента, с которым ведется строительство.
  • Соглашение - соглашение с партнером выбором из справочника Соглашения с поставщиком.
  • Подразделение - подразделение, которое выполняет работу.
  • Объект строительства.
  • Период  работ С..  По - период выполнения работ по строительству объекта.
  • Если установлен флаг Отразить выполнение принятых работ = да, то делается движение документа по регистру «Учет выполнения работ», в который записывается табличная часть «Работы».
  • Номер КС-2 - номер документа КС-2.
  • Дата КС-2 - дата документа КС-2.
  • Номер КС-3 - номер документа КС-3.
  • Дата КС-3 - дата документа КС- 3.

 

На закладке Работы содержатся сведения:

  • Код СДР - код структурной декомпозиции работ.
  • Работа - работа из справочника Строительные работы.
  • Объем общий - общий объем работы строительства.
  • Единица объема.
  • Длительность - длительность работы строительства.
  • Единица длительности - единица длительности работы строительства.
  • % выполнено - % выполнения работы строительства.
  • Объем выполнено - объем выполнения работы строительства.
  • Дата начала - дата начала работы строительства объекта.
  • Дата окончания - дата окончания работы строительства объекта
  • Общая стоимость - общая стоимость работ с НДС.

 

Принято на начало периода:

  • % принято - % выполнения работы строительства на начало периода.
  • Объем - объем выполнения работы строительства на начало периода.
  • Стоимость с НДС - стоимость работ с НДС на начало периода.

 

           Принято за текущий период:

  • % принято - % выполнения работы строительства, принятых за текущий период.
  • Объем - объем выполнения работы строительства, принятых за текущий период.
  • Стоимость с НДС -  стоимость работ с НДС, принятых за текущий период.
  • Ставка НДС - отображается ставка НДС.
  • Сумма НДС - отображается сумма НДС.

 

По кнопке-подменю Заполнить и кнопки Заполнить из плана-графика заполняется табличная часть «Работы» документа.
