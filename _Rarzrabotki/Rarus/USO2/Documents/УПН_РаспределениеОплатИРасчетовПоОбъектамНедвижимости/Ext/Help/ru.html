Распределение оплат и расчетов по объектам недвижимости 

Документ предназначен для распределения платежей, поступивших по договорам недвижимости, по конкретным объектам недвижимости.

Документ может быть создан на основании документа оплаты, например, Поступление безналичных ДС или Приходный кассовый ордер.

По кнопке Заполнить по контрагенту происходит автозаполнение табличной части данными.

По кнопке Распределить сумму общая сумма платежа может быть распределение по площади или по стоимости.

При проведении документ фиксирует уменьшение задолженности по договору в разрезе объектов недвижимости
