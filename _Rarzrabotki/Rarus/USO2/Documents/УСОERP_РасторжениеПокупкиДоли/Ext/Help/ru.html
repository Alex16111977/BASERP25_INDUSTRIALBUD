Документ «Расторжение покупки доли» предназначен для отражения информации о расторжении договора долевого участия в бухгалтерском учете.

Документ формируется на основании документа «Расторжение сделки по недвижимости».

В верхней части документа указывается:

  • Организация - организация, которая осуществляет строительство;
  • Контрагент – контрагент, который покупает долю объекта строительства;
  • Партнер – покупатель доли, выбирается из справочника «Партнеры»;
  • Договор – договор с контрагентом, выбирается из справочника «Договоры с контрагентами»;
  • Соглашение - соглашение с покупателем, выбирается из справочника «Соглашения об условиях продаж»;
  • Объект эксплуатации - объект эксплуатации, соответствующий указанному объекту строительства, выбирается из справочника «Объекты эксплуатации»;
  • Объект строительства – объект строительства, выбирается из справочника «Объекты строительства»;
  • Сумма доли – стоимость доли объекта эксплуатации. Поле «Сумма доли» заполняется по формуле: поле «Сумма возврата» - поле «Санкции» из табличной части документа «Расторжение сделки по недвижимости». 
  • Валюта;
  • Направление деятельности – направление деятельности, по которому ведутся расчеты с партнером.

 

Закладка Отражение в регл. учете предназначена для полей, в которых указываются учетные характеристики долей объекта.

В случае если документ создан на основании документа «Договор по недвижимости», то поля «Организация», «Партнер», «Контрагент», «Соглашение», «Договор», «Объект эксплуатации», «Сумма документа» заполняются автоматически из соответствующих полей.

Поля «Назначение целевых средств», «Движение целевых средств» и «Группа финансового учета» заполняются автоматически из одноименных дополнительных реквизитов в справочнике «Договор с контрагентом».
