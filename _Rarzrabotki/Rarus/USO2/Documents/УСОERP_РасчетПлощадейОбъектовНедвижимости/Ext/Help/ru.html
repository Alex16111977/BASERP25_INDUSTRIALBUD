Расчет площадей объектов недвижимости

Документ Расчет площадей объектов недвижимости предназначен для предварительного расчета площадей объектов недвижимости перед закрытием месяца. Документ должен быть заполнен сводными площадями по объектам эксплуатации в разрезе объектов недвижимости.

              В верхней части документа расположены поля:

  • Организация – организация, по которой фиксируются площади объекта строительства;
  • Объект эксплуатации – по наименованию совпадает с объектом строительства, по которому фиксируются площади;
  • По обмерам БТИ – признак, регулирующий отражение в документе плановых или фактических площадей. Если признак активен, то данным документом фиксируются фактические площади, иначе плановые.

Табличная часть может быть заполнена автоматически по кнопке Заполнить или вручную.

В случае ручного заполнения можно сводно внести площади без указания объекта недвижимости одной строкой. Для этого необходимо заполнить следующие реквизиты табличной части на закладке Объекты недвижимости:

  • Объект недвижимости – заполняется из перечня объектов недвижимости, которые относятся к выбранному в шапке объекту эксплуатации. Для сводного ввода площадей по объекту эксплуатации данный реквизит может не заполняться.
  • Площадь собственных жилых помещений – площадь непроданных жилых помещений;
  • Площадь собственных нежилых помещений – площадь непроданных нежилых помещений;
  • Площадь собственных машиномест – площадь непроданных машиномест;
  • Площадь жилых помещений ДДУ - площадь жилых помещений, проданных по ДДУ;
  • Площадь нежилых помещений ДДУ - площадь нежилых помещений, проданных по ДДУ;
  • Площадь машиномест ДДУ - площадь машиномест, проданных по ДДУ;
  • Площадь жилых помещений ИНВЕСТ - площадь жилых помещений, проданных по инвестиционным договорам;
  • Площадь нежилых помещений ИНВЕСТ - площадь нежилых помещений, проданных по инвестиционным договорам;
  • Площадь машиномест ИНВЕСТ - площадь машиномест, проданных по инвестиционным договорам.

 

Для автоматического заполнения табличной части должны быть зарегистрированы данные по площадям объектов недвижимости документами «Регистрация параметров объектов недвижимости».

Вид договора определяется по документу «Договор по недвижимости». Если договор расторгнут, т.е. зарегистрирован документ «Расторжение сделки по недвижимости», то считаем, что заключенных договоров нет.

Если по объекту недвижимости заключенных договоров нет, то тогда в зависимости от реквизита карточки объекта недвижимости «Тип недвижимости» заполняются следующие колонки табличной части:

  • Площадь собственных жилых помещений – заполняется по тем объектам недвижимости, у которых тип недвижимости «жилая»;
  • Площадь собственных нежилых помещений - заполняется по тем объектам недвижимости, у которых тип недвижимости «коммерческая»;
  • Площадь собственных машиномест - заполняется по тем объектам недвижимости, у которых тип недвижимости «гараж машиноместо».

Если по объекту недвижимости есть заключенные договоры, то в зависимости от вида договора (ДДУ или ИНВЕСТ), а также типа объекта недвижимости заполняются соответствующие колонки табличной части. Если вид договора по объекту недвижимости «Договор купли-продажи», то данные по площадям в табличную часть не заполняются.
