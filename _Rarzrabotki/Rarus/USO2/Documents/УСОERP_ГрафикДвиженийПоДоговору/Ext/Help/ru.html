График движений по договору

Документ График движений по договору предназначен для ввода и хранения информации о планируемых событиях по договору. Данные этого графика могут являться основанием для формирования прогнозных бюджетов, контроля исполнения обязательств по договору.

На форме элемента вводятся следующие данные: дата, Объект строительства, статус (который может принимать значения: Не согласован, Действует, Закрыт).

Установка флага Вести расширенный график движений по договору  влияет на состав табличной части «График движения по договору», табличная часть становится более расширенной, отображаются данные по авансу и гарантийным удержаниям.

В табличной части График движения по договор, если флаг не установлен,  указываются следующие данные:

  • Дата - указывается дата события.
  • Вид ДДС - указывается вид движения денежных средств, который может принимать значения:   Аванс, Предоплата, Кредит, Гарантийное удержание.
  • Вид Доход/Расход - указывается вид движения доход или расход, который может принимать значения: Реализация или Поступление затрат.
  • Сумма - указывается сумма движения денежных средств.
  • Статья бюджета - указывается статья бюджета из справочника Статьи бюджетов.
  • Вид работ - указывается вид работ из справочника Виды работ. Поле доступно, если в группе реквизитов договора указано «Формирование движений по договору» «По видам работ» = истина.
  • Работа - указывается работа из справочника Строительные работы.

 

В табличной части График движения по договору, если флаг установлен,  указываются следующие данные:

  • Дата аванса;
  • Сумма аванса;
  • Дата приема работ - дата приемки исполненных работ;
  • Сумма выполненных работ;
  • Дата остатка платежа - дата внесения остатка платежа;
  • Сумма остатка платежа - сумма внесения остатка платежа;
  • Сумма гарантийного удержания;
  • Сумма итого;
  • Дата возврата  гарантийного удержания;
  • Сумма гарантийного удержания.

 

По кнопке Заполнить происходит автозаполнение табличной части работами/видами работ на основании документов Договор с Заказчиком или Договор с Субподрядчиком, если соответствующий договор указан в данных документах.

 

По кнопке Рассчитать график движений происходит расчет графика исполнения/оплат. Табличная часть заполняется автоматически, исходя из данных о сроках работ и стоимости работ.
