Установка параметров учета по строительству

Документ предназначен для ввода учетной политики организации в части правил распределения НДС и затрат применительно к организациям, которые занимаются долевым строительством.

Документ создается по каждой организации в отдельности один раз и по мере изменений в учетной политике по распределению НДС создаются новые документы от новой даты.

На закладке Основное документа расположены поля:

  • Номер - номер документа;
  • От - дата документа;
  • Организация - организация, которая осуществляет строительство;
  • Ответственный – сотрудник, ответственный за регистрацию документа в системе;
  • Комментарий – текстовое поле.

На вкладке Распределение НДС необходимо установить правила распределение НДС для тех счетов затрат, НДС по которым будет распределяться отлично от типового механизма системы (согласно выручке по облагаемой и необлагаемой деятельности).

Табличные части документа заполняются вручную. Заполняются следующие реквизиты:

  • Счет затрат – к какому счету затрат относится входящий НДС (20.01. 20.02, 44, 08.33).
  • Правило распределения НДС – выбирается элемент справочника «Правила распределения НДС».
  • Только по введенным объектам - данный признак отвечает за момент времени, в которой будет происходить распределение НДС по выбранному счету. Если признак стоит в значении «Истина», тогда НДС по объектам выбранного счета затрат будет распределяться с момент сдачи объекта (счета 08.33), иначе ежемесячно (20.02, 44).
  • Восстановление НДС при сдаче объекта строительства – данный признак отвечает за восстановление НДС, в случае если ранее распределенный по плановым площадям НДС относящийся к облагаемой деятельности оказался больше рассчитанного по фактическим площадям НДС относящийся к облагаемой деятельности.
  • Счет списания НДС и затрат - счет списания НДС в случае необлагаемой деятельности. Если счет списания НДС совпадает со счетам затрат, то поле не заполняется (20.01, 20.02, 08.33), в противном случае выбирается отличный счет затрат со статьей затрат, относящейся к данному счету, на который будет отнесен НДС по необлагаемой деятельности (например, 20.07.1 на 08.33, 20.07.2 на 20.02, 20.07.3 на 91.02). В справочнике Статьи расходов имеется возможность создать специальные статьи расходов: «НДС по комплексным расходам счета 20.07.1» и т.д..
  • Счет списания НДС по необл. деятельности для введенных объектов - счет отнесения НДС по необлагаемой деятельности по тем объектам, которые уже сданы в эксплуатацию. Причем счет указывается как для объектов, которые были введены в текущем году (90.02.1), так и для объектов, которые были введены в предыдущих годах (91.20).
