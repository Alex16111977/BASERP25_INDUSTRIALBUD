Документ  используется для распределения по долям и передачи инвестору «входного» НДС, учтенного в организации - заказчике строительства  на отдельном счете 19.08.  Оформляется на основании документа «Сдача объекта недвижимости в эксплуатацию». Документу «Формирование сводных счетов-фактур для дольщиков» должен предшествовать документ «Распределение НДС» с отражением информации по накопленному НДС, т.к. при автоматическом заполнении анализируются остатки по регистру накопления «НДС инвестиционный» по указанному в шапке документа объекту строительства.

Документ имеет 3 закладки: «Инвестиционный НДС», «Передача инвестору», «Принятие к учету».

При вводе на основании вкладка «Основное» автоматически заполняется данными из документа "Сдача объекта недвижимости в эксплуатацию".

Закладка «Инвестиционный НДС» предназначена для полей, в которых указывается накопленный инвестиционный НДС, который не был включен в стоимость объекта строительства.

Закладка "Инвестиционный НДС" может быть заполнена вручную или автоматически, с помощью обработок "Заполнить - Пропорционально фактической площади" и "Заполнить - Пропорционально сумме затрат".

Закладки «Передача инвестору» и «Принятие к учету» заполняются с помощью обработок "Распределить - По фактической площади" или "Распределить - По сумме затрат". При распределении сумма накопленного инвестиционного НДС увеличивает стоимость доли объекта недвижимости, которая первоначально была сформирована в документе "Сдача объекта недвижимости в эксплуатацию".  В зависимости от вида помещения (жилое или нежилое) устанавливаются  различные счета учета НДС.  Для нежилых помещений НДС подлежит принятию к вычету, поэтому для таких долей счет учета НДС устанавливается по данным, хранящимся в  РН «НДС предъявленный». Для жилых помещений НДС подлежит включению в стоимость, поэтому для таких долей  счет учета НДС устанавливается 43 «Готовая продукция».

Для того, чтобы сформировать сводные счет-фактуры дольщикам необходимо нажать на кнопку "Создать счет-фактуры" на вкладке «Принятие к учету».

Из документа по каждому договору ДДУ/ИД можно вывести "Реестр счетов-фактур полученных" нажав на кнопку "Реестр счетов-фактур полученных".
