Учет работы сотрудников и техники

Документ Учет работы сотрудников и техники предназначен для учета фактически отработанного времени сотрудников и техники в разрезе работ.

На форме элемента вводятся следующие данные:     

  • Организация - организация, которая ведет строительство.
  •  Подразделение - подразделение, которое выполняет работу.
  • Объект строительства.
  • Период  работ С..  По - период выполнения работ по строительству объекта.

 

На закладке Группа табель содержатся сведения:

  • Работа / ресурс - работа или ресурс из справочников Строительные работы либо Ресурсы.
  • Объем работ - объем работы строительства или ресурса.
  • Состав - состав работ из справочника Состав ресурсов.
  • Должность / Тип машин и механизмов - должность или тип машин и механизмов.
  • Сотрудник / Основное средство - исполнитель работы или основное средство.
  • Количество часов 1, 2, 3, 4. 5, 6, 7 - количество часов, фактически отработанных.

 

По кнопке Заполнить табличная часть «Табель» заполняется работами, ресурсами и исполнителями.

 

По кнопке Новая строка добавляется новая строка к текущей работе или ресурсу для выбора ресурса или исполнителя. Если реквизит проекта «Отражать факт работы водителей и техники путевыми листами» = Истина, то заполняются только исполнителями-рабочими. При добавлении ресурсов должны заполниться исполнители, исходя из заполненных табличных частей справочника «Ресурсы».

 

По кнопке Разбить строку (только для строк с ресурсами и исполнителями) имеется возможность указать исполнителей.

 

По строке-гиперссылке Сводная информация о работе ресурсов (скрыть / показать) открывается табличная часть «Табель сводно». По умолчанию табличная часть не отображается.

 

Табличная часть Табель сводно предусмотрена в 2-х вариантах: «По исполнителям» (присутствуют  исполнители работ и количество отработанных часов сводно по табличной части «Табель») и «По ресурсам» (присутствуют ресурсы и количество отработанных часов сводно по табличной части «Табель»).
