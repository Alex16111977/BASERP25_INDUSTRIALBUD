Документ "Регистрация условий продажи объектов"

Документ позволяет зарегистрировать в информационной системе данные по условиям продаж по объекту недвижимости. При этом если производится корректировка существующих данных по объекту недвижимости, то достаточно зарегистрировать только изменения (внести изменения в табличную часть документа) по отношению к предыдущим данным.
