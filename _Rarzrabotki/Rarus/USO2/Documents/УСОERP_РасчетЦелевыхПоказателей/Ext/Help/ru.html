Расчет целевых показателей

Документ Расчет целевых показателей предназначен для расчета значений по заданным формулам, их дальнейшего использования и анализа в подсистеме бюджетирования.

В документе указываются следующие данные:

  • Проект / портфель проектов - указывается проект либо портфель проектов из справочников Объекты строительства либо Портфель проектов.
  • Сценарий - указывается сценарий из справочника Сценарии.
  • Вид бюджета - указывается вид бюджета из справочника Экземпляры бюджетов.
  • Начало - указывается дата начала проекта.
  • Окончание - указывается дата окончания проекта.
  • Периодичность -  указывается период проекта.
  • Показатель чистого денежного потока - указывается плановые или фактические данные денежного потока для расчета показателей.

 

На закладке Параметры и показатели в табличной части Параметры отображаются данные:

  • Показатель - указывается целевой показатель из справочника Целевые показатели и параметры.
  • Значение - указывается значение показателя.

На закладке Параметры и показатели в табличной части Показатели отображаются данные:

  • Показатель - указывается целевой показатель и параметр объекта строительства.
  • Значение - указывается значение показателя.
  • Документ установка значений нефинансовых показателей - указывается для связи целевых показателей с типовой системой бюджетирования.

На закладке Ставка дисконтирования в табличной части Ставки дисконтирования отображаются данные:

  • Дата начала - указывается дата начала действия ставки.
  • Значение - указывается значение ставки дисконтирования.

 

Показатели проекта рассчитываются согласно установленной формуле справочника по кнопке Рассчитать показатели. Расчет осуществляется только для документов, у которых в реквизите Проект / портфель проектов выбран тип – Справочник Проекты. Также показатели можно заполнить вручную. Для документов, у которых тип значения реквизита – Справочник Портфель проекта показатели заполняются вручную в документе.
