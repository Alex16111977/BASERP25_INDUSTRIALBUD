Условия по договору с подрядчиком

Документ Условия по договору с подрядчиком предназначен для хранения  перечня работ, их объемов, сроков выполнения и стоимости, определенной по объекту строительства по договору с подрядчиком.

На форме элемента вводятся следующие данные:

  • Организация - указывается организация, которая ведет строительство.
  • Субподрядчик - указывается субподрядчик из справочника Партнеры.
  • Контрагент.
  • Объект строительства.
  • Договор - указывается договор контрагента, с которым ведется строительство.
  • Номер договора - указывается номер договора с заказчиком.
  • Дата договора - указывается дата договора с заказчиком.
  • Соглашение - указывается соглашение с партнером выбором из справочника Соглашения с поставщиками.
  • Валюта - указывается валюта расчетов по договору.
  • Флаг Использовать понижающий коэффициент - установка флага равно «Истина», означает, что в шапке и табличной части появляется обязательный для заполнения реквизит «Понижающий коэффициент». По умолчанию галочка не стоит.
  • Понижающий коэффициент - указывается коэффициент в числовом значении.

 

На закладке Работы содержатся сведения:

  • Код СДР - код структурной декомпозиции работ.
  • Работа - работа из справочника Строительные работы.
  • Объем - объем работы строительства.
  • Единица объема.
  • Дата начала - начала работы строительства объекта.
  • Дата окончания - окончание работы строительства объекта
  • Длительность - длительность работы строительства.
  • Единица длительности - единица длительности работы строительства.
  • Стоимость Заказчика - стоимость заказчика для работы строительства.
  • Понижающий коэффициент - понижающий коэффициент стоимости работы строительства.
  • Стоимость выполнения с НДС - стоимость работы строительства с НДС, по которой эту работу будет выполнять Субподрядчик.
  • Ставка НДС.
  • Сумма НДС.

 

По кнопке Заполнить в табличную часть автоматически попадают все работы, относимые к объекту строительства.

 

По кнопке Подбор открываться форма выбора работ, с отбором по объекту строительства (при выборе этапа, заполняются все работы, относящиеся к этапу).
