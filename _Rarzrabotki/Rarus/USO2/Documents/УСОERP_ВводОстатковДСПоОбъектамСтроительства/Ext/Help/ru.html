Ввод остатков денежных средств по объектам строительства

Документ предназначен для учета денежных средств по объектам строительства, их ввода на первоначальную дату и корректировки остатков по статьям движений денежных средств. Для каждой организации необходимо оформить отдельный документ ввода остатков.

Ввод остатков происходит одновременно по управленческому и регламентированному учету. 

Принадлежность денежных средств определяется по корреспонденции поступления и списания денежных средств по объектам строительства. Данный способ удобен для организаций, которые не могут явно разделить расчетные счета и кассы.

Разделение денежных средств по объектам строительства происходит виртуально, без реальных движений и перебросок между расчетными счетами и кассами. Денежные средства по объектам не делятся на наличные и безналичные и по кассам и счетам. Деньги могут поступать на один расчетный счет по объектам строительства, а тратиться из другого расчетного счета или кассы по объектам строительства.

В программе осуществляется ввод начальных остатков по статьям движений денежных средств. Данная процедура предназначена для тех операций, для которых в конфигурации нет автоматизированного учета. Дополнительный учет данных статей позволит получить в дальнейшем корректный остаток денежных средств на текущий день в отчете Прогноз платежей по объектам строительства.
