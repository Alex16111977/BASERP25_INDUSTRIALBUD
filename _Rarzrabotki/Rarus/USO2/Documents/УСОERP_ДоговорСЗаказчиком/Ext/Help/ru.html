Условия по договору с Заказчиком

Документ Условия по договору с Заказчиком предназначен для хранения перечня работ, их объемов, сроков выполнения и стоимости, определенной по объекту строительства по договору с Заказчиком.

На форме элемента вводятся следующие данные: 

  • Организация - указывается организация, которая ведет строительство.
  •  Заказчик - указывается заказчик из справочника Партнеры.
  • Контрагент.
  • Объект строительства.
  • Договор - указывается договор контрагента, с которым ведется строительство.
  • Номер договора - указывается номер договора с заказчиком.
  • Дата договора - указывается дата договора с заказчиком.
  • Соглашение - указывается соглашение с партнером выбором из справочника Соглашения с клиентами.
  • Валюта - указывается валюта расчетов по договору.

 

На закладке Работы содержатся сведения:

  • Код СДР - указывается код структурной декомпозиции работ.
  • Работа - указывается работа из справочника Строительные работы.
  • Объем - указывается объем работы строительства.
  • Единица объема.
  • Дата начала - указывается начала работы строительства объекта.
  • Дата окончания - указывается окончание работы строительства объекта
  • Длительность - указывается длительность работы строительства.
  • Единица длительности - указывается единица длительности работы строительства.
  • Стоимость с НДС - указывается стоимость работы строительства с НДС.
  • Ставка НДС.
  • Сумма НДС.

 

По кнопке Заполнить в табличную часть автоматически попадают все работы, относимые к объекту строительства.

 

По кнопке Подбор открываться форма выбора работ, с отбором по объекту строительства (при выборе этапа, заполняются все работы, относящиеся к этапу).
