Документ включает договора строительного подряда, по которым ведется учет в соответствии с ПБУ 2/2008.
По договорам, включенным в реестр будет заполняться документ "Определение меры готовности по договору подряда".
Документ заполняется автоматически по договорам, в дополнительных параметрах  которых установлен флаг "Применение ПБУ 2/2008".
