Документ предназначен для выделения на отдельном субсчете 19.30 "Инвестиционный НДС" сумм НДС, связанных со строительством объектов долевой собственности. Субсчет, на котором будет учитываться Инвестиционый НДС, указывается в регистре сведений "Учетная политика по долевому строительству" и может быть изменен вручную. В документе можно отразить «Накопление инвестиционного НДС по СМР», «Накопление инвестиционного НДС по материалам», «Включение инвестиционного НДС в стоимость объекта».  Документ является регламентным и формируется ежемесячно перед документом «Формирование записей книги покупок».

Операция «Накопление инвестиционного НДС по СМР» используется в том случае, когда требуется выделить в бухгалтерском учете суммы «входного» НДС, предъявленные подрядчиками по выполненным СМР и относящиеся к объекту строительства,  для дальнейшей их передачи инвестору.

При проведении документа формируются  движения вида «приход» по регистру накопления «НДС Инвестиционный», сторнировочные записи по регистру накопления "НДС Покупки" через документы "Запись книги покупок", движения регистра бухгалтерии вида Дт 19.30 Кт 19.04.

Операция «Накопление инвестиционного НДС по материалам» используется в том случае, когда требуется выделить в бухгалтерском учете суммы «входного» НДС по списанным на строительство объекта ТМЦ для дальнейшей передачи их инвестору.  

При проведении документа формируются  движения вида «приход» по регистру накопления «НДС Инвестиционный», сторнировочные записи по регистру накопления "НДС Покупки" через документы "Запись книги покупок", движения регистра бухгалтерии вида Дт 19.30 Кт 19.03.

Операция «Включение инвестиционного НДС в стоимость объекта строительства»  используется в том случае, когда требуется включить в стоимость передаваемого инвестору объекта строительства суммы НДС от подрядчиков и прочих поставщиков.  При автоматическом заполнении документа анализируются данные РН «Инвестиционный НДС» по указанному в шапке объекту строительства. 

При проведении документа формируются   движения вида «расход» по регистру накопления «НДС инвестиционный», движения регистра  бухгалтерии вида Дт 08.03 Кт 19.30.
