Заказ на доставку

Документ Заказ на доставку предназначен для ввода, хранения и отслеживания информации об адресах доставки материалов, перевозчиках в разрезе Заказов поставщикам.

В документе указывается статус заказа на перевозку, который может принимать значение:

  • Подготовлен;
  • Согласован;
  • В работе;
  • Завершен;
  • Отменен.

 

Указывается вид операции, которая может принимать значение:

  • Собственными силами;
  • Сторонний перевозчик;
  • Поставщик.

 

В документе также указывается такая информация, как: 

  • Срок доставки - указывается срок доставки материалов.
  • ПеревозчикПартнер - указывается перевозчик из справочника Партнеры.
  • Перевозчик - указывается перевозчик из справочника Контрагенты.
  • Адрес отправления -  указывается адрес отправления заказа.
  • Адрес доставки -  указывается адрес доставки заказа.
  • Склад доставки - указывается склад доставки из справочника Склады.
  • ПеревозчикДоговор - указывается договор перевозки заказа.
  • Склад доставки - указывается склад доставки из справочника Склады.
  • Вид доставки - указывается вид доставки, который может принимать значение (Авиа, Авто, Ж/д, Море).
  • Валюта - указывается валюта заказа.
  • Сумма документа - указывается сумма заказа по документу.
  • Цена включает НДС - указывается стоимость с НДС.
  • Валюта взаиморасчетов - указывается валюта взаиморасчетов.
  • Налогообложение НДС - указывается налогообложение НДС.

 

В табличной части К доставке отображаются данные:

  • Заказ поставщику - указывается документ Заказ поставщику.
  • Номенклатура - указывается материал из справочника Номенклатура.
  • Характеристика - указывается характеристика материала из справочника Характеристики номенклатуры.
  • Единица измерения - указывается единица измерения;
  • Количество - указывается количество материала.
  • Вес - указывается вес материала.

 

На закладке К доставке  выводятся данные табличной части «К доставке». Табличная часть недоступна для редактирования, пользователь может только удалять строки из данной табличной части.

 

В табличной части Затраты отображаются данные по затратам, необходимым для доставки материала по указанному адресу:

  • Содержание - указывается содержание затрат.
  • Статья расходов - указывается статья расходов на перевозку. Для выбора доступна номенклатура с типом = «Услуга».
  • Цена - указывается цена затрат.
  •  Количество - указывается количество затрат.
  • Сумма - указывается сумма затрат.
  • Ставка НДС - указывается ставка НДС.
  • Сумма НДС - указывается сумма НДС.
  • Сумма с НДС - указывается сумма затрат.

 

Документ  является основанием для:

·         документа Поступление услуг и прочих активов с видом операции «Сторонней организацией» и статусами «Подготовлен», «В работе»;

·         документа Задание на перевозку с видом операции «Собственными силами» и статусами «Подготовлен», «В работе».
