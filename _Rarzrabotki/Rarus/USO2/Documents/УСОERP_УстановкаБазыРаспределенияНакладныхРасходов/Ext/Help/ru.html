Установка базы распределения накладных расходов

Документ Установка базы распределения накладных расходов предназначен для определения перечня объектов строительства, на которые будут распределяться затраты счета 20.01, 20.02, учтенные по направлению деятельности с признаком «Распределяемые расходы».

В верхней части документа расположены поля:

  • Организация – наша организация, для которой задается распределение;
  • Направление деятельности – распределяемое (общее) направление деятельности, по которому необходимо задать базу распределения;
  • Счет затрат – счет затрат, к которому относится распределяемое (общее) направление деятельности. По каждому счету затрат должно быть свое распределяемое направление деятельности.

              В табличной части База распределения отображаются следующие данные:

  • Направление деятельности – по наименованию совпадает с объектом строительства, который входит в базу распределения;
  • Параметр распределения – процент распределения или площадь объекта строительства, совпадающего с выбранным направление деятельности.

По кнопке Заполнить – По данным строительства объектов можно автоматически заполнить табличную часть документа перечнем направлений деятельности по остаткам счета 08.33 регистра бухгалтерии «Хозрасчетный» (остаток берется в разрезе объектов эксплуатации, из которых можно получить основное Направление деятельности). Если среди выборки имеются Направления деятельности с признаком «Распределяемые затраты», то они исключаются.

 

В качестве параметра распределения в табличной части по выбранным направлениям деятельности заполняются данные:

1)     по объекту недвижимости, в карточке которого указано выбранное Направление деятельности, причем категория объекта недвижимости должна быть «Здание»;

2)     на основании документов «Регистрация параметров объектов недвижимости» на дату заполнения по выбранному в п.1 Объекту недвижимости определяется общая площадь.

По кнопке Заполнить - Параметр распределения по данным площадей можно автоматически заполнить параметр распределения по выбранным направлениям деятельности данными исходя из данных по площадям объектов строительства.
