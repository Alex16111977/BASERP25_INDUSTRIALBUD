Реализация строительных работ (КС-2 внутренняя)

Документ Реализация строительных работ (КС-2 внутренняя) предназначен для принятия работ внутренним контролем службы главного инженера.

На форме элемента вводятся следующие данные:     

  • Организация - организация, которая ведет строительство.
  • Заказчик - заказчик из справочника «Партнеры».
  • Контрагент - поставщик строительства из справочника «Контрагенты».
  • Договор - договор контрагента, с которым ведется строительство.
  • Соглашение - соглашение с партнером выбором из справочника «Соглашения с клиентами».
  • Объект строительства - объект строительства.

 

На закладке Работы содержатся сведения:

  • Код СДР - код структурной декомпозиции работ.
  • Работа - работа из справочника Строительные работы.
  • План по работе - объем работ по плану:
  • Объем - общий объем работы строительства.
  • Единица объема - единица объема.
  • Стоимость с НДС - общая стоимость работ с НДС.
  • Выполнено (всего) - % фактически выполненной работы:
  • Объем - объем выполнения работы строительства.
  • % - % выполнения работы строительства.
  • Стоимость с НДС - стоимость работ с НДС.
  • Принято (всего) - объем принятой работы:
  • Объем - объем принятой работы строительства.
  • % - % принятой работы строительства.
  • Стоимость с НДС - стоимость работ с НДС.
  • Данные к приему - данные по работе строительства к приему:
  • Объем - объем принятой работы строительства.
  • % - % принятой работы строительства.
  • Стоимость с НДС - стоимость работ с НДС.
  • НДС - отображается ставка НДС.
  • Сумма НДС - отображается сумма НДС.

 

На закладке Выполнено всего содержатся сведения об услугах:

  •  Номенклатура - номенклатура работы строительства.
  • Характеристика - характеристика номенклатуры работы строительства.
  • Номенклатурная группа - номенклатурная группа работы строительства.
  • Количество упаковок - количество номенклатур.
  • Упаковка - единица измерения номенклатуры.
  • Цена - цена за номенклатуру.
  • Сумма - стоимость строительных работ.
  • Ставка НДС.
  • Сумма НДС.

 

По кнопке Заполнить заполняется табличная часть «Работы». Работы заполняются иерархически, из регистра «Учет выполнения работ» - реквизиты % выполнения и Объем выполнения рассчитываются за период (Реквизиты % реализации и Объем реализации).

 

По кнопке Подбор отображается форма выбора справочника Строительные работы, с возможностью множественного выбора, причем если выбран этап работ, то в документ должны заполниться все работы этапа.

 

По кнопке Заполнить на закладке «Выполнено всего» заполняется табличная часть услугами по строительной работе.

 

В документе имеются печатные формы КС-2 и КС-3.
