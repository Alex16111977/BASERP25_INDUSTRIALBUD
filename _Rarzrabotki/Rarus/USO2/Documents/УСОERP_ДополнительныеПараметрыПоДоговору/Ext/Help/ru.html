Дополнительные параметры по договору

Документ Дополнительные параметры по договору предназначен для ввода дополнительных параметров по договору и хранения дополнительных значений реквизитов договора, необходимых для УСО 2.0.

Договоры используются для дополнительной детализации взаиморасчетов с клиентами и поставщиками. Договор заключается между контрагентом и организацией предприятия. В договоре определяются условия ведения расчетов по договору: валюта, порядок расчетов, порядок оплаты. Предусмотрены различные варианты расчетов по договору: в целом по договору и с детализацией по заказам или накладным.

 Документ содержит учетные характеристики договора: 

 «Объект строительства» - указывается объект строительства по договору.

  • Сумма договора;
  • Сумма НДС;
  • Сумма без НДС.

 

Установка флага Договор строительного подряда означает признак строительного договора.

Установка флага Применение ПБУ 2/2008 означает принадлежность договора в соответствии с ПБУ.

Установка флага Дополнительное соглашение означает доп. реквизит в режиме предприятия. Договор является дополнительным соглашением.

 

Договор-родитель - указывается основной договор с контрагентом.

 

Группа реквизитов Гарантийные удержания  доступна, если установлена функциональная опция «Использовать гарантийные удержания». В группе «Гарантийные удержания» указываются следующие данные:

  • Флаг Предусмотрены гарантийные удержания по договору - установка флага означает, что имеются гарантийные удержания по договору.
  • % гарантийных удержаний;
  • Срок гарантийного удержания;
  • Статья финансового учета - указывается статья финансового учета из справочника Группы финансового учета расчетов.

 

В группе Бюджетирование указываются следующие данные из справочника Статьи бюджетов:

  • Статья бюджета БДР;
  • Статья БДДС авансового платежа;
  • Статья БДДС основного платежа;
  • Статья БДДС гарантийного удержания.

 

В группе Формирование графика движений по договору указываются следующие данные:

  • Флаг По работам - установка флага означает, что договор ведется по работам.
  • Флаг Учитывать процент гарантийных удержаний по работам - установка флага означает, что отображается табличная часть «Процент гарантийных удержаний по работам».
  • Флаг По видам работ - установка флага означает, что договор ведется по видам работ.
  • Флаг Учитывать процент гарантийных удержаний по работам - установка флага означает, что отображается табличная часть «Процент гарантийных удержаний по видам работ».

 

Табличная часть Процент гарантийных удержаний по работам  заполняется по работам указанного в договоре объекта строительства. В табличной части отображаются данные:

  • Работа - указывается работа из справочника Строительные работы.
  • Значение процента гарантийного удержания;
  • Срок (дн.) гарантийного удержания.

 

Табличная часть Процент гарантийных удержаний по видам работ  заполняется по видам работ указанного в договоре объекта строительства (виды работ утвержденного плана-графика) либо вручную. В табличной части отображаются данные:

  • Вид работы - указывается вид работы из справочника Виды работ.
  • Значение процента гарантийного удержания;
  • Срок (дн.) гарантийного удержания.

 

По кнопке Связанные договора открывается отчет Связанные договоры.
