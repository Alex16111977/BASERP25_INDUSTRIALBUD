Распределение по аналитике графика договора

Документ Распределение по аналитике графика договора предназначен для распределения фактических данных оперативного учета в разрезе аналитики, в которой ведется договор: работа/виды работ.

На форме элемента вводятся следующие данные:

  • Документ-основание - указывается ссылка на документ-основание, на основании которого вводится данный документ.
  • Организация;
  • Контрагент - указывается контрагент строительства из справочника Контрагенты.
  • Договор - указывается договор строительства из справочника Договоры контрагентов.
  • Партнер - указывается партнер строительства из справочника Партнеры.
  • Соглашение - указывается соглашение к договору строительства из справочника Соглашения с клиентами или Соглашения с поставщиками.

 

Табличная часть Распределение по аналитике договора заполняется вручную. Для выбора должны предоставляться утвержденные работы по объекту строительства. В табличной части отображаются данные:

  • Вид работы - указывается вид работы из справочника Виды работ.
  • Работа - указывается работа из справочника Строительные работы.
  • Порядок расчетов - указывается порядок расчетов. Перечисление для порядка расчетов выбирается в зависимости от вида договора (с клиентом/поставщиком). Использование перечислений зависит от вида документа-основания. Порядок расчетов используется для документов движения денежных средств.
  •  ПорядокДоховРасходов - указывается порядок доход или расходов, которое может принимать значение:  Поступления или  Реализация.
  • Сумма - указывается сумма по договору.
  • Статья движения денежных средств - указывается статья ДДС из справочника Статьи движения денежных средств.
  • Статья бюджета - указывается статья бюджета из справочника Статьи бюджетов.

 

По кнопке Заполнить по аналитике графика договора табличная часть автоматически заполняется значениями аналитики Графика движений по договору, пользователь впоследствии указывает суммы по строкам табличной части.
