Документ предназначен для определения на объекте строительства:

- исполнителя работ: подразделение из структуры предприятия или субподрядная организация;

- количества материалов для закупки;

- перечня и количества трудовых ресурсов и техники для выполнения работ.

Документ заполняется для выбранного Объекта строительства.

Табличная часть закладки "Работы" автоматически заполняется работами, утвержденными во внутреннем плане производства работ. Для каждой работы указывается исполнитель: подразделение или контрагент и объем выполняемых работ.

Табличная часть закладки "Материалы" автоматически заполняется материалами, которые требуются для выполнения утвержденного плана производства работ. Для каждой номенклатуры указывается количество собственное - объем потребности для поставки материалов или количество, передаваемое для закупки субподрядной организации. В последствии, документ "План потребности в материалах" может быть сформирован по сводной потребности или с учетом данных разделительной ведомости, т.е. в него попадет перечень номенклатуры и количество собственной поставки.

Табличная часть закладки "Ресурсы" автоматически заполняется ресурсами, которые требуются для выполнения утвержденного плана производства работ. Для каждого ресурса указывается количество собственное - потребность в собственных ресурсах и количество, требуемое в собподрядной организации для выполнения переданных им работ.
