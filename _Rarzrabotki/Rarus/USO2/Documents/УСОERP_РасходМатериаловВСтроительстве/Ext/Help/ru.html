Расход материалов в строительстве

Документ Расход материалов в строительстве предназначен для списания материалов с объекта строительства в разрезе работ.

На форме элемента вводятся следующие данные:

  •  Организация - организация, которая ведет строительство.
  • Вид операции - вид операции расхода материалов в строительстве. Может принимать значения «Собственные материалы» и «Переданные субподрядчику». В зависимости от вида операции отображаются различные поля документа.
  •  Субподрядчик - субподрядчик из справочника Партнеры.
  • Контрагент - поставщик строительства из справочника Контрагенты.
  • Договор - договор контрагента, с которым ведется строительство.
  • Соглашение»- соглашение с партнером выбором из справочника Соглашения с поставщиками.
  • Подразделение - подразделение, которое выполняет работу.
  • Объект строительства.
  • Период  работ С..  По - период выполнения работ по строительству объекта.
  • Склад - склад, с которого списываются материалы.

 

На закладке Материалы содержатся сведения:

  • Код СДР - код структурной декомпозиции работ.
  • Работа - работа из справочника Строительные работы.
  • Объем - объем работы строительства.
  • Единица объема.
  • Материалы - материалы, используемые в строительстве. Выбор из справочника Номенклатура.
  • Характеристика - характеристика номенклатуры.
  • Упаковка, Ед. изм. - единица измерения номенклатуры.
  • Количество - количество материалов, расходуемых в строительстве.

 

По кнопке Заполнить заполняется табличная часть «Работы» работами и материалами.

 

По кнопке Новая строка добавляется новая строка к текущей работе для выбора материала для расхода.

 

По кнопке Разбить строку (только для строк с материалами) имеется возможность указать количество материалов.

 

По кнопке Подбор материалов по остаткам отображается табличная часть с реквизитами: колонка с флажками, материал, характеристика, количество остатка, количество.

 

По строке-гиперссылке Подробная информация об остатках (показать/скрыть) открывается виртуальная таблица «Материалы сводно», в которой отображаются свернуто материалы из табличной части «Материалы». В реквизит «Остаток» заполняются данные остатков на дату окончания работ, с отбором по складу или по контрагенту соответственно. По умолчанию табличная часть не отображается.
