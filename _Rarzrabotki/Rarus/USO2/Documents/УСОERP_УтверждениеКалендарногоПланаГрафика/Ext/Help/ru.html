Внутренний план производства работ 

Документ Внутренний план производства работ предназначен для утверждения календарного плана-графика на определенную дату версии. План используется во всех учетных документах.  

На форме элемента вводятся следующие данные:

  • Дата версии плана - указывается дата, на которую собираются данные плана.
  • Объект строительства - указывается объект строительства.
  • Статус - указывается статус согласования, который может принимать значение «Согласован», «Не согласован».

 

По кнопке Отобразить план-график формируется отчет Объемно календарный план график с потребностями в материалах и ресурсах на дату «Дата версии плана» по «Объекту строительства» по рабочему сценарию.
