Документ «Сдача объекта недвижимости в эксплуатацию» предназначен для отражения принятия законченного объекта строительства к управленческому, бухгалтерскому и налоговому учету.

Сдача объекта недвижимости в эксплуатацию означает, что формирование стоимости объекта закончено, и себестоимость объекта подлежит распределению по долям.

Ввод объекта строительства в эксплуатацию оформляется последним числом месяца после проведения всех регламентных операций бизнес-процесса «Закрытие месяца».

Закладка Основное предназначена для отображения основных параметров по объекту строительства.

На закладке Общее необходимо выбрать «Объект строительства», сдача которого осуществляется, и нажать на кнопку «Заполнить» для автоматического заполнения табличной части «Направления деятельности» всеми затратами по выбранному объекту эксплуатации.

На закладке Общее документа в верхней табличной части указываются:

  • Направление деятельности – направление деятельности, по которому были отражены затраты по счету 08.33 по выбранному «Объекту эксплуатации».
  • Сумма к распределению БУ – сумма затрат в БУ, накопившихся на счете 08.33 по выбранному Объекту эксплуатации и Направлению деятельности.
  • Сумма к распределению НУ – сумма затрат в НУ, накопившихся на счете 08.33 по выбранному Объекту эксплуатации и Направлению деятельности.
  • Сумма к распределению ВР – сумма затрат ВР, накопившихся на счете 08.33 по выбранному Объекту эксплуатации и Направлению деятельности.
  • Сумма к распределению ПР – сумма затрат ПР, накопившихся на счете 08.33 по выбранному Объекту эксплуатации и Направлению деятельности.
  • Сумма инвестиционного НДС – сумма НДС, относящаяся на счета затрат 08.33 и 20.07.1 в части необлагаемой деятельности по выбранному Объекту эксплуатации и Направлению деятельности.
  • Способ распределения – способ распределения затрат на объекты недвижимости в зависимости от их типа. Также может быть задан в карточке направления деятельности. В этом случае при заполнении он автоматически подставится из карточки. В противном случае необходимо заполнить его вручную. Перечень возможных вариантов распределения ограничен предопределенными значениями: на все объекты недвижимости, на жилые помещения, на нежилые помещения, на паркинг, на жилые и нежилые помещения, на жилые помещения и паркинг, на нежилые помещения и паркинг.

 

Нижняя табличная часть «Детализация по направлениям деятельности» заполняется одновременно с верхней табличной частью «Направления деятельности» и содержит информацию по статьям затрат, из которых сложилась сумма в верхней табличной части.

По кнопке Заполнить в табличную часть попадает информация в разрезе долей объекта недвижимости по выбранному на закладке Общее объекту строительства. В карточке элемента объекта недвижимости указывается соответствующий объект эксплуатации. Также заполняется табличная часть «Детализация по статьям» по каждой доли.

При заполнении система распределяет все собранные затраты по счету 08.33 по выбранному объекту эксплуатации между объектами недвижимости, входящими в состав объекта эксплуатации, пропорционально фактическим площадям этих объектов недвижимости.

Нижняя табличная часть «Детализация по статьям» заполняется одновременно с верхней табличной частью «Объекты недвижимости» и содержит информацию по статьям затрат, из которых сложилась сумма в верхней табличной части по каждой строке.

По кнопке Распределить происходит распределение полученных значений по долям на две группы (закладки): те доли, по которым не заключены договора ДДУ и ИД и которые станут готовой продукцией перейдут на вкладку «Принятие к учету», другие доли, по котом заключены договора ДДУ и ИД и будут рассчитана Экономия Заказчика-Застройщика перейдут на вкладку «Сдача инвестору».

Закладка Счет-фактуры предназначена для формирования счет-фактур выданных на начисленный НДС по Инвестиционным договорам.

По кнопке Сформировать счет-фактуры автоматически по каждой строке табличной части закладки «Сдача инвестору», в которой рассчитана сумма НДС, будет сформирован документ «Запись книги продаж». В созданном документе также будет ссылка на сформированную «Счет-фактуру выданную».

После окончания заполнения всех табличных частей необходимо провести документ и сформировать проводки в БУ-НУ. В итоге данный документ должен сформировать проводки по закрытию счетов 08.33, 20.01, 86.03, а также по оприходованию готовой продукции на 43 счет.
