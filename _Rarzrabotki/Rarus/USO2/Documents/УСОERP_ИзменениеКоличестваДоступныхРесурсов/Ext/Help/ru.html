Изменение количества доступных ресурсов

Документ предназначен для корректировки доступного количества
имеющихся ресурсов в организации, и утверждения нового
количества ресурсов.

В верхней части документа расположены поля:
■ Номер - номер документа;
■ От - дата документа;

■ Организация - организация, которая осуществляет строительство;

■ Статус – статус документа, который может принимать значения

«Подготовлен», «Согласован», «В работе», «Завершен» и
«Отменен»;
■ Ответственный - сотрудник, ответственный за ввод документа
в систему.
На закладке "Ресурсы" корректируется количество имеющихся
ресурсов в организации.
 
Важно! Поле Организация обязательное для заполнения.

На закладке "Ресурсы"документа в табличной части указываются:
 
■ Ресурс – ресурс, выбирается из справочника «Ресурсы для
выполнения строительных работ»;
■ Подразделение - подразделение, в котором числится ресурс,
выбирается из справочника «Структура предприятия»;
■ Количество – новое количество доступных ресурсов.
На закладке "Комментарий" можно указать произвольный
комментарий.
 
Документ делает движение по регистру накоплений «Доступные ресурсы».
