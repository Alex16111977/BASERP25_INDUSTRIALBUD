План потребностей в материалах

Документ План потребностей в материалах предназначен для фиксирования общего количества материалов для Объекта строительства в разрезе работ и периодов.

В документе указывается вид операции плана потребности, который может принимать значение: «По плану» и «Сверх плана». Если «Операция» = «По плану», то изменять состав строк запрещено, вручную можно указывать склад и распределять количество. Если «Операция» = «Сверх плана», то пользователь может добавлять строки вручную, корректировать количество.

Также указывается периодичность плана, дата начала  и окончания плана потребностей в материалах, объект строительства для плана потребностей в материалах. Указывается статус плана потребности, который принимает значение «На подготовке», «На утверждении» или «Утвержден».

Установка флага Выделять цветом рабочие дни влияет на выделение цветом колонок с рабочими днями дней в дереве потребностей. Флаг доступен для изменения, если «Периодичность» = «День».

На закладке Основные в табличной части Потребности отображаются данные:

  • Работа - указывается работа из справочника «Строительные работы».
  • Материал - указывается работа из справочника «Номенклатура».
  • Характеристика - указывается характеристика материала из справочника «Характеристики номенклатуры».
  • Склад - указывается склад из справочника «Склады и магазины». Для отображения склада в списке требуется, чтобы в складе был указан объект строительства, равный выбранному в документе.
  • Единица измерения - указывается единица измерения материала.
  • Период - указывается период.
  • Количество - указывается количество потребности в материале.

 

На закладке Заказы в табличной части Заказы отображаются данные:

  • Документ основание - отображаются документы Заказ на внутреннее потребление, созданные на основании данного документа План потребностей в материалах.

 

Для табличной части Потребности имеется переключатель Номенклатура/Работа для изменения представления верхнего уровня дерева на форме (номенклатура или работа).

По кнопке Заполнить происходит заполнение табличной части потребностями в материалах. Кнопка доступна, если Операция = «По плану».

По кнопке Отбор при заполнении устанавливаются отборы, которые будут действовать при заполнении табличной части при нажатии на кнопку «Заполнить». Кнопка доступна, если «Операция» = «По плану».

Документ формирует документы Заказ на внутреннее потребление для возможности использования типового механизма обеспечения в блоке «Управление закупками».

У документа имеется печатная форма График обеспечения материалами.
