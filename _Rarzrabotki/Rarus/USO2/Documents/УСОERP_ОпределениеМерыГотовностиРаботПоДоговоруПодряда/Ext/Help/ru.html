Документ «Определение меры готовности работ по договору подряда»

Документ «Определение меры готовности работ по договору подряда» предназначен для определения степени готовности работ по договору подряда способами:
-по доле выполненного объема работ;
-по доле понесенных расходов.
Документ расчетно-аналитический, записей в регистры не формирует, признаков отражения в различных видах учета не имеет.
