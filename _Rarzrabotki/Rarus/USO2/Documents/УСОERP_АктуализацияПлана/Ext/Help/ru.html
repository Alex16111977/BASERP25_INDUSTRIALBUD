Актуализация плана 

Документ предназначен для отображения плана-графика объекта строительства, фактически выполненных работ на дату актуализации и утверждения нового плана-графика для оставшихся невыполненных строительных работ от даты актуализации по оптимальному способу строительства объекта.

Закладка Основное предназначена для отображения основных параметров по объекту строительства для утверждения нового плана-графика для оставшихся невыполненных строительных работ по оптимальному способу строительства:

  • Организация – организация, которая осуществляет выполнение работ по плану производства работ;
  • Объект строительства - объект строительства, выбирается из справочника «Объекты строительства»;
  • Вид операции – вид актуализации плана, который имеет два значения:
  • Перепланирование с учетом факта – актуализация плана-графика строительных работ по объекту с учетом фактически выполненных работ, перенос плана-графика на дату актуализации;
  • Оптимизация графика – оптимизация внутреннего плана производства работ с учетом планируемых свободных ресурсов.
  • Внутренний план производства работ – документ утверждения плана-графика выполнения работ;
  • Дата актуализации – дата, на которую актуализируется внутренний план производства работ;
  • Статус – статус согласования, который может принимать значение «Согласован», «Не согласован»;
  • Ответственный - указывается сотрудник, ответственный за документ в системе.

 

Закладка Диаграмма предназначена для отображения утвержденного календарного плана-графика, фактически выполненных работ, а также установки новых сроков выполнения строительных работ в виде диаграммы Ганта. Перепланирование плана-графика производится при помощи диаграммы.

На закладке Работы отображаются сроки выполнения строительных работ по утвержденному календарному плану-графику, фактические сроки выполненных работ и новые сроки выполнения оставшихся строительных.

На закладке Работы документа в табличной части указываются:

  • Код СДР - код структурной декомпозиции работ (недоступен для редактирования);
  • Работа – работа календарного плана-графика;
  • Объем – объем работы по плану-графику;
  • Ед. объема - единица объема работы;
  • Начало работы – начало выполнения работы по плану-графику;
  • Окончание работы - окончание выполнения работы по плану-графику;
  • Длительность – длительность строительной работы по плану-графику;
  • Ед. длительности – единица длительности выполнения работы;
  • Окончание выполненной работы – фактическая дата выполнения работы внутреннего плана производства работ;
  • Начало работы (план) после пересчета – дата начала невыполненных работ по план-графику после пересчета;
  • Окончание работы (план) после пересчета - дата окончания невыполненных работ по план-графику после пересчета;
  • Длительность после растягивания – новая длительность выполнения строительной работы, после ее растягивания;
  • Тип ограничения – дата ограничения начала строительной работы в случае сдвига работы;
  • Объем работ выполненный – объем фактически выполненных работ;
  • Дата выполнения – дата последнего зарегистрированного в программе документа Учет выполненных работ, в котором указан объем выполнения работы;
  • Длительность после пересчета – оставшаяся длительность работы, разница между плановой и фактически выполненной длительностью работы.

Рассмотрим работу с документов в зависимости от вида операции:

§  Вид операции «Перепланирование с учетом факта»

По кнопке Заполнить на закладке Основное осуществляется заполнение табличной части закладки Работы строительными работами по утвержденному плану-графику выполнения работ данного объекта строительства. На закладке Диаграмма эти работы графически отображены красным цветом.

По кнопке Актуализировать осуществляется сравнение плана-графика работ, фактического выполнения работ и отображение новых сроков по выполнению работ на дату актуализации.

На диаграмме выполненные работы отображены зеленым цветом, где в левой части диаграммы отображены фактически выполненные работы на дату актуализации, а в правой части диаграммы то, что осталось выполнить.

На закладке Работы отобразились данные по новым срокам выполнения работ после пересчета.

Пересчет производится следующим образом: производится анализ календарно-сетевого графика внутреннего плана работ, определяется объем выполненных работ графика и с учетом выполненного объема производится перепланирование работ от даты актуализации с соблюдением связей между работами, указанных во внутреннем плане работ. По оставшимся невыполненным работам внутреннего плана производства работ строится новый график в соответствии со связями работ.

При помощи графического отображения работ на диаграмме изменяем в случае необходимости длительность работ и сроки. Для этого необходимо растянуть/укоротить зеленую полоску отображения работы, либо передвинуть линию по периоду. На закладке Работы сроки и длительность автоматически меняются в соответствии с диаграммой. При изменении работы производится пересчет всего срока графика с учетом новой длительности работы или даты ограничения ее начала.

§  Вид операции «Оптимизация графика»

При данном виде операции отображается новая закладка Оптимизация АСО (по умолчанию она скрыта) по кнопке Настройки. Закладка предназначена для отображения рекомендуемых настроек оптимизации процесса перепланирования план-графика.

На закладке Оптимизация АСО указываются:

■     Параметр – параметр настроек оптимизации процесса перепланирования графика работ;

■     Значение – количество, настройка оптимизации процесса перепланирования графика работ.

Закладка Ресурсы предназначена для отображения всех доступных и учитываемых ресурсов, необходимых для выполнения работ.

В табличной части Учитываемые ресурсы закладки Ресурсы указываются:

■     Ресурс – ресурс, который необходимо учитывать при оптимизации плана-графика;

■     Учитывать при актуализации – при установленном флаге в оптимизации план-графика учитывается данный ресурс.

В табличной части Доступные ресурсы закладки Ресурсы указываются:

■     Ресурс – ресурс, который доступен для выполнения строительных работ;

■     Период – период, в котором рабочий ресурс свободен;

■     Количество – количество доступного ресурса;

■     Организация – организация, у которой доступен данный ресурс;

■     Подразделение – подразделение, в котором учитывается ресурс.

По кнопке Заполнить ресурсы осуществляется заполнение табличной части закладки Ресурсы всеми доступными рабочими ресурсами.

По кнопке Заполнить на закладке Основное осуществляется заполнение табличной части закладки Работы строительными работами по утвержденному плану-графику выполнения работ данного объекта строительства и с учетом фактически выполненного объема работа. На закладке Диаграмма эти работы графически отображены красным и зеленым цветом соответственно.

По кнопке Актуализировать осуществляется автоматическая оптимизация плана-графика с учетом доступных ресурсов для выполнения строительных работ.
