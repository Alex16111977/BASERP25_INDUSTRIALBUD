Документ  предназначен для резервирования рабочего времени сотрудников для выполнения работ на объекте строительства.

В документе в соответствии с внутренним планом производства работ по выбранному объекту строительства и периоду заполняется табличная часть "Состав ресурсов работ" на закладке "Состав ресурсов работ" перечнем работ, которые в соответствии с утвержденным планом выполняются в установленный период.  В табличной части указываются исполнители работ из справочника "Состав ресурсов". Табличная часть "Назнчение исполнителей" заполняется сотрудниками, указанными в выбранном составе ресурса. Далее, указывается, в какие дни какое количество часов сотрудник будет занят, также, эти данные можно заполнить автоматически по кнопке "Заполнить часы по графику".
На закладке "Занятость исполнителей" отражается сводная информация по исполнителям, выполняемым ими работам и количестве часов рабочего времени в разрезе каждой работы.
