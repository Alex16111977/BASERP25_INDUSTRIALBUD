Учет выполненных работ

Документ Учет выполненных работ предназначен для оперативного отражения объемов выполненных работ собственными силами либо силами Субподрядчика. Данные этого документа в последствие будут использованы при формировании КС-2 внутренней (аналог внутренней приемки работ).

На форме элемента вводятся следующие данные: 

  • Организация - организация, которая ведет строительство.
  • Вид операции -  вид операции кем выполнена работа. Может принимать значения «Выполнение собственными силами» или «Выполнение силами субподрядчика». Если вид операции принимает значение «Выполнение силами субподрядчика», то отображаются поля:
  •  Субподрядчик - субподрядчик из справочника Контрагенты.
  • Поставщик - поставщик строительства из справочника Партнеры.
  • Договор - договор контрагента, с которым ведется строительство.
  • Соглашение - соглашение с партнером выбором из справочника Соглашения с поставщиком.
  • Подразделение - подразделение, которое выполняет работу.
  • Объект строительства.
  • Период С..  По - период строительства объекта.

 

На закладке Работы содержатся сведения:

  • Код СДР - код структурной декомпозиции работ.
  • Работа - работа из справочника Строительные работы.
  • Объем - объем работы строительства.
  • Единица объема.
  • Длительность - длительность работы строительства.
  • Единица длительности - единица длительности работы строительства.
  • % выполнения на начало периода - % выполнения работы строительства на начало периода.
  • Объем на начало периода - объем выполнения работы строительства на начало периода.
  • % выполнения - % выполнения работы строительства.
  • Объем - объем выполнения работы строительства.
  • Дата начала - начала работы строительства объекта.
  • Дата окончания - окончание работы строительства объекта.

 

По кнопке-подменю Заполнить и кнопке Заполнить из плана-графика заполняется табличная часть «Работы» документа.
