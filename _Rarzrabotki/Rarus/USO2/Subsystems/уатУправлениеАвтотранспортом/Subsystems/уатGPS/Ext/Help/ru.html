Подсистема "Мониторинг ТС"

Назначение

Предназначена для отслеживания текущего местоположения ТС согласно данным мониторинга, а также учета пробега и расхода топлива по данным датчиков ТС.

Состав

  • Отчеты
    • Данные по ТС (Dynafleet)
    • События по мониторингу
    • История местоположения по мониторингу
    • Текущее местоположение по мониторингу
    • Сравнение заправок по данным учета и мониторинга
    • Сравнение пробега и расхода ГСМ по путевым листам и данным мониторинга
  • Обработки
    • Загрузка данных Dynafleet
    • Загрузка данных Omnicomm
    • Загрузка данных Автотрекер
    • Загрузка данных Wialon
    • Загрузка данных СКАУТ
    • Загрузка данных мониторинга из файла
  • Регистры сведений
    • События по мониторингу
    • Координаты по мониторингу
    • Пробег и расход по мониторингу
  • Регламентные задания
    • Загрузка данных Dynafleet
    • Загрузка данных Omnicomm
