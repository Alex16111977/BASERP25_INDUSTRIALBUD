Цепочка поставок

Отчет Цепочка поставок предназначен для анализа нахождения материала в цепочке поставки.

В отчете отображаются такие данные как склад, объект строительства, подразделение, номенклатура, характеристика номенклатуры.

В отчете участвуют следующие показатели:

  • Количество (по плану);
  • Количество (заказали поставщику);
  • Количество по документу Заказ на доставку;
  • Количество (заказали на склад);
  • Количество (переместили по заказу на перемещение);
  • Количество (в задании на перевозку);
  • Количество (выполнено по заданию на перевозку).
