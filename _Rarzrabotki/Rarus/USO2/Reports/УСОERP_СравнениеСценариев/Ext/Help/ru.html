Отчет предназначен для сравнения сценариев выполнения работ по следующим критериям:
- наименование работы (сортирвка выполняется по коду СДР - структурной декомпозиции работ);
- объем работы, единица измерения объема;
- длительность выполнения работы;
- период выполнения: дата начала и окончания работы;
- работы-предшественники;
- сводное количество материалов на работу (с возможностью расшифровки);
- сводная трудоемкость работы (с возможностью расшифровки);
- сводная машиноемкость работы (с возможностью расшифровки).
 
В настройках отчета выбирается Объект строительства и его сценарии планирования, которые необходимо сравнить.

Для сравнения сроков выполнения работ по сценариям планирвоания отчет может быть выведен в форме диаграммы Ганта. Для наглядного графического отображения необходимо установить флаг Настроить цвета сценариев и выбрать различные цвета для сценариев в табличной части Сценарии.
