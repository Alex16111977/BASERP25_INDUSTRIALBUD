Ошибки расчета калькуляции продукции

Отчет предназначен для выявления ошибок при расчете плановой стоимости продукции.
Отображает:

  • перечень материалов необходимых для производства продукции для которых не установлена плановая цена;
  • трудозатраты, необходимые для производства продукции для которых не установлены расценки.
