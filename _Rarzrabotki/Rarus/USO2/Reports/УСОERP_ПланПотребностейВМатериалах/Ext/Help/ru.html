План потребностей в материалах

Отчет предназначен для анализа плана производства по материалам, необходимым для его исполнения.

В отчете отображены следующие показатели потребности в материалах:

■     Общая потребность

■     Общая потребность по плану;

■     Потребность по периодам, вид планирования Календарный;

■     Потребность по периодам, вид планирования из шапки отчета;

■     План по периодам (по плану);

■     Отклонение по периодам (по плану);

■     План по периодам (по плану + сверх плана);

■     Отклонение по периодам (по плану + сверх плана).
