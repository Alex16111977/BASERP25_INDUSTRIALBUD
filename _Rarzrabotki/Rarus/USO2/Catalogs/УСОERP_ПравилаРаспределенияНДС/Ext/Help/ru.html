Правила распределения НДС

Справочник предназначен для регистрации формул распределения НДС по облагаемой и необлагаемой деятельности.

На форме элемента справочника отображаются две закладки: для не введенных в эксплуатацию объектов, для введенных в эксплуатацию объектов. На обеих закладках указывается алгоритм расчета процента по облагаемой и необлагаемой деятельности:

  • в случае ручного распределения необходимо вручную указать пропорцию по облагаемой и необлагаемой деятельности;
  • в случае автоматического заполнения необходимо заполнить формулы для расчета пропорции по облагаемой и необлагаемой деятельности по кнопке Изменить. При создании формулы необходимо использовать типы площадей из верхней табличной части Параметры распределения и арифметические операторы. По окончанию создания формулы необходимо нажать на кнопку Проверить формулу. В случае отсутствия ошибок необходимо нажать ОК.

Аналогичным образом вводится алгоритм расчета пропорции по введенным объектам, т.е. либо вручную, либо с помощью формулы.
