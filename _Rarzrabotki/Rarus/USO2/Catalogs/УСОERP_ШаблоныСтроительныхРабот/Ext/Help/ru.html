Шаблоны строительных работ

Справочник предназначен для хранения шаблонов строительных работ. Создавать шаблоны можно непосредственно из плана-графика (справочник Строительные работы).

Справочник содержит иерархию групп и элементов строительных работ.

В карточке элемента вводятся следующие данные:

  • Наименование - указывается наименование работы строительства.
  • Код СДР - указывается код структурной декомпозиции работ (недоступен для редактирования).
  • Этап - указывается этап работы строительства из справочника Строительные работы.

 

На закладке Основная отображаются данные:

  • Объем работы - указывается объем работ строительства.
  • Единица объема - указывается единица объема работ строительства.
  • Начало работы План - указывается дата начала работы по плану.
  • Окончание работы План - указывается дата окончания работы по плану.
  • Длительность План - указывается длительность работы строительства по плану.
  • Единица длительности - указывается единица длительности работы строительства.

 

На закладке Дополнительно отображаются данные:

  • Вид работ - указывается вид работ строительства из справочника Виды работ.
  • Статья сводного сметного расчета - указывается статья сводного сметного расчета из справочника Статья сводного сметного расчета.
  • График работы - указывается график работы строительства из справочника Графики работы.
  • Конструктив - указывается конструктив строительства из справочника Конструктив.

 

На закладке Материалы отображаются данные:

  • Материал - указывается материал для строительства из справочника Номенклатура.
  • Характеристика - указывается характеристика материала для строительства из справочника Характеристики номенклатуры.
  • Единица измерения.
  • Количество на единицу объема.

 

На закладке Ресурсы отображаются данные:

Ресурс - указывается ресурс строительства из справочника Ресурсы.

Количество - указывается количество ресурсов.

Загрузка % - указывается процент загрузки ресурсов.

График работы - указывается график работы строительства из справочника Графики работы.
