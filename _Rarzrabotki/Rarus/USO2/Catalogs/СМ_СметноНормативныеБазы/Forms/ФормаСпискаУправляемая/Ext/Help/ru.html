Справочник «Сметно-Нормативные Базы»

Справочник представляет список региональных баз, входящих во внешнюю базу сметных норм и цен.

В справочнике содержатся все данные, характеризующиеся сметно-нормативную базу.

Данные для автоматического заполнения справочника поставляются с внешней  сметно-нормативной базой.

Общие сведения

Форма предназначена для работы со списком сметно-нормативных баз.

Реквизиты:

    • Код - двухсимвольный код нормативной базы
    • Наименование - наименование нормативной базы
    • Уровень базы - уровень базы (федеральный, территориальный, отраслевой и др.)
    • Тип коэффициентов - тип коэффициентов, применяемый для пересчета сметной стоимости в текущий уровень цен
    • Правообладатель - наименование правообладателя (разработчика) сметно-нормативной базы
    • Год выпуска - уровень базисных цен сметно-нормативной базы
    • Версия - версия сметно-нормативной базы

Табличная часть "Районы" содержит список районов, для которых рассчитана нормативная база.  

 

Для обновления нормативно-справочной информации, поставляемой вместе с внешней сметно-нормативной базой, предусмотрена возможность обновления данных (кнопка "Обновить из ВНБ"). При этом по текущей сметно-нормативной базе производится автоматическая загрузка данных в справочники "Территориальные районы", "Единицы измерения сметных ресурсов", "Поправки по техническим частям", "Ресурсы", регистры сведений "Сметные наименования ресурсов", "Сметные цены ресурсов".
