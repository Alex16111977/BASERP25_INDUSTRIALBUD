Шаблоны лимитированных затрат

Справочник  предназначен для задания шаблонов лимитированных затрат. Шаблон представляет собой список лимитированных затрат, который можно использовать  при составлении сметной документации для заполнения табличной части «ЛимитированныеЗатраты» документов «Локальная смета», «Объектная смета», «Сводная смета».

Общие сведения

Форма предназначена для редактирования параметров шаблона.

Реквизиты:

    • Код - код шаблона
    • Наименование - наименование шаблона
