Справочник "Единицы измерения сметных ресурсов"

Справочник предназначен для хранения списка единиц измерения, применяемых при расчете сметной документации в строительстве.

Данные для заполнения справочника поставляются с внешней сметно-нормативной базой . Заполнение справочника производится при установке внешней сметно-нормативной базы.

Справочник может дополняться пользователем при необходимости. Редактировать загруженные из внешней нормативной базы единицы измерения не рекомендуется, т.к. это может привести к искажению сметной информации.

Основные реквизиты

Форма для работы со списком единиц измерения сметной подсистемы.

Реквизиты:

    • Код -  код
    • Наименование - наименование единицы измерения
    • Базовая единица - базовая единица измерения
    • Коэффициент перевода - коэффициент перевода от базовой единицы измерения
    • Код ОКЕИ - код по ОКЕИ (может быть не заполнен)
