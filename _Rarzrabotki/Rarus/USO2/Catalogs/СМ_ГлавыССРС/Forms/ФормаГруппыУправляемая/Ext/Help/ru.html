Справочник «Главы ССРС»

Справочник предназначен для хранения наименований глав сводного сметного расчета. Для сводной сметы существует строго определенная номенклатура глав, в которые собираются затраты на строительство объекта. В соответствии с методическими указаниями набор глав (их количество и описание) при составлении ССР может быть различным для разных типов строительства: промышленное и жилищно-гражданское строительство (новое строительство), капитальный ремонт и дорожное строительство.

Заполнение справочника производится при первом запуске программы.

Общие сведения

Форма редактирования сведений о группе глав сводного сметного расчета.

Реквизиты:

    • Код - уникальный код
    • Наименование - наименование главы сводного сметного расчета (для группы -наименование типа строительства)
    • Тип строительства
    • Номер главы
    • Порядковый номер - порядковый номер главы в пределах иерархии. Недоступен для редактирования пользователем. 
    • Идентификатор - идентификатор главы, формируемый программно («Г»+НомерГлавы). Недоступен для редактирования пользователем. Используется для задания формул расчета итогов и лимитированных затрат в сметах.
    • Подзаголовок - подзаголовок для   печати в сметах перед наименованием главы
