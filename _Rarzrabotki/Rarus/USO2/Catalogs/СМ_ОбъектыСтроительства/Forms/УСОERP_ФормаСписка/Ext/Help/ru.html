Объекты строительства

Справочник Объекты строительства предназначен для хранения списка объектов строительства. Справочник содержит список наименований объектов строительства.

Справочник содержит иерархию групп и элементов.

В карточке элемента вводятся следующие данные:

  • Наименование;
  • Статус строительства - статусы объектов строительства, со значениями «Подготовлен», «Инициирован», «Утвержден», «Выполняется», «Завершен»;
  • Заказчик - заказчик строительства, выбор его из справочника Контрагенты;
  • Начало строительства;
  • Окончание строительства;
  • Установка флага Использовать месячные планы означает, ведется или не ведется строительство данного объекта по месячному плану;
  • Установка флага Использовать недельно-суточные планы означает, ведется или не ведется строительство данного объекта по недельно-суточному плану.

 

На закладке Основная информация содержатся сведения:

  • Руководитель строительства - руководитель, сотрудник организации, ответственный за строительство.
  • Объект строительства - выбор объекта строительства из справочника Объекты эксплуатации.
  • Адрес объекта строительства - адрес объекта строительства заполняется из классификатора  адресов России (КЛАДР).
  • График работы - указывается график работы. Выбор из справочника Графики работы.
  • Ед. длительности по умолчанию - единица длительности по умолчанию может принимать значение «час» или «день».
  • Описание - строка неограниченной длины, в которой указываем необходимо описание объекта строительства.

 

На закладке Участники проекта содержатся сведения об участниках в табличной части:

  • Контрагент - список контрагентов, которые участвуют в строительстве данного объекта;
  • Роль - указывается роль контрагента, участвующего в строительстве объекта. Может принимать значения: «Инвестор», «Заказчик», «Генподрядчик», «Проектировщик», «Субподрядчик».

 

На закладке Сценарии планирования содержатся сведения о сценариях в табличной части:

  • Сценарий - указываем сценарий планирования объекта строительства, выбрав его из справочника Сценарии планирования;
  • Вид сценария,  Дата начала, Дата окончания  - отображают параметры указанного сценария;

По нажатию кнопки Открыть работы на панели действий формы отображается форма списка справочника Строительные работы.

 

 

На закладке Настройки содержатся сведения:

  • Номенклатура работ при отгрузке заказчику - указывается номенклатура, которая будет подставлена автоматически в документ Реализация строительных работ.
  •  Номенклатура для отражения услуг заказчика - указывается номенклатура, которая будет подставлена автоматически в документ Поступление товаров и услуг.
  • Номенклатура для отражения услуг генподрядчика - указывается номенклатура, которая будет подставлена автоматически в документ Реализация товаров и услуг.
  • Флаг Автоматически заполнять плановый расход материалов при учете фактического расхода - при установке флага, в документе Расход материалов в строительстве будет отражено плановое значение списания материалов на работы.
  • Флаг Отражать факт работы водителей и техники путевыми листами - при установке флага, в документе Табель учета рабочего времени будет отражено факт работы водителей и техники по путевым листам.

 

На форме списка элемента расположена  кнопка Открыть базовый план на панели действий форм, по нажатию на которую отображается форма списка справочника Строительные работы сценарию с видом «Базовый».

На форме списка элемента имеется кнопка Открыть рабочий план на панели действий форм, по нажатию на которую отображается форма списка справочника Строительные работы по сценарию с видом «Рабочий»
