Предопределенные элементы

Справочник предназначен для хранения предопределенных значений параметров, используемых для выполнения регламентных операций по РСБУ в конце месяца.

В карточке элемента вводятся следующие данные:

■     Наименование - наименование предопределенного элемента.

■     Значение - значение предопределенного элемента.

■     Список - данный признак проставляется если предопределенный элемент может принимать значение из списка.

В данный момент в перечне предопределенных значений содержится следующий список:

■     Счет учета затрат по выполнению строительных работ - счет затрат, по которому в системе отражается выполнение СМР собственными силами. Данный счет используется для определения суммы затрат по СМР (собст. силы), которые были отнесены на счет 08.33. В соответствии с текущим планом счетов рекомендуется использовать счет 20.02.

■     Счет учета затрат по выполнению функций заказчика застройщика - счет затрат, по которому в системе отражается выполнение функций заказчика-застройщика. В соответствии с текущим планом счетов рекомендуется использовать счет 20.01.

■     Счет учета объектов недвижимости - счет затрат, на котором в системе собираются все затраты, связанные со строительством объекта эксплуатации. В соответствии с текущим планом счетов рекомендуется использовать счет 08.33.

■     Счет учета объектов недвижимости (забалансовый) - забалансовый счет, на котором числятся объекты недвижимости, проданные по ДДУ и ИД, но право собственности на которые еще не перешло. В соответствии с текущим планом счетов рекомендуется использовать счет 086.

■     Счет учета расчетов по целевому финансированию - счет учета целевого финансирования объектов капитального строительства. В соответствии с текущим планом счетов рекомендуется использовать счет 86.03.

■     Счета расчетов с дольщиками - счет учета взаиморасчетов с дольщиками по договорам ДДУ и ИД. В соответствии с текущим планом счетов рекомендуется использовать счет 76.07.

Если по какой-либо константе не указаны значения кодов затрат, то в соответствующих документах, отражающих фактические строительные затраты, пользователю не удастся выбрать никакой код затрат.
