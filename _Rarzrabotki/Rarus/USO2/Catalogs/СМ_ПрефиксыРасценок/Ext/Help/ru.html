Префиксы расценок

Справочник предназначен для задания префиксов расценок для различных типов нормативных сборников по региональным базам. Данные справочника используются при печати отчетов.

Справочник имеет иерархическую структуру, ограничение 2 уровня .

Реквизиты: 

    • ТипНормативногоСборника - тип нормативного сборника (заполняется для группы)  
    • РегиональнаяБаза -региональная база (заполняется для элементов)  
    • Наименование - префикс. Для группы заполняется значение префикса по умолчанию. Для элемента –  значения префикса для конкретной базы

При определении префикса для позиции сметы поиск префикса производится по типу нормативного сборника и региональной базе, которой принадлежит расценка. Если не найдена региональная база (элемент справочника), то префиксом позиции является префикс, указанный для типа нормативного сборника (группа справочника). Если не найден тип нормативного сборника, то префикс не печатается.
