Справочник предназначен для хранения перечня целевых показателей и параметров, по которым может выполняться анализ инвестиционного проекта.
В систему включены формулы расчета основных целевых показателей:

 - Приведенная стоимость (PV);

 - Чистая приведенная стоимость (NPV);  

 - Окупаемость (PB);

 - Дисконтированная окупаемость (DPB);

 - Внутренняя норма рентабельности (IRR);

 - Бухгалтерская норма прибыли (ARR).

Каждому целевому показателю сопоставляется нефинансовый показатель бюджета для хранения рассчитанных значений и использования в видах бюджетов.
