Ресурсы для выполнения строительных работ

Справочник  Ресурсы для выполнения строительных работ предназначен для хранения списка ресурсов, используемых для выполнения строительных работ.

Справочник содержит иерархию групп и элементов.

В карточке элемента вводятся следующие данные:

  • Наименование - указывается наименование ресурса.
  • Код - код элемента ресурса.

 

На закладке Рабочие содержатся сведения:

  • Должность - должность рабочих, участвующих в строительных работах. Выбирается из справочника Должности.
  • Количество - указывается количество должностей, участвующих в строительных работах.

 

На закладке Механизмы содержатся сведения:

  • Тип механизма - тип механизма, участвующего в строительстве. Выбирается из справочника Типы транспортных средств.
  • Количество - количество типа механизма, участвующего в строительных работах.
