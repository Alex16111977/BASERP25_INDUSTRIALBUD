Форма "Настройки мониторинга"

 

Закладка "1С:ЦСМ". Позволяет включить использование механизмов взаимодействия с системой GPS мониторинга "ЦСМ".

  • Использовать ЦСМ. Включает использование взаимодействия с системой GPS мониторинга "ЦСМ".

Закладка "Omnicomm". Позволяет включить использование механизмов взаимодействия с системой мониторинга "Omnicomm".

  • Использовать Omnicomm. Включает использование взаимодействия с системой мониторинга "Omnicomm".
  • Учетная запись. Учетная запись системы мониторинга.
  • Способ работы. Позволяет указать источник данных для загрузки. Возможные значения: "ВебСервис", "БД".
  • Логин. Логин пользователя для подключения к источнику данных (веб сервису или базе данных).
  • Пароль. Пароль пользователя для подключения к источнику данных (веб сервису или базе данных).
  • Адрес сервиса. Адрес веб сервиса системы мониторинга. (Доступно только для способа работы "ВебСервис").
  • Подключение. Способ подключения к базе данных. Возможные значения: "Стандартное подключение", "PIPE-подключение", "DSN-подключение". (Доступно только для способа работы "ВебСервис")
  • Сервер. Адрес сервера базы данных. (Доступно только для способа работы "ВебСервис").
  • Имя базы. Имя базы данных на сервере. (Доступно только для способа работы "ВебСервис").
  • Драйвер. Имя драйвера для подключения к серверу. (Доступно только для способа работы "ВебСервис").
  • Имя PIPE. Наименвание именованного канала для работы с сервером. (Доступно только для способа работы "ВебСервис").
  • Параметры хранения данных и регламентного задания "Загрузка данных" (Перейти к описанию).

Закладка "Wialon". Позволяет включить использование механизмов взаимодействия с системой мониторинга "Wialon".

  • Использовать Wialon. Включает использование взаимодействия с системой GPS мониторинга "Wialon".
  • Учетная запись. Учетная запись системы мониторинга.
  • Версия. Используемая версия системы мониторинга Wialon. Поддерживается загрузка из систем "Wialon Hosting" и "Wialon Local".
  • Токен авторизации. Используется для авторизации в системе.
  • Адрес сервиса. Адрес веб сервиса системы мониторинга.
  • Имя ресурса. Имя ресурса в системе "Wialon", от имени которого будут формироваться отчеты. 
  • Использовать смены. При использовании смен будет сформирован один запрос к системе мониторинга с настроенными сменами. Если смены не используются - для получения детальных данных будет выполнено несколько запросов с шагом, указанным в настройке "Хранение загруженных данных с интервалом".
  • Пробег. Вид загружаемого пробега: общий пробег по всем сообщениям или только пробег по поездкам.
  • Параметры хранения данных и регламентного задания "Загрузка данных" (Перейти к описанию).

Параметры хранения данных и регламентного задания "Загрузка данных":

  • Загрузить пробег и расход ГСМ. При работе регламентного задания будет загружен пробег и расход топлива по указанным в таблице ТС транспортным средствам.
  • Загрузить дополнительные сведения. При работе регламентного задания будут загружены дополнительные сведения по указанным в таблице ТС транспортным средствам.
  • Загрузить координаты. При работе регламентного задания будет загружена история местоположения по указанным в таблице ТС транспортным средствам.
  • Хранение загруженных данных с интервалом. Например, при выборе значения "15 минут" в процессе загрузки данных будет сформирована запись на каждый 15-минутный интервал. Чем больше записей в регистре сведений, тем точнее можно сопоставить эти записи с путевыми листами в отчетах, однако большое количество записей приведет к росту объема информационной базы. Рекомендуется использовать стандартное значение: 15 минут.
  • Загрузка данных регламентным заданием за. Например, при выборе значения "24 часа" регламентное задание выполнит загрузку данных за последние 24 часа с момента начала выполнения регламентного задания.
  • Хранение координат с интервалом. Интервал хранения координат (в секундах). Позволяет сократить объем информации, загружаемой из системы мониторинга.
  • Таблица ТС. Позволяет указать список транспортных средств, по которым необходимо загружать данные регламентным заданием.
