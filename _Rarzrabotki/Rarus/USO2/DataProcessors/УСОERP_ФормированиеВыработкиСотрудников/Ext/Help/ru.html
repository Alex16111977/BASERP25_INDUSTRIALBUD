Обработка предназначена для автоматического формирования типовых документов 1С ERP Выработка сотрудников на основании данных учета работы сотрудников и техники подсистемы Управление строительным производством.

На форме обработки указываются следующие данные:

■     Организация – организация, которая выполняет строительство объекта;

■     Объект строительства – объект строительства, для которого ведется учет работ сотрудников и техники;

■     Подразделение – подразделение, в котором работают сотрудники;

■     Вид цены – вид стоимости ресурса;

■     Дата сбора данных – дата сбора данных по выработке сотрудников.

Возможен дополнительный отбор по работе, ресурсу и исполнителю.

 

По кнопке Далее открывается окно с отображением выработки сотрудников по табелю исполнителей работ.

Выделяем флагом тех сотрудников, для которых необходимо сформировать документ Выработка сотрудников и нажимаем кнопку Создать документы.

По кнопке Продолжить с другими отборами можно продолжить работу с данной обработкой только уже с другими отборами.
