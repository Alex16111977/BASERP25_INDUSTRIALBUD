Обработка "Групповая обработка позиций"

Данная обработка используется для выполнения различных действий с группой позиций документов «Локальная смета» или «Акт выполненных работ».

Если по локальной смете имеются акты выполненных работ, то выполнять групповые операции с позициями сметы не разрешается.

На экран выдается иерархический список позиций сметы (акта), содержащий шифр позиции, наименование, измеритель, объем работ.

Действия выполняются с отмеченными позициями. Предусмотрена возможность установить отметку/снять отметку для всех позиций сметы, текущего раздела, текущей позиции. Например, при установке отметки на раздел, помечаются все подчиненные позиции. Также предусмотрена возможность отбора позиций по следующим критериям: определителю, виду расценки, типу нормативного сборника, номеру сборника.

Областями обработки позиций могут быть:

  • расценки;
  • ресурсы;
  • поправки;
  • начисления;
  • индексы пересчета

При выборе одного из действий, которые пользователь собирается произвести с группой позиций локальной сметы или акта, меняется интерфейс данной обработки: выводятся дополнительные сведения, поля ввода и т.д.

Общие сведения

Форма позволяет осуществить отбор позиций по заданным на форме критериям.
