Обработка предназначена для резервирования рабочего времени сотрудников для выполнения строительных работ, анализа зарезервированного времени выполнения работ и автоматического формирования документов "Назначение исполнителей работ".

На закладке Работы отображается список строительных работ по объекту строительства. Указываем у строительной работы состав ресурсов, и в верхней части обработки графически отображается занятость сотрудников, состоящих в данном ресурсе. Выделив свободные дни, когда необходимо задействовать ресурс на работу, нажимаем в контекстном меню кнопку Задействовать ресурс и указываем количество рабочих часов. В строке Зарезервировано отображается количество зарезервированных часов по сотруднику.

В случае неверного отражения количества часов по сотруднику по кнопке Освободить ресурс осуществляется сброс указанных часов.

По кнопке Развернуть все осуществляется раскрытие строк табличной части по строительным работам.

По кнопке Свернуть все осуществляется сворачивание строк табличной части по этапам работ.

На закладке Сотрудники отображаются сотрудники, занятые на строительных работах и входящие в состав рабочего ресурса, выделенного на закладке Работы.

На закладке Зарезервировано отображается занятость сотрудников, которые заняты на строительной работе и по которым был сделан резерв.

На закладке Назначения отображаются ссылки на документы Назначения исполнителей работ. По кнопке Сформировать документы назначений создается документ по указанному резерву в верхней части обработки, предварительно указав подразделение исполнителя.

По каждой работе формируется отдельный документ Назначения исполнителей работ.
