Сформировать экземпляр бюджета инвестиционного проекта

Обработка предназначена для формирования плановых данных (БДДС и БДР) по бюджету проекта на основании данных графиков по договору.

В зависимости от типа бюджета, который может принимать значение "Движение денежных средств" или "Доходы и расходы", выбираются данные в табличную часть для формирования бюджетов.

Табличная часть обработки заполняется и рассчитывается автоматически на основании данных документов "График движения по договору" по кнопке "Заполнить".

По кнопке "Сформировать" формируется документ "Экземпляр бюджета".
