Распределение доставки

        Обработка Распределение доставки предназначена для распределения маршрутов  доставки между собственными силами и сторонними организациями, автоматического формирования документов Заказ на доставку.

В обработку попадают все документы Заказ поставщику, для которых определен маршрут доставки, но не определен перевозчик. После распределения маршрутов между исполнителями доставки (сторонние организации или собственные силы), автоматически формируются документы Заказ на доставку.

 

На форме обработки указывается организация, исполнитель, перевозчик, перевозчик-Партнер.

 

В табличной части К доставке отображены следующие данные: документ Заказ поставщику, поставщик, номенклатура, характеристика, единица измерения, вес, количество, дата потребности, исполнитель, перевозчик, перевозчик-Партнер, адрес доставки, адрес отправления, склад доставки, адрес склада, заказ на доставку.

 

В табличной части В заказ отображены: документ Заказ поставщику, номенклатура, характеристика, единица измерения, вес, количество, срок доставки, исполнитель, перевозчик, адрес доставки, адрес отправления, перевозчикПартнер, вид доставки.

 

Для определения способа группировки для пользователя на форму выведен признак. Если используется группировка «по заказам», то колонка «Характеристика» на форму не выводится.

 

По кнопке Все заказы отображаются все документы Заказ поставщику на закладке «К доставке».

 

В табличной части К доставке имеется колонка «Флаг» для возможности переноса данных нескольких строк (выделенных) в табличную часть «К заказу» с помощью кнопки Перенести.

 

В табличной части В заказ доступны для редактирования следующие данные: Срок доставки, Исполнитель, Перевозчик, Перевозчик-Партнер, Вид доставки. Если в табличной части В заказ значение реквизита «Исполнитель» = «Сторонний перевозчик», то реквизиты «Перевозчик» и «Перевозчик-Партнер» доступны для редактирования; иначе не заполняются.

 

По кнопке Добавить промежуточную точку открывается форма для указания промежуточного адреса доставки. После указания адреса каждая строка табличной части В заказ разбивается на две (производится разбиение пути доставки на два):

  • Адрес отправления;
  • Адрес промежуточной точки доставки.

 

При нажатии на кнопку Выполнить для данных табличной части В заказ создаются документы Заказ на доставку.
