Setting of an autonomous workplace on a PC

Attention: at first, purchase and install the software [НазваниеПрограммы] locally on a PC for autonomous work without connection to Internet. See more details in the additional information below.

  1. Create a new folder where the infobase of the autonomous workplace will be located on your PC. For example, in the folder "My Documents".
  2. Open the downloaded file Autonomous work.zip and copy (retrieve) all files from it to this folder.
  3. Start 1C:Enterprise and press the button "Add..." in the open window "Start 1C:Enterprise"
  4. Specify the option "Add an existing infobase into the list" and press "Next".
  5. Specify the option "On this PC or on the local network PC" on the next page of the helper and enter the name of the infobase. It is recommended to specify the same name as the name of the autonomous workplace.
  6. Specify the subfolder Infobase on the next page in the folder created at the 1st step and then press "Ready" on the final page of the helper.
  7. Start the software using the button 1C:Enterprise (in the top right corner of the window "Start 1C:Enterprise").
    In the window of the access to the infobase in the field "User" choose the user from the list on whose behalf the autonomous workplace was created. Leave the field "Password" blank.

 

Furthermore, start 1C:Enterprise to enter into the software and choose this infobase in the list on the open window "Start 1C:Enterprise". You may use the command "Autonomous work" of the section "Administration" during work with the software, to change data synchronization parameters with the online application.

2. How to set up the autonomous workplace for work of other users?

The autonomous workplace is ready for work immediately after the first start. Your account has administrative rights like in the online application.

If other users have to work with this autonomous workplace, you should allow access to the software for them in the list "Users"of the section "Administration". At this, the same access rights as in the online application will be assigned to them. More details about maintenance of the list of users and setting access rights see in documents to the software.

Moreover, if users must synchronize data with the online application by their own, without your intervention, you should change default settings of online connection. For this, you may use the button "Set up connection..." in the window "Autonomous work" of the section "Administration". Set up the user on whose behalf the data must be synchronized in the setting form. Specify the profile "Data synchronization with other software" for this user in the online application.
