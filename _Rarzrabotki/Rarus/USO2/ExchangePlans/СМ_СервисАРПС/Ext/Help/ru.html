Синхронизация данных с сервисом разработчика "АРПС"

Общая информация

Синхронизация данных позволяет разработчику получать сведения о текущих новых настройках пользователя в части соответствий префиксов, лимитированных затрат, итогов, шифров для обмена сметной документациии. Синхронизация данных позволяет улучшить качество обмена сметной документацией с другими программами.

Основные возможности:
  • синхронизация настроек шаблонов префиксов;
  • синхронизация настроек соовтетсвия шифров;
  • синхронизация настроек итогов (не загружемых лимитированных затрат);
  • синхронизация настроек соответствий лимитированных затрат;
