## Архитектура отчёта (НЕ ломать)

**Программная компоновка СКД**: `ПриКомпоновкеРезультата` → `ПолучитьДанные(Период, СС)` строит
плоскую ТаблицуЗначений → внешний набор данных `"Детали"` (DataSetObject в Template.xml).
Причина программности — маппинг факт-материалов на Этап через
`Номенклатура.А_ОбщееНазваниеНоменклатуры` в BSL (`ЗаполнитьЭтапФактМатериалов`) и синтетические
строки EAC (`ЗаполнитьПланНаФакт`). В такой схеме КОЛОНКАМИ рендерятся только РЕСУРСЫ;
измерения — только уровнями группировок (проверено: поле-ссылку колонкой поставить нельзя).

**Запрос — 7 веток UNION в ВТ_Детали** (все ветки обязаны иметь одинаковый набор/порядок колонок!):
1. Труд-план: `Справочник.А_СтруктураСебестоимости.Работы` → Аналитика=Р.Работа, ПланЧасы/ПланГрн;
2. Материалы-план: `...Комплектующие` → Аналитика=Номенклатура, ПланКол/ПланГрн;
3. Табель-факт: `РН.А_ДанныеТабелирования` → Аналитика=ФизЛицо, ФактЧасы;
4. ЗП-факт: `РН.А_ВзаиморасчетыССотрудниками` (ОЗФУ) → Аналитика=ФизЛицо, ФактГрн;
5. Материалы-факт (закупки): `РН.СебестоимостьТоваров` Приход/ПриобретениеТоваровУслуг → ФактКол/ФактГрн;
6. EV-выполнение: `РН.А_ВыполнениеРаботМодулей` → Аналитика=ВРМ.Работа, ВиконанняЧасы
   (категория через LEFT JOIN ВТ_РаботыСС по НаВыезде).

**Измерения набора «Детали» (текущие):** Подразделение, Блок(строка), Категория(строка),
Этап(А_ЭтапыРабот), ОбщееНазвание(А_ОбщиеНазванияНоменклатуры), Аналитика(составное:
Номенклатура+ФизическиеЛица), Единица(УпаковкиЕдиницыИзмерения), Документ(составное:
ПриобретениеТоваровУслуг+А_СтруктураСебестоимости).
**Ресурсы (15):** ПланЧасы, ФактЧасы, ВиконанняЧасы, ОтклонениеЧасы, ОтклонениеВиконання,
ПроцентЧасы, ПроцентВиконання, ПланКол/ФактКол/ОтклонениеКол/ПроцентКол (скрыты из selection),
ПланГрн, ФактГрн, ОтклонениеГрн, ПроцентГрн, ПланНаФактГрн, ПрогнозГрн, ОтклонениеПрогнозГрн,
ПроцентПрогнозГрн.
**Структура группировок по умолчанию:** Подразделение → Блок → Категория → Этап →
ОбщееНазвание → Аналитика → Единица → Документ.
**Постобработки в BSL** (не сломать!): `ЗаполнитьЭтапФактМатериалов` (Этап+Категория факт-материалов
по общей назве), `ЗаполнитьПланНаФакт` (синтетические строки EAC на уровень ОбщееНазвание).
Значения группировок РУССКИЕ: `"1. Труд"`, `"2. Материалы"`, `"Производство"`, `"Монтаж"`.
