## Правила проекта

- Rule #-1: запросы — сначала Python COM на живой базе. Алиасы `В`, `ПО`, `ИЗ`, `КАК` в
  запросах запрещены; имена переменных `Ссылка`, `Выполнить` в BSL запрещены.
- Правило источника факта (регистры только за последний месяц периода, всё раньше —

- После правок BSL — grep-чек парности `КонецФункции`/`КонецПроцедуры`; Write даёт LF —
  после копирования в конфигурацию контрольный diff (память `bsl_write_lf_crlf_canon`).
- Скилы: `skd-edit`/`skd-validate`, `erf-build`, `bas-verify`, `1c-bsl-review`.
