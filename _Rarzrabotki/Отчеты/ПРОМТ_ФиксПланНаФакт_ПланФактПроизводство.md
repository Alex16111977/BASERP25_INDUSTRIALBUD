# ЗАДАЧА: исправить алгоритм колонки «План на факт, грн» в отчёте А_ПланФактныйПроизводствоПолный

## Роль

Действуй как бухгалтер-методолог + 1С-разработчик. Колонка «План на факт, грн» (ETC — стоимость
ещё не закупленных материалов по плановой цене) считается с потерями. Инвариант бухгалтера:
**если закупок нет вообще (Факт, грн = 0), то «План на факт, грн» = «План, грн» копейка в копейку**,
«Прогноз, грн» = «План, грн», «% вик. прогнозу» = 100.

## Багрепорт (живой кейс, воспроизводится)

Отчёт по СС **«МД IRS 2026 15 м (МД IRS 2026) / ІБ _МД IRS 2026»**, период 01.06.2026–30.06.2026:
- «2. Матеріали»: План, грн = **704 612,01**; Факт, грн = **0** (закупок нет);
- «План на факт, грн» показывает **597 724,74** — а должно быть **704 612,01**;
- потеряно 106 887,27 грн.

## Корень (уже найден чтением кода — проверь и подтверди)

Файл: `C:\Configuration_downloads\BASERP25\_Rarzrabotki\Отчеты\А_ПланФактныйПроизводствоПолный\Ext\ObjectModule.bsl`,
процедура `ЗаполнитьПланНаФакт(ТЗ)` (строки ~398+). Алгоритм: нетто ПланКол/ФактКол/ПланГрн по
(Подразделение, ОбщееНазвание) → ПланЦена = ПланГрн/ПланКол → Залишок = max(0, ПланКол−ФактКол) →
ПланНаФакт = Залишок × ПланЦена; синтетическая строка на уровень ОбщееНазвание.

Две дыры (строка `Если НЕ ЗначениеЗаполнено(СтрокаАгр.ОбщееНазвание) ИЛИ СтрокаАгр.ПланКол <= 0 Тогда Продолжить`):
1. **Материалы плана БЕЗ «Загальної назви»** (Номенклатура.А_ОбщееНазваниеНоменклатуры пусто) —
   полностью выпадают из «План на факт».
2. **Строки плана с ПланКол = 0 при ПланГрн > 0** (сумма внесена без количества) — тоже выпадают.
Плюс копеечный дрейф: при ФактКол = 0 сумма считается как Кол × (ПланГрн/ПланКол) — round-trip
через среднюю цену теряет копейки против исходного ПланГрн.

## Правила расчёта (утверждённая методология, реализовать точно)

Гранулярность нетто: **(Подразделение, «Загальна назва»)** — разрез Етап в расчёте НЕ участвует
(уже так; не возвращать этап в ключ). Для каждой группы:

1. **Если ФактКол = 0** (по группе за период): `ПланНаФакт = ПланГрн` группы — ровно сумма плана,
   БЕЗ пересчёта через цену×количество (никакой «игры с копейками», отчёт должен быть точным).
2. **Если ФактКол > 0**: `ПланНаФакт = max(0, ПланКол − ФактКол) × (ПланГрн / ПланКол)`
   (остаток некупленного количества × средняя плановая цена группы). Защита деления на 0.
3. **Материалы без «Загальної назви»**: НЕ выбрасывать. Fallback-ключ группы — сама Номенклатура
   (нетто (Подразделение, Номенклатура) для строк с пустой ОН), правила 1–2 те же; синтетическую
   строку класть с пустым ОбщееНазвание и этой Номенклатурой в Аналитике (или на уровень
   ОбщееНазвание=пусто — выбери вариант, при котором итоги по Категорія/Підрозділ верны и
   расшифровка не ломается).
4. **ПланКол = 0 при ПланГрн > 0**: группа не может считаться через количество → применяется
   правило: ПланНаФакт = ПланГрн − ФактГрн группы, но не меньше 0 (стоимостное нетто вместо
   количественного). При ФактГрн = 0 это даёт ровно ПланГрн (согласуется с правилом 1).
5. Итоговые формулы НЕ трогать: «Прогноз, грн» = Σ(ФактГрн) + Σ(ПланНаФактГрн);
   «Відхилення прогнозу» = Прогноз − План; «% вик. прогнозу» = Прогноз / План × 100
   (totalField в Template.xml — менять не нужно).
