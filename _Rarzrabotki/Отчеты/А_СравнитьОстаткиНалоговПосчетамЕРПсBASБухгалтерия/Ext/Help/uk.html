Звірка залишків податків по рахунках: ЕРП ↔ BAS Бухгалтерія

Звіт звіряє регламентований бухоблік обох баз по податкових рахунках: РегистрБухгалтерии.Хозрасчетный в ЕРП (локально) проти РегистрБухгалтерии.Хозрасчетный у базі BAS Бухгалтерія (BuhBud) (через COM). Рахунки 641x / 642 / 651.

Порівняння будується по рахунку (Счёт.Код), без розрізу по організації. Колонка «Вид податку» — довідкова мітка по карті рахунок→податок. По кожному з чотирьох показників виводяться колонки ЕРП, Бухгалтерія та Різниця (= ЕРП − Бухгалтерія): Поч.залишок, Нараховано (оборот Кт), Сплачено (оборот Дт), Кін.залишок. Знак вирівняно до пасив = плюс (сальдо Кт − Дт).

Як обмінюються рахунки. Правила обміну (правило конвертації «Хозрасчетный») синхронізують план рахунків 1:1 по Коду + GUID (поле пошуку — Код, ідентична таблиця предвизначених рахунків, без перекодування). Тому рахунок 6411 в ЕРП і 6411 у Бухгалтерії — гарантовано один і той самий рахунок, а звірка по Счёт.Код іде за штатним ключем обміну.

Сенс звіту. Регл. Хозрасчетный ЕРП у нормі відображає (мирорить) дані BuhBud. Тому Різниця ≠ 0 по рахунку, або рахунок, присутній лише в одній базі, = пробіл завантаження/обміну між базами (а не «різні плани рахунків»). Це й є робочий сигнал для розбору. Організації беруться за прапором А_ВБалансе (є лише в ЕРП); зв'язка між базами — за КодПоЕДРПОУ.
