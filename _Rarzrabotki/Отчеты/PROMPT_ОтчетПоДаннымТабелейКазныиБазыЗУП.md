## Цель

1. Ячейки «8м» (и чистая «М») в `Документ.ТабельУчетаРабочегоВремени` Казны должны
   проводиться в регистр `ДанныеТабелирования` как Состояние «М» с часами в НОВОМ ресурсе
   `ЧасыОфициальные`. `ЧасыФакт` остаётся только оплатой по ставке Казны.
2. Буквы О, Б, С, К, Н, В, Д получают своё Состояние (сейчас всё кроме В/Б/Н уходит как «Р» с 0 ч).
3. Штатный отчёт `ОтчетПоДаннымТабелей` показывает `ЧасыОфициальные`.
4. Новый внешний отчёт `ОтчетПоДаннымТабелейКазныиБазыЗУП` (база Казна) сверяет табели
   Казны с ЗУП по сотрудникам и по дням и подсвечивает контрольные признаки.

**НЕ ТРОГАТЬ:** ЕРП (`А_ТабельУчетаРабочегоВремени`, `А_ДанныеТабелирования`, план-факт
производства), правила обмена Казна-ЕРП, документы `РаспределениеЗаработнойПлаты` и
`РаспределениеФ2`. Часы «М» специально не идут в распределение ЗП и в ЕРП.

## Грабли (обязательны к учёту)

- Rule −1: любой запрос сначала Python COM на живой базе. Алиасы `В` и `ПО` в запросе
  запрещены (зарезервированы). Переменная `Ссылка` в BSL запрещена.
- COM сдвигает даты на −3 ч: в Python передавать `datetime(y,m,d,3,0,0)`; конец периода
  считать в 1С `КОНЕЦПЕРИОДА(&Д, ДЕНЬ)` / `КонецДня()`, никогда `23:59:59` из Python
  (обрезает движения Казны, которые стоят на 23:59:59). Даты в ЗУП передавать `pywintypes.Time`.
- Через COM у строки ТЗ поля брать `getattr(row, "Имя")`, не `row["Имя"]`.
- `Число("8М")` бросает исключение; в ЗУП-запросах SELECT только примитивы.
- Частичная загрузка в kazna: список файлов БЕЗ `Configuration.xml` (новых объектов нет;
  память `config_xml_partial_load_deletes_objects`). Конфигуратор kazna должен быть закрыт.
- Историю (перепроведение табелей) делает пользователь; тесты перепроводят ТОЛЬКО
  документ 000003260 от 01.08.2026 (ІНДЕПТ СТІЛ, скриншот пользователя) и ничего не удаляют.
- Клон внешнего отчёта: перегенерировать uuid корня, `ObjectId`, `TypeId`, `ValueId`
  (память `epf_clone_regen_internal_guids`); в XML типы только через `<v8:Type>`.
- В BSL после правки grep-проверка парности `КонецФункции` / `КонецПроцедуры`;

## Задача 2. Разбор ячейки (модуль менеджера) + проведение

Новый файл `_Rarzrabotki/Kazna/Documents/ТабельУчетаРабочегоВремени/Ext/ManagerModule.bsl`:

```bsl
// Разбор значения ячейки дня табеля.
// Возвращает Структуру: Состояние (Строка), ЧасыФакт, ЧасыОфициальные (Число),
// Ошибка (Строка, пустая если значение допустимо).
Функция РазобратьЗначениеЯчейки(Знач Значение) Экспорт
```

Правила (в этом порядке):
1. `Текст = ВРЕГ(СокрЛП(Строка(Значение)))`; латиницу M O B H C K заменить на М О В Н С К;
   запятую заменить на точку.
2. Пусто: Состояние "", 0, 0, Ошибка "".
3. Разделить на числовую часть (ведущие символы 0–9 и точка) и остаток.
4. Остаток пуст и число есть: «Р», ЧасыФакт = Число(числовая часть).
5. Числовой части нет и остаток одна буква из «О Б Н В С К М Д»: Состояние = буква, 0, 0.
6. Число есть и остаток равен «М»: «М», ЧасыФакт 0, ЧасыОфициальные = число.
7. Всё остальное: Состояние «?», 0, 0, Ошибка = "Недопустимое значение '" + Текст +
   "'. Допустимо: число, буква О/Б/Н/В/С/К/М/Д или число с М (8М)".
`Число()` вызывать в Попытке; при исключении переход к пункту 7.

`ObjectModule.bsl`, `ОбработкаПроведения`: вместо блока `Если КвоЧасов="В" ... КонецЕсли`
вызвать `Разбор = Документы.ТабельУчетаРабочегоВремени.РазобратьЗначениеЯчейки(...)`;
`локСостояние = Разбор.Состояние`, `КвоЧасовФакт = Разбор.ЧасыФакт`; при
`Разбор.Ошибка <> ""` вывести `Сообщить("Строка " + НомерСтроки + " (" + Сотрудник + "), день " +
СчКолонок + ": " + Разбор.Ошибка)` без Отказа. В движение добавить
`Движение.ЧасыОфициальные = Разбор.ЧасыОфициальные`. Условие создания движения прежнее
(`ЗначениеЗаполнено(локСостояние) ИЛИ КвоЧасовПлан > 0`). Остальной код проведения не менять.

с выражениями от `Период`, `ТолькоТрудоустроенные` (булево, Ложь),
`ПоказыватьЗУПБезТабеля` (булево, Истина). Итоги: суммы по всем числовым полям.
Варианты: «Сводно по сотрудникам» (группировка Сотрудник/ФИО, колонки Казны, ЗУП,
Контроль; условное оформление: фон при `ЕстьКонтроль`, отдельный цвет при
`НетФлагаТрудоустроен`), «Контроль» (то же с отбором `ЕстьКонтроль = Истина`),
«По дням» (таблица: строки Сотрудник, затем Дата; отбор `Расхождение <> ""` выключен по умолчанию).

### 6.3 Модуль объекта (`Ext/ObjectModule.bsl`)
- `СведенияОВнешнейОбработке()` Экспорт: Вид «ДополнительныйОтчет», команда «Табели Казны и ЗУП».
- `ПриКомпоновкеРезультата`: `СтандартнаяОбработка = Ложь`; период из настроек
  (`КомпоновкаДанныхКлиентСервер.ПолучитьПараметр`, границы `НачалоДня`/`КонецДня`);
  флаги; `ТаблицаКазна = ПолучитьДанныеКазны(...)`; COM к ЗУП; `ТаблицаЗУПВремя`,
  `ТаблицаЗУПНачисления`, `МножествоАктуальныхДРФО`; `Свод` и `ПоДням` из
  `Объединить(...)`; внешние наборы; стандартный вывод с `ДанныеРасшифровки`.
- `ПолучитьДанныеКазны(Нач, Кон)`: один запрос к физической таблице
  `РегистрНакопления.ДанныеТабелирования` (Активность, период между `&Нач` и `&Кон`),
  поля Сотрудник, Сотрудник.ИНН, Сотрудник.Трудоустроен, Организация, Подразделение,
  Состояние, `НАЧАЛОПЕРИОДА(Период, ДЕНЬ)`, ЧасыФакт, ЧасыОфициальные, ЧасыПлан.
  Свёртку по дням и по сотруднику делать в BSL. Сотрудник считается «есть табель»,
  даже если все его ячейки буквы.
- `ПолучитьВремяЗУП(V83, Нач, Кон)`: запрос к физической таблице
  `РегистрНакопления.РабочееВремяРаботниковОрганизаций` (Активность):
  `Сотрудник.Физлицо.КодПоДРФО`, `Сотрудник.Физлицо.Наименование`, `Организация.Код`,
  `Организация.Наименование`, `Период`, `ВидИспользованияРабочегоВремени.БуквенныйКод`,
  `ВидИспользованияРабочегоВремени.РабочееВремя`, СУММА Дней, СУММА Часов; группировка по
  всем. Только примитивы. Читать через `Выбрать()` и копировать в локальную ТЗ.
- `ПолучитьНачисленияЗУП(V83, Нач, Кон)`: `РегистрРасчета.ОсновныеНачисленияРаботниковОрганизаций`,
  `ПериодРегистрации МЕЖДУ`, группировка по ДРФО: СУММА Результат, СУММА ОтработаноДней,
  МАКСИМУМ НормаДней.
- `ПолучитьАктуальныхЗУП(V83)`: ДРФО из `Справочник.СотрудникиОрганизаций` с
  `Актуальность` и без пометки удаления.
- Объединение: ключ `СокрЛП(ИНН)`; Казна без ИНН даёт строку с `НетИНН`; ЗУП-ДРФО без
  строки Казны даёт строку с `НетТабеляКазны` (если `ПоказыватьЗУПБезТабеля`); фильтр
  `ТолькоТрудоустроенные` применять к строкам Казны, строки только из ЗУП оставлять.
- Подключение: константа модуля со строкой `Srvr="localhost";Ref="zup";Usr="АвтообменБУ";Pwd="АвтообменБУ123"`;
  при ошибке подключения `Сообщить` и вывод только Казны с признаком «ЗУП недоступен»
  в колонке Контроль (отчёт не падает).
