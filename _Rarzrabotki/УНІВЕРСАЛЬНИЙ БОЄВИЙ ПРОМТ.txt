## 🔴 ПРАВИЛО #3 - СИНХРОНІЗАЦІЯ ГОЛОВНОГО XML ТА FORM.XML (КРИТИЧНО!)

### ⛔ НАЙЧАСТІША ПОМИЛКА:
```
Form.xml містить <Table> з DataPath="Объект.ИмяТЧ"
АЛЕ в головному XML НЕМАЄ TabularSection з ім'ям "ИмяТЧ"
= ПОМИЛКА "Неверный путь к данным"!
```

### 🔴 ЗАЛІЗНЕ ПРАВИЛО:
```
КОЖЕН DataPath="Объект.XXX" в Form.xml 
ПОВИНЕН МАТИ відповідний елемент в головному XML:
- Объект.ИмяРеквизита → <Attribute><n>ИмяРеквизита</n>
- Объект.ИмяТЧ → <TabularSection><n>ИмяТЧ</n>
- Объект.ИмяТЧ.Колонка → <TabularSection>...<Attribute><n>Колонка</n>
```

### ✅ АЛГОРИТМ ПЕРЕВІРКИ (ОБОВ'ЯЗКОВО!):

**КРОК 1: Збери всі DataPath з Form.xml**
```
Знайди всі входження: DataPath="Объект.XXX"
Приклад:
- Объект.Организация
- Объект.НачалоПериода  
- Объект.Кассы (таблиця)
- Объект.Кассы.Касса (колонка)
- Объект.Кассы.Сумма (колонка)
```

**КРОК 2: Перевір наявність в головному XML**
```
Для кожного DataPath перевір:
- Объект.Организация → є <Attribute><n>Организация</n>? ✅
- Объект.Кассы → є <TabularSection><n>Кассы</n>? ❌ ПОМИЛКА!
- Объект.Кассы.Касса → є реквізит Касса в ТЧ Кассы? ❌ ПОМИЛКА!
```

**КРОК 3: Додай відсутні елементи**
```
Якщо ТЧ відсутня → додай <TabularSection> в головний XML
Якщо реквізит відсутній → додай <Attribute>
```

### ❌ ПРИКЛАД ПОМИЛКИ (те що було зламано):

**Form.xml:**
```xml
<Table name="Кассы" id="9">
    <DataPath>Объект.Кассы</DataPath>  <!-- ❌ ТЧ не існує! -->
    <ChildItems>
        <InputField name="КассыКасса" id="25">
            <DataPath>Объект.Кассы.Касса</DataPath>  <!-- ❌ -->
        </InputField>
        <InputField name="КассыСумма" id="31">
            <DataPath>Объект.Кассы.Сумма</DataPath>  <!-- ❌ -->
        </InputField>
    </ChildItems>
</Table>
```

**Головний XML (ЗЛАМАНИЙ):**
```xml
<ChildObjects>
    <Attribute>...</Attribute>  <!-- Є реквізити -->
    <!-- ❌ НЕМАЄ <TabularSection><n>Кассы</n>! -->
    <Form>Форма</Form>
</ChildObjects>
```

**Результат:** `Неверный путь к данным: "Объект.Кассы"`

### ✅ ПРИКЛАД ПРАВИЛЬНОЇ СТРУКТУРИ:

**Головний XML (ПРАВИЛЬНИЙ):**
```xml
<ChildObjects>
    <Attribute uuid="...">
        <Properties><n>Организация</n>...</Properties>
    </Attribute>
    
    <!-- ✅ TabularSection ПЕРЕД <Form>! -->
    <TabularSection uuid="...">
        <InternalInfo>
            <xr:GeneratedType name="DataProcessorTabularSection.ИмяОбработки.Кассы" category="TabularSection">
                <xr:TypeId>...</xr:TypeId>
                <xr:ValueId>...</xr:ValueId>
            </xr:GeneratedType>
            <xr:GeneratedType name="DataProcessorTabularSectionRow.ИмяОбработки.Кассы" category="TabularSectionRow">
                <xr:TypeId>...</xr:TypeId>
                <xr:ValueId>...</xr:ValueId>
            </xr:GeneratedType>
        </InternalInfo>
        <Properties>
            <n>Кассы</n>  <!-- ✅ Ім'я співпадає з DataPath -->
            ...
        </Properties>
        <ChildObjects>
            <Attribute uuid="...">
                <Properties><n>Касса</n>...</Properties>  <!-- ✅ Колонка -->
            </Attribute>
            <Attribute uuid="...">
                <Properties><n>Сумма</n>...</Properties>  <!-- ✅ Колонка -->
            </Attribute>
        </ChildObjects>
    </TabularSection>
    
    <Form>Форма</Form>  <!-- ✅ Form ПІСЛЯ TabularSection! -->
</ChildObjects>
```

### 🔴 ПОРЯДОК ЕЛЕМЕНТІВ В ChildObjects:
```
1. <Attribute> (реквізити шапки)
2. <TabularSection> (табличні частини)  
3. <Form> (ЗАВЖДИ ОСТАННІЙ!)
```

## ПРАВИЛО #4 - XML СТРУКТУРА ЗОВНІШНІХ ОБРОБОК

### ⚠️ ГОЛОВНИЙ ПРИНЦИП
```
СПОЧАТКУ ЧИТАЙ ЗРАЗОК → ПОТІМ КОПІЮЙ СТРУКТУРУ → ТІЛЬКИ ПОТІМ ЗМІНЮЙ КОНТЕНТ
```

### Структура файлів обробки/звіту:
```
ИмяОбработки.xml                    # Головний файл метаданих
ИмяОбработки/
  ├── Ext/
  │     └── ObjectModule.bsl        # Модуль об'єкта (опціонально)
  └── Forms/
        └── Форма/
              ├── Форма.xml         # Метадані форми (⛔ НЕ ЧІПАТИ!)
              └── Ext/
                    ├── Form.xml    # Структура форми
                    └── Form/
                          └── Module.bsl  # Модуль форми (код)
```

### АЛГОРИТМ роботи з обробками:
```
1. Знайти РОБОЧУ обробку в тій же папці як ЗРАЗОК
2. Прочитати її XML файли ПОВНІСТЮ (головний + Form.xml)
3. Скопіювати СТРУКТУРУ (не вигадувати!)
4. Змінити тільки потрібний контент
5. 🔴 ПЕРЕВІРИТИ СИНХРОНІЗАЦІЮ DataPath ↔ головний XML!
6. Перевірити всі id на унікальність
7. Зберегти з тим же форматуванням
```

### 4.2. Form.xml - КРИТИЧНІ ПРАВИЛА

**⛔ ЗАБОРОНЕНО ЗМІНЮВАТИ без крайньої потреби:**
- Порядок секцій
- Формат namespace
- Структуру InternalInfo

**✅ Порядок секцій (ЗАВЖДИ такий!):**

```xml
<Form xmlns="..." xmlns:v8="..." ...>
    <AutoSaveDataInSettings>Use</AutoSaveDataInSettings>
    <AutoCommandBar>...</AutoCommandBar>  <!-- 1. Командна панель -->
    <ChildItems>...</ChildItems>          <!-- 2. Елементи форми -->
    <Attributes>...</Attributes>          <!-- 3. Реквізити форми -->
    <Commands>...</Commands>              <!-- 4. Команди -->
</Form>
```

**✅ Commands - ПРАВИЛЬНИЙ формат:**

```xml
<Commands>
    <Command name="ЗагрузитьОстатки" id="1">  <!-- ⚠️ ОБОВ'ЯЗКОВО id="число"! -->
        <Title>
            <v8:item>
                <v8:lang>ru</v8:lang>
                <v8:content>Загрузить остатки</v8:content>
            </v8:item>
        </Title>
        <ToolTip>
            <v8:item>
                <v8:lang>ru</v8:lang>
                <v8:content>Загрузить остатки из базы BuhBud</v8:content>
            </v8:item>
        </ToolTip>
        <Action>ЗагрузитьОстатки</Action>  <!-- ⚠️ ПРОСТО ім'я, БЕЗ xsi:type! -->
    </Command>
</Commands>
```

**❌ ЗАБОРОНЕНО в Command:**

```xml
<!-- ВСЕ ЦЕ - ПОМИЛКИ! -->
<Action xsi:type="v8:FormCommand">...</Action>     <!-- НІ! -->
<Command name="Cmd">                                <!-- БЕЗ id - НІ! -->
<Use><common>true</common></Use>                   <!-- ЗАЙВЕ! -->
<Representation>Auto</Representation>               <!-- ЗАЙВЕ! -->
<CurrentRowUse>Auto</CurrentRowUse>                <!-- ЗАЙВЕ! -->
```

**✅ Button в командній панелі - ПРАВИЛЬНИЙ формат:**

```xml
<AutoCommandBar name="ФормаКоманднаяПанель" id="-1">
    <ChildItems>
        <Button name="ФормаЗагрузитьОстатки" id="100">
            <Type>CommandBarButton</Type>

            <ExtendedTooltip name="ФормаЗагрузитьОстаткиРасширеннаяПодсказка" id="101"/>

    </ChildItems>

```

**✅ Table (таблична частина на формі):**

```xml
<Table name="БанковскиеСчета" id="50">
    <DataPath>Объект.БанковскиеСчета</DataPath>  <!-- 🔴 ПЕРЕВІР наявність ТЧ! -->
    <ChildItems>
        <InputField name="БанковскиеСчетаБанковскийСчет" id="51">
            <DataPath>Объект.БанковскиеСчета.БанковскийСчет</DataPath>  <!-- 🔴 ПЕРЕВІР реквізит! -->
```

**⚠️ ПРАВИЛО УНІКАЛЬНОСТІ ID:**
- Всі `id` в межах Form.xml мають бути УНІКАЛЬНИМИ

## ПРАВИЛО #5 - МОДУЛЬ ФОРМИ (Module.bsl)

**✅ Структура процедур:**

```1c
// ========== ОБРОБНИКИ ПОДІЙ ФОРМИ ==========

&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    // Ініціалізація значень за замовчуванням
КонецПроцедуры

// ========== ОБРОБНИКИ КОМАНД ==========

&НаКлиенте
Процедура ЗагрузитьОстатки(Команда)  // ⚠️ Ім'я = Action в Form.xml!
    // Валідація на клієнті
    // Виклик серверної процедури
    Результат = ЗагрузитьОстаткиНаСервере();
    // Повідомлення користувачу
КонецПроцедуры

&НаСервере
Функция ЗагрузитьОстаткиНаСервере()
    ОбъектОбработки = РеквизитФормыВЗначение("Объект");
    ОбъектОбработки.ЗагрузитьОстатки();
    ЗначениеВРеквизитФормы(ОбъектОбработки, "Объект");
    Возврат Объект.ИмяТЧ.Количество();
КонецФункции
```

**⚠️ КРИТИЧНО:** Ім'я процедури-обробника команди = значення `<Action>` в Form.xml!

## ⚠️ ТИПОВІ ПОМИЛКИ (НЕ РОБИ ТАК!)

| ❌ ПОМИЛКА | ✅ ПРАВИЛЬНО |
|-----------|-------------|
| 🔴 **DataPath в Form.xml без ТЧ в головному XML** | **Спочатку додай TabularSection!** |
| 🔴 **Table на формі → немає TabularSection** | **Синхронізуй Form.xml ↔ головний XML** |
| `<Action xsi:type="...">Cmd</Action>` | `<Action>Cmd</Action>` |
| `<Command name="Cmd">` (без id) | `<Command name="Cmd" id="1">` |
| Вигадувати структуру XML | Копіювати з ЗРАЗКА |
| Міняти порядок секцій | Зберігати порядок |
| Пропускати `<ExtendedTooltip>` | Завжди додавати |
| Дублювати id | Унікальні id (100+, 200+) |
| `&НаСервере` для обробника команди | `&НаКлиенте` + виклик серверної |
| `<Form>` перед `<TabularSection>` | `<TabularSection>` ПЕРЕД `<Form>`! |
