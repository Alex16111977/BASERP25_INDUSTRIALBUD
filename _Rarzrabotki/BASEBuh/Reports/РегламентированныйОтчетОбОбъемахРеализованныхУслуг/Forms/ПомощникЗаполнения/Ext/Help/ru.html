Помощник заполнения отчета об объемах реализованных услуг

Этот помощник можно открыть по кнопке Открыть помощник заполнения.

Предусмотрены следующие варианты заполнения:  

  • Заполнить по КВЕД организации. Все данные по реализации услуг будут выведены в отчете под одним КВЕД из карточки организации.

  • Заполнить в помощнике. Подбираются документы по реализации услуг. КВЕД заполняется автоматически, если заполнено субконто Номенклатура на счете доходов или есть запись в регистре "Выручка и себестоимость продаж". КВЕД заполняется Кодом для НН по умолчанию номенклатуры. 

Флаг Сворачивать данные в таблице по субконто предоставляет возможность объединить документы по аналитике в одном периоде.

При заполнении КВЕД в одной строке, автоматически заполнится КВЕД в строках с одинаковой аналитикой. Если установлен флаг НЕ заполнять КВЕД для аналогичных строк автоматически, КВЕД не будет переносится автоматически.

По кнопке Заполнить данные КВЕД из отчета предыдущего периода можно заполнить КВЕД из отчета прошлого периода для строк с совпадающими параметрами. 

Перенос данных в отчет осуществляется по кнопке Записать и закрыть.
