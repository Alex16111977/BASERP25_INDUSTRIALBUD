## 3. ЗАДАЧА A — форма документа: вкладки как в Казне

Заменить текущую вкладку «Визирование» (одна страница, 3 таблицы подряд, 4 отдельные кнопки) на структуру Казны:

### 3.3 Командная кнопка-меню «Виза» (в командной панели формы, как в Казне)

## 4. ЗАДАЧА B — рабочее место на динамическом списке (как в Казне)

Пересобрать форму `.epf` с **ДинамическийСписок** (сейчас — таблица значений). Реквизит `Список`

### 4.1 Визуал списка (как Казна `Виза_Список`)
- **Двухстрочные ячейки** через `ColumnGroup` с `Group=Vertical` (как Казна): напр. «Плательщик/Дата»,
  «Контрагент/Дата(вх)/Номер(вх)» стопкой. Колонки: Организация, Номер, Дата, Партнёр/Контрагент,
  `СуммаДокумента`, `Статус` заказа, `А_Виза_Состояние`, `А_Виза_ТекущаяРоль`, `А_Виза_ТекущиеВизирующие`,
  `А_Виза_Дата`, Подразделение, Автор, Комментарий.
- **Подсветка строк по состоянию визы — КОДОМ** (ЕРП-паттерн `ФормаСпискаЗаявокКСогласованию:271–341`):
  `Список.КомпоновщикНастроек.Настройки.УсловноеОформление` в `ПриСозданииНаСервере`. НаВизировании —
  жёлтый фон, Утвержден — зелёный, Отклонено — красный текст, Анулировано — серый. `ЦветаСтиля.*`.
  **НЕ** авторить DCS-настройки руками, **НЕ** `<TextColor>`-XML (валит `epf-build`).
- **Штатный поиск** (строка поиска списка) и меню «Ещё» — нативные для динсписка.
- Открытие заказа по двойному клику (`Список.Выбор` → `ПоказатьЗначение`).

### 4.2 Режимы очереди — радио «Виза на визу мне» (как Казна `Виза_НаВизуМне`)
Переключатель `РежимОчереди` (0 Все · 1 Мне на визирование · 2 Пред. виза) → задаёт параметры
`Список.Параметры` (`РежимОчереди`, `ТекущийПользователь`, `Состояние_НаВизировании`) и обновляет список.

### 4.3 Отборы — панель с чекбоксами (Казна) через типовой механизм (ЕРП)
Подразделение (в иерархии), Организация, Партнёр/Контрагент, Состояние визы, Статус заказа, Автор, период.
Через `ОтборыСписковКлиентСервер.ОтборПоЗначениюСпискаПриСозданииНаСервере/ПриЗагрузкеИзНастроек`
(`ФормаСпискаЗаявокКСогласованию:24–96`) — **отборы сохраняются между сеансами**. Дефолт — «Мне на визирование».

### 4.4 Массовые действия — ПО ВЫДЕЛЕННЫМ СТРОКАМ (как Казна, взять по максимуму)
Кнопки с иконками: **Утвердить** (зелёная ✓), **Отклонить** (красный ✗), **Подписать заранее**,
**Вернуть в черновик**, **Аннулировать**. Паттерн Казны (`ФормаСписка_Визирование\Ext\Form\Module.bsl`):
- `Виза_Утвержден(Команда)` (:115) → `ПоказатьВопрос("…N заказов?")` → `Виза_УтвержденПродолжение` (:81) →
  цикл по `Элементы.Список.ВыделенныеСтроки`;
- «Отклонить»/«Аннулировать» — `ПоказатьВводСтроки` причины (`Виза_ОтклоненоПродолжение` :149).

**У динамического списка `ВыделенныеСтроки` — это ССЫЛКИ** (не идентификаторы): передавать массив прямо в
`А_ВизированиеВызовСервера.УстановитьВизуДокументов(ВыделенныеСтроки, "Утвержден", Допы)` (ВызовСервера —
вызывается с клиента). Для «Предварительная» — `ИмяСостояния = "Предварительная"`. После — `Список.Обновить()`.
Можно использовать типовые хелперы `ОбщегоНазначенияУТКлиент.ПроверитьПолучитьВыделенныеВСпискеСсылки` и
`.ОповеститьПользователяОбУстановкеСтатуса` (ЕРП).

### 4.5 Панель «Всего выбрано» (как Казна)
Реквизит-надпись `Выделено` (ReadOnly). `ПриАктивизацииСтроки` пересчитывает сумму `СуммаДокумента` по
`Элементы.Список.ВыделенныеСтроки` (паттерн Казны `ПолучитьСуммуКолонок` :414 / `Выделено_Виза`).
Формат: «Всего выбрано: Сумма 11 437,34».

### 4.6 Master-detail (опционально, оставить из текущего)
Панель «История виз» по активной строке — через `ObjectModule.ЗаполнитьИсториюВиз(Ссылка)` с дебаунсом

## 5. Грабли (проверены на этом проекте — см. LESSONS базы знаний)

- **Динсписок: `ВыделенныеСтроки` = ссылки** (у ТЗ формы — идентификаторы; не перепутать при переходе с ТЗ).
- **`СГРУППИРОВАТЬ ПО` в динсписке запрещено** — ломает основную таблицу и открытие по 2-клику. Очередь —
  подзапросом по ТЧ (`Т.Ссылка В (ВЫБРАТЬ … ИЗ …А_ТекущиеВизирующие …)`).
- **Подсветка — только кодом** через `Список.КомпоновщикНастроек.Настройки.УсловноеОформление`
  (не `УсловноеОформление` формы, не `<TextColor>`-XML).
- **Движок документ не пишет** — после `А_Виза_УстановитьСостояние` вызывающий делает `Записать()`
  (в форме документа) / это делает пакетный движок (в РМ).
- **Версия формата обработки 2.13**; частичная загрузка формы — по объекту, не Ext-подпути; `ДатаВизы` не `Дата`;
  `КАК В` зарезервировано.
- **Dangling `<Event>`** после `form-compile`/`form-edit` = падение; сверять Event↔модуль. `form-validate`
  ложно ругается на `ExternalDataProcessorObject`/версию 2.13 — не дефекты.
- **Rule #-1:** текст запроса динсписка прогнать Python COM ПЕРЕД вставкой в форму.
