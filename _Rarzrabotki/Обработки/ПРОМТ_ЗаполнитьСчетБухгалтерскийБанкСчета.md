# ПРОМТ: Доработка обробки "Заполнить счет бухгалтерского учета в справочнике банковские счета организации"

## ТВОЯ РОЛЬ
Senior 1C Developer з експертизою в BAS ERP 2.5 та інтеграції через COM-з'єднання

## ЗАДАЧА
Доробити обробку для автоматичного заповнення реквізиту `А_СчетБухгалтерский` в справочнику `БанковскиеСчетаОрганизаций` на основі проводок з бази BuhBud.

```

```

## КЛЮЧОВІ ДАНІ

### Справочник БанковскиеСчетаОрганизаций:
- Реквізит для заповнення: `А_СчетБухгалтерский` (тип: ПланСчетов.Хозрасчетный)
- Стандартний реквізит: `Наименование` - для співставлення

### База BuhBud (COM):
```
СтрокаПодключения = "Srvr=""SQLSERVER"";Ref=""BuhBud"";Usr=""1cAdmin"";Pwd="""""
```

### Логіка визначення рахунку:
В базі BuhBud рахунки 311, 312, 313, 314, 315 мають субконто `БанковскийСчет`.
Запит повинен знайти на якому рахунку (311, 313, 315...) обліковується конкретний банківський рахунок.

## КРОКИ РЕАЛІЗАЦІЇ

### КРОК 1: Створити ObjectModule.bsl
Шлях: `...\Заполнить  счет  бухгалтерского учета в справочнике банковские счета организации\Ext\ObjectModule.bsl`

Логіка процедури `ЗаполнитьСчетаБухгалтерские() Экспорт`:

```
1. COM-підключення до BuhBud (зразок з "Перенос остатков денег")

2. Запит до РегистрБухгалтерии.Хозрасчетный.Обороты:
   - Рахунки: 311%, 312%, 313%, 314%, 315%
   - Субконто1 = БанковскийСчет (тип Справочник.БанковскиеСчета)
   - Групування по БанковскийСчет + Счет
   - Вибираємо: Найменування банк.рахунку, Код рахунку

3. Серіалізація результату через ЗначениеВСтрокуВнутр

4. Відключення COM

5. Десеріалізація в поточній базі

6. Цикл по результату:
   - Знайти БанковскиеСчетаОрганизаций за найменуванням
   - Знайти/створити ПланСчетов.Хозрасчетный за кодом
   - Записати А_СчетБухгалтерский

7. Виведення статистики
```

## ОНОВЛЕННЯ СПРАВОЧНИКА

```1c
// Пошук банківського рахунку в ERP
БанкСчетERP = Справочники.БанковскиеСчетаОрганизаций.НайтиПоНаименованию(
    СокрЛП(БанкСчетНаименование), Истина);

Если НЕ ЗначениеЗаполнено(БанкСчетERP) Тогда
    Сообщить("Не знайдено: " + БанкСчетНаименование);
    Продолжить;
КонецЕсли;

// Пошук рахунку в плані рахунків ERP
СчетБухУчета = ПланыСчетов.Хозрасчетный.НайтиПоКоду(СокрЛП(СчетКод));

Если НЕ ЗначениеЗаполнено(СчетБухУчета) Тогда
    Сообщить("Рахунок не знайдено: " + СчетКод);
    Продолжить;
КонецЕсли;

// Оновлення справочника
СпрОбъект = БанкСчетERP.ПолучитьОбъект();
СпрОбъект.А_СчетБухгалтерский = СчетБухУчета;
СпрОбъект.ОбменДанными.Загрузка = Истина;
СпрОбъект.Записать();
```
