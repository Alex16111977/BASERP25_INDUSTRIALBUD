Движение по взаимозачет по балансу упр

Назначение

Обработка создает/обновляет документ Взаимозачет задолженности для компенсации разрыва управленческого баланса между подразделениями.

Управленческий баланс построен на принципе двойной записи по подразделениям: каждая операция должна иметь равные дебет и кредит в пределах каждого подразделения. Когда документ затрагивает два подразделения (перемещение товаров, списание и т.д.) — возникает разрыв. Баланс по организации в целом сходится, но в разрезе подразделений — нет.

Как использовать

  • Откройте обработку из формы документа-источника дисбаланса;
  • В поле Документ основание выберите документ, который разрывает баланс;
  • Нажмите кнопку Сформировать взаимозачет.

Принцип определения сторон

Дебитор (Контроль > 0, больше дебета) = Поставщик — получил актив, "задолжал".

Кредитор (Контроль < 0, больше кредита) = Клиент — отдал актив, ему "задолжали".

Принцип: кто получил (+) — тот "задолжал" (поставщик), кому отдали (-) — тому "задолжали" (клиент).

Примеры дисбаланса

  • ПеремещениеТоваров (КМД-2 → Глобино-2): Дебитор=Глобино-2 (Товары на оптовых складах), Кредитор=КМД-2 (Товары на оптовых складах);
  • СписаниеНедостачТоваров (Астарта.Тищенки): Дебитор=Астарта (Расходы текущего периода), Кредитор=ЦО (Товары на оптовых складах);
  • ПриобретениеТоваровУслуг (Логистика): Дебитор=ЦО (Товары на оптовых складах), Кредитор=Логистика (Выданные авансы);
  • СписаниеБезналичныхДС: Дебитор=Логистика (Выданные авансы), Кредитор=Администрация (Денежные средства безналичные).

Условия создания взаимозачета

  • В регистре ПрочиеАктивыПассивы есть движения по документу-основанию;
  • Баланс по организации сходится (сумма Контроль по всем подразделениям = 0);
  • Минимум 2 подразделения с дисбалансом.

Если баланс по организации не сходится — это другая проблема (ошибка проведения), взаимозачет между подразделениями не применим.

Заполняемые реквизиты

  • Дата — дата документа-основания;
  • Организация — из регистра ПрочиеАктивыПассивы;
  • ВидОперации — Произвольный взаимозачет;
  • КонтрагентДебитор / КонтрагентКредитор — контрагенты подразделений;
  • ТипДебитора = Поставщик; ТипКредитора = Клиент;
  • А_ДокументОснованиеДляБаланса — документ-источник дисбаланса;
  • А_СтатьяДисбалансаПоПодразделению — элемент справочника А_ДисбалансПоПодразделению (аналитика: на каких статьях рвется баланс).

Аналитика дисбаланса

Реквизит А_СтатьяДисбалансаПоПодразделению заполняется из справочника А_ДисбалансПоПодразделению. Элемент ищется по табличной части СтатьиБаланса (две статьи: дебитора и кредитора). Если не найден — создается автоматически. Это позволяет анализировать: на каких статьях актива/пассива рвется баланс по подразделениям.

Идемпотентность

При повторном запуске обработка находит существующий взаимозачет по реквизиту А_ДокументОснованиеДляБаланса, распроводит его, очищает табличные части, перезаполняет и проводит заново. Дубликаты не создаются.
