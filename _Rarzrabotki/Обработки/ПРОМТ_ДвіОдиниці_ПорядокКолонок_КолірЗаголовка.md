## 3. РЕАЛІЗАЦІЯ

### 3.1 Дані — нове поле `ЕдиницаСС` (спільне для всіх звітів/форми)

1. **`ПолучитьНормы`** (`ObjectModule.bsl`): у SELECT додати `К.Единица КАК ЕдиницаСС` і у GROUP додати `К.Единица`.
   У циклі побудови `НоменклаДані`: `НоменклаДані.Вставить(Стр.Номенклатура, Новый Структура("Эталон, Единица, ЕдиницаСС", Стр.ОбщееНазвание, Стр.Единица, Стр.ЕдиницаСС));`

2. **`ЗаполнитьАнализ`**: після `НоваяСтрока.Единица = Стр.Единица;` додати штамп одиниці норми:
   ```bsl
   ДаніНорми = Нормы.НоменклаДані.Получить(Стр.Номенклатура);
   Если ДаніНорми <> Неопределено Тогда
       НоваяСтрока.ЕдиницаСС = ДаніНорми.ЕдиницаСС;
   КонецЕсли;
   ```
   (Для субститутів `ДаніНорми = Неопределено` → ЕдиницаСС порожня.) Норм-картки без залишку вже проходять через `ЗаполнитьАнализ`
   (їх Стр.Номенклатура є в НоменклаДані) → ЕдиницаСС заповниться.
3. **Манифест** `Создания комплектаций для бух учета.xml`: у ТЧ `ТабличнаяЧастьОстатков` додати колонку `ЕдиницаСС`
   тип `CatalogRef.КлассификаторЕдиницИзмерения` (як існуюча `Единица`). Hand-uuid — УНІКАЛЬНИЙ (перевір існуючі:
   `grep -o 'uuid="[^"]*"'`; узяти вільний, напр. `a2000000-0000-4000-8000-000000000019`).
4. **Форм-VT** `Form.xml`: додати `<Column name="ЕдиницаСС" id="...">` тип `CatalogRef.КлассификаторЕдиницИзмерения` (клон Column `Единица`, вільний id).
5. **`ПрименитьОтборИИтоги`** (`Form/Module.bsl`): після `НС.Единица = Стр.Единица;` додати `НС.ЕдиницаСС = Стр.ЕдиницаСС;`.
6. **`ДанныеВТаблицуПланФакт`**: додати `ТЗ.Колонки.Добавить("ЕдиницаСС");` і у циклі `Н.ЕдиницаСС = Стр.ЕдиницаСС;`.

```bsl
// Скидає заливку/колір тексту шапки-заголовка СКД (щоб УО не фарбувало його янтарем).
Процедура СкинутиКолірЗаголовка(ТабДок, НазваЗвіту)
    Для р = 1 По Мин(8, ТабДок.ВысотаТаблицы) Цикл
        Для к = 1 По ТабДок.ШиринаТаблицы Цикл
            Если СтрНайти(Строка(ТабДок.Область(р, к, р, к).Текст), НазваЗвіту) > 0 Тогда
                Обл = ТабДок.Область(1, 1, р, ТабДок.ШиринаТаблицы);
                Обл.ЦветФона = Новый Цвет();   // авто/без заливки
                Обл.ЦветТекста = Новый Цвет();  // авто/чорний (жирність лишається)

            КонецЕсли;
        КонецЦикла;
    КонецЦикла;
КонецПроцедуры
```
