## Грабли, на которые уже наступили

- `РегистрНакопления.СебестоимостьТоваров` **не имеет измерения `Номенклатура`** —
  только `АналитикаУчетаНоменклатуры`. Путь: `СТ.АналитикаУчетаНоменклатуры.Номенклатура.<...>`.
- `erp.Дата(...)` через COM **не работает** (кириллица в dispatch) — использовать
  `datetime.datetime(...)` из Python.
- Факт материалов берётся ресурсом **`Стоимость` (с НДС)**. Менять на `СтоимостьБезНДС`
  запрещено — план в СС заведён с НДС.
- Колонка «вересень» в `МАТЕРИАЛИ.xlsx` — **артефакт формулы** (продублирован ПДВ серпня),
  реального плана сентября нет. Итоговые строки листа (175+) в парсинг не берём.
- В `Комплектующие` 346 из 354 строк **без ссылки на номенклатуру** — ОН берётся из
  ТЧ-реквизита `ОбщееНазвание`, ключ сверки с Excel — текстовый `НоменклатураСС`.
