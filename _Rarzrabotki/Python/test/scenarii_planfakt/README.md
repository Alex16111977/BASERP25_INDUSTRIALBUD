# Сценарии к «План Факт Производство» (оптимистичный / пессимистичный)

Собирает `План Факт Производство <дата> сценарии с примечаниями.xlsx` по образцу
`18092026\План Факт Производство 18-09-2026 новый_исправленный.xls`: колонки A–O — выгрузка казны без изменений,
P–W — сценарии с живыми формулами, низ — Ф1/Ф2/ФА, Free CF, Fix Ф1, остаток и три вывода. Каждая ячейка сценариев
имеет примечание Excel «почему здесь эта цифра», колонка X — краткий источник по строке.

Правила (разбор отчёта 18.09, `18092026\Стенограмма объяснения отчета.txt`, `Записка по сценариям и лимитам`):
- **оптимистичный** — «ИТОГО сумма к получению» (кол. K) финотчёта: подписанные долги + поданные, но не
  подписанные / не проведённые акты; плюс ожидаемые по договору платежи;
- **пессимистичный** — только подписанные акты с неоплаченным остатком (формула K договора с H = 0) и подтверждённые
  платежи;
- лимит = max(0; поступления − недобор маржи) при наличии поступлений; доп. маржа = поступления − лимит
  («МД ООН 2026»: ещё − потребность, аванс получен ранее);
- Free CF = Σ доп. маржи + Ф1 + ФА; остаток = Free CF − Fix Ф1.

Запуск из этой папки (входные — финотчёт с расшифровкой и план-факт казны в папке недели, пути в `fo_docs.py`,
`fo_contracts.py`, `fo_pess.py`, `build_scen.py`):

```
C:\Python313\python.exe -B fo_contracts.py
C:\Python313\python.exe -B fo_pess.py
C:\Python313\python.exe -B build_scen.py
```

(словарь `inp`, константы `F1, F2, FA, FIX`) и тексты примечаний — в `scen_notes.py` (`MANUAL`, `PESS_MANUAL`).
