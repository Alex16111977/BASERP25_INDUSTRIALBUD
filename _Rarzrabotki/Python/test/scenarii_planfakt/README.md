# Сценарии к «План Факт Производство» (оптимистичный / пессимистичный)

Собирает `План Факт Производство <дата> сценарии.xlsx` по образцу
`18092026\План Факт Производство 18-09-2026 новый_исправленный.xls`: колонки A–O — выгрузка казны без изменений,
P–W — сценарии с живыми формулами (нижний раздел Ф1/Ф2/ФА, Free CF и выводов с 09.10 не выводится). Каждая ячейка сценариев
имеет примечание Excel «почему здесь эта цифра», колонка X — краткий источник по строке.

Правила (разбор отчёта 18.09, `18092026\Стенограмма объяснения отчета.txt`, `Записка по сценариям и лимитам`):
- **оптимистичный** — «ИТОГО сумма к получению» (кол. K) финотчёта: подписанные долги + поданные, но не
  подписанные / не проведённые акты; плюс ожидаемые по договору платежи;
- **пессимистичный** — только подписанные документы: акты «оригинал получен» с неоплаченным остатком, срок оплаты
  которых по договору прошёл или наступает до конца месяца (можем требовать платёж; срок — кол. M финотчёта, условие —
  кол. N строки договора). Платежи без документов (гарантийный, план поступлений) не ставим;
- лимит = max(0; поступления − недобор маржи) при наличии поступлений; доп. маржа = поступления − лимит
  («МД ООН 2026»: ещё − потребность, аванс получен ранее);

Запуск из этой папки (входные — финотчёт с расшифровкой и план-факт казны в папке недели; пути и даты
`DATA_OTCHETA`/`KONEC_MESYACA` — в `fo_docs.py`, папка недели — в `build_scen.py`):

```
C:\Python313\python.exe -B fo_docs.py      # проверка: акты, сроки оплаты, суммы сценариев по объектам
C:\Python313\python.exe -B build_scen.py   # сборка xlsx
```

Ручные решения по объектам (поступления без документов, гарантийные, Ф1/Ф2/ФА/Fix, потребность) — в `build_scen.py`
(словарь `inp`) и тексты примечаний — в `scen_notes.py` (`MANUAL`, `PESS_MANUAL`).
Решения 09.10: ООН 2025 гарантийный платёж — только оптимистичный; потребность производство не дало — пусто;
пессимистичный — только подписанные документы с наступившим сроком оплаты (комментарий к каждому акту).
