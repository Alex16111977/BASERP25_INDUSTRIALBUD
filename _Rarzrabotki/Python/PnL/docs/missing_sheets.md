# Инвентаризация подразделений 1С ↔ листов Excel (1.4)

**Дата**: 2026-04-17
**Период**: декабрь 2025
**Источник**: АДР (РегистрНакопления.ПрочиеРасходы + ПрочиеДоходы) + `data/json/01_raw_sheets.json` + `data/json/07_mapping_sheet_to_struct.json`

## Резюме

- **78 подразделений** имеют ненулевые обороты в АДР декабрь 2025.
- **12 листов Excel** замаппировано в 1С-подразделения (+ 1 unmapped).
- **Техника** отфильтрована `SUMMARY_SHEET_PATTERNS` и не парсится.
- **~60+ подразделений** в 1С не имеют листа в Excel.
