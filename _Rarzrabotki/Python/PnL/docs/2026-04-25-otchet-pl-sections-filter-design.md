# А_ОтчетPL — фільтр розділів через Multi-select параметр

**Дата:** 2026-04-25
**Статус:** узгоджено з фінансистом

## Context

Звіт `А_ОтчетPL` зараз завжди повертає **усі 7 блоків** через UNION ALL (PL + ЕРП-ПоPL + ЕРП-БезPL + Казна-ПоPL + Казна-БезPL). Коли фінансист знімає галочку «СуммаДДСизКазныОборот» у налаштуваннях полів, СКД лише ховає колонки — рядки лишаються. У drill-down документа це створює «пусті» рядки контрагентів з нулями (Касса-обіги без PL/ЕРП-сум).

## Рішення (multi-select)

Додаємо СКД-параметр `Розділи` тип `СписокЗначений(Строка)`. Default — усі 3 значення: `"PL"`, `"ЕРП"`, `"Казна"`.

У запиті — фільтр у фінальному UNION ALL для відповідних блоків через 3 boolean-параметри запиту:

```sql
ВЫБРАТЬ * ИЗ втPL_Строки      ГДЕ &ПоказPL
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ * ИЗ втЕРП_ПоPL_Расх  ГДЕ &ПоказЕРП
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ * ИЗ втЕРП_ПоPL_Доходы ГДЕ &ПоказЕРП
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ * ИЗ втЕРП_БезPL_Расх ГДЕ &ПоказЕРП
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ * ИЗ втЕРП_БезPL_Доход ГДЕ &ПоказЕРП
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ * ИЗ втКазна_ПоPL    ГДЕ &ПоказКазна
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ * ИЗ втКазна_БезPL   ГДЕ &ПоказКазна
```

У `ПриКомпоновкеРезультата`:
```bsl
ПарРозділи = КомпоновкаДанныхКлиентСервер.ПолучитьПараметр(КомпоновщикНастроек, "Розділи").Значение;
показPL    = ?(ПарРозділи <> Неопределено, ПарРозділи.НайтиПоЗначению("PL")    <> Неопределено, Истина);
показЕРП   = ?(ПарРозділи <> Неопределено, ПарРозділи.НайтиПоЗначению("ЕРП")   <> Неопределено, Истина);
показКазна = ?(ПарРозділи <> Неопределено, ПарРозділи.НайтиПоЗначению("Казна") <> Неопределено, Истина);

ТаблицаДанных = ПолучитьОбъединенныеДанные(НачалоПериода, КонецПериода, ВключатьДочерние, показPL, показЕРП, показКазна);
```

## Тести (per Rule #4 — спочатку Python, потім .bsl)

**Baseline (поточний стан):**
- `test_otchet_pl_sections.py --baseline` — викликає звіт без нового параметра, фіксує:
  - кількість рядків у Casa-блоці (де `СуммаДДСизКазныРасход + СуммаДДСизКазныПриход <> 0`)
  - кількість рядків у ЕРП-блоці (де `СуммаЕРП <> 0`)
  - кількість рядків у PL-блоці (де `СуммаPL <> 0`)
  - сумарна `СуммаЕРП` по Глобино-2 = 50 884 827.10 (з попереднього тесту)
  - сумарна `СуммаPL` по Глобино-2 = 71 436 211.28

**Після правок (4 сценарії):**
| # | Параметр Розділи | Очікувано |
|---|---|---|
| 1 | `("PL", "ЕРП", "Казна")` (default) | те саме що baseline |
| 2 | `("PL",)` | 0 ЕРП-рядків + 0 Casa-рядків |
| 3 | `("PL", "ЕРП")` (use case користувача) | 0 Casa-рядків + PL/ЕРП-суми НЕ змінюються |
| 4 | `("Казна",)` | тільки Casa-рядки, 0 PL/ЕРП-сум |

- [ ] Baseline тест PASS на поточному .bsl.
