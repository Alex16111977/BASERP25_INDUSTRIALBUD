## Документ А_ВыполнениеРаботМодулей — модель (соблюдать строго)

- Документ = СНИМОК НАКОПЛЕННЫХ процентов на дату (не дельта!). Каждый лист Excel — полный снимок.
- Шапка: Организация (req), СтруктураСебестоимости (req), Подразделение (авто из СС),
  КоличествоМодулей (авто из СС.А_КоличествоМодулей, 0→1), Ответственный, Комментарий.
- ТЧ `Работы` нормализована: строка = Работа(Номенклатура) × НомерМодуля;
  ПланЧасыМодуля = СС.Работы.Количество(по работе) / КоличествоМодулей;
  Процент = накопленный % модуля; ЧасыВыполнение = ПланЧасыМодуля × Процент/100.
  Писать ВСЕ клетки 1..N (включая нули).
- Проведение (уже реализовано в модуле документа): РН = дельта против предыдущего снимка
  (срез РС по Границе), РС = снимок %. Проводить документы СТРОГО в хронологическом порядке
  (19.06 → 26.06 → 03.07), иначе предупреждения о поздних снимках.

## Excel — структура (проверено)

- Листы снимков: `ЗВіт (19.06)`, `ЗВіт (26.06)`, `ЗВіт (03.07)` (+ `Зразок`, текущий `ЗВіт` — не грузить по умолчанию).
- Колонка A = наименование работы (сопоставлять с СС.Работы по наименованию, нормализуя
  пробелы/апострофы); колонка G = «Факт виконання робіт по проекту»: текст вида
  `«5 модулів --100%;1 модуль --50% 2 модулі --30%»` — сегменты заполняют модули
  последовательно М1..М8; `«0%»` без числа модулей = все нули; нераспознанное
  («в роботі», «не ставляться», пусто) = нули. Регэксп-эталон — в `test_vrm_e2e.py`
  (функция `парс_проценты`).
- Дата документа = дата из имени листа `ЗВіт (dd.mm)` + год (параметр формы, по умолчанию 2026),
  время — параметр формы (по умолчанию 9:00, как в BaseERP).

## Доработка (сделать)

1. Новый режим в обработке (вкладка/страница «Загрузка выполнения»):
   - реквизиты: ИмяФайла, СтруктураСебестоимости, Год (2026), ВремяДокумента (9:00),
     флаг «Проводить»; таблица предпросмотра листов (лист → дата → строк распознано);
   - кнопка «Загрузить выполнение»: для каждого листа `ЗВіт (dd.mm)` по возрастанию даты —
     get-or-create документа (поиск по СтруктураСебестоимости + Дата), перезаполнение ТЧ,
     запись с проведением (если флаг); протокол в сообщения (лист → документ, строк, EV-часов).
2. Перед созданием документов: если `СС.А_КоличествоМодулей = 0` — установить 8
   (значение — параметр формы «Количество модулей», по умолчанию 8) и записать СС
   (с сообщением в протокол). Без этого не грузить.
3. Работы листа, не найденные в СС.Работы, — в протокол (пропустить; НЕ создавать работы
   в этом режиме).
4. Идемпотентность: повторный запуск обновляет те же документы (по СС+дате), не плодит новые.
5. Существующий режим загрузки работ в СС — не трогать.
