# 02. СКД, вариант PL_Отчет, форма листа

## СКД (ОсновнаяСхемаКомпоновкиДанных)

Один набор данных **«Данные»** типа DataSetObject (внешний: ТаблицаДанных из
модуля, запрос в СКД отсутствует). **37 полей**, ключевые:

| Поле | Смысл |
|---|---|
| СтрокаЛиста / СортЛиста | строка Excel-листа (группа затрат или показатель водопада) и её порядок |
| СтатьяPL / Группа | статья `Справочник.А_Статьи_PL` и её группа `А_ГруппаСтатей_PL` |
| СтатьяPLРус / ГруппаРус | русские представления (реквизит НаименованиеДляОтчетаНаРусском) |
| КолонкаСорт / КолонкаPL / ВидКолонки | ось колонок: ГГГГММ месяцев → 890000 «PL с начала года» → 900000 «Накопительный PL» → 900100 «План итого» |
| СуммаФ1 / СуммаФ2 / СуммаИтого | факт: Форма 1 (безнал/начисления) / Форма 2 (касса) / итого |
| ВидСтроки | «Статья» / «Показатель» / «ПоказательПроцент» / служебные |
| СуммаСтатья / Знаменатель | числитель и знаменатель строк-показателей водопада |
| БазаПроцента | база «% суммы затрат» (константа колонки, см. ниже) |
| Подразделение / НаправлениеДеятельности / ПодразделениеСтрока | разрез объекта |
| Документ / Контрагент / Аналитика / Аналитика1 / Комментарий | расшифровка строки |
| ФиксФ1 / ФиксФ2 / ФиксИтого / Отклонение / ВыполнениеНормы | разрез фиксов (норма постоянных затрат) |
| ИсточникиФакта / ДокументыПо / ЕРПС / НакопительноС / ПланАктуаленНа | служебное раскрытие источников |
| ПоказыватьСтатью | флаг отбора строк статей в варианте |

Вычисляемые поля: **Процент, Отклонение, ВыполнениеНормы**. Ресурсов 19 —
суммы, `Максимум(БазаПроцента)`, `Максимум(СортЛиста)`, представления.
Формулы ресурсов Ф1/Ф2/Итого различают ВидСтроки: у «ПоказательПроцент» выводят
`Сумма(числителя)/Сумма(Знаменатель)` строкой с «%», у «Показатель» — сумму
только показательных строк, иначе обычную сумму.

**14 параметров**: Период (СтандартныйПериод), СводыНаправлений,
ПоказИтогиПрибыли, ПоказатьСлужебныеСтроки, ПолныйШаблон, НачалоПериода,
КонецПериода (служебные), ВыводитьМесяцы, ВыводитьСНачалаГода (дефолт Ложь),
ВыводитьНакопительный, ВыводитьПлан, ВыводитьФиксы, ТолькоСтатьиСФиксами,
НазванияНаРусском. Снятый флажок блока = колонки нет вовсе (данные не читаются).

## Вариант PL_Отчет — единственный предопределённый (с 01.09.2026)

Прежние предопределённые (PL_Объект/PL_СводНаправления/PL_Фиксы) удалены
финансистом. Структура PL_Отчет «Отчет PL (месяц, накопительно)»:

- Таблица: **строки** СтрокаЛиста → СтатьяPL, **колонки** КолонкаСорт.
- Отбор строк статей: ПоказыватьСтатью = Истина И (СуммаФ1 заполнена ИЛИ
  СуммаФ2 заполнена); сортировка СтатьяPL.Сорт.
- Параметры по умолчанию: СводыНаправлений=Ложь, ПоказИтогиПрибыли=Истина,
  ПоказатьСлужебныеСтроки=Ложь, ПолныйШаблон=Истина, ВыводитьМесяцы=Истина,
  СНачалаГода=Ложь, Накопительный=Истина, План=Ложь, Фиксы=Ложь,
  ТолькоСтатьиСФиксами=Ложь, НазванияНаРусском=Истина.
- Оформление: макет Sea; шапки колонок #D9D9D9; показатели водопада #BDD7EE
  (жирный, вправо); %-строки #C6E0B4; заголовок/параметры/отбор не выводятся.

**Пользовательские варианты** живут в `Справочник.ВариантыОтчетов` (привязка
через `Справочник.ИдентификаторыОбъектовМетаданных`,
ПолноеИмя = «Отчет.А_ОтчетPL_ПолныйЕРП_Остатки») — 19 штук, перенесены
01.09.2026 копированием с одноимённого отчёта без суффикса («P&L: Месяц, PL
накопительный», «1.P&L …» по направлениям и т.д.). Переносить варианты между
отчётами — только копированием элементов справочника (Скопировать() + подмена
реквизита Отчет); загрузка настроек из XML-файла через диалог падает XDTO-ошибкой
«Отсутствует отображение для типа CatalogRef.СтруктураПредприятия» — ограничение
диалога, файл не виноват.

## Форма листа (водопад строк, снизу вверх по СортЛиста)

Операционный доход → Себестоимость проданной продукции → Дополнительные расходы
→ **Маржинальный доход, грн/%** → Общепроизводственные затраты → Маркетинговые
затраты → Административные затраты → **EBITDA, грн/%** → Амортизация (статья
000000068, вынута из ОПЗ, сорт 115) → **EBIT / Операционный доход, грн/%** →
**Финансовая деятельность** (НЕТТО: финдоходы − финрасходы; минус легален) →
Налоги и сборы (включая налог на прибыль 000000057, вынесен из финдеятельности)
→ **Чистый доход** → **Чистый доход, %** (= Чистый/ОД). Строк «Дивиденды» и
«Прибыль в распоряжении компании» нет. %-строки водопада считаются от ОД той же
колонки. При НазванияНаРусском=Ложь тексты: «EBIT / Операционная прибыль…»,
«Рентабельность продукции, %».

## «% суммы затрат в общем объеме» (v13, 01.09.2026)

Доля статьи в «Итого затрат» ТОЙ ЖЕ колонки. Состав базы: СС + ДР + ОПЗ +
Амортизация + МЗ + АЗ + Налоги и сборы + 3 финрасхода + налог на прибыль
(доходы и финдоход НЕ входят). Сумма затратных статей = 100%.

Механика: модуль читает отбор компоновщика (`МножествоПодразделенийОтбора` —
поля Подразделение и НаправлениеДеятельности; Равно/ВСписке точно,
В(Списке)ПоИерархии группами, НеВ* — исключения; запрос по СтруктураПредприятия
с булевым `&ЕстьВключающие`) и пишет ВСЕМ строкам колонки ЕДИНУЮ базу
(`БазыЗатратПоОтбору` суммирует «Итого затрат» пар из «Итоги» по попавшим в отбор
подразделениям). Формула СКД `Максимум(БазаПроцента)` по константе колонки
корректна на любом уровне группировок. Строкам группы ОД (код 000000006) база
не пишется → их процент пуст (NULL).

⚠ Не переносить знаменатель в СКД: `Вычислить(...,"ОбщийИтог")` в кросс-таблице
смешивает ОБЕ оси (знаменатель по всем колонкам), а имя поля («КолонкаСорт»)
как группировка в `Вычислить` не резолвится.

## Аналитика ЕРП-строк (месяцы после границы 30.06.2026; поле Аналитика)

CASE по типу регистратора в втЕРП_Расх_Детали (обе копии — ВЫБРАТЬ и
СГРУППИРОВАТЬ ПО): ПТУ, СписаниеБезнал, АктВыполненныхРабот, ВозвратПоставщику,
ПКО, ПоступлениеБезнал, ВозвратОтКлиента → Контрагент; АвансовыйОтчет →
ПодотчетноеЛицо; ОтражениеЗарплатыВФинУчете → А_ФизическоеЛицо; РКО с операцией
«Прочая выдача ДС» и непустым комментарием → ВЫРАЗИТЬ(Комментарий, Строка(200)),
иначе Контрагент; СписаниеНедостачТоваров, ВнутреннееПотреблениеТоваров,
ПрочиеДоходыРасходы → комментарий; АмортизацияОС → Р.АналитикаРасходов
(карточка Справочник.ОбъектыЭксплуатации; строка статьи дробится на карточки).
Поле составное (ссылки + строки); безлимитные строки — только через ВЫРАЗИТЬ.

## Жёстко русский язык

Месяцы: `Формат(ТекМесяц, "Л=ru_RU; ДФ='MMMM yyyy'")` — не зависит от языка
сеанса/сервера. НСтр не используется (обычные литералы). Служебная шапка
(«Параметри:», «Так/Ні», виды сравнения, украинские месяцы) дочищается экспортной
`РусифицироватьСлужебныеТексты(ТабДок)` после вывода (только строки до заголовка
«Статья PL», данные не трогает).
