# KNOWLEDGE MAP — Отчет.А_ОтчетPL_ПолныйЕРП_Остатки

Entry-point. **Прочитать первым.** База знаний самодостаточна.

## Что это

Конфигурационный отчёт **«PL по объекту (остатки): фикс накопительных из документа
остатков»** (BaseERP, BAS ERP 2.5 INDUSTRIALBUD). Строит PL в форме Excel-листа
«!PL по компании»: строки — статьи PL в водопаде прибыли, колонки — месяцы периода
и накопительные показатели. Существует также как внешний
`_Rarzrabotki/Отчеты/А_ОтчетPL_ПолныйЕРП_Остатки.erf` (те же исходники).

Ключевое отличие от «обычного» PL-отчёта: **накопительные колонки СТРОГО зафиксированы
документами остатков** — история до точки фиксации не пересчитывается из документов,
а берётся из регистра остатков.

## 🔴 Закон источника факта (решение финансиста 02.09.2026, исключений нет)

Граница — **константа** `ГраницаОстатков() = 30.06.2026 23:59:59` в модуле отчёта.
Документы `А_ОтчетPL` и `А_ВводОстатковОтчетаPL` больше не загружаются: остатки разовые.

| Колонка | Месяцы ≤ 30.06.2026 | Месяцы ≥ 01.07.2026 |
|---|---|---|
| Месячные | `Документ.А_ОтчетPL` (слой = `ВключатьДочерние`) | ТОЛЬКО регистры ЕРП (ПрочиеРасходы, ВыручкаИСебестоимостьПродаж, ПрочиеДоходы) |
| «PL с начала года» (890000) | РН `А_ОстаткиОтчетаPL`, `…СНачалаГода` (только если год границы = год конца периода) | + ЕРП за ВСЕ месяцы от 01.07.2026 по конец периода, включая месяцы вне периода |
| «Накопительный PL» (900000) | РН `А_ОстаткиОтчетаPL`, `…Накопительно` | + те же ЕРП |
| «План итого» (900100) | `Документ.А_БюджетМесяц` (ВидПериода = Объект) | |

Документы `А_ОтчетPL` с датой после границы не читаются никуда. Внутри месяца источники не смешиваются.
Период целиком до границы: накопительные = остатки на 30.06.2026 как есть.
Точка фиксации: 30.06.2026 23:59:59 (по-листово, 30 документов + 2 копии объектного слоя для Спецтехники/ЦО).

## 🔴 Критические инварианты — НЕ МЕНЯТЬ

1. Закон источника выше. Документы `А_ОтчетPL`/`А_ВводОстатковОтчетаPL` заморожены:
   дыры после 30.06.2026 не бывает (ЕРП), дыры до границы не чинятся.
2. Слои НЕ складывать: параметр `СводыНаправлений` выбирает слой —
   Ложь = объектные документы (`ВключатьДочерние = Ложь`) и объектный слой
   регистра остатков; Истина = свод-документы корней направлений и свод-слой
   остатков. Свод корня ≠ сумма его объектов (свод-доки содержат закрытые
   объекты, у которых нет объектных строк).
3. Граница — константа в модуле (`ГраницаОстатков()`), документом не вычисляется;
   параметров `ПоследнийМесяц`/`МесяцОстатков` в запросе нет.
4. База «% суммы затрат» — единая на колонку по отбору компоновщика (см. 02),
   формулу СКД `Максимум(БазаПроцента)` не менять.
5. Опечатка `СуммаФома1` в ТЧ `Документ.А_ОтчетPL.ДанныеОтчета` — историческая,
   НЕ чинить (ключ совместимости запроса).
6. Статья «Дивиденды» (код 000000058) исключена из вывода и из базы процента.
7. Спецтехника и ЦО представлены в ОБОИХ слоях остатков (объектный слой — копии
   документов №32/№33, 02.09.2026): в объектном режиме январь–июнь по ним пустые,
   накопительные = копия остатков + ЕРП с 01.07.2026. Исключений в коде отчёта нет.
