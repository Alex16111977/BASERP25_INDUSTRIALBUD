## Задача

Полная доработка двух форм документа `А_ТабельУчетаРабочегоВремени` (табель учёта рабочего времени):

1. **ФормаСписка** — починить пустую командную панель, подключить БСП-меню, добавить быстрые отборы.
2. **ФормаДокумента** — типовое «единое окно» (ПодключаемыеКоманды: Печать / Отчёты / Создать на основании).
3. **Module.bsl формы документа** — рефакторинг по стандартам BSL **без изменения поведения**.
4. **Оптимизация** — убрать серверные вызовы из интерактивных событий таблицы.

Работа разбита на 4 этапа, каждый завершается гейтом проверки. Не переходить к следующему этапу, пока гейт текущего не пройден.

## Поведение-инвариант (проверяется на этапе 5)

1. При создании нового документа: Дата = текущая, НачДата = начало месяца, КонДата = конец месяца.
2. Смена Дата/НачДата/КонДата перестраивает заголовки и видимость колонок дней (видимы только дни периода, остальные скрыты; период > 31 дня — сообщение «Некорректный период табеля, больше месяца»).
3. В колонку дня можно ввести только: пусто, цифры, О, В, Н, Б, Д, К, С — иначе предупреждение «Можно вносить только О, Б, Н, В, Д, К, С, 8» и очистка значения.
4. Изменение часов пересчитывает `ВсегоЧасов` и `ВсегоГрн` (= Ставка × ИтогоЧасов − ФОТ); по плановой таблице — `ВсегоЧасовПлан`.
5. Без роли ПолныеПрава: шапка (БригадаСпр, Подразделение, НачДата, КонДата — если заполнены) только-просмотр; колонки `Ставка`, `ФОТ`, `ВсегоГрн` скрыты; прошлые дни только-просмотр; добавление/удаление строк запрещено.
6. Колонки оборудования (`ЧетвертыйВидВремениN`) видимы только если у Подразделения или БригадыСпр включено `ИспользоватьОборудование`.
7. `ДатыЗапретаИзменения` продолжают работать при чтении.

## Известные грабли (из памяти проекта)

1. **form-validate** может ругаться `attribute '~Список' not found` на колонках динамического списка — это ЛОЖНОЕ срабатывание (платформа такие формы принимает, в конфигурации 48 таких форм). Игнорировать, только если все ошибки такого вида.
2. **Partial-load модуля формы**: в `/db-load-xml` передавать корневой дескриптор `ФормаДокумента.xml` / `ФормаСписка.xml`, не файлы Ext/.
3. **Dangling-обработчики**: в формах проекта уже ловили `<Event>` без процедур в модуле — после правок сверять Events ↔ модуль (PowerShell: выбрать `Event name=...>значение<` из Form.xml и `Процедура <Имя>` из Module.bsl, сравнить множества).
4. **Designer кэширует BSL**: просто `cp` в основной каталог недостаточно — обязательно `/db-load-xml -Mode Partial` (сам обновит ConfigDumpInfo) + `/db-update`.
5. **`Ссылка` — зарезервированное имя**: не объявлять локальных переменных `Ссылка` в BSL.
6. **«Выполнить» — зарезервированное имя процедуры**: не называть так процедуры.
7. В COM/Python тестах кириллические имена методов могут не резолвиться — `erp.String(...)`, `erp.XMLСтрока(...)` по паттернам из `_Rarzrabotki/Python/test/`.
