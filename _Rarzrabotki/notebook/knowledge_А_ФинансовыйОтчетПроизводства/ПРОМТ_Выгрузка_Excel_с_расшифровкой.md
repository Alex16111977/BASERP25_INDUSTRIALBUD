## Задача

Кнопка «Зберегти в Excel» сейчас выгружает только **уровень договора**: документы видны лишь в примечаниях
к E/F/H. Нужно **два варианта выгрузки** из одного документа — так же, как уже есть два варианта печати:

| Вариант | Что в файле |
|---|---|
| **Звіт** (как сейчас) | объект → сумма → договоры → «Итого»; документы — в примечаниях |
| **Звіт з розшифровкою до документів** | то же + **под каждым договором строки его документов** (акты с «Оригінал», оплаты, поданные и непроведённые акты), свёрнутые группировкой: директор видит договоры, «+» раскрывает документы |

## Как сейчас реализовано (опора)

**Печать — два варианта из одной функции.** Форма:

```bsl
&НаКлиенте
Процедура ПечатьОтчетРасшифровка(Команда)
	Если НЕ ЕстьРезультатДляПечати() Тогда
		Возврат;
	КонецЕсли;
	ПоказатьПечатнуюФорму(ПолучитьПечатнуюФорму("Расшифровка"),
		"Фінансовий звіт виробництва з розшифровкою");
КонецПроцедуры
```

Модуль объекта: `СформироватьПечатьОтчет()` и `СформироватьПечатьОтчетРасшифровка()` оба вызывают
`СформироватьТабличныйОтчет(СРасшифровкой)`. При `СРасшифровкой = Истина` под договором
`ВывестиДокументыДоговора(ТабДок, СтрокаДоговора)`: строки `РасшифровкаДокументов` с отбором
Подразделение + Договор, сортировка по дате и имени, в колонках — E = `СуммаДт` для проведённого с
«Оригінал», F = `СуммаКт`, H = `СуммаДт` остальных; непроведённые — «(не проведено)» коричневым;
уровень группировки 4 (Підрозділ 1 → Контрагент 2 → Договор 3 → документы 4); `Расшифровка` ячейки =
документ (клик открывает).

**Excel — своя модель + свой OOXML-писатель:**
- `ДвоичныеДанныеExcel()` (экспорт) → `МодельКнигиExcel()` → **модуль менеджера** `ДвоичныеДанныеКнигиExcel(Модель)`.
- Блок подразделения — `ДобавитьБлокМодели(Модель, Подразделение, Договоры, КартаПараметров, ТаблицаПН)`:
  объект (ссылки на строку суммы) → строка суммы (`SUM(первый договор:последний)`) → договоры (уровень 1) →
  «Итого» → пустая.
- Строка договора: C, D, E, F, H — значения; G, I, J, K — формулы (`ФормулаКолонкиДоговора`) с кешем значения.
- Примечания: A — `ТекстУсловийДоговора`, E/F/H — `ПримечанияДоговора` (документы + ПН + сроки),
  строка объекта — `ТекстПланФактаКазны`.
- Готовые помощники для строк документов: `ДокументДляПримечания` (вид + номер, по-русски),
  `ТекстПНАкта` / `СтатусПН` (ПН и регистрация в ЄРПН), `НеоплаченныеОстаткиАктов` (FIFO оплат),
  `СтрокаСрокаОплаты` («оплата до» / «просрочено N дн.»), `ДанныеПНДоговоров`.
- Писатель: `outlineLevel` строки из модели; ⚠ `sheetFormatPr outlineLevelRow="1"` и
  `outlinePr summaryBelow="1"` сейчас зашиты константами; признаков `collapsed` нет.

## Что сделать

### 1. Команды
- На форме: «Зберегти в Excel» → **подменю «Зберегти в Excel ▾»** с двумя пунктами: «Звіт» и «Звіт з розшифровкою
  до документів». Паттерн сохранения — как `СохранитьExcel` / `ПолучитьАдресExcel`, параметр варианта передаётся
  на сервер. Имя файла второго варианта: «Финансовый_отчет Производства дд-мм-гггг с расшифровкой.xlsx».
- В модуле объекта: `ДвоичныеДанныеExcel(СРасшифровкой = Ложь) Экспорт` → `МодельКнигиExcel(СРасшифровкой)`.
  Вариант без расшифровки должен остаться **байт-в-байт по содержанию** прежним (регрессия).

### 2. Строки документов в модели
Под каждой строкой договора (только в варианте с расшифровкой) — строки `РасшифровкаДокументов` этого договора
(отбор Подразделение + Договор, сортировка по дате, затем по номеру):

| Колонка | Строка документа |
|---|---|
| A | `ДокументДляПримечания(Документ) + " от " + дата` (по-русски, как в примечаниях) |
| B | статус: «оригинал получен дд.мм» / «не подписан» / «не проведён»; для оплаты — подразделение казны |
| E / F / H | сумма в той колонке, где документ учтён (как в `ВывестиДокументыДоговора`) |
| C, D, G, I, J, K | пусто |
| L (новая, только в этом варианте) | ПН акта и статус регистрации (`ТекстПНАкта` без префикса «; ») |
| M (новая, только в этом варианте) | срок оплаты: «оплата до …» / «просрочено N дн.» (для договоров со сроком) |

- Уровень группировки документов — **2** (договоры 1); по умолчанию документы **свёрнуты** (строки скрыты).
- Стиль строк документа — новый в `ТекстСтилейКниги`: Arial 8, курсив или серый шрифт, без заливки, формат чисел
  как у договора (нули пустые). Непроведённые — коричневый шрифт (как в печати).
- **Формулы договора в варианте с расшифровкой (решить при реализации, рекомендация):** E/F/H строки договора =
  `SUM(E<первый документ>:E<последний>)` с кешем значения документа — тогда правка суммы документа в Excel
  пересчитывает договор, блок и K. Если у договора нет документов (статус «Всегда» без движения) — значения как сейчас.
- Примечания E/F/H на строке договора в варианте с расшифровкой **не дублировать** (документы и так видны).
  Примечание условий договора (A) и план-факт казны (строка объекта) — оставить.

### 3. Писатель xlsx (модуль менеджера)
- `outlineLevelRow` = максимальный уровень из модели (не константа 1).
- Свёрнутые группы: скрытые строки документов (`hidden="1"` + `outlineLevel="2"`) и признак `collapsed="1"` на строке,
  к которой относится кнопка группы. ⚠ Сейчас `summaryBelow="1"` (как у директора: «Итого» ниже договоров), а
  строка договора стоит **над** своими документами — проверить в Excel, где встаёт кнопка «+» для уровня 2, и при
  необходимости перейти на `summaryBelow="0"` (кнопка у строки договора) только в варианте с расшифровкой.
  Выбор подтвердить открытием файла в Excel.
- Колонки L, M — ширины в модели (например 40 и 28), только в варианте с расшифровкой; шапка L4:M5 — «ПН / ЄРПН»,
  «Срок оплаты».
- Лимит Excel на высоту строки (409 pt) и длину текста ячейки (32 767) — соблюдать при длинных названиях.

### 4. Не делать
- Не менять расчёт документа, `Расчет`, `РасшифровкаДокументов` и печатные формы.
- Не возвращать документы в примечания варианта с расшифровкой.
- Не трогать вариант без расшифровки (кроме рефакторинга общих частей без изменения результата).
