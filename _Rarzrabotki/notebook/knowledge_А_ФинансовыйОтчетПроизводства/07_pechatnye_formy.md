# 07. Печатные формы

Три выхода: табличный документ «Фінансовий звіт виробництва», табличный документ «Доповідь»
и HTML-текст доклада для сохранения в файл. Все — **программные `ТабличныйДокумент`**,
без макетов: макет не даёт двухэтажную шапку с переменным числом строк-подразделений.

## Финансовый отчёт

11 колонок, иерархия строк, итоговая строка. Ширины из Excel: A=45, B=48, C=18,5, G=20,3,
H=18,5, I=18,5.

⚠ **`ШиринаКолонки` ставится только на НЕобъединённой строке.** Для этого выделена пустая
строка 3 — она же служит разделителем между шапкой и таблицей. На объединённой области
платформа ширину игнорирует.

### Шапка

С 14.08.2026 — **русская двухэтажная**, 1:1 с Excel (строки 4–5 печати; заливка `#C6D9A0`,
жирный, центр, перенос по словам). Реализация: `ВывестиЗаголовкиКолонокОтчета()` +
`ОформитьЯчейкуШапки()`. Не переводить на украинский — заказчик сверяет с Excel.

Объединения эталона: `B4:B5`, `C4:C5`, `D4:D5`, `I4:I5`, `J4:J5`, `K4:K5` — вертикальные;
`E4:G4` — горизонтальное. **A и H не объединены** — два этажа с разным текстом
(«Контрагент» / «Договор», «Поданные акты на рассмотрении» / «Акты поданные на Заказчика»).

Текст брать дословно, **включая опечатку «незарегестрированного»** — директор сверяет глазами.

### Строки

Строка подразделения (жирная, светло-зелёная заливка) и подрядки контрагентов из свёртки
расшифровки. У строк с ручными корректировками ставилось примечание ячейки — уйдёт вместе
с ТЧ ([06](06_korrektirovki_isklyucheniya.md)).

Отрицательные числа красятся `Новый Цвет(160, 0, 0)`. Формат чисел в таблице —
`"ЧДЦ=2; ЧРГ=' '; ЧН="`: пустой ноль здесь намеренный, таблица чище.

⚠ В **текстах сообщений** наоборот нужен `ЧН=0,00`, иначе нули печатаются пустотой
([LESSONS §11](LESSONS.md)).

## Доклад

Шпаргалка для зачитывания на совещании: фраза по каждому объекту, затем сводная таблица
из пяти колонок, затем блок замечаний.

Фразы строит `МассивФразДоклада()`. Формулировки нейтральные, по регламенту
[`../knowledge_Письмо Директору/`](../knowledge_Письмо%20Директору/): «виконано робіт»,
а не «освоєно»; передоплата и заборгованість называются прямо; оценок нет.

Пример: «МК Кривий ріг: виконано робіт на 4 713 575,00 грн, оплачено 4 823 281,25 грн,
подано актів на 1 481 816,00 грн (з них не проведено в обліку 54 614,00 грн).
Замовник має передоплату 109 706,25 грн. Разом до отримання — 1 390 101,77 грн.»

Скобка про непроведённые появляется только если они есть — это то же предупреждение К10,
но словами.

## HTML-доклад

`ТекстДокладаHTML()` возвращает готовую страницу: инлайновый CSS, таблица, блок замечаний
с цветовой градацией. Сохранение из формы — `НачатьПолучениеФайлов` с
`ОписаниеПередаваемогоФайла`.

🔴 `НачатьПолучениеФайлаИзВременногоХранилища` **в платформе не существует** — проверка
тонкого клиента ловит это как «Процедура или функция с указанным именем не определена».

Экранирование — своя `ЭкранироватьHTML()`: `&`, `<`, `>`, `"`. Наименования договоров
содержат кавычки, без экранирования вёрстка ломается.

## Блок «Зауваження до розрахунку»

Выводился в обеих печатных формах и в HTML: ошибки красным, предупреждения оранжевым.
Замысел — чтобы отчёт не выглядел «чистым», если расчёт чего-то не смог сопоставить.

**Удалён 14.08.2026** по решению пользователя: замечания остаются рабочим инструментом
на вкладке «Контроль», но в документе, который уходит директору, им не место.

⚠ Убирается **только вывод в печать**. ТЧ `Контроль`, вкладка формы и коды П\*/К\* остаются.

## Проверка печати через COM

Печатные формы вызываются на несохранённом объекте и проверяются по размеру:

```python
таб = док.СформироватьПечатьОтчет()
assert int(таб.ВысотаТаблицы) > 5
```

Это ловит падение метода, но не проверяет вёрстку — её смотреть глазами в клиенте.

Связанные файлы: [02_metodika_kolonok.md](02_metodika_kolonok.md) — что в колонках;
[LESSONS.md](LESSONS.md) — грабли табличного документа.

## Выгрузка в Excel (с 29.09.2026)

Кнопка «Зберегти в Excel» (панель формы) → `ДвоичныеДанныеExcel()` → модель `МодельКнигиExcel()` → запись xlsx в
**модуле менеджера** `ДвоичныеДанныеКнигиExcel(Модель)`: свой Office Open XML (части, `ЗаписьZipФайла`, UTF-8 без BOM).
Почему не `ТабличныйДокумент.Записать(XLSX)`: формул не пишет, закрепление/свёрнутость/размер окна примечаний не
переносит, числа с `ЧРГ` уходят текстом. Экономист правит файл руками → нужны живые формулы.

**Макет — директорский:** лист «дд.мм.гггг», строки 1–3 скрыты, шапка 4–5 (тексты, объединения, #C3D69B/#003F2F,
примечания E5/F5/H5), закрепление до строки 5; блок: объект «Подразделение (контрагенты)» (A:B, #92CDDC) → сумма
(#D7E4BD) → договоры (группировка 1) → «Итого» (#D6E5CB) → пустая. Блок выводится и без договоров.

**Формулы** (формула + кеш значения, `fullCalcOnLoad`): G = E−F; I = `-ROUND(MIN(удерж.,MAX(0,G+H)),2)`;
J по правилу (−H/6, для P — неавансовая часть, −MAX(0,G)/6; `НеУчитывать` и `ПослеРегистрацииПН` — значение);
K: Z `ROUND(MAX(0,G+I+J+H*(1-p)),2)`, V, P с константой `Расчет.ОстатокАванса`; суммы блока `SUM`, объект и «Итого» —
ссылки. Smoke `doc_finrep_excel_smoke.py`: Excel COM `CalculateFull` → K всех договоров = документ.

**Примечания (по-русски):** колонка A договора — условия (№/дата/стороны, сумма соглашения, срок оплаты, аванс/зачёт,
удержание, НДС, ПН: кол-во/НДС/зарегистрировано, текст условий); E/F/H — документы «<вид> <номер> от дд.мм — сумма»,
«(не проведён)/(не подписан)», к акту — его ПН со статусом регистрации, для договоров со сроком — «оплата до …» /
«просрочено N дн.» (FIFO оплат по актам); строка объекта — план-факт казны месяца. Окно подогнано под текст.

### Вариант «с расшифровкой до документов» (29.09.2026, [ПРОМТ](ПРОМТ_Выгрузка_Excel_с_расшифровкой.md))

`ДвоичныеДанныеExcel(СРасшифровкой)`; «Зберегти в Excel ▾» → «Звіт» / «Звіт з розшифровкою до документів» (файл
«… с расшифровкой.xlsx»). Под договором — строки `РасшифровкаДокументов` (отбор Подразделение+Договор, по дате),
уровень 2, скрыты (группа свёрнута, `collapsed` на строке договора, `summaryBelow=0` — кнопка у строки-итога сверху):
A — вид/номер/дата, B — статус (оригинал получен дд.мм / не подписан / не проведён / оплата; казна), суммы в E/F/H
как в печати, L — ПН и регистрация в ЄРПН, M — срок оплаты. Стили 12–15 (курсив серый / коричневый для непроведённых).
E/F/H договора = `SUBTOTAL(9, документы)`, сумма блока = `SUBTOTAL(9, весь блок)` — SUBTOTAL пропускает SUBTOTAL-ы
договоров, двойного счёта нет. Примечания E/F/H на договоре в этом варианте не выводятся. Smoke: 161 строка
документов = расшифровке, Σ документов = E/F/H договора, K после пересчёта = документ.
