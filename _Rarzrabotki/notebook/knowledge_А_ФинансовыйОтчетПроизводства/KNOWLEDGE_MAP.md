## TL;DR за 60 секунд

Документ заменяет ручной Excel «Финансовый_отчет Производства»: собирает из бухучёта то, что
экономист сводил руками. **Непроводимый** (`Posting=Deny`) — движений по регистрам не делает,
это калькулятор с сохранением результата, расшифровкой и печатью.

1. **Разрез** — `ДоговорКонтрагента.Подразделение` (справочник `Подразделения`, те же имена,
   что в отчёте «План факт Производство» из базы **kazna**). Фильтр по `Направление` = «Производство».
   НЕ `ПодразделенияОрганизаций` — это другое дерево, совпадений с отчётом ноль.
2. **Источник** — счёт **361** «Расчеты с отечественными покупателями», субконто
   1 = Контрагенти, 2 = Договори, 3 = Документи розрахунків.
3. **Четыре колонки** ([02](02_metodika_kolonok.md)):
   `E` — оборот Дт по документам **с** отметкой `ОтправкаПолучениеДокументов.ДокументыПолучены`;
   `F` — оборот Кт; `H` — проведённые **без** отметки + **непроведённые** документы;
   `G = E − F` (это **НЕ сальдо**: сальдо содержит ещё и H).
4. **Параметры расчёта живут в РЕГИСТРЕ** `РС.А_ПараметрыДоговоровФинотчета`
   (с 14.08.2026; измерение Договор — ведущее; с 29.09 — 14 ресурсов: + зачёт предоплаты,
   правило НДС, сумма удержания, срок оплаты, статус в отчёте, условия договора). Реквизиты `А_*` из `Справочник.ДоговорыКонтрагентов` удалены.
   Ввод — список регистра, TSV-цикл ([04](04_parametry_dogovora.md)).
4а. **Оплаты сверяются с казной** (с 28.09.2026, [03](03_istochniki_zaprosy.md)): UUID 1:1 через ЕРП;
   договор без актов, все оплаты которого казна относит к другому подразделению отчёта, показывается
   там целиком; прочие расхождения — К14–К16. Казна недоступна → один П34, расчёт по бухгалтерии.
4б. **Состав отчёта** (с 29.09.2026, [04](04_parametry_dogovora.md)): подразделение договора — ТОЛЬКО
   из `ДоговорыКонтрагентов.Подразделение` (ТЧ «Договори додатково» удалена); статус договора в регистре —
   авто / «Всегда» / «Закрыт» (К24–К26); подразделения из план-факта казны за месяц добавляются при расчёте (П35).
4в. **Выход — Excel** (с 29.09.2026, [07](07_pechatnye_formy.md)): кнопка «Зберегти в Excel» — свой xlsx
   в макете директора, живые формулы, примечания (условия договора, документы, ПН с регистрацией в ЄРПН, сроки).
5. **Строка результата = ДОГОВОР** (ТЧ `Расчет`: +Контрагент, +Договор). Итог K считается
   по варианту формулы договора (Z / V / P `ЗачетПредоплаты` / ТолькоРучной), **не меньше 0**;
   выше по иерархии (контрагент, підрозділ) — **суммируется**, а не пересчитывается.
6. **Валидация** ([05](05_validaciya_kontroli.md)): коды `П*` до расчёта (блокируют) и
   `К*` после (в ТЧ `Контроль`). Каждое замечание привязано к строке ТЧ.
   С 14.08 нет П10/П14/П19/П22–П28 и К11 (ушли с ТЧ-параметрами и корректировками);
   добавлены П33–П35 (заполнение из kazna). С 28.09 — К14–К23, К06 удалён, в панель
   не больше 10 сообщений на «код + уровень».
7. **Пересчёт безопасен**: очищаются только результатные ТЧ, параметры и ручные правки живут.

**Архитектура:** движок в `Ext/ObjectModule.bsl` (3942 строки, 107 процедур/функций, 12 экспортных — на 28.09.2026),
форма — тонкий диспетчер через `РеквизитФормыВЗначение("Объект")` / `ЗначениеВРеквизитФормы`.

## Реквизиты шапки

| Реквизит | Тип | Смысл |
|---|---|---|
| `ДатаРасчета` | Дата | приводится к `КонецДня()` функцией `МоментРасчета()` |
| `НачалоПериода` | Дата | пусто = с начала учёта |
| `Направление` | `CatalogRef.Направления` | по умолчанию «Производство» |
| `ЗаполнятьТолькоСДвижениями` | Булево | иначе 45 подразделений вместо 17 (на 07.08; после правок истории — 46 и 19) |
| `ВключатьНепроведенные` | Булево | вторая ветка колонки H |
| `ЕстьОшибки` | Булево | служебный |
| `Ответственный`, `Комментарий` | | |
| `ДокументСравнения` | `DocumentRef.А_ФинансовыйОтчетПроизводства` | база «Динаміки»; пуст — автоподбор при `Рассчитать()` (последний непомеченный того же направления с меньшей ДатаРасчета) |

**Четыре реквизита удалены 16.08.2026** (решение пользователя — минимум полей на форме):
`СтавкаНДС` (ставка константой в коде — функция `СтавкаНДСРасчета()` = 20, проверка П18 снята),
`ЗаголовокОтчета` (заголовок печати всегда из даты расчёта), `Статус` (дубль надписи
«Стан розрахунку» на форме) и **`Организация`** — она НИКОГДА не участвовала в отборе:
ни один из пяти запросов по ней не фильтровал, отчёт считает по ВСЕМ организациям,
разрез задают `Направление` + `Подразделение`; поле лишь дописывало строку в шапку печати.
Проверено: после удаления все цифры приёмки и smoke не изменились.

## Табличные части (7 с 29.09.2026)

**Параметры:** `Подразделения` (2 реквизита: Подразделение, Включать), `СчетаРасчетов`,
`СтатьиИсключенияКазны` (Статья — ССЫЛКА `СправочникСсылка.СтатьиДвиженияДенежныхСредств`:
справочник синхронизирован обменом, UUID шести статей в BuhBud и kazna совпадают 1:1;
6 статей по умолчанию в ОбработкеЗаполнения / `ЗаполнитьСтатьиИсключенияПоУмолчанию()`;
в запрос казны идут НАИМЕНОВАНИЯ ссылок).
**Результат:** `Расчет` (с 29.09 + `ОстатокАванса` — для формулы K в Excel), `РасшифровкаДокументов`
(с 28.09 + `ПодразделениеКазны` Строка 150 — корень казны для строки «Оплата»; с 29.09 + `ДатаПодписания` —
`ОтправкаПолучениеДокументов.ДатаПолучения`, база срока оплаты), `Контроль`,
`Казна` (очищается при расчёте: Подразделение, ИмяВКазне, Поступления/Затраты/Маржа План+Факт;
план-факт производства из kazna механикой Отчеты.ПланФакт, свёртка иерархии до корня,
сопоставление по имени; затраты хранятся ОТРИЦАТЕЛЬНЫМИ, Маржа = Поступления + Затраты).

**ТЧ «Договори додатково» удалена 29.09.2026** (решение пользователя): её функции — показ договора
без движения и перенос в другое подразделение — перешли на статус «Всегда» в регистре и на подразделение
в карточке договора (IRC 15/30 м → «МД IRC 2026», «забор» → «МК Подгорцы» переназначены в справочнике).

«Коригування» и «Виключені документи» удалены 14.08.2026 — расхождения чинятся в первичке
([06](06_korrektirovki_isklyucheniya.md) — историческое).

## Перечислений НЕТ (с 16.08.2026)

Все 4 перечисления `А_*` удалены (решение пользователя: минимум объектов в типовой
конфигурации, «всё в коде документа»). Значения — СТРОКИ:
- `Статус`: «Чернетка» / «Розрахунок виконано» / «Є зауваження»;
- `Контроль.Уровень`: «Помилка» / «Попередження» / «Інформація»;
- `РасшифровкаДокументов.Вид`: «Виконані роботи» / «Оплата» / «Акт поданий» /
  «Акт поданий (непроведений)»;
- `Расчет.ВариантФормулы` и `РС.ВариантФормулыИтога` — ТЕХНИЧЕСКИЕ имена
  `ЗадолженностьПлюсАкты` / `ВыполнениеМинусОплата` / `ТолькоРучной` / `ЗачетПредоплаты` (ключи TSV-цикла);
- `РС.ПравилоНДС` — `ОтАктов` (пусто) / `НеУчитывать` / `ОтЗадолженности`.

Константа `А_СтрокаПодключенияКазна` тоже удалена — строка подключения kazna живёт
литералом в функции `СтрокаПодключенияКазны()` модуля объекта.
