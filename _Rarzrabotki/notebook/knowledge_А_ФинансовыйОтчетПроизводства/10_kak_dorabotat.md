# 10. Как дорабатывать

## Порядок, который работает

1. **Rule #-1.** Любой новый запрос сперва прогнать Python COM на живой базе, только потом
   вставлять в BSL. Все ошибки запросов в этом проекте — следствие пропуска этого шага.
2. Правка метаданных — `meta-edit` (точечно) или `meta-compile` (перегенерация).
3. Правка формы — `form-compile` по обновлённому `doc_finrep_form.json`, затем патч
   `Autofill → true`.
4. **Патчер украинских подписей** `doc_finrep_patch_uk.py` — после любой перегенерации.
5. Проверка XML на валидность **до** загрузки.
6. Загрузка `db-load-xml -Mode Partial -UpdateDB`; форма — **только обёрткой**.
7. `1cv8 DESIGNER /CheckConfig -ThinClient -Server` — синтаксис модулей.
8. COM-smoke `smoke_doc_finrep.py`.

## Рецепты

**Добавить колонку в расчёт.** Реквизит в ТЧ `Расчет` (`meta-edit add-ts-attribute`) →
заполнение в `ЗаполнитьСтрокиРасчета()` → колонка в форме → перевод в словарь →
колонка в печатной форме → проверка в smoke.

**Добавить проверку.** Код по схеме: `П*` — в `ПроверитьПараметры()` и производные,
`К*` — в `КонтролиПослеРасчета()`. Уровень «Ошибка» блокирует расчёт. Обязательно указать
`ПутьКДанным` — без него сообщение не кликабельно. Добавить негативный сценарий в smoke.

**Добавить параметр расчёта.** Сперва решить, где он живёт: если свойство договора —
реквизит `А_*` в справочник ([04](04_parametry_dogovora.md)); если свойство конкретного
расчёта — реквизит шапки документа. В ТЧ `Подразделения` больше ничего не класть:
семь колонок оттуда уже удаляются как дубли договора.

**Изменить печатную форму.** Только программный `ТабличныйДокумент`. `ШиринаКолонки` —
на необъединённой строке. Числа в таблице `ЧН=`, в сообщениях `ЧН=0,00`.

**Изменить форму.** Править `doc_finrep_form.json` и пересобирать — не редактировать Form.xml
руками. После пересборки: патч `Autofill`, патчер uk, `form-validate`, сверка обработчиков.

## Чек-лист перед «готово»

- [ ] Новые запросы прогнаны на живой базе
- [ ] Баланс `Процедура/КонецПроцедуры` и `Функция/КонецФункции` (grep)
- [ ] Нет `Абс(`, нет локальной переменной `Ссылка`
- [ ] Нет `Ссылка + "строка"` — ссылка справа или в `Строка()`
- [ ] XML валиден (`xml.dom.minidom.parse`)
- [ ] uk-подписей не меньше ru
- [ ] База свободна (нет `1cv8.exe`)
- [ ] `CheckConfig -ThinClient` — «Ошибок не обнаружено»
- [ ] COM-smoke зелёный, эталоны сходятся
- [ ] Форму открыл и понажимал **пользователь** — COM её не рендерит

## Чего не делать

- Не менять методику E/F/G/H — она проверена и сходится с Excel до копейки.
- Не возвращать «коэффициент актов» — он сведён к проценту удержания.
- Не класть параметры договора в документ — они переехали намеренно.
- Не доверять «Load completed successfully» — загрузчик BSL не компилирует код.
- Не редактировать Form.xml вручную — пересобирать из JSON.
- Не подставлять `ПустаяСсылка()` как заглушку в `В (&Параметр)`.
