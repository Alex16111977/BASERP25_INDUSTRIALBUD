# Карта залежностей: Документ -> Регістр -> Звіт (BAS ERP 2.5 INDUSTRIALBUD)

Цей документ описує яким чином документи впливають на регістри, і з яких регістрів будуються фінансові звіти. Це дозволяє зрозуміти: якщо документ не має руху по регістру X — який звіт буде неправильним.

---

== ФУНДАМЕНТАЛЬНЕ ПРАВИЛО: ПІДРОЗДІЛ ОБОВ'ЯЗКОВИЙ СКРІЗЬ ==

Підрозділ (Подразделение / СтруктураПредприятия) — ФУНДАМЕНТАЛЬНИЙ вимір конфігурації ІНДАСТРІАЛБУД.
УправленческийБаланс будується ДО РІВНЯ ПІДРОЗДІЛІВ через регістр ПрочиеАктивыПассивы.
Кожна операція, кожна гривня — прив'язана до підрозділу.

ЗАБОРОНЕНО: шукати документи/залишки/платіжки без фільтра по Подразделение.
ЗАБОРОНЕНО: пропонувати fallback "пошукаємо без підрозділу" — це системна помилка що ламає баланс.
Якщо підрозділ не знайдений — Сообщить і пропустити, НЕ ігнорувати.

== КАРТА ЗВІТІВ І ЇХНІХ ДЖЕРЕЛЬНИХ РЕГІСТРІВ ==

Звіт: УправленческийБаланс (Управлінський баланс)
Тип: Оперативний (не бухгалтерський)
Джерельний регістр: РегистрНакопления.ПрочиеАктивыПассивы (ОстаткиИОбороты)
Додаткове: РегистрСведений.КурсыВалют (для валютних перерахунків)
Що показує: Початкові залишки, надходження, витрати, кінцеві залишки по статтях
Групування: Статья, Организация, Подразделение, НаправлениеДеятельности
ВАЖЛИВО: Цей звіт використовує ОПЕРАТИВНІ регістри (18 регістрів двойної записи), НЕ бухгалтерський регістр Хозрасчетный!

Звіт: ВедомостьРасчетовСПартнерами (Відомість розрахунків з партнерами)
Тип: Оперативний
Джерельні регістри:
- РегистрНакопления.РасчетыСКлиентами (розрахунки з клієнтами)
- РегистрНакопления.РасчетыСПоставщиками (розрахунки з постачальниками)
Додаткове:
- РегистрСведений.АналитикаУчетаПоПартнерам
- РегистрСведений.ПартнерыСегмента
Що показує: Заборгованість по партнерах/контрагентах
ВАЖЛИВО: В новій архітектурі взаєморозрахунків використовує РасчетыСКлиентамиПоСрокам (фінансовий), а НЕ РасчетыСКлиентами (оперативний)!

Звіт: ДвиженияДенежныхСредств (Рухи грошових коштів)
Тип: Оперативний
Джерельні регістри:
- РегистрНакопления.ДенежныеСредстваБезналичные (безготівкові)
- РегистрНакопления.ДенежныеСредстваНаличные (готівкові)
- РегистрНакопления.ДенежныеСредстваВКассахККМ (каси ККМ)
- РегистрНакопления.ДенежныеСредстваВПути (в дорозі)
Додаткове:
- РегистрСведений.КурсыВалют
- РегистрСведений.ГрафикПлатежей
Що показує: Рухи грошових коштів по рахунках/касах

Звіт: РасчетыСПартнерами (Розрахунки з партнерами — деталізований)
Тип: Оперативний
Джерельні регістри:
- РегистрНакопления.РасчетыСКлиентами
- РегистрНакопления.РасчетыСКлиентамиПоДокументам
- РегистрНакопления.РасчетыСПоставщиками
- РегистрНакопления.РасчетыСПоставщикамиПоДокументам
Додаткове:
- РегистрСведений.АналитикаУчетаПоПартнерам

Звіт: А_БДДС (Бюджет руху грошових коштів — бюджет vs факт)
Тип: Кастомний (А_)
Джерельні регістри:
- РегистрНакопления.А_БюджетыНаМесяц (бюджет)
- РегистрНакопления.ДвиженияДенежныеСредстваДоходыРасходы (факт доходи/витрати)
- РегистрНакопления.ДвиженияДенежныеСредстваКонтрагент (факт по контрагентах)
- РегистрНакопления.ДвиженияДенежныхСредств (факт загальний)

Звіт: А_СравнитьОстаткиТоваровЕРПсBASБухгалтерия (Звірка товарів ERP vs BuhBud)
Тип: Кастомний (звірка)
Джерельні: 
- ERP: РегистрНакопления.ТоварыНаСкладах
- BuhBud: РегистрБухгалтерии.Хозрасчетный (рахунки 20, 28 тощо)
Що показує: Розбіжності залишків товарів між ERP і Бухгалтерією

Звіт: А_СравнитьОстаткиВзаиморасчетыКонтрагентыЕРПсBASБухгалтерия
Тип: Кастомний (звірка)
Джерельні:
- ERP: РегистрНакопления.РасчетыСКлиентами + РасчетыСПоставщиками
- BuhBud: РегистрБухгалтерии.Хозрасчетный (рахунки 36, 63 тощо)
Додаткове: РегистрСведений.АналитикаУчетаПоПартнерам

Звіт: А_СравнитьОстаткиДенегЕРПсBASБухгалтерия (Звірка грошей ERP vs BuhBud)
Тип: Кастомний (звірка)
Джерельні:
- ERP: РегистрНакопления.ДенежныеСредстваБезналичные + ДенежныеСредстваНаличные
- BuhBud: РегистрБухгалтерии.Хозрасчетный (рахунки 311, 301)

Звіт: А_СравнитьОстаткиДенегЕРПсКазной (Звірка грошей ERP vs Казна)
Тип: Кастомний (звірка)
Джерельні:
- ERP: регістри грошових коштів
- Казна: COM-підключення до БухКазн
- Доповнюючий шар: РегістрНакопичення.А_ДвиженияДенегИзКазны (паралельний шар, який заповнюється Документом.А_ПереносДвиженийИзКазны для замикання прогалин обміну — див. perenos_dvizheniy_iz_kazny.md)

Звіт: УправленческийБалансКонтроль (Контроль управлінського балансу)
Тип: Контрольний
Джерельний: РегистрНакопления.ПрочиеАктивыПассивы

== КАРТА ДОКУМЕНТ -> РЕГІСТРИ ==

Документ: ПриобретениеТоваровУслуг (Придбання)
Рухає регістри:
- ТоварыНаСкладах (приход товарів на склад)
- ТоварыОрганизаций (товари по організації)
- СебестоимостьТоваров (вартість товарів)
- РасчетыСПоставщиками (борг постачальнику)
- РасчетыСКлиентамиПоСрокам (через РегистраторРасчетов)
- ПрочиеАктивыПассивы (для управлінського балансу)
Впливає на звіти: УправленческийБаланс, ВедомостьРасчетов, Звірка товарів

Документ: РеализацияТоваровУслуг (Реалізація)
Рухає регістри:
- ТоварыНаСкладах (розход товарів зі складу)
- ТоварыОрганизаций (зменшення)
- ВыручкаИСебестоимостьПродаж (виручка та собівартість)
- СебестоимостьТоваров (списання)
- РасчетыСКлиентами (борг клієнта)
- РасчетыСКлиентамиПоСрокам (через РегистраторРасчетов)
- ПрочиеАктивыПассивы
Впливає на звіти: УправленческийБаланс, ВедомостьРасчетов, Звірка товарів

Документ: ПриходныйКассовыйОрдер (ПКО)
Рухає регістри:
- ДенежныеСредстваНаличные (приход готівки)
- РасчетыСКлиентами або РасчетыСПоставщиками (залежно від ХозОперации)
- ПрочиеАктивыПассивы
Впливає на звіти: ДвиженияДенежныхСредств, ВедомостьРасчетов, Звірка грошей

Документ: РасходныйКассовыйОрдер (РКО)
Рухає регістри:
- ДенежныеСредстваНаличные (розход готівки)
- РасчетыСКлиентами або РасчетыСПоставщиками
- ПрочиеАктивыПассивы
Впливає на звіти: ДвиженияДенежныхСредств, ВедомостьРасчетов, Звірка грошей

Документ: ПоступлениеБезналичныхДенежныхСредств
Рухає регістри:
- ДенежныеСредстваБезналичные (приход на рахунок)
- РасчетыСКлиентами (погашення боргу клієнта)
- ПрочиеАктивыПассивы
Впливає на звіти: ДвиженияДенежныхСредств, ВедомостьРасчетов, Звірка грошей

Документ: СписаниеБезналичныхДенежныхСредств
Рухає регістри:
- ДенежныеСредстваБезналичные (розход з рахунку)
- РасчетыСПоставщиками (погашення боргу постачальнику)
- ПрочиеАктивыПассивы
Впливає на звіти: ДвиженияДенежныхСредств, ВедомостьРасчетов, Звірка грошей

Документ: ПеремещениеТоваров
Рухає регістри:
- ТоварыНаСкладах (розход зі складу відправника, приход на склад одержувача)
- ТоварыОрганизаций
Впливає на звіти: Звірка товарів

Документ: ЗаказКлиента
Рухає регістри:
- ЗаказыКлиентов (резервування)
- ОбеспечениеЗаказов
НЕ впливає на: ТоварыНаСкладах, ДенежныеСредства (поки не відвантажений)

Документ: ЗаказПоставщику
Рухає регістри:
- ЗаказыПоставщикам (потреби)
Впливає на: планування закупівель

Документ: АвансовыйОтчет
Рухає регістри:
- ВзаиморасчетыССотрудниками (борг підзвітної особи)
- ДенежныеСредстваВПодотчете
- РасчетыСПоставщиками (якщо є закупки)

Документ: ВзаимозачетЗадолженности
Рухає регістри:
- РасчетыСКлиентами (зменшення боргу клієнта)
- РасчетыСПоставщиками (зменшення боргу постачальнику)
- РасчетыСКлиентамиПоСрокам (через РегистраторРасчетов)

Тип: Оборотний (Turnovers)

Реєстратор: тільки Документ.А_ПереносДвиженийИзКазны
Виміри (9): БанковскийСчетКасса, Организация (упр.), А_ОрганизацияБухгалтерия (з Казни по КодПоЕДРПОУ), ТипДенежныхСредств, СтатьяДвиженияДенежныхСредств, ПодразделениеКазна, НаправлениеДеятельностиКазна, Подразделение (обчислюється), ДокументДвиженияКазны (склад. з парних ERP-документів + самопосилання)

== ЛАНЦЮЖОК ВПЛИВУ: ЩО СТАНЕТЬСЯ ЯКЩО РЕГІСТР ПУСТИЙ ==

Якщо ТоварыНаСкладах пустий:
- УправленческийБаланс: неправильні залишки товарів
- Звірка з BuhBud: розбіжності по товарах
- Собівартість: не розрахується

Якщо РасчетыСКлиентами/ПоСрокам пустий:
- ВедомостьРасчетовСПартнерами: не показує заборгованість
- Управлінський баланс: неправильні дебітори/кредитори
- Звірка з BuhBud: розбіжності по взаєморозрахунках

Якщо ДенежныеСредства пустий:
- ДвиженияДенежныхСредств: не показує рухи грошей
- Звірка з BuhBud: розбіжності по грошах
- БДДС: факт = 0

ПРИЧИНА пустих регістрів: найчастіше — Курс=0 або Кратність=0, що дає СуммаВзаиморасчетов=0, що дає нульові рухи.
