сверх сметы 556 909,84 и вне сметы 243 799,39.

Метод проверен на прошлой неделе: прогон по файлам 12.08 дал ровно числа отправленного
письма (708 003,17 / 298 878,54 / 208 497,86).

## Пять правок пользователя — и что из них следует

| Правка | Следствие для базы знаний |
|---|---|
| «Не нужны такие трактаты» — блок с таблицей факторов убрать | Методика — в расчёте, в письме только колонки ТОП ([01](01_struktura_pisma.md)) |
| «Такое вообще нельзя писать» — про уточнение у прораба | Письмо не задаёт вопросов ([04](04_takt_i_granicy.md), грабля 30) |
| «И так понятно» — про падение процента экономии | Не пересказывать таблицу (грабля 31) |
| Блок «Додатки» не писать | Письмо заканчивается сводкой (грабля 32) |
| ТОП-7 → до ТОП-10 «если есть значительные показатели» | Порог значимости 3 % (грабля 35) |
| «Укажи, на какой процент цена выше/ниже и сколько закуплено» | Три колонки факторного разбора + ярлык с отклонением |

## Что осталось за кадром письма

Проверка доставки: `ПриобретениеУслугПрочихАктивов` кладёт свои суммы в ресурс `ДопРасходы`,
которого отчёт не читает, — то есть цена факта неполная. По этому объекту 2 811 грн (0,05 %),
поэтому в письмо не пошло; по Глобино-2 за 2026 это 3,84 млн, и там про цену так сказать нельзя.
