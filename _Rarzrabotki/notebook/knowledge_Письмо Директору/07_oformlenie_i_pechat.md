# 07. Оформление HTML и печать

Готовый каркас — `Шаблон_письма.html` в этой же папке. Здесь — принципы.

## Почему HTML, а не Word?

Письмо вставляется в почту и печатается. HTML даёт стабильный вид, таблицы с выравниванием чисел
и печать без «уползания», а файл лежит рядом с отчётами в папке недели.

## Куда сохранять

В папку той недели, рядом с отчётами-источниками:
`…/Письмо директору/05082026/Лист_МД_IRS_2026_05-08-2026.html`.
Имя — «Лист_<проект>_<дата>.html»; для ответов — «Відповідь_директору_<проект>.html»;
для доклада — «Доклад.html» рядом с «Доклад.docx».

## Визуальные правила

| Элемент | Как оформляется |
|---|---|
| Заголовок письма | синий (акцентный), 17–19 px |
| Заголовки разделов | акцентный цвет, тонкая подчёркивающая линия |
| Числа в таблицах | выравнивание вправо, моноширинные цифры, неразрывный пробел |
| Экономия / «ожидаем» | зелёный |
| Перерасход / «не ожидаем» | красный |
| Нули и «нет данных» | серый, не жирный |
| Итоговые строки таблиц | жирные, серая заливка, верхняя граница |
| Названия объектов в докладе | синий жирный (чтобы находить строку при чтении вслух) |

Выделять цветом только смысл (лучше/хуже), а не «красиво». Никаких иконок и эмодзи в письме.

## Таблицы

- Первая колонка — текст, остальные — числа вправо.
- Колонка «%» — последняя.
- Итоговая строка всегда подписана словом «Разом» / «Итого».
- Долю ТОП-7 писать прямо в итоговой строке: «73 % економії».

## Печать: один лист А4

- Размер и поля: A4 книжная, поля 10–12 мм.
- В печати уменьшать шрифт: текст 11–12 pt, таблицы 9,5–10,5 pt.
- Фон страницы при печати убирать, рамку и тень блока — тоже.
- Если не помещается — резать **не цифры, а повторы**: первым кандидатом идёт сводная таблица,
  данные которой уже разложены в детальных таблицах, затем дублирующая строка итога над таблицей.

## Что проверить перед отдачей

1. Открывается и читается в браузере, числа не переносятся по разрядам.
2. Предпросмотр печати — один лист (для доклада обязательно).
3. Кодировка UTF-8, украинские буквы «і», «ї», «є», апострофы отображаются.
4. Ни одного «TODO», ни одной пустой ячейки без «—».
