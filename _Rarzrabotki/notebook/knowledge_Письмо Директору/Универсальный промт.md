# 🧩 Универсальный промт: собрать письмо / ответ / доклад

Мета-шаблон. Пользователь копирует нужный блок в чат, заполняет 3–4 строки — ИИ делает остальное
по этой базе знаний.

---

## А. Еженедельное письмо директору

```
ЗАДАЧА: написать письмо директору по отчётам, регламент —
_Rarzrabotki/notebook/knowledge_Письмо Директору/KNOWLEDGE_MAP_Письмо.md

1. Папка с отчётами этой недели: C:\...\Письмо директору\__________
2. Папка прошлой недели (для динамики): C:\...\Письмо директору\__________
3. Дата в заголовке: ____.____.2026
4. Особые указания: нет   (напр.: без просьб; вне сметы — только три позиции)

Действовать по базе: структура «Матеріали → Роботи → Додатки», динамика недели обязательна,
без счётчиков позиций, «освоєно» не употреблять. Все цифры сверить скриптом с отчётами,
собственные итоги пометить. Показать мне перед отправкой.
```

## Б. Ответ на вопросы директора

```
ЗАДАЧА: подготовить ответ директору, регламент —
_Rarzrabotki/notebook/knowledge_Письмо Директору/05_otvety_na_voprosy.md

1. Письмо, на которое пришёл ответ: C:\...\__________.html
2. Отчёты-приложения: C:\...\__________
3. Вопросы директора:
   —
   —
4. Что НЕ поднимать: __________

Отвечать по одному блоку на вопрос, заголовком повторять вопрос, каждую цифру подкреплять
источником (документ, отчёт, расчёт). Если термин в письме был неудачным — признать мягко.
```

## В. Доклад по производству

```
ЗАДАЧА: оформить доклад по производству, регламент —
_Rarzrabotki/notebook/knowledge_Письмо Директору/06_doklad_shpargalka.md

1. Папка: C:\...\Доклады по производству\__________
2. Текст доклада (мой): Доклад.docx
3. Отчёты: Финансовый_отчет Производства ____.xlsx, План факт Производство ____.xlsx
4. Особые указания: нет

Формулировки — дословно из моего docx, своё не выдумывать. В каждом разделе: текст-шпаргалка
для зачитывания + таблица под ним. Один лист А4. Цифры сверить с отчётами.
```

---

## Что ИИ делает сам, без напоминания

1. Проверяет **дату файлов отчётов** — их перевыпускают; берёт самые свежие.
2. Считает динамику к прошлой неделе (сравнивая **отчёт с отчётом**).
3. Собирает ТОП-7 экономии и ТОП-7 перерасхода, позиции вне сметы.
4. Соблюдает границы из `04_takt_i_granicy.md`: без счётчиков позиций, без строки «План СС»
   в динамике, без обвинительных формулировок и имён.
5. **Сверяет каждую цифру скриптом** и сообщает, что именно посчитал сам.
6. Сохраняет HTML в папку недели рядом с отчётами и проверяет печать на один лист.

## Что ИИ обязан спросить

- дату в заголовке, если имя файла и дата отчёта расходятся;
- нужна ли просьба к директору (внести в кошторис / прокомментировать перерасход) или только констатация;
- сокращать ли длинные списки позиций и до скольких строк;
- поднимать ли разрезы, которые ранее просили не подсвечивать.

## Стоп-сигналы (сообщить пользователю, не решать самому)

- цифры письма не сходятся с отчётом;
- сальдо экономии не равно разнице снижений и превышений;
- в данных найден дефект (например, потерянные при загрузке проценты);
- отчёты в папке свежее прошлого прогона — цифры изменились.
