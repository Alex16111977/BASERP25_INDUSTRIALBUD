# FINDINGS — что выяснили исследованием (30.09.2026)

## Типовой донор `ДебиторскаяЗадолженностьПоставщиковПоСрокамДолгаРасширенная`

- **Механизм «Бухгалтерські звіти», а не чистая СКД.**
  - Модуль объекта вызывает `БухгалтерскиеОтчетыВызовСервера.ОбработкаСобытияПриКомпоновкеРезультата`.
  - Модуль менеджера в `ПередКомпоновкойМакета` строит текст запроса под число интервалов, параметры, поля
    `ОстатокПериода*` и внешний набор просрочки.
  - Форма своя: ТЧ «Интервалы», «Группировка», «ДополнительныеПоля».
- **«Розширена» — доработка типового.** В запрос добавлены ветки «поступления без полученных оригиналов»
  (`ПоступлениеТоваровУслуг`, `ПоступлениеДопРасходов` по `РС.ОтправкаПолучениеДокументов`). Отсюда
  `ДатаНачалаБас = 01.07.2023`, жёстко в коде.
- **Интервалы по умолчанию** механизма — 7, 15, 30, 60, 90 (`БухгалтерскиеОтчетыВызовСервера`).
  Бухгалтер работает с 7, 15, 30.
- `Период` = `КонецДня(дата) + 1`. Интервалы — от даты отчёта. Колонка «Понад N днів» строится всегда, поэтому
  Σ интервалов = общей.
- Колонки интервалов в типовом без копеек (`ЧЦ=15; ЧДЦ=0`). У поля «Счет на оплату» в макете тип ограничен двумя
  документами и есть только русский заголовок.

## Платформа и БСП в BuhBud

- **Режим совместимости 8.3.12**:
  - строковых функций в языке запросов нет (`СТРЗАМЕНИТЬ`);
  - в выражениях СКД нет `СтрЗаменить`.
- **БСП-панель раздела «Керівнику»** (`ПанельОтчетовОтчетыДляРуководителя`) строит группы по подсистемам, куда
  входит отчёт. Типовые «Дебіторські» входят в `Руководителю → РасчетыСПоставщиками`.
- **Права на типовые «Дебіторські»** дописаны в роли `ВызовОнлайнПоддержки` и `ЗапускВебКлиента`. На
  `ЗадолженностьПоставщикам` — в `ДобавлениеИзменениеДанныхБухгалтерии` и `ЧтениеДанныхБухгалтерии`.
  «Права для новых объектов» — только у `ПолныеПрава`.
- **Регистрация вариантов БСП:** только отчёты, у которых `ОтчетПодключенКХранилищу` = Истина. Умолчание
  конфигурации `<ReportsVariantsStorage/>` пустое, значит нужен явный `VariantsStorage`.
- **Исключённые счета** — `ХранилищеОбщихНастроек`, персонально. У `cfo` настройки нет.
- **Основная организация** — `БухгалтерскийУчетПереопределяемый.ПолучитьЗначениеПоУмолчанию("ОсновнаяОрганизация")`.
  У `cfo` пусто.
