# 02. Данные и расчёт

Логика — модуль менеджера типового `ДебиторскаяЗадолженностьПоставщиковПоСрокамДолгаРасширенная`:
`ПолучитьТекстЗапроса`, `УстановитьПараметры`, `ЗаполнитьПоляВСоответствииСоСпискомИнтервалов`,
`ПолучитьПросроченнуюЗадолженность`. В отчёте это функции `ТекстЗапросаОтчета`, `УстановитьПараметрыСхемы`,
`НастроитьПоляИнтервалов`, `ПросроченнаяЗадолженность`.

## Основной запрос (набор `ОсновнойНабор`)

Пакет временных таблиц:

1. **`СчетаКД`** — счета с субконто «Контрагенты» и «Договоры». Исключаются забалансовые, `&ИсключенныеСчета`
   (в иерархии) и «Податковий кредит».
2. **`ПолученныеДоки`** — документы `ПоступлениеТоваровУслуг` и `ПоступлениеДопРасходов` организации, у которых
   `РС.ОтправкаПолучениеДокументов.ДокументыПолучены = Истина`.
3. **`ВзаиморасчетыОстатки`** — `ОБЪЕДИНИТЬ ВСЕ` трёх веток. Поля: Организация, Контрагент, Договор, СчетНаОплату,
   **Статус**, Счет, ОстатокДолга0:
   - **ветка 1 — «Передоплата»:** `Хозрасчетный.Остатки(&Период, Счет В СчетаКД, &ВидыСубконтоКД,
     Организация = &Организация И ВидДоговора В (СПоставщиком, СКомитентом))`, сумма `СуммаРазвернутыйОстатокДт`;
     `СчетНаОплату = Субконто3`;
   - **ветка 2 — «Немає оригіналу»:** проведённые `ПоступлениеТоваровУслуг` организации, которых нет в `ПолученныеДоки`,
     с датой между `&ДатаНачалаБас` и `&Период`; сумма `СуммаДокумента`, `СчетНаОплату` — сам документ, `Счет = NULL`;
   - **ветка 3** — то же для `ПоступлениеДопРасходов`.
4. **`ОборотыK`** (K = 1..N) — те же три ветки за интервал K. Ветка 1 —
   `Хозрасчетный.Обороты(&НачалоИнтервалаK, &КонецИнтервалаK)`, «увеличение долга» = положительный оборот Дт
   минус отрицательный оборот Кт. Ветки 2–3 — документы, попавшие датой в интервал.
5. **`ОстатокИОбороты`** — `ВзаиморасчетыОстатки` с `ЛЕВОЕ СОЕДИНЕНИЕ ОборотыK` по пяти ключам: Организация,
   Контрагент, Договор, СчетНаОплату, **Статус**.
6. **`ОстаткиПоПериодам`** — `ОстатокДолгаK = макс(0, ОстатокДолга0 − Σ УвеличениеДолга1..K)`.
7. **Итог** — `ОстатокПериодаK = ОстатокДолга(K−1) − ОстатокДолгаK`, `ОстатокПериода(N+1) = ОстатокДолгаN`,
   `ОстатокДолга = ОстатокДолга0`.

Смысл: долг раскладывается **с конца** — самые свежие увеличения долга попадают в первый интервал, остаток
старше последней границы — в «Понад N днів».

Статус в запросе — `ВЫРАЗИТЬ("Передоплата" КАК СТРОКА(20))` и `ВЫРАЗИТЬ("Немає оригіналу" КАК СТРОКА(20))`:
тип объединения не зависит от длины литерала.

## Параметры (`УстановитьПараметрыСхемы`)

| Параметр | Значение | Как в типовом |
|---|---|---|
| `Период` | `КонецДня(ДатаОтчета) + 1` — остатки на начало следующего дня, то есть включая дату отчёта | да |
| `НачалоИнтервалаK` | `НачалоДня(ДатаОтчета) − ДнейK · сутки` | да |
| `КонецИнтервала1` | `КонецДня(ДатаОтчета)` | да |
| `КонецИнтервалаK` (K>1) | `КонецДня(ДатаОтчета) − (Дней(K−1) + 1) · сутки` | да |
| `ВидыСубконтоКД` | Контрагенты, Договоры, ДокументыРасчетовСКонтрагентами | да |
| `ИсключенныеСчета` | `БухгалтерскиеОтчетыВызовСервера.ПолучитьСписокСчетовИсключаемыхИзРасчетаЗадолженности(2)` | да |
| `ДатаНачалаБас` | параметр отчёта | в типовом жёстко 01.07.2023 |

`ИсключенныеСчета` — персональная настройка из `ХранилищеОбщихНастроек`. Если её нет, функция возвращает
`Неопределено`, и отчёт передаёт пустой список, то есть ничего не исключает.

Значения ставятся и в параметры копии схемы, и в настройки компоновки. Параметры для интервалов сверх трёх,
заложенных в макет, добавляются в схему кодом.

## Колонки интервалов (`НастроитьПоляИнтервалов`)

- Перед компоновкой из копии схемы удаляются все поля и итоги `ОстатокПериода*` и добавляются заново под текущие
  интервалы: заголовок («До 7 днів» / «Від 8 до 15 днів» / «Понад 30 днів»), формат `ЧЦ=15; ЧДЦ=0`, итог `Сумма`.
- В выборе пересобирается только папка «Загальна заборгованість по строках боргу». Остальной выбор пользователя
  не трогается.

## Просроченная задолженность (внешний набор `ПросроченнаяЗадолженность`)

`ПросроченнаяЗадолженность(Организация, ДатаОтчета, ДатаНачалаБас)` — перенос `ПолучитьПросроченнуюЗадолженность`
типового плюс Статус в ключах:

1. **Срок оплаты** по каждому ключу: `Договор.СрокОплаты`, если `Договор.УстановленСрокОплаты`, иначе
   `Константы.СрокОплатыПоставщикам`.
2. **Обороты-увеличения долга** за последние «срок оплаты» дней. Запросы режутся пачками по 10 сроков
   и объединяются в `ОБЪЕДИНИТЬ ВСЕ`.
3. **Просрочено** = `Остаток − мин(Остаток, Увеличение)`, в выборку только > 0.

Ветка «Немає оригіналу» здесь только по `ПоступлениеТоваровУслуг`, без допрасходов — как в типовом.
Набор связан с основным по пяти ключам, включая Статус.

## Чем отличается от типового (сознательно)

| Отличие | Почему |
|---|---|
| Поле **Статус** и ключ Статус во всех соединениях | Требование пользователя. Побочный эффект: документ, попавший и в ветку 1, и в ветку 2, раскладывается по интервалам внутри своей ветки, а не вперемешку |
| Отбор по организации — **в условии виртуальных таблиц** | В типовом его ставил отбор СКД из формы «Бухгалтерських звітів» |
| Интервалы — параметр-строка | В типовом — ТЧ формы |
| `ДатаНачалаБас` — параметр | В типовом — константа в коде |
| «Загальна заборгованість» с копейками | Бухгалтеру нужна сверка до копейки; интервалы без копеек, как было |
| Нет диаграммы и обособленных подразделений | В группе обособленных подразделений нет |
