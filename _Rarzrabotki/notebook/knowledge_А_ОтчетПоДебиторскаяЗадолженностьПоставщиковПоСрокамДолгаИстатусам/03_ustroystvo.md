# 03. Устройство отчёта

## Две копии, один источник

| | Встроенный (основной) | Внешний (запасной) |
|---|---|---|
| Где | `_Rarzrabotki/BASEBuh/Reports/<имя>.xml` + папка | `_Rarzrabotki/Отчеты/<имя>.xml` + папка + `.erf` |
| Метаданные | `<Report>`, `UseStandardCommands = true`, `VariantsStorage = ХранилищеВариантовОтчетов` | `<ExternalReport>`, `ClassId` — константа класса |
| Модуль | без `СведенияОВнешнейОбработке` и таблицы команд | с ними (регистрация в «Додаткові звіти») |
| Макет СКД | тот же файл | тот же файл |

Обе копии **генерирует** `otchet_debitorka_statusy_generate.py`:
- корневые XML и метаданные макета — с постоянными UUID;
- `Template.xml` — запрос N=3 из `otchet_debitorka_statusy_zapros.py`, отборы из `otchet_debitorka_statusy_otbory.xml`;
- модуль встроенного — модуль внешнего без функций внешнего отчёта.

Модуль объекта пишется руками только во внешней копии: `_Rarzrabotki/Отчеты/<имя>/Ext/ObjectModule.bsl`.
**Править XML и модуль встроенного отчёта напрямую нельзя** — генератор перезапишет ([05](05_kak_dorabotat.md)).

Формы своей нет: `CommonForm.ФормаОтчета`, `ФормаНастроекОтчета`, `ФормаВариантаОтчета`.

## Модуль объекта

| Процедура / функция | Экспорт | Назначение |
|---|---|---|
| `ОпределитьНастройкиФормы` | да | БСП: включает событие `ПередЗагрузкойНастроекВКомпоновщик` |
| `ПередЗагрузкойНастроекВКомпоновщик` | да | Умолчания варианта, только пустые: Період = сегодня, Організація = основная, значения отборов «Не в списку» |
| `ТекстЗапросаОтчета(N)` | да | Текст основного запроса на N интервалов (экспорт — для приёмки) |
| `ПросроченнаяЗадолженность(Орг, Дата, ДатаБАС)` | да | Таблица внешнего набора просрочки |
| `ПриКомпоновкеРезультата` | — | `СтандартнаяОбработка = Ложь` → `СформироватьОтчет` |
| `СформироватьОтчет(ДокументРезультат, ДанныеРасшифровки)` | да | Весь путь пользователя (экспорт — для приёмки через COM) |
| `ТекстВеткиДокумента` | — | Ветки 2–3 запроса (`ПТУ` / `ПДР`) по шаблону `#Д#` |
| `ВидыСубконтоРасчетов`, `ИсключенныеСчета` | — | Параметры запроса |
| `ОтборыПоУмолчанию`, `СписокСсылок` | — | Ссылки отборов бухгалтера по UUID |
| `РазобратьИнтервалы`, `ЗаголовокИнтервала` | — | «7, 15, 30» → массив; заголовки колонок |
| `НастроитьПоляИнтервалов`, `ПапкаИнтервалов` | — | Поля и итоги `ОстатокПериода*` под интервалы; папка в выборе |
| `УстановитьПараметрыСхемы` | — | Значения параметров в схеме и настройках |
| `ВывестиШапку`, `ТекстОтбора`, `ТекстЗначенияОтбора`, `ПредставлениеВидаСравнения`, `ТекстПорядка`, `ЗаголовокПоля` | — | Шапка: организация, заголовок, «Відбір:», «Сортування:» по-украински |
| `ЗначениеПараметра` | — | Чтение параметра из настроек. В BuhBud нет `КомпоновкаДанныхКлиентСервер.ПолучитьПараметр` |

**Порядок `СформироватьОтчет`:**
1. Настройки из компоновщика.
2. Дата, организация (пусто → основная → иначе исключение), дата начала BAS, интервалы.
3. Свежая копия схемы `ПолучитьМакет(…)`, в неё — текст запроса на N интервалов, поля интервалов, параметры.
4. Внешний набор просрочки.
5. `КомпоновщикМакета` + `ПроцессорКомпоновки` с `ДанныеРасшифровки` — двойной клик открывает документ.
6. Очистить документ, вывести шапку, вывести результат СКД.

СКД сама считает фиксацию шапки (12 строк: 7 нашей шапки + 5 заголовка таблицы).

## Схема СКД (`Templates/ОсновнаяСхемаКомпоновкиДанных`)

**Наборы:**
- `ОсновнойНабор` — запрос, `autoFillFields = false`. В макете текст на 3 интервала, при формировании подменяется.
- `ПросроченнаяЗадолженность` — объект, внешний набор.
- Связи по 5 ключам: Организация, Контрагент, Договор, СчетНаОплату, Статус.

**Поля** (заголовки только украинские, в `title` ru и uk одинаковые):

| Поле | Заголовок | Тип / роль |
|---|---|---|
| Организация, Контрагент, Договор | Організація, Постачальник, Договір | ссылки, измерения |
| СчетНаОплату | Рахунок на оплату | измерение, **тип не задан** — составной из запроса |
| Статус | Статус боргу | Строка(20), измерение: для отборов и группировок |
| ОстатокДолга | Загальна заборгованість | `ЧЦ=15; ЧДЦ=2` |
| ОстатокПериода1..4 | До 7 / Від 8 до 15 / Від 16 до 30 / Понад 30 днів | `ЧЦ=15; ЧДЦ=0` |
| ПросроченнаяЗадолженность | У т.ч. прострочена заборгованість | из внешнего набора, `ЧДЦ=0` |

**Вычисляемые поля и ресурсы:**
- `СтатусДокумента` («Статус») = `Статус`; ресурс `Максимум(Статус)` только в группировке `СчетНаОплату`.
  Обычное поле в строке группировки не выводится ([LESSONS §3](LESSONS.md)).
- `Коментар` = `""`; ресурс `""` только в группировке `СчетНаОплату`; `МинимальнаяШирина = 45`.
- Итоги `Сумма(…)` для ОстатокДолга, ОстатокПериода*, ПросроченнаяЗадолженность.

**Параметры:**
- видимые: Период («На дату», Дата), Организация, Интервалы (Строка 100), ДатаНачалаБас;
- служебные, скрытые: ВидыСубконтоКД, ИсключенныеСчета, НачалоИнтервала1..3, КонецИнтервала1..3.

**Вариант «Основний»** (представление — название отчёта):
- выбор: Вх. номер (`СчетНаОплату.НомерВходящегоДокумента`, заголовок «Вх. номер»), Загальна заборгованість,
  папка интервалов, прострочена (выкл.), Статус, Коментар;
- 12 отборов: 11 бухгалтерских + «Статус боргу» выкл.; `userSettingID` у отбора;
- данные: Период и Организация — быстрые настройки; Интервалы и ДатаНачалаБас — обычные;
- порядок: ОстатокДолга по убыванию;
- условное оформление: поле Контрагент — цвет `#B22222`, шрифт `sys:DefaultGUIFont height=10 bold`;
- вывод: макет «Море», `РасположениеРеквизитов = Отдельно` («Вх. номер» в своей колонке); стандартные заголовок,
  отбор и параметры выключены — шапку выводит модуль;
- структура: Договор.Ответственный → Договор.Подразделение → Контрагент (иерархия) → Договор → СчетНаОплату.

## Встраивание в конфигурацию

- **Регистрация:** `<Report>…</Report>` в `_Rarzrabotki/BASEBuh/Configuration.xml` **основного каталога**.
  Файл в worktree отстаёт от живой базы — не использовать.
- **Подсистема:** `Subsystems/Руководителю/Subsystems/РасчетыСПоставщиками.xml` — строка после типового «Розширеного».
  По подсистемам отчёта БСП-панель раздела «Керівнику» строит группы.
- **Права Use + View:**
  - `ВызовОнлайнПоддержки` и `ЗапускВебКлиента` — как у типовых «Дебіторських», в git;
  - `ДобавлениеИзменениеДанныхБухгалтерии` и `ЧтениеДанныхБухгалтерии` — только в основном каталоге,
    там незакоммиченные боевые правки ролей.
- **БСП-вариант** зарегистрирован: справочники `ВариантыОтчетов` и `ПредопределенныеВариантыОтчетов`, ключ «Основний».
  Регистрация возможна только при `VariantsStorage = ХранилищеВариантовОтчетов`.
