# 01. Назначение и использование

## Для чего

Отчёт заменяет еженедельный Excel бухгалтера («Дебеторка на 22_09.xls»), в котором к выгрузке типового отчёта
«Дебіторська заборгованість постачальників по строках боргу (розширений)» вручную дописывались статус и ответственный.

- **Статус** теперь считается автоматически.
- **Ответственный** — первый уровень группировки «Договір.Відповідальний». Реквизит договора заполнен по счетам казны.

## Где открыть

- **Основной путь:** раздел «Керівнику» → панель отчётов → группа рядом с типовыми «Дебіторська заборгованість
  постачальників…». Отчёт входит в подсистему «Руководителю → РасчетыСПоставщиками». Вариант называется полным именем отчёта.
- **Запасной путь:** внешний `.erf` через «Адміністрування → Друковані форми, звіти та обробки → Додаткові звіти та обробки».
  Если встроенный доступен, внешний не подключать, чтобы не было двух одинаковых пунктов.

Права (Use, View): роли «ДобавлениеИзменениеДанныхБухгалтерии», «ЧтениеДанныхБухгалтерии», «ВызовОнлайнПоддержки»,
«ЗапускВебКлиента» — та же аудитория, что у соседних отчётов раздела. «ПолныеПрава» — автоматически.

## Параметры

| Параметр | Где | По умолчанию | Смысл |
|---|---|---|---|
| **На дату** (`Период`) | шапка формы | сегодня | Остатки на конец этой даты |
| **Організація** | шапка формы | основная организация пользователя | Обязательна; пусто и нет основной → «Вкажіть організацію.» |
| **Інтервали, днів** | «Настройки…» | `7, 15, 30` | Границы интервалов: числа через запятую; порядок, повторы и нули не важны |
| **Дата початку обліку в BAS** | «Настройки…» | 01.07.2023 | С какой даты брать поступления без оригиналов |

Из интервалов `7, 15, 30` получаются колонки «До 7 днів», «Від 8 до 15 днів», «Від 16 до 30 днів», «Понад 30 днів».
Можно задать сколько угодно интервалов — колонки перестроятся.

**Исключённые счета** берутся из персональной настройки пользователя «Настройка рахунків обліку розрахунків
з постачальниками». Её задают в форме типового отчёта, так же, как в типовом.

## Что выводится

**Шапка:**
1. Организация.
2. «Дебіторська заборгованість постачальників по строках боргу на ДД.ММ.РРРР».
3. «Відбір:» — включённые отборы по-украински.
4. «Сортування:».

**Группировки** (вариант «Основний»):
1. Договір.Відповідальний.
2. Договір.Підрозділ.
3. Постачальник — с группами справочника.
4. Договір.
5. Рахунок на оплату — документ расчётов: рахунок, банківське списання, надходження, повернення…

**Колонки слева направо:**

| Колонка | Формат | Примечание |
|---|---|---|
| Вх. номер | — | Входящий номер документа (реквизит «Рахунок на оплату») |
| Загальна заборгованість | с копейками (`ЧДЦ=2`) | |
| Загальна заборгованість по строках боргу | без копеек (`ЧДЦ=0`), как в типовом | Колонки интервалов |
| У т.ч. прострочена заборгованість | | Есть в выборе, по умолчанию **выключена** (в эталоне её нет) |
| **Статус** | | Только в строке документа |
| **Коментар** | ширина ~45 символов | Пустая, для заметок менеджеров |

Сумма интервалов строки равна «Загальна заборгованість» с точностью до округления копеек.

**Оформление:** макет «Море», поставщик — тёмно-красным (цвет стиля «Важлива подія», `#B22222`) полужирным,
сортировка по загальній заборгованості по убыванию.

## Статус

| Статус | Откуда строка | Что значит для бухгалтера |
|---|---|---|
| **Передоплата** | дебетовый остаток по счетам расчётов с поставщиками (договоры «С поставщиком» и «С комитентом») | Поставщику заплатили больше, чем он поставил: ждём поставку или возврат денег |
| **Немає оригіналу** | проведённые надходження товарів/послуг и допрасходов без отметки «документи отримані» | Поставка в учёте есть, оригинала первички нет |

Других значений нет — решение пользователя от 30.09.2026. Ручные статусы бухгалтера («на візі», «заморожено»,
«претензія» и т.п.) не переносились. Если документ попал в обе ветки (переплата по поставке без оригинала),
он выводится двумя строками — по строке на статус.

## Отборы варианта по умолчанию

Это рабочие отборы бухгалтера, подставляются при загрузке варианта:
- Постачальник **не в списку** «ДЖИ ТРИ КОНСТРАКШН ТОВ»;
- Договір.Підрозділ **не в списку**: «Главный офис», «Пьемонт Реал Эстейт», Пьемонт Реал Эстейт №1–№4, №7;
- Рахунок на оплату.Дата **більше** початку минулого року.

Ещё 9 отборов выключены и доступны в «Настройки…»: договор, документ, наименования («глоб», «аврор»), вх. дата
и номер, підрозділ «дорівнює», **Статус боргу = …** (быстро показать один статус).

Свои изменения пользователь сохраняет обычным способом — они перекрывают умолчания.

## Выгрузка в Excel

Стандартная «Зберегти…» формы отчёта. Колонка «Коментар» широкая — для ручных заметок.
Группировки строк переносятся в xlsx (уровни можно сворачивать в Excel).
