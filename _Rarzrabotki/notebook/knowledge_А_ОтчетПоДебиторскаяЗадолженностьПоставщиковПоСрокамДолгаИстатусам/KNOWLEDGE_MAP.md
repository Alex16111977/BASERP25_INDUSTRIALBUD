# KNOWLEDGE MAP — Отчет.А_ОтчетПоДебиторскаяЗадолженностьПоставщиковПоСрокамДолгаИстатусам

Точка входа для ИИ-сессий. **Прочитать первым** перед любой доработкой отчёта.

> Синоним «Дебіторська заборгованість постачальників за строками боргу та статусами».
> База: **BuhBud** — `Srvr="SQLSERVER";Ref="bas_industrialbud";Usr="cfo";Pwd="2442"`. **НЕ BaseERP.**
> Источник истины — **живой код** `_Rarzrabotki/BASEBuh/Reports/<имя>/` и генератор
> `_Rarzrabotki/Python/test/otchet_debitorka_statusy_generate.py`, а не эта база знаний.

## Суть за 60 секунд

1. **Данные — типовой отчёт `ДебиторскаяЗадолженностьПоставщиковПоСрокамДолгаРасширенная` один в один.**
   Это не чистая СКД, а механизм «Бухгалтерські звіти»: текст запроса строится кодом под число интервалов.
   Логику перенесли в модуль объекта ([02](02_dannye_i_raschet.md)).
2. **Три источника строк** (`ОБЪЕДИНИТЬ ВСЕ`):
   1. дебетовые остатки расчётов с поставщиками в `РегистрБухгалтерии.Хозрасчетный`; «Рахунок на оплату» = `Субконто3`;
   2. проведённые `ПоступлениеТоваровУслуг` без отметки `ОтправкаПолучениеДокументов.ДокументыПолучены`;
   3. то же для `ПоступлениеДопРасходов`.
3. **Статус — по источнику строки**, а не по виду документа:
   - ветка 1 → «Передоплата»;
   - ветки 2–3 → «Немає оригіналу».

   Статус — литерал в каждой ветке и ключ всех соединений.
4. **Интерфейс — БСП**: `CommonForm.ФормаОтчета`, вариант «Основний», «Настройки…». Вариант по умолчанию повторяет
   рабочие настройки бухгалтера Шостак Жанети ([01](01_naznachenie_i_ispolzovanie.md)).
5. **Две копии одного отчёта.**
   - **Встроенный** (основной): `_Rarzrabotki/BASEBuh/Reports/<имя>` — подсистема «Руководителю → РасчетыСПоставщиками».
   - **Внешний** (запасной): `_Rarzrabotki/Отчеты/<имя>.erf`.

   Оба выпускает один генератор ([03](03_ustroystvo.md)).
6. **Ссылки на данные базы в варианте не хранятся.** В `.erf` они превращаются в строки, поэтому организацию,
   дату и отборы бухгалтера подставляет `ПередЗагрузкойНастроекВКомпоновщик` — только если значения пустые.
7. **Только украинский.** Свои тексты — шапка, «Відбір», «Сортування», заголовки — по-украински. Представления
   документов и «Разом» переводит платформа в украинском интерфейсе; своего кода перевода нет.
