# LESSONS — грабли (проверенные на этом проекте)

## Метаданные / конфигурация
- **`ВнешнееСоединение=Истина` у общих модулей**, вызываемых из модуля документа — иначе запись документа
  через COM падает на компиляции («Переменная не определена»). `Привилегированный` при этом несовместим.
- **Реквизит ТЧ `Дата`** конфликтует со стандартным именем — назвать `ДатаВизы`.
- **Версия формата исходников обработки — 2.13**, не 2.17: платформа 8.3.20 иначе не грузит `.epf`
  («Неизвестная версия формата 2.17»). `epf-init` ставит 2.17 — поправить во всех XML обработки.
- **Частичная загрузка формы** — указывать объект метаданных `…\Forms\ФормаДокумента.xml`, а **не**
  Ext-подпути (`…\Ext\Form.xml`, `…\Ext\Form\Module.bsl`) — иначе «Неизвестный объект метаданных …Ext».

## BSL / запросы
- **Rule #-1:** каждый запрос — Python COM на реальной базе ПЕРЕД BSL.
- **`В`, `ИЗ`, `ПО`, `КАК` — зарезервированы.** Алиас `КАК В` → «Ожидается имя». Использовать `Виз` и т.п.
- **Неограниченная строка** (`Комментарий`) в `ГДЕ`/сравнении — только через `ВЫРАЗИТЬ(… КАК СТРОКА(N))`.
- **`Уровень()`** (метод ссылки, монотонен по иерархии) вместо `ПолныйКод()` для меры специфичности:
  `ПолныйКод()` падает на пустой ссылке и немонотонен.
- **Движок визы документ НЕ пишет** — после `А_Виза_УстановитьСостояние(...)` вызывающий делает `Записать()`.
- **`РеквизитФормыВЗначение("Заказы").Итог()`** — у коллекции формы `.Итог()` нет; считать итог по реальной
  ТЗ **до** `Заказы.Загрузить(ТЗ)`.

## Формы
- **Цвет во внешней обработке — только кодом** (`Новый Цвет`/`WebЦвета`/`ЦветаСтиля` + `УсловноеОформление`);
  `<TextColor>style:`-XML валит `epf-build` («Исключение XDTO»).
- **Подсветка динсписка** — `Список.КомпоновщикНастроек.Настройки.УсловноеОформление` (не `УсловноеОформление`
  формы — оно для ТЗ/реквизитов, к строкам динсписка не применяется).
- **Период динсписка = два отбора по одному полю `Дата`** (>= и <=): типовой
  `УстановитьЭлементОтбораДинамическогоСписка` НЕ годится — ищет элемент только по имени поля, второй вызов
  перезаписывает первый. Нужен свой поиск по **полю + виду сравнения** (`ФиксированныеНастройки.Отбор`).
- **Отборы, сохраняемые между сеансами** (`ОтборыСписковКлиентСервер.ОтборПоЗначениюСпискаПриЗагрузкеИзНастроек`):
  реквизиты формы должны называться **именами полей списка** (ключ Настроек = имя колонки), плюс `<Save>`
  у реквизита и `AutoSaveDataInSettings=Use` у формы.
- **Картинок Казны `Успешно32`/`Ошибка32` в ЕРП НЕТ.** Аналоги: `ВыполненоУспешно`, `ОтменитьОперацию`,
  `ВыполненоСОшибками`, `РедактироватьФайл`, `ВыполнитьРегламентноеЗаданиеВручную`.
- **Контроль формы .epf без клиента** — обратная выгрузка
  `/DumpExternalDataProcessorOrReportToFiles` и diff XML: видно, что платформа реально сохранила
  (headless-рендер невозможен, а сборка «успешно» не гарантирует состав).
- **Условное оформление динсписка/таблицы** — идемпотентно: первым делом `УсловноеОформление.Элементы.Очистить()`.
- **Dangling `<Event>`** без процедуры в модуле = падение в рантайме. После `form-compile`/`form-edit`
  сверять имена обработчиков (Event↔модуль). Здесь: `Selection`→`ЗаказыВыборСтроки` (не `ЗаказыВыбор`).
- **`ВыделенныеСтроки` ТЗ формы = идентификаторы** (нужен `НайтиПоИдентификатору`); у динамического
  списка — уже ссылки.
- **`form-validate` ложно ругается** на `ExternalDataProcessorObject.*` («External* in configuration
  context») и версию 2.13 для форм внешних обработок — это НЕ дефекты (существующие рабочие `.epf`
  проекта используют ровно `ExternalDataProcessorObject`).
- **Управляемую форму нельзя проверить headless через COM** — визуальный рендер только открытием в клиенте.

## COM (в тестах, не дефекты кода)
- `erp.String()` от перечисления → **синоним**, а не имя.
- `ДокОбъект.УстановитьСтатус("X", None)` из Python ломается (Python `None` ≠ `Неопределено`); из BSL работает.
- `erp.ТекущаяДата()` / `CurrentDate()` — нет; брать `datetime`.
- Пустая дата 1С (`ДАТАВРЕМЯ(1,1,1)`) через `SetParameter(datetime(1,1,1))` — Invalid argument; в запросе
  использовать литерал `ДАТАВРЕМЯ(1,1,1)`.
- Тесты проведения — не `Удалить()`, а get-or-create по маркеру + `ОтменаПроведения` в уборке.
