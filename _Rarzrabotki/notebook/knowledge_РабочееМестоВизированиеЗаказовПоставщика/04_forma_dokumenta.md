# 04. Вкладки визы в форме документа `ЗаказПоставщику.ФормаДокумента`

> Визуал «как в Казне» (эталон `СчетНаОплатуПоставщика.ФормаДокумента`): две вкладки в `ГруппаСтраницы`
> и **динамическое подменю «Виза»** в командной панели формы. Переделано 15.07.2026 (ПРОМТ3) с одной
> страницы «Визирование» (3 таблицы подряд + 4 фиксированные кнопки). Форма — большая БСП «единое окно»,
> правка хирургическая (Form.xml + регион `//++ А_Визирование` модуля). Типовые страницы/логика не тронуты.
> Загружена в BaseERP частичной загрузкой (`db-load-xml -Mode Partial`), проверена в клиенте.

---

## 1. Вкладка «Виза» (`А_ГруппаВиза`, аналог Казны `грВиза`)

Горизонтальная страница, внутри вертикальная колонка:

| Блок | Содержание |
|---|---|
| `А_ГруппаВизаТаблицы` (AlwaysHorizontal, ReadOnly) | **слева** таблица `А_Визы` — маршрут/история: `N` (НомерСтроки), `Роль`, `Авто`, `Пользователь`, `ДатаВизы`, `Виза_Состояние`, `Комментарий`; **справа** узкая таблица `А_ТекущиеВизирующие` (`Пользователь`) |
| `А_ГруппаВизаНиз` (Vertical) | `А_ПриоритетнаяСхемаВизирования` (редактируемая), `А_КомментарийЗаказа` (`Объект.Комментарий`), `А_Виза_Причина` (просмотр; видимость — только когда заполнена, ставится кодом) |

Отдельных полей состояния (`А_Виза_Состояние`/`ТекущаяРоль`/`Дата`) на вкладке больше нет: текущее
состояние видно по таблицам и по **заголовку подменю «Виза»** (= текущая роль).

## 2. Вкладка «Предварительные визы» (`А_ГруппаПредВиза`, аналог `грПредВиза`)

Таблица `А_ПредварительныеВизы`: `N`, `Пользователь`, `Роли`, `Утверждено`, `ДатаУтверждения` (просмотр).

## 3. Подменю «Виза» в командной панели (динамические кнопки, паттерн Казны)

XML: в `AutoCommandBar` формы добавлен `Popup А_Кнопки_Виза_Заголовок` (картинка
`CommonPicture.ВыполненоУспешно`, PictureAndText) с пустой `ButtonGroup А_Кнопки_Виза`; единственная
команда формы — `А_Виза_Нажатие` (`CurrentRowUse=DontUse`). Кнопки создаются в рантайме.

Регион `А_Визирование` модуля формы:

| Процедура | Что делает |
|---|---|
| `А_Виза_УстановитьДоступностьФормы()` (сервер) | чистит группу кнопок; заголовок Popup = `А_Виза_ТекущаяРоль` или «Виза»; видимость `А_Виза_Причина`; по **сохранённому** заказу берёт `Документы.ЗаказПоставщику.А_Виза_ДоступныеСостояния(Ссылка).Состояния` и на каждый элемент списка создаёт команду (`А_Виза_КомандаНайтиСоздать("А_Виза_"+ИмяСостояния)` → действие `А_Виза_Нажатие`) и кнопку с картинкой. Вызовы: конец `ПриСозданииНаСервере`, конец `ПослеЗаписиНаСервере`, после каждого действия визы |
| `А_Виза_Нажатие(Команда)` (клиент) | гард: заказ записан и не модифицирован; имя состояния = `СтрЗаменить(Команда.Имя, "А_Виза_", "")`; для `Отклонено`/`Анулировано`/`УтвержденСКомментариями` — `ПоказатьВводСтроки` причины/комментария |
| `А_Виза_ДействиеСервер(ИмяСостояния, Причина)` | `А_ВизированиеВызовСервера.УстановитьВизуДокументов({Ссылка}, ИмяСостояния, Допы)` (пакетный движок сам пишет) → `ЗначениеВРеквизитФормы(...ПолучитьОбъект(), "Объект")` → перестроить кнопки |

Картинки состояний (в ЕРП НЕТ казначейских `Успешно32`/`Ошибка32`!):

| Состояние | `БиблиотекаКартинок.` |
|---|---|
| `Утвержден`, `УтвержденСКомментариями` | `ВыполненоУспешно` |
| `Отклонено` | `ОтменитьОперацию` |
| `Черновик` | `РедактироватьФайл` |
| `Анулировано` | `ВыполненоСОшибками` |
| `ПустаяСсылка()` («Подписать заранее» → имя `Предварительная`) | `ВыполнитьРегламентноеЗаданиеВручную` |

## 4. Ключевые отличия от Казны

- **Форма не гасится**: Казна выключала `ТолькоПросмотр` всех полей при недоступности визы — у нас виза
  ничего не блокирует (см. FINDINGS §Решение), строится только набор кнопок.
- Представления кнопок приходят готовыми из `ДоступныеСостояния` (`СписокЗначений`: значение = состояние,
  представление = текст кнопки: «Отправить на визирование», «Утвердить», «Подписать заранее»...).
- Пустая ссылка состояния маппится в имя **`Предварительная`** (контракт пакетного движка), а не `ПустаяСсылка`.

## 5. Проверка

Частичная загрузка `Documents\ЗаказПоставщику\Forms\ФормаДокумента.xml` + `/UpdateDBCfg` — успешна;
`form-validate` — 0 ошибок; сверка Event/Action ↔ процедуры модуля — полная; визуально проверено в клиенте
(вкладки «Виза»/«Предварительные визы», подменю показывает текущую роль, напр. «Тест Снабженец»).
