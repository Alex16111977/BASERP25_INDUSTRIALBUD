```python
def fifo(card, thr, temp):
    hs = sorted([h for h in VRM["houses"] if h["card"] == card], key=lambda h: int(h["house"].split("№")[1].split()[0]))
    out, left, i = [], temp, 0
    for h in hs:
        need = max(0.0, h["plan_h"] * thr - h["done_h"])
        if need == 0: out.append("отгружен"); continue
        while need > 1e-6:
            take = min(need, left); need -= take; left -= take
            if need > 1e-6: i += 1; left = temp
        out.append(["2026-10", "2026-11", "2026-12", "2027-01"][i])
    return out
print(fifo("000000009", 1.0, 1139.09), fifo("000000011", 1433.3332 / 2149.9998, 1554.67))  # порог — точный, как в F8
```

**Посчитать «что если», ничего не записывая** (так получен §5; проверено запуском на коде v2, вывод с точностью

```python
spec = importlib.util.spec_from_file_location("calc_copy", os.path.join(T, "calc_copy.py"))

for n in ("save", "excel", "записать", "сверки", "conn", "query"): setattr(m, n, None)  # запись невозможна
ИСХ = {n: copy.deepcopy(getattr(m, n)) for n in ("VRM", "CARDS")}  # глобальные снимки, которые правит pre()
def сброс():  # без него правки pre() накапливаются от сценария к сценарию и §5 не воспроизводится
    for n, v in ИСХ.items():
        g = getattr(m, n); g.clear(); g.update(copy.deepcopy(v))   # тот же объект: функции модуля видят сброс
def run(patch=None, сц="real", pre=None):

    return sum((r["sum"] if r["dir"] == "Приход" else -r["sum"]) for r in rows
               if r["art"] not in m.ОПЕР_ИСКЛ and r["proj"] in m.ПРОЕКТЫ13)

print(чистый(run()))                                            # база
print(чистый(run(lambda д, н, пф: пф["un"].update(lag50=1))))   # 50 % УВБК через +1 мес.
print(чистый(run(lambda д, н, пф: пф["fa"].update(rate=0.15))))  # комиссия ФА 15 %
```

Как менять разные виды параметров в такой копии:
- **Параметры профилей** (`пф[...]`: `irc.same/next`, `un.*`, `fa.*`, `mat_lead`, `labor_kernel`) — через
  `patch(д, н, пф)`. `пф`, `д`, `н` создаются заново при каждом `run()`, сброс не нужен.
- **График ООН 2026** — правка `д["houses"]["МД ООН 2026"][i]["ship_real"]` и пересборка
  `д["real"]["МД ООН 2026"] = Counter(...)` (тоже в `patch`).
- **Темп** — масштабировать `m.VRM["ev"][].hours` за 2026-09 **только через `pre`** (пример `темп(k)`).
- **Нормы карточек** — `m.CARDS[код]["materials"]` **только через `pre`** (пример `нормы_эк()`).
- **Внимание:** `m.VRM`, `m.CARDS` и другие снимки (`m.PLAN`, `m.OTGR`, `m.REC`, `m.KNIGA`, `m.DOLGI`, `m.ECON`,
  `m.FAKT`) — глобальные объекты модуля. Правка без восстановления остаётся на все следующие `run()` в той же
  сессии (например, строки 7 и 8 подряд дадут × 1,2 × 0,8). Поэтому `run()` начинается со `сброс()`. Если правите
  другой снимок — добавьте его имя в `ИСХ` (`m.OTGR`, `m.REC`, `m.ECON` — списки, для них сброс
  `g[:] = copy.deepcopy(v)` вместо `clear()/update()`) или
  перезагружайте модуль перед каждым сценарием.
- **Порог ООН Админ** зашит аргументом в `РАСЧ:182`. Для «что если» править текст копии: заменить
  `д["thr_adm"], темп_адм` на `1.0, темп_адм`.
- **Константы-справочники v2** (`ВНУТР`, `ДОП_ЗАКАЗЫ`, `ФИН_ПОМОЩЬ`, `РАСЧ:34–43`) — множества и словарь модуля;
  для «что если» менять их в копии **до** `run()`. Проверено: `m.ВНУТР = {"УТ-001163"}` воспроизводит v1 до
  копейки (−10 590 062,11, 302 строки). Пустое `m.ВНУТР = set()` — **не** v1: в v1 УТ-001163 была исключена из ЦО
  явным списком, а в v2 только через `ВНУТР`, и её поступления-возвраты попадут в ЦО (−7 523 949,16, 305 строк).
  `ОПЕР_ИСКЛ` собирается из `ФИН_ПОМОЩЬ` при импорте (`РАСЧ:672`) и сам не пересчитается.

**Изменить параметр всерьёз** (новая версия сценария):
1. Поменять константу в `РАСЧ` (строки в §1). Для данных — обновить снимки скриптами `moy_byudzhet_06 → 01 → 03 →
   04 → 05 → 08 → 09 → 10` (`07_moy_metod…`, §8). Это перезапишет `DATA\*.json`. Калибровка (14,12 %, лаги,
