- **документ `Документ.А_ПотребаЗавершенняПроекту`** — «Потреба на завершення проєкту». Хранит список директора
  «что ещё купить, чтобы закончить проект»;

  если докупить только этот список.

## Коротко для пользователя

Директор присылает Excel со списком: что ещё нужно купить по проекту — позиция, количество, цена, сумма, дома.
Порядок работы:

1. В документе «Потреба на завершення проєкту» выбрать підрозділ проєкту и нажать **«Заповнити з Excel»**. Документ
   сам найдёт раздел проекта в файле, подберёт загальні назви из сметы и покажет, что не нашёл.
2. Документ **провести** — это значит «список затверджено».
3. Отчёт «Прогноз виконання СС за потребою» на нужную дату считает:
   - **Прогноз** = уже закуплено + список директора;
   - **Економія за потребою** = план СС − прогноз. Это главная колонка.

   Колонки «Прогноз за СС» и «Економія за СС» нужны только для сравнения: так считал прежний «План-факт», который
   докупал всё недокупленное по цене сметы.
4. Новый список — новый документ. Старые остаются историей, отчёт берёт последний на дату.
