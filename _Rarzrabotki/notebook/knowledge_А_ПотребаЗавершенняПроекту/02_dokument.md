# 02. Документ `А_ПотребаЗавершенняПроекту`

Синоним «Потреба на завершення проєкту». Синонимы и заголовки — на `ru` и `uk`, в обоих текст украинский: у
пользователей с украинским интерфейсом без `uk` были бы пустые подписи.

## Метаданные

- **Номер:** строка, 11 символов, периодичность Year. Проведение `Allow`, `RealTimePosting=Deny`, `RegisterRecords` пусто,
  блокировки `Managed`.
- **Формы:** `ФормаДокумента`, `ФормаСписка`, `ФормаВыбора`. Образец формы — `А_ПередачаНачисленийМеждуПодразделениями`:
  `CommandSet`, команды «Провести та закрити» / «Записати» / «Провести», подменю БСП.
- **Движений нет. «Проведён» значит «затверджено».** Отчёт видит только проведённые и не помеченные на удаление.
  `ОбработкаПроведения` нет, `ПроведениеДокументов.*` не вызывается: из `bas-doc-new` взяты только метаданные и
  формы. Проведение без движений работает.

## Модули

- **Модуль объекта** (`Ext/ObjectModule.bsl`):
  - `ОбработкаЗаполнения` и `ПриКопировании` — `Ответственный`; при копировании очищаются `ИмяФайла` и `РазделФайла`;
  - `ПередЗаписью` — выход по `ОбменДанными.Загрузка`, затем `СуммаДокумента = Потреба.Итог("Сумма")`;
  - `ОбработкаПроверкиЗаполнения`:
    - подразделение должно быть среди подразделений активных СС;
    - в каждой строке заполнено `ОбщееНазвание` или `НазваниеСС`;
    - `Сумма >= 0`.
- **Модуль менеджера** (`Ext/ManagerModule.bsl`) — вся логика, вызывается и формой, и через COM:

  | Экспортная функция | Что делает |
  |---|---|
  | `ПодразделенияАктивныхСС()` | массив подразделений активных `А_СтруктураСебестоимости` |
  | `ПрочитатьФайлПотребы(ИсточникФайла, ИмяФайла)` | читает xlsx; источник — адрес временного хранилища **или путь на сервере** (для COM). Возвращает `Структура(Ошибка, Разделы)`. Разделы — массив структур **только из примитивов**: раздел ходит сервер → клиент → сервер |
  | `ЗаполнитьПотребу(ДокументОбъект, Раздел, ЦеныБезНДС)` | подбор ОН и единиц, заполнение ТЧ и шапки. Возвращает `Структура(Ошибка, Строк, Сумма, НеНайдено, Предупреждений)` |
  | `ОбщиеНазванияПроектаПоИмени(Подразделение)` | соответствие «СокрЛП-имя ОН → (Ссылка, Единица, Сумма)» по СС проекта; используется отчётом |
  | `ЧастиСкладеногоНазвания(НазваниеСС)` | «A / B» → массив частей |
  | `НормализоватьТекст(Текст)` | NBSP, апострофы, пробелы, нижний регистр, латинская i → і |

- **Модуль формы документа:**
  - `ПриСозданииНаСервере` — БСП `ПодключаемыеКоманды`, список выбора подразделений (`ПодразделенияАктивныхСС`) и условное оформление;
  - команда `ЗаполнитьИзExcel` — асинхронная цепочка:
    1. подразделение не выбрано — «Спочатку оберіть підрозділ проєкту.» и выход;
    2. `НачатьПомещениеФайла` → `ПрочитатьФайлНаСервере`; ошибка чтения или нет ни одного раздела — `ПоказатьПредупреждение`;
    3. `ПоказатьВыборИзСписка`, если разделов несколько; ошибка раздела (например, контроль ИТОГО) — `ПоказатьПредупреждение`;
    4. в шапке раздела «без пдв» — флажок «Ціни у файлі без ПДВ» включается автоматически;
    5. вопрос «Замінити рядки потреби даними з файлу?» — **только если ТЧ уже не пустая**;
    6. `ЗаполнитьПотребуНаСервере` → `ПоказатьОповещениеПользователя` (или `ПоказатьПредупреждение` с ошибкой).

    Синхронных вызовов нет: режим совместимости 8.3.14, `Асинх/Ждать` недоступны.

## Форма документа

- **Шапка:** номер и дата; «Підрозділ проєкту» — выпадающий список подразделений активных СС; «Файл» и «Розділ файлу»
  только для чтения; флажок «Ціни у файлі без ПДВ (при завантаженні +20 %)».
- **Таблица «Потреба»:** кнопка «Заповнити з Excel» на панели таблицы, итог суммы в подвале.
- **Условное оформление:**
  - строка без загальної назви — колонки «Загальна назва» и «Назва згідно СС» с фоном `WebЦвета.БледноЗолотистый`;
  - заполненное «Попередження» — текст `WebЦвета.ТемноКрасный`. `WebЦвета.Бордовый` в платформе нет, см. [LESSONS](LESSONS.md).
- **Внизу:** «Відповідальний», «Коментар».

## Права, подсистема, интерфейс

- **Роль `А_ПотребаЗавершенняПроектуРедактирование`** (синоним «Потреба на завершення проєкту: редагування»):
  - документ — все права, кроме удаления;
  - отчёт — Use, View;
  - Read/View/InputByString на `А_ОбщиеНазванияНоменклатуры`, `А_СтруктураСебестоимости`, `СтруктураПредприятия`,
    `УпаковкиЕдиницыИзмерения`, `А_ЭтапыРабот`.
- **Чтобы видеть раздел,** пользователю нужна ещё роль `ПодсистемаПроизводство`. В профили групп доступа роли автоматически не добавлялись.
- **Подсистема** «Виробництво → Внутрішньоцеховий облік» (`Subsystems/Производство/Subsystems/ВнутрицеховойУчет.xml`):
  документ, отчёт и роль — рядом с ВРМ.
- **В планы обмена документ не входит:** проверено, ни один план обмена его не содержит.
