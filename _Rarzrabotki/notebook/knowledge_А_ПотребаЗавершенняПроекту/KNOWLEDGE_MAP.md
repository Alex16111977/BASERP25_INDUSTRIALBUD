## Суть за 60 секунд

1. **Документ хранит список директора по проекту.** Один проект — один документ на дату; новый список — новый документ.
   - Движений нет, **«проведён» значит «затверджено»**: отчёт видит только проведённые и не помеченные на удаление.
   - Загрузка — кнопкой «Заповнити з Excel» ([02](02_dokument.md), [03](03_zagruzka_iz_excel.md)).
2. **Отчёт не пересчитывает план и факт сам.** Он вызывает `Отчеты.А_ПланФактныйПроизводствоПолный.Создать().ПолучитьДанные(Период)`
   и берёт строки материалов (`Блок = "2. Матеріали"`). Поэтому план СС, закуплено и «план на факт» совпадают с «План-факт»
   копейка в копейку ([04](04_otchet_raschet.md)).
3. **Метод:**
   - Прогноз = Куплено + Залишок потреби;
   - Економія = План СС − Прогноз. Главная колонка — «Економія за потребою»;
   - «Прогноз/Економія за СС» — для сравнения, это старый метод ([01](01_naznachenie_i_metod.md)).
4. **Списание после списка.** Закупки с датой позже **момента документа** (дата + время) уменьшают потребу той же
   загальної назви, иначе через неделю купленное посчитается дважды.
   - **По количеству** — только для однородных строк с сопоставимыми единицами и правдоподобной ценой.
   - Иначе **по деньгам** ([04](04_otchet_raschet.md)).
5. **Ключ групп = `КлючГруппыПланНаФакт` «План-факт» 1:1**: UUID подразделения + `СокрЛП(ОН.Наименование)`. Дубли
   карточек загальних назв склеиваются по имени. Строка списка без ОН — отдельная группа «поза СС».
6. **«Не докуповуємо (поза списком)»** — залишок за СС, от которого директор отказывается. Сюда входят позиции, которых
   нет в списке, и частичный недокуп по позициям списка. Это поле есть во всех трёх вариантах.
7. **Только украинский текст в выводе, независимо от языка сеанса** ([05](05_otchet_skd_i_vyvod.md)):
   - шапку («на дату. Відбір: …») собирает код;
   - «Итого» заменяется на «Разом»;
   - документ потребы выводится текстом «список від …».
8. **Два носителя отчёта:**
   - встроенный `Reports/А_ПрогнозВиконанняССЗаПотребою` — боевой;
   - `.erf` — для разработки.

   Модуль одинаков, схема — из одного генератора ([08](08_kak_rabotat_i_dorabotat.md)).
