## Корневая причина (системная)

Документы созданные через обмен с Казной (`А_ОбработанКазна=True`) приходят БЕЗ Подразделения в шапке. При проведении:
- Типовая `ПроцедураПроведения` СписанияБезнал/ПКО пишет в РНДС напрямую из `Документ.Подразделение`
- А в ПАП Подразделение берётся через `ВзаиморасчётыСервер` (из Партнёра/ОР) или из Кассы.Подразделение/БС.Подразделение

Системный фикс (на будущее) — варианты:
- **A**: исправить обработку обмена ERP↔Казна — заполнять Подразделение из БС/Кассы при создании документа
- **B**: исправить `ОбработкаПроведения` документов СписаниеБезнал/ПКО — при пустом `Документ.Подразделение` брать из `Касса.Подразделение`/`БанковскийСчет.Подразделение` для записи в РНДС
- **C**: контроль при записи — `ПередЗаписью` запрещает запись с пустым Подразделением

Рекомендация: **B** (точечно в проведении) — минимально инвазивный.
