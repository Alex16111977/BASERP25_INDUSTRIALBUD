# KNOWLEDGE MAP — Balanse Money (расхождение Свод_ДенежныеСредства vs ПАП)

> **Назначение:** карта базы знаний по задаче `Расхождение=Истина` в
> `РегистрСведений.А_ОтчётБаланс_Свод` по источникам **Денежные средства**
> (Безналичные / Наличные / Подотчётные / В пути) для ТОВ ІНДАСТРІАЛБУД.
>
> **Главный entry-point** для ИИ-сессий — читать ПЕРВЫМ.

## TL;DR (за 30 секунд)

**Симптом:** в `А_ОтчётБаланс_Свод` за декабрь 2025 — апрель 2026 ~100 строк с
`Расхождение=Истина` по источникам «Денежные средства *». Главные узлы:
- **ЦО / Денежные средства (безналичные)** — стабильно ±19,2 М каждый месяц
- **Строительство / Денежные средства в пути** — нарастает: 4,9 → 29,4 М
- **Глобино-2 / Денежные средства в пути** — нарастает: -2,6 → -17,0 М
- **КГ Подгорцы / Денежные средства в пути** — нарастает: 0,66 → -19,8 М
- **(пусто) / Денежные средства (безналичные)** — стабильно +19,2 М (зеркало ЦО)
- **(пусто) / Денежные средства (наличные)** — стабильно -1,7 М

**Архитектурная находка (см. README.md):** статья «Денежные средства в пути»
**НЕ имеет источника-регистра** в формуле `Свод_ДенежныеСредства` →
любая запись ПАП по этой статье автоматически даёт плуг
`Расхождение=Истина` с `Δ КО = ПАП − 0`.

**Статус:** 🔴 ОТКРЫТО — исследование стартовало 2026-05-23.

## Принципы для будущих сессий ИИ

См. подробно в [LESSONS.md](LESSONS.md). Краткий список:

1. **Сверка ПАП vs Регистр.Денежные*** — по ключу `(Орг, Подр, Объект)` где Объект = БанковскийСчет / Касса / ПодотчётноеЛицо. **БЕЗ ДокументРегистратор** (в отличие от klient — здесь ОстаткиИОбороты сразу агрегаты).
2. **Денежные средства в пути** — НЕТ источника в `Свод_ДенежныеСредства` → ВСЕ плуги по этой статье архитектурные.
3. **«(пусто)» подразделение** — это `Подразделение = ПустаяСсылка` (записи где не указано подразделение). Скрипты должны обрабатывать ОБА случая.
4. **Дата СЕРВЕРНО** через `ДАТАВРЕМЯ(ГГГГ,М,Д)` в тексте запроса — НЕ через `SetParameter(datetime)` (memory `feedback_balans_etalon_period_serverside`).
5. **Использовать `_common.py`** — не дублировать connect/get_refs/money.
6. **Канон/образец из klient:** `phase6_dec25_co_exact.py` — там показано как зеркалить логику Свод_ из BSL в Python.
