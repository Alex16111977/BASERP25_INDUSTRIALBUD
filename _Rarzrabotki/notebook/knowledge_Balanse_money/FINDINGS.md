## 2. Гипотезы

### 2.1 Гипотеза «ЦО / Безналичные ↔ (пусто) / Безналичные = зеркало»

Видим:
- ЦО / Безнал КМ апр = **-19 236 057,03**
- (пусто) / Безнал КМ апр = **+19 252 492,92**
- Сумма = -19 236 + 19 252 = **+16 435,89** = ровно МД ВООЗ 2025 -16 435,89 (по модулю)

**Гипотеза:** все три суммы по Безналичным являются **группировочной асимметрией** одного и того же набора банковских счетов:
- ПАП пишет с Подразделение=ЦО на сумму X
- РегистрДенСрБезнал пишет с Подразделение=ПустаяСсылка на сумму Y  
- РегистрДенСрБезнал пишет с Подразделение=МД ВООЗ на сумму Z
- X = Y + Z (раскладка по подразделениям другая)

**Проверка:** запросить per БанковскийСчет в обоих регистрах и сравнить группировки.

### 2.2 Гипотеза «Денежные средства в пути = архитектурно нет источника»

В `Свод_ДенежныеСредства` (`ObjectModule.bsl` стр. 621-845) ветки "ВПути" в `втДС` НЕТ. Любая запись ПАП с `Источник=ДенежныеСредстваВПути` автоматически плуг.

**Подтверждение:** все плуги по статье "Денежные средства в пути" имеют `СуммаДССт = 0` (т.е. ПАП есть, втДССт=NULL → Δ = ПАП − 0).

### 2.3 Гипотеза «(пусто) / Наличные = касса без подразделения»

(пусто) / Наличные стабильно -1 724 371,00. Это касса с НЕ заполненным `Подразделение`. Аналогично кейсу ЦО.Безнал.

## 2.4 ⚠️ КРИТИЧЕСКОЕ ОТКРЫТИЕ (2026-05-23): РН.ДенежныеСредстваВПути НЕТ Подразделения
