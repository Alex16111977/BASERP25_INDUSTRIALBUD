## 1. Заголовок и подготовка

```bsl
Функция Свод_ДенежныеСредства(СтруктураШапки, Отказ) Экспорт
    МассивПредст = Новый Массив;
    МассивПредст.Добавить("Денежные средства (безналичные)");
    МассивПредст.Добавить("Денежные средства (наличные)");
    МассивПредст.Добавить("Денежные средства в пути");           // ⚠ ОДНО ВОСПОМИНАНИЕ
    МассивПредст.Добавить("Денежные средства у подотчетных лиц");
    МассивИст = _РефыИсточников(МассивПредст);                   // → ссылки на Перечисление.ИсточникиУправленческогоБаланса
```

`МассивИст` используется ТОЛЬКО для фильтра `втПАП.Источник В (&МассивИст)`.

```bsl
    ПредстБ → ИстБезнал (Перечисление.ИсточникиУправленческогоБаланса.ДенежныеСредстваБезналичные)
    ПредстН → ИстНал    (...ДенежныеСредстваНаличные)
    ПредстП → ИстПодотч (...ДенежныеСредстваУПодотчетныхЛиц)
    // Денежные средства в пути — РЕФА В МАССИВ НЕ БЕРЁТСЯ
```

```bsl
    СтБезнал, СтНал, СтПодотч → ПланВидовХарактеристик.СтатьиАктивовПассивов
    // Денежные средства в пути — СТАТЬЯ НЕ ИСКОМАЯ
```

## 2. Источник РСКПС → таблица `втДС` (UNION ALL 3 регистров)

```sql
-- Безналичные
ВЫБРАТЬ
    Б.Организация, ЕСТЬNULL(Б.Подразделение, ПустаяСсылка) КАК Подр,
    &СтБезнал КАК Статья, &ИстБезнал КАК Source,
    Б.БанковскийСчет КАК ДенежныеСредства,
    ЗНАЧЕНИЕ(Справочник.ФизическиеЛица.ПустаяСсылка) КАК ФизическоеЛицо,
    СУММА(Б.СуммаНачальныйОстаток) КАК СуммаНачальныйОстаток,
    СУММА(Б.СуммаКонечныйОстаток) КАК СуммаКонечныйОстаток
ИЗ РегистрНакопления.ДенежныеСредстваБезналичные.ОстаткиИОбороты(
    &НачМес, &КонМес, , , Организация = &Орг) КАК Б
СГРУППИРОВАТЬ ПО Б.Организация, ЕСТЬNULL(Б.Подразделение, …), Б.БанковскийСчет

ОБЪЕДИНИТЬ ВСЕ

-- Наличные (Касса)
… РегистрНакопления.ДенежныеСредстваНаличные.ОстаткиИОбороты(…, Организация=&Орг) КАК Н
СГРУППИРОВАТЬ ПО (Орг, Подр, Н.Касса)

ОБЪЕДИНИТЬ ВСЕ

-- У подотчётных
… РегистрНакопления.ДенежныеСредстваУПодотчетныхЛиц.ОстаткиИОбороты(…) КАК П
СГРУППИРОВАТЬ ПО (Орг, Подр, П.ПодотчетноеЛицо)
```

**КЛЮЧЕВОЕ:** в `втДС` НЕТ ветки для **`Денежные средства в пути`** — это **БАГ**. Регистр `РегистрНакопления.ДенежныеСредстваВПути` **СУЩЕСТВУЕТ** в системе (используется в штатном отчёте `ВедомостьПоДенежнымСредствам` стр. 1754 шаблона СКД), но автор `Свод_ДенежныеСредства` его не включил. См. [`02_etalon_otchet.md`](02_etalon_otchet.md) и предлагаемый фикс в [`README.md`](README.md).

## 3. Источник ПАП → таблица `втПАП`

```sql
ВЫБРАТЬ
    Т.Организация, ЕСТЬNULL(Т.Подразделение, ПустаяСсылка) КАК Подр,
    Т.Статья, Т.Источник КАК Source,
    СУММА(ВЫБОР КОГДА Т.Период < &НачМес  -- НО до НМ
        ТОГДА signed_по_ВидДвижения ИНАЧЕ 0 КОНЕЦ) КАК НО,
    СУММА(signed_по_ВидДвижения) КАК КО      -- КО за всю историю до КонМес
ИЗ РегистрНакопления.ПрочиеАктивыПассивы КАК Т
ГДЕ Т.Организация = &Орг
    И Т.Период <= &КонМес
    И Т.Источник В (&МассивИст)             -- ← включает Денежные средства в пути!
    И НЕ Т.Статья В ИЕРАРХИИ(&Искл)
СГРУППИРОВАТЬ ПО (Орг, Подр, Статья, Источник)
```

**КЛЮЧЕВОЕ:** `втПАП` берёт **ВСЕ 4 источника** включая `Денежные средства в пути`. Это асимметрично `втДС` (там 3 источника).

## 4. Финальный JOIN → детали + плуги

```sql
-- Ключи: все комбинации (Орг, Подр, Статья, Source) из обеих таблиц
ВЫБРАТЬ РАЗЛИЧНЫЕ … ПОМЕСТИТЬ втКлючи ИЗ (втПАП ОБЪЕДИНИТЬ ВСЕ втДССт)

-- Детали (Расхождение=Ложь): берём напрямую из втДС
ВЫБРАТЬ
    Орг, Подр, Статья, Source,
    ДенежныеСредства, ФизическоеЛицо,
    ПРЕДСТАВЛЕНИЕ(ДенежныеСредства | ФизическоеЛицо) КАК Аналитика1,
    "" КАК Аналитика2, "" КАК Аналитика3,
    ЛОЖЬ КАК Расхождение,
    СуммаНачальныйОстаток, 0 КАК СуммаПриход, 0 КАК СуммаРасход,
    СуммаКонечныйОстаток
ИЗ втДС

ОБЪЕДИНИТЬ ВСЕ

-- Плуги (Расхождение=Истина): где |ПАП − втДССт| > 0.01
ВЫБРАТЬ
    К.Орг, К.Подр, К.Статья, К.Source,
    НЕОПРЕДЕЛЕНО, ПустаяСсылка ФизЛицо,
    "", "", "", ИСТИНА КАК Расхождение,
    ЕСТЬNULL(втПАП.НО, 0) - ЕСТЬNULL(втДССт.НО, 0) КАК СуммаНО_Δ,
    0, 0,
    ЕСТЬNULL(втПАП.КО, 0) - ЕСТЬNULL(втДССт.КО, 0) КАК СуммаКО_Δ
ИЗ втКлючи К
    ЛЕВОЕ СОЕДИНЕНИЕ втПАП ПО (Орг, Подр, Статья, Source)
    ЛЕВОЕ СОЕДИНЕНИЕ втДССт ПО (Орг, Подр, Статья, Source)
ГДЕ |ЕСТЬNULL(втПАП.НО)-ЕСТЬNULL(втДССт.НО)| > 0.01
    ИЛИ |ЕСТЬNULL(втПАП.КО)-ЕСТЬNULL(втДССт.КО)| > 0.01
```

## 5. Источники плугов (классификация)

| Class | Описание | Пример из данных |
|---|---|---|
| **C1: "Денежные средства в пути"** | Архитектурный — `втДССт` нет такой статьи, всё ПАП.в_пути → плуг | Строительство в пути +29 М, Глобино-2 в пути -17 М |
| **C2: Группировка БанковскийСчет vs Подр** | Расхождение группировки: ПАП пишет по одному Подр, регистр.Безнал — по другому (или БЕЗ Подр) | ЦО.Безнал -19,2 М ↔ (пусто).Безнал +19,2 М (зеркало) |
| **C3: Касса vs Подр** | Аналогично для наличных | (пусто).Наличные -1,7 М |
| **C4: Подотчётный без проводки в ДС** | Расход по подотчёту проведён в ПАП, но не в РегДСУПодотч | — |
| **C5: НО ≠ 0 на старте периода** | На первый запрашиваемый месяц уже есть Δ в НО (унаследованное) | ЦО.Безнал дек25 КМ=-19 252 492,92 (наследие) |

## 7. Подход к фиксу (на выбор)

| # | Подход | Сложность | Эффект |
|---:|---|---|---|
| **A** | **Добавить ветку UNION ALL в `втДС` для `РегистрНакопления.ДенежныеСредстваВПути.ОстаткиИОбороты(...)`** | **низкая** | **устранит весь C1; зеркалит штатный `Отчёт.ВедомостьПоДенежнымСредствам`** |
| B | Исключить `Денежные средства в пути` из `МассивПредст` (тогда ПАП.в_пути не попадёт в фильтр) | низкая | плуги исчезнут, но ПАП.в_пути не отразится в свод-отчёте — НЕ рекомендуется |
| C | Tolerable — оставить плуги для "в пути" | 0 | плуг остаётся как технический артефакт |

**Рекомендация:** Опция **A** — точно по образцу штатного отчёта, минимальное изменение в `Свод_ДенежныеСредства`. См. [`README.md`](README.md) раздел «Фикс (предложение)» — точный BSL-код добавляемой ветки.
