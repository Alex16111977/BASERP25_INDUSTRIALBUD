# Промт для новой ИИ-сессии — разбирательство Расхождение=Истина по деньгам (Безналичные + Наличные)

## TL;DR (контекст за 30 секунд)

В `РегистрСведений.А_ОтчётБаланс_Свод` остаются записи `Расхождение=Истина` по статьям **«Денежные средства (безналичные)»** и **«Денежные средства (наличные)»**. Логика свода (`Функция Свод_ДенежныеСредства` в `Documents/А_ФинРез_Баланс/Ext/ObjectModule.bsl` стр. 621-845) для этих статей **корректна** — она агрегирует `РегистрНакопления.ДенежныеСредстваБезналичные/Наличные.ОстаткиИОбороты` per (Орг, **Подразделение**, БанковскийСчет/Касса) и сверяет с ПАП per (Орг, Подр, Статья, Source).

**Здесь должна быть полная прозрачность** — данные приходят из одного и того же документа (ПКО / РКО / ПлатёжноеПоручение / СписаниеБезнал / ПоступлениеБезнал). Раз есть расхождение — значит документ пишет в ПАП с одним Подразделением, а в РНДС — с другим (или без). Задача: найти **конкретные документы-виновники** и причину асимметрии.

**Пример из CSV-выгрузки пользователя (за дек 2025 — апр 2026):**
- ЦО / Безналичные КМ ≈ **−19 252 492,92** каждый месяц
- (пусто) / Безналичные КМ ≈ **+19 252 492,92** каждый месяц (зеркальная сумма)
- (пусто) / Наличные КМ ≈ **−1 724 371,00** каждый месяц

Это **типичное зеркало**: один и тот же банковский счёт/касса учитываются в ПАП по Подразделению ЦО, а в РНДС — без подразделения (или наоборот).

## 🔑 КЛЮЧЕВАЯ ПОДСКАЗКА ПОЛЬЗОВАТЕЛЯ

> **Подразделение надо брать из ИЗМЕРЕНИЯ регистра** `РегистрНакопления.ДенежныеСредстваБезналичные.Подразделение` (или `.ДенежныеСредстваНаличные.Подразделение`), а **НЕ** из реквизита справочника `Справочник.БанковскиеСчетаОрганизаций.Подразделение` / `Справочник.Кассы.Подразделение`.

Почему это критично:
- Регистр запоминает **Подразделение на момент проводки** (что было в БС/Кассе тогда)
- Реквизит справочника — это **текущее** значение, может быть изменено позже
- Если в справочнике изменили Подразделение БанкСчёта (например, перевели с ЦО на «пустое»), **старые движения в регистре сохраняют прежнее Подразделение**, а новые пишутся с новым → асимметрия
- **Свод_ДенежныеСредства использует ИЗМЕРЕНИЕ регистра** (`Б.Подразделение`, BSL 691) — это правильно. Все Python-сверки должны использовать тот же подход.

## Гипотезы расхождения (порядок проверки)

### Гипотеза 1: «БанкСчет/Касса с разным Подразделением» (наиболее вероятна)

Зеркальные суммы ЦО vs (пусто) ≈ ±19,2 М безнал и (пусто) ≈ -1,7 М налич — типичный паттерн. Один и тот же БанкСчет/Касса пишет в РНДС с одним Подр, а в ПАП — с другим.

**Проверка:** скрипт `04_drill_beznal_per_bs.py` покажет — есть ли БС в обоих Подр одновременно.

### Гипотеза 2: «Документ ВводОстатков (исторический)»

Если расхождение постоянно равно НМ на старте периода (т.е. не растёт от месяца к месяцу) — скорее всего ВводОстатков с неверным Подразделением.

**Проверка:** в `02_pap_vs_reg_2025-12.csv` смотреть Δ_НО vs Δ_КМ. Если Δ_НО = Δ_КМ → расхождение из истории.

**Образец:** `phase6_dec25_co_history.py` из klient — поиск виновника по всей истории до КМ.

### Гипотеза 3: «Exchange ERP↔BuhBud↔Казна» (асимметрия проводок)

Документы созданные через обмен (есть флаг `А_ОбработанКазна`, `А_ВведенВЕРП`) могут писать в ПАП и РНДС по-разному.

**Проверка:** для виновного документа посмотреть `Д.А_ОбработанКазна`, `Д.А_ВведенВЕРП` через объект.

### Гипотеза 4: «Дублирующий КассаЗП на нескольких Подр»

Из скриншота пользователя видны «Касса ЗП» и «Касса ЦО Строительство» — если они дублируются по Подразделениям, это даёт расхождение.

### Особенности денежных регистров (vs РСКПС/РСППС в klient)

| Аспект | РСКПС/РСППС (klient) | РНДС.Безнал/Налич (money) |
|---|---|---|
| Регистратор | Документ.**РегистраторРасчётов** (служебный) | Сам первичный документ (ПКО/РКО/...) |
| ДокументРегистратор | реквизит → первичный документ | **ОТСУТСТВУЕТ** |
| Ключ сверки с ПАП | `ПАП.Регистратор ↔ РСКПС.ДокументРегистратор` | `ПАП.Регистратор ↔ РНДС.Регистратор` |
| Подразделение | НЕТ как измерения, берётся из АналитикаУчётаПоПартнёрам | **ЕСТЬ как измерение** в Безнал и Наличных |

| Аналитика главная | ОбъектРасчётов, Партнёр | БанковскийСчет, Касса |
