## Часть 1: Code Review BSL-кода (1c-bsl-review)

Проверка BSL-кода по 17-пунктному чеклисту с 3 уровнями критичности.

### КРИТИЧЕСКИЙ (блокирует merge)

1. **Запросы в циклах** -- `Запрос.Выполнить()` или `Новый Запрос` внутри `Для`/`Для Каждого`/`Пока`. Решение: пакетный запрос + временная таблица + ИНДЕКСИРОВАТЬ ПО.
2. **Неправильная транзакция**: НачатьТранзакцию ПЕРЕД Попытка, ЗафиксироватьТранзакцию ПОСЛЕДНЯЯ строка в Попытка, ОтменитьТранзакцию ПЕРВАЯ строка в Исключение, ВызватьИсключение обязательно.
3. **Проглоченные исключения** -- пустой блок Исключение или нет ЗаписьЖурналаРегистрации.
4. **Попытка/Исключение;Продолжить** внутри цикла в транзакции -- транзакция "отравлена".
5. **Составные типы без ВЫРАЗИТЬ()** -- LEFT JOIN ко ВСЕМ таблицам типа.

### ВЫСОКИЙ (требует исправления)

6. **&НаСервере вместо &НаСервереБезКонтекста** -- передаёт ВСЮ форму.
7. **Фильтрация ВТ через ГДЕ вместо параметров** виртуальной таблицы.
8. **JOIN с виртуальной таблицей напрямую** -- материализовать через ПОМЕСТИТЬ.
9. **COM-объекты не освобождаются** -- нет `= Неопределено`, `Для Каждого` на COM.
10. **Нет `ОбменДанными.Загрузка`** в ПередЗаписью/ПриЗаписи.

### СРЕДНИЙ (рекомендуется)

11. **Точка от ссылки в цикле** -- запрос к БД на каждой строке.
12. **Неинициализированные переменные** в условных ветвях.
13. **Прямой вызов обработчика** из другого обработчика.
14. **Нет документирования экспортных** (#std453).
15. **Магические числа/строки**.
16. **Подзапросы в JOIN**.
17. **OR в WHERE** -- В() или ОБЪЕДИНИТЬ ВСЕ.

### Формат вывода

```
[КРИТИЧЕСКИЙ/ВЫСОКИЙ/СРЕДНИЙ] Строка NNN: <описание>
  Почему плохо: <объяснение>
  Как исправить: <решение с кодом>
```

Сводка: `Найдено: X критических, Y высоких, Z средних`.

## Часть 2: Стандарты кода BSL (1c-bsl-standards)

Обязательные правила при генерации BSL-кода для 1С:Предприятие 8.3 / BAS ERP 2.5.

### Именование
- PascalCase, буква е вместо ё
- Процедуры -- глагол: `ЗагрузитьКонтрагента()`
- Функции -- результат без "Получить": `ПолноеИмя()`
- Конструкторы -- "Новый": `НовыеПараметрыЗаполнения()`
- Булевы -- "Это" или причастие: `ДокументПроведен()`

### Области (#std455)
- Модуль формы: ОбработчикиСобытийФормы -> ОбработчикиКомандФормы -> СлужебныеПроцедурыИФункции
- Общий модуль: ПрограммныйИнтерфейс -> СлужебныйПрограммныйИнтерфейс -> СлужебныеПроцедурыИФункции

### Директивы
- ВСЕГДА указывать для модулей формы
- ПРЕДПОЧИТАТЬ &НаСервереБезКонтекста вместо &НаСервере

### Транзакции
НачатьТранзакцию ПЕРЕД Попытка -> ЗафиксироватьТранзакцию ПОСЛЕДНЯЯ -> ОтменитьТранзакцию ПЕРВАЯ -> ВызватьИсключение ВСЕГДА

### Запросы
- НИКОГДА в циклах
- Параметры ВТ для измерений
- ВЫРАЗИТЬ() для составного типа
- ПОМЕСТИТЬ + ИНДЕКСИРОВАТЬ ПО
- ЕСТЬNULL() для LEFT JOIN

### Обработчики
- Не вызывать один из другого
- ОбменДанными.Загрузка обязательна в ПередЗаписью/ПриЗаписи

### Документирование (#std453)
Экспортные: `// Параметры:` + `// Возвращаемое значение:`

### БСП
- Только ПрограммныйИнтерфейс для внешних вызовов
- Расширения: &Перед/&После предпочтительнее &Вместо

### BAS ERP 2.5
- Отложенное отражение в учёте (Хозрасчетный через РегламентированныйУчетПроведениеСервер)
- Функциональные опции -- проверять включённость
- COM для legacy, HTTP-сервисы для нового

### Форматирование
- 120 символов, табуляция, один оператор на строке
- Удалять мёртвый код

## Часть 3: Оптимизация запросов 1С (1c-query-optimizer)

Анализ и оптимизация запросов по 10 правилам.

### 10 правил оптимизации

1. **Параметры ВТ** для измерений, не WHERE
2. **Материализация ВТ**: ПОМЕСТИТЬ + ИНДЕКСИРОВАТЬ ПО перед JOIN
3. **ВЫРАЗИТЬ()** для составного типа (Регистратор)
4. **Запросы в циклах** -> пакетный запрос + временная таблица
5. **OR -> В()** или ОБЪЕДИНИТЬ ВСЕ
6. **Индексы** временных таблиц по полям JOIN/WHERE
7. **Подзапросы в JOIN** -> временные таблицы
8. **SELECT *** -> только нужные поля
9. **ВидДвижения** -- системное перечисление ВидДвиженияНакопления
10. **Точка в цикле** -> ПРЕДСТАВЛЕНИЕ() или точка в SELECT

### Таблица антипаттернов

| Антипаттерн | Решение |
|---|---|
| Запросы в циклах | Пакетный запрос + ВТ |
| JOIN с ВТ | ПОМЕСТИТЬ + ИНДЕКСИРОВАТЬ |
| Фильтр ВТ через ГДЕ | Параметры ВТ |
| Точка через составной тип | ВЫРАЗИТЬ() |
| OR в WHERE | В() или ОБЪЕДИНИТЬ ВСЕ |
| Нет ЕСТЬNULL | ЕСТЬNULL(поле, 0) для LEFT JOIN |
