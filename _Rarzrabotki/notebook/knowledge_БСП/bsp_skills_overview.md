## 2. Архитектура связки

```
bas-house-style  ← ХАБ: конвенции типовых + ссылки
   ├── bas-common-module   (ГДЕ живёт код: А_<Объект>Сервер, #455/#469/#std551)
   └── bas-bsp-form        (КАК выглядит форма: меню + подсистемы БСП)

bas-doc-new      ← оркестратор документа  →  читает house-style + common-module + bsp-form
bas-catalog-new  ← оркестратор справочника →  читает house-style + common-module + bsp-form
bas-register-new ← регистр + движения      →  читает house-style + common-module
bas-verify       ← гейт проверки (в конце любой задачи)
```

**Разделение ответственности:**
- `bas-house-style` — «что значит типовой стиль» (стандартные реквизиты, делегирование, состав форм). Хаб.
- `bas-common-module` — «куда положить логику» (модуль на объект, тонкие модули). Это **организация кода**.
- `bas-bsp-form` — «как сделать типовое окно» (меню + подсистемы). Это **интерфейс/поведение формы**.
- `bas-doc-new`/`bas-catalog-new`/`bas-register-new` — **оркестраторы**: ведут пошагово, подтягивая 3 базовых скила.
- `bas-verify` — **гейт качества**, в т.ч. проверяет, что меню не пустое и контракты вшиты.

---

## 3. Цепочка подтягивается сама

`bas-doc-new`/`bas-catalog-new` в разделе **REQUIRED BACKGROUND** обязывают прочитать `bas-house-style`
+ `bas-common-module` + `bas-bsp-form`. Поэтому **один промт «создай документ» включает всю связку** —
звать остальные скилы отдельно не нужно.

## 4. Q&A

**Q: Какой скил для какой задачи?**
- Новый документ → `bas-doc-new` (+ связка). Новый справочник → `bas-catalog-new` (+ связка).
- Нет меню на форме / доделать форму → `bas-bsp-form`. Куда положить логику → `bas-common-module`.
- Новый регистр / привязать движения → `bas-register-new`. Проверить перед коммитом → `bas-verify`.

**Q: Чем `bas-common-module` отличается от `bas-bsp-form`?**
`bas-common-module` — про **серверный код** (где живёт бизнес-логика: `А_<Объект>Сервер`).
`bas-bsp-form` — про **форму** (меню + подсистемы БСП). Они ортогональны и оба нужны новому объекту.

**Q: Зачем `bas-house-style`, если есть оркестраторы?**
Это единый источник конвенций (стандартные реквизиты, делегирование проведения, состав форм) +
точка входа со ссылками. Оркестраторы на него опираются, не дублируя.

**Q: Скилы в git?**
Нет. `.claude` в `.gitignore`, все `bas-*` скилы — локально на диске. Работают сразу; версионируются
только спека+план в `docs/superpowers/`.
