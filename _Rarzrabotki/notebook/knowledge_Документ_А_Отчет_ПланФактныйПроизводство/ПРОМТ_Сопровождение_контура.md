## 4. 🔴 Инварианты — не менять без явного решения пользователя

| Инвариант | Почему |
|---|---|
| План умножается на `КоличествоДомов`, EV — **нет** | нормы кошториса заведены на один дом; EV ведётся по-домно |
| `ФактГрн` = `СТ.Стоимость` (**брутто, с НДС**) | план в Комплектующие заведён с НДС; замена ломает план↔факт и EAC |
| Факт соединяется с `ВТ_Подр1`, а не с `ВТ_СС` | при двух активных СС в подразделении факт удвоится |
| `НАЧАЛОПЕРИОДА(..., ДЕНЬ)` в каждой ветке | периодичность регистра «День»; иначе дубль ключа |
| В `СГРУППИРОВАТЬ ПО` — только измерения | реквизит в группировке = гарантированный дубль ключа |
| Количества в ETC округляются до 2 знаков | методика выверена бухгалтером именно так (FINDINGS §3) |
| Ключ нетто-группы ETC = (Подразделение, имя общей назвы), **без Этапа** | добавление Этапа завышало прогноз на 31 932,22 грн |
| `ФактКол` и `ВиконанняЧасы` сверять с первоисточником, не с отчётом | отчёт округляет построчно до 2 знаков (FINDINGS §2) |
| План и ETC не фильтруются периодом | план — состояние кошториса «как сейчас» |
| Значения перечисления `А_ТипыСтрокПланФактПроизводство` | используются в DAX буквально; переименование = молчаливый регресс мер |
| `_Rarzrabotki\Olap\Ai_Olap` не трогать | чужой контур PnL/Cashflow/Balance |

## 5. Rule #-1 — запрос сначала в Python

Любой новый или изменённый запрос 1С прогоняется через Python COM на живой базе **до** вставки
в BSL. Шаблон — `test_planfakt_svertka_query.py`: он берёт запрос, гоняет по всем подразделениям
и сверяет с эталоном.

При проверке отчётов через COM помнить (FINDINGS §7–9): `Тип()` недоступен, вывод в коллекцию
значений невозможен — компоновать в `ТабличныйДокумент`, а числа брать запросом, **извлечённым
из самой схемы**.

## 7. Чего НЕ делать

* ❌ не удалять документы контура (только перепроводить);
* ❌ не расширять WHITELIST и не запускать `refresh_mapping.py` в `Ai_Olap`;
* ❌ не переименовывать значения перечисления и колонки витрины без правки DAX;
* ❌ не читать производные `НачалоПериода`/`КонецПериода` из настроек СКД (LESSONS §6);
* ❌ не собирать `.pbix` скриптом — его формат бинарный, работаем через `.pbip`;
* ❌ не менять точность ресурсов регистра «чтобы совпало с отчётом» — отчёт менее точен.
