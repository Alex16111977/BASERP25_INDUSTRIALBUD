# 10. Скрипты и данные: что где лежит и как перезапустить

> Все скрипты папки **только читают** базы BuhBud и ERP или файлы. Ни один не пишет в 1С. Описания составлены по коду файлов 03.10.2026, а не по памяти. Где файл опирается на что-то вне папки, это сказано явно. Пути внутри папки даны относительно `Разработка связей/`.

## 1. Подключение к базам (только чтение)

Образец — `scripts/01_analiz_tekushchey_svyazi/com_conn.py`: функции `connect('buh'|'erp')`, `q(c, text, params)`, `rows(c, vt, cols)`.

```python
import win32com.client, sys
if sys.stdout.encoding.lower() != "utf-8":
    sys.stdout.reconfigure(encoding="utf-8")
v8 = win32com.client.Dispatch("V83.COMConnector")
B = v8.Connect('Srvr="localhost";Ref="bas_industrialbud";Usr="cfo";Pwd="…"')   # BuhBud; пароль — CLAUDE.md, Rule #5
# ERP: Ref="BaseERP";Usr="Администратор" — только для 05_byudzhet_v3_irc/verify_irc.py, v3_deficit.py
q = B.NewObject("Запрос"); q.Text = "ВЫБРАТЬ …"
try:
    vt = q.Execute().Выгрузить()
except Exception as e:
    print("FAIL:", e.excepinfo[2] if getattr(e, "excepinfo", None) else e); raise
```

Правила (подробно — [09_grabli_i_uroki.md](09_grabli_i_uroki.md) §C):
- Никаких `Записать()`, `Провести()`, `Удалить()` и изменений метаданных. Новую ТЧ связи сейчас создавать нельзя: механизм не согласован ([08_otkrytye_voprosy.md](08_otkrytye_voprosy.md) §5).
- Каждый новый запрос сначала прогнать в Python и только потом переносить в BSL (CLAUDE.md, Rule #-1).
- Даты не передавать параметром из Python: дату задавать в тексте запроса через `ДАТАВРЕМЯ(...)`, читать через `B.String(...)`.
- Псевдонимы — минимум два осмысленных символа или безопасные одиночные (`К`, `Д`, `С`, `Н`, `О`, `Т`). `В`, `И`, `ПО` использовать нельзя.
- Нужен Python с `pywin32`. Скрипты без COM (`base.py` … `final3.py`, `v2`–`v7`, `f04`, `f05`) работают на любом Python 3. Кириллические пути передавать в файле скрипта, не через `python -c` ([../LESSONS.md](../LESSONS.md) §Д11).
- Временные файлы класть в `C:/Users/SUPPOR~1/AppData/Local/Temp/claude/kb_svyaz_tmp/`, а не в базу знаний.

## 3. Как перезапустить прототип и получить свежий `demo_svyaz_ss_30m.json`

`raw.json` в папку **не скопирован** (4,8 МБ). Сейчас он лежит во временном каталоге сессии `C:\Users\SUPPOR~1\AppData\Local\Temp\claude\C--Configuration-downloads-BASERP25--claude-worktrees-budget-calc-oct-dec-2026-20c998\74acb5f4-5c54-4380-b2d5-fb369593cb1b\scratchpad\svyaz\raw.json`. Этот каталог может быть очищен. Скрипты там побайтно совпадают со `scripts/03_prototip_svyazi_30m/` (сверено `cmp` 03.10.2026).

1. Скопировать `scripts/03_prototip_svyazi_30m/` в рабочую папку вне базы знаний, например `…/Temp/claude/kb_svyaz_tmp/proto/`.
2. Поправить пути (§4): в `final.py` — `OUT` (обязательно, иначе перезапишется основной файл) и `IRC`.
3. `python c01_collect.py` — COM, только чтение. Скрипт печатает `SS: … 170 строк; коэф 34`, `РК: 4 док.; 398 строк ТЧ остатков`, `Движений: 4800`, `Строк приходов: 503` (сверено рецензентом по `raw.json`: `ss` 170, `koef` 34, `rk` 4, `rk_ost` 398, `moves` 4 800, `receipts` 503). **Если счётчики другие, база изменилась**, и канонические числа папки устарели ([09_grabli_i_uroki.md](09_grabli_i_uroki.md) §E1).
4. `python final3.py` — собирает и пишет JSON (цепочка импортов выполнится сама).
5. Скопировать `scripts/04_proverka_prototipa/v7_patch.py` рядом, заменить `sys.path.insert(0, r"..\svyaz")` на путь к прототипу и `P` на путь из шага 2, запустить. Без этого шага в JSON не будет `ponad_yak_u_zviti_N_bilshe_0`, `dokupyty_yakby_treba_i_po_1_2_uah` и последних 4 оговорок.
6. Проверка: `v1_query.py` (COM) → `v1.json`; затем из той же папки `v2_cmp.py`, `v4_rk.py`, `v5.py`, `v6.py`. Ожидаемо: 0 расхождений по карточкам; по РК №9/№11 совпадают все 127 ОН; Σ вкладов = Σ карточек.
7. Сверка с каноном: `summary`, `totals`, `coverage.by_method`, `vs_budget_v3` нового JSON против `data/demo_svyaz_ss_30m.json`. При том же снимке (4 800 / 503) разница должна быть 0,00.

Пересчёт карты 15 м (`maprows.json`): `02_…/econ.py` и `pn.py` (COM) → `econ.json`, `pn.json` в cwd → `01_…/map2.py` из той же папки.
