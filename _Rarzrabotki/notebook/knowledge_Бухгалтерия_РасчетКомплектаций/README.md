## Краткое описание

**Сохраняемое рабочее место бухгалтера в виде документа.** То же, что делает внешняя обработка
`СозданиеКомплектацийБух` — раскладывает остатки материалов «під списання» (счета класса 2:
20/28 → материалы, 22 → малоценка) на нормы спецификации `СтруктураСебестоимости` и разносит по
документам, — но **результат расчёта хранится в базе** (движок = порт `ObjectModule` обработки 1:1).

Документ **непроводимый** (`Posting=Deny`) — он не делает движений по регистрам. Его роль:
1. **Рассчитать** анализ (остаток / норма / в норме / понад норму / економія) и сохранить его в ТЧ;
2. дать бухгалтеру **отредактировать понаднормовое списание** (ТЧ `СписаниеСверхНормы`: количество/цена, добавить строки, указать причину);
3. по кнопке **заполнить целевые документы** `КомплектацияНоменклатуры` (материалы) и `ПередачаМалоценныхАктивовВЭксплуатацию` (малоценка) — из сохранённых таблиц списания;
4. **напечатать** аналитику (8 форм: 5 аналитических + «Акт на списання понаднормових матеріалів» + «Розбіжності одиниць» + **М-29** по факту проводок).

Целевые документы `КомплектацияНоменклатуры`/`ПередачаМалоценныхАктивовВЭксплуатацию` заводит и проводит
пользователь; сам расчёт их только **заполняет** (`РежимЗаписиДокумента.Запись`, без проведения).
