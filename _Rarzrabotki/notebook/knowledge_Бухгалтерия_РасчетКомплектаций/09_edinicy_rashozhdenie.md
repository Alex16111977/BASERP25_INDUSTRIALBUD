# 09. Розбіжності одиниць ★ (Фаза 2, документ-специфично)

Задача: подсветить позиции, где **одиниці виміру не согласованы** между нормой СС, остатком и эталоном. Чтобы
бухгалтер увидел, что норму нельзя сравнивать с фактом «в лоб» (кг ≠ шт).

## Три источника единицы

| Поле | Откуда | В коде |
|---|---|---|
| `Единица` | `Номенклатура.БазоваяЕдиницаИзмерения` (единица остатка) | из `ПолучитьОстатки` |
| `ЕдиницаСС` | `СтруктураСебестоимости.Комплектующие.Единица` (единица нормы) | из `ПолучитьНормы` → `НоменклаДані` |
| единица эталона | `ОбщиеНазванияНоменклатуры.Единица` | из `ЕдиницыЭталонов()` (кэш) |

## Правило — `ЕстьРасхождениеЕдиниц(ЕдиницаСС, ЕдиницаОстатков, ЕдиницаЭталона, ЕстьЭталон)`

Решение заказчика:
1. Если **эталон заполнен, а его `Единица` пустая** → расхождение (эталон обязан иметь единицу).
2. Среди **ЗАПОЛНЕННЫХ** из {ЕдиницаСС, ЕдиницаОстатков, ЕдиницаЭталона} есть **разные** → расхождение.
   (пустая `ЕдиницаСС` у субститутов сама по себе НЕ расхождение.)

```bsl
Если ЕстьЭталон И НЕ ЗначениеЗаполнено(ЕдиницаЭталона) Тогда Возврат Истина; КонецЕсли;
// сравниваем СокрЛП(Наименование) заполненных: первая ≠ последующая → Истина
```

**⚠ Сравнение — по `СокрЛП(Наименование)`, НЕ по ссылке.** В классификаторе единиц есть дубли одной единицы
(`" шт"` и `"шт"`), и заказчик НЕ хочет править документы. Поэтому:
- сравниваем **строки-наименования** (после `СокрЛП`), а не ссылки → `" шт"` == `"шт"` (не расхождение);
- **регистр сознательно НЕ игнорируется** (нет `ВРег`); `"пач"` vs `"пак"` остаются расхождением (разные написания).

Это же правило продублировано в запросе `КількістьРозбіжностейОдиниць` (через `СОКРЛП(...)`).

## Флаг в анализе

`ЗаполнитьАнализ` ставит `НоваяСтрока.РасхождениеЕдиниц = ЕстьРасхождениеЕдиниц(...)` на каждой строке
(`ЕдиницыЭталона.Получить(ОбщееНазвание)` — кэш `ЕдиницыЭталонов`, один запрос до цикла). Колонка `РасхождениеЕдиниц`
(Булево) — в ТЧ `ТабличнаяЧастьОстатков`.

## Подсветка формы

`УстановитьУсловноеОформлениеСтрок` (`ПриСозданииНаСервере`), **два правила по порядку**:
1. `ПонадНорму > 0` → янтарный `Новый Цвет(250,235,200)`;
2. `РасхождениеЕдиниц = Истина` → **розовый** `Новый Цвет(250,215,215)`.

Правило розбіжності **позже** — перекрывает янтарное. `РассчитатьНаСервере` считает розбіжності и сообщает:
«Розбіжностей одиниць: N рядків (рожеві рядки; див. Друк розбіжностей одиниць)».

## Печать — `СформироватьПечатьРозбіжностіОдиниць()` (программный ТабДок)

- Только **эталоны, где есть хоть один рядок с `РасхождениеЕдиниц`** (эталоны без расхождения не печатаются).
- Карточки **свёрнуты по номенклатуре**: `Агрегат.Норма += Стр.НормаНоменкл` — `НормаНоменкл` штампуется 1× на номенклатуру, поэтому Σ по складам **не задваивается**.
- Рендер блока — `ВывестиБлокЕталона`: строка-эталон (серый фон) `«<эталон> [од. еталона: X]»` либо `«… [!!! од. еталона не заповнена]»` (**красный текст** `Новый Цвет(132,60,12)`); под ней карточки; ячейки единиц (Одиниця залишків / Одиниця СС) при расхождении — **янтарные** `Новый Цвет(255,230,153)`.
- Итог: «Еталонів з розбіжностями: N, номенклатур з розбіжністю: M» (Структура `Итоги` по ссылке).
- 5 колонок: Загальна назва / Залишок / Одиниця виміру залишків / Згідно з СС / Одиниця виміру СС.

## Норму НЕ пересчитываем

`ПопередитиПроРозбіжністьОдиниць()` (в `РассчитатьАнализ`) пишет в журнал регистрации **предупреждение**, если
`КількістьРозбіжностейОдиниць() > 0` — но норму берём **как есть** (пересчёт единиц не делаем, YAGNI; на практике
норма уже в базовой единице). Разведка: ~36/312 эталонов без единицы; правило по `СокрЛП` снизило ложные срабатывания (15→11 строк).

## Профилактика на входе — контроль при оприходовании

Этот отчёт показывает расхождения **постфактум**. Чтобы они не попадали в учёт, на `Документ.ПоступлениеТоваровУслуг`
висит подписка, блокирующая **проведение** приходной накладной при несогласованных единицах — см. **[12](12_kontrol_edinic_postuplenie.md)**.

Отличия от правила этого отчёта:
| | Отчёт «Розбіжності одиниць» (здесь) | Контроль прихода ([12](12_kontrol_edinic_postuplenie.md)) |
|---|---|---|
| Сравнивает | 3 источника: `ЕдиницаСС` ↔ `Единица` (остаток) ↔ единица эталона | 2: `БазоваяЕдиницаИзмерения` ↔ единица эталона |
| Эталон не заполнен | строка просто не проверяется (субститут) | **нарушение `НетЭталона`** — блок проведения |
| Реакция | подсветка + печать | `Отказ` при проведении |
| Общее | сравнение по `СокрЛП(Наименование)`, регистр не игнорируется; пустая единица заполненного эталона = нарушение | то же |
