# FINDINGS — эталоны и контрольные данные

Discovery-факты для smoke-тестов и проверки запросов. База **BuhBud** (`Srvr="localhost";Ref="bas_industrialbud";Usr="cfo";Pwd="2442"`).
Общая часть (спецификации/склады/остатки) наследуется от обработки; ниже — акцент на документ.

## Спецификации (нормы) — `Справочник.СтруктураСебестоимости`

| Код | Наименование | Использование |
|---|---|---|
| `000000003` | МД ПРООН (Цех МД ПРО ООН) | базовая регрессия движка (126 строк, баланс 0) |
| `000000004` | МД МХП ОРІЛЬ (Підрозділ=МД МХП ОРІЛЬ) | **кейс «Профнастил»** (склад «СТІЛ МД МХП ОРІЛЬ виробничий», 07.07.2026) |
| `000000005` | МД Вооз EMS Мала 2026 | план по номенклатуре (все строки Комплектующие с номенклатурой) |

ТЧ `Комплектующие`: `ОбщееНазвание` (`CatalogRef.ОбщиеНазванияНоменклатуры`), `Номенклатура`, `Единица`,
`Количество`, `Сумма` (**введена З ПДВ** → факт ×1.2), `Этап` (`CatalogRef.ЭтапыРабот`). Реквизиты справочника:
`Подразделение`, `Склад`.

## Склады и организации

| Поиск (ПОДОБНО) | Склад / орг |
|---|---|
| `%ПРО%ООН%виробнич%` / `%відвантаж%` | Цех МД ПРО ООН виробничий / відвантажено (орг ІНДАСТРІАЛБУД) |
| `%МХП%ОР%виробнич%` | СТІЛ МД МХП ОРІЛЬ виробничий + Цех МД МХП Оріль виробничий |
| `%ІБ%МШП%` | склад малоценки (семейство 22 → ПередачаМалоценныхАктивовВЭксплуатацию) |
| орг `%ІНДЕПТ%` / `%ІНДАСТРІАЛБУД%` | ТОВ «ІНДЕПТ СТІЛ» / ТОВ «ІНДАСТРІАЛБУД» |

⚠ На одном складе МХП ОРІЛЬ остатки у ДВУХ юрлиц (ІНДЕПТ + ІНДАСТРІАЛБУД) → орг-фильтр обязателен для разделения.

## Счета класса 2 (BuhBud)

- **Материалы** (`СчетаОстатков`, default группы **20/28**): 201, 203, 204, 205, 2051, 206, 207, 2071, 209, 281…
- **Малоценка** (`СчетаМалоценки`, default **22**): 221…
- Субконто всех кл.2: **1=Номенклатура, 2=Партії, 3=Склади**.
- `РегистрБухгалтерии.Хозрасчетный` измерения: Организация, Счет, Субконто1-3, Валюта, НалоговоеНазначение.

## Целевые документы

| Документ | ТЧ | Реквизиты строки |
|---|---|---|
| `КомплектацияНоменклатуры` | `Комплектующие` | Номенклатура, ЕдиницаИзмерения, Количество, Коэффициент, **СчетУчетаБУ**, **Сумма** (без НДС) |
| `ПередачаМалоценныхАктивовВЭксплуатацию` | `МалоценныеАктивы` | Номенклатура, СчетУчетаБУ, Количество, Коэффициент, ФизЛицо, НалоговоеНазначение (`НДС_Облагаемая`), НазначениеИспользования — **без Сумма** |

### Проводки целевых документов (для отчётности о фактических затратах)

| Документ | Проводки при проведении | Аналитика |
|---|---|---|
| `КомплектацияНоменклатуры` | `Дт 26 Кт <счёт запасов>` | `СубконтоКт1` = Номенклатура, `СубконтоКт3` = Склад |
| `ПередачаМалоценныхАктивовВЭксплуатацию` | `Дт 231 Кт 221` **+ забалансовая `Дт МЦ` с пустым `СчетКт` на ту же сумму** | балансовая: `СубконтоКт1` = Номенклатура; забалансовая: номенклатура в `СубконтоДт2` |

⚠⚠ **Стоимость МШП существует ТОЛЬКО в проводках** — в `МалоценныеАктивы` нет реквизита `Сумма` (§Д21).
⚠⚠ Любой запрос по этим проводкам обязан фильтровать `СчетКт <> ПустаяСсылка`, иначе МШП **удваивается** (§Д20).
⚠ ТЧ-сумма комплектации ≠ проводке: ІБ00-000115 — 1 013 776,70 в ТЧ против 1 009 403,18 в проводках (FIFO, §Д23).

## Эталон COM-smoke движка

```python
doc = buh.Документы.РасчетКомплектаций.СоздатьДокумент()
doc.Период = datetime.datetime(2026, 7, 7, 23, 59, 59)
doc.Спецификация = buh.Справочники.СтруктураСебестоимости.НайтиПоКоду("000000004")
# doc.СкладыОстатков.Добавить().Склад = <СТІЛ МД МХП ОРІЛЬ виробничий>
doc.РассчитатьАнализ()
# инвариант: для каждой строки ВНорме + ПонадНорму == Остаток
# инвариант: СписаниеПоНормам/СверхНормы = срезы анализа с суммой ÷1.2
```
Управляемую форму COM headless не рендерит → подсветку/раскладку проверять в клиенте BuhBud ([10](10_forma_dokumenta.md)).
