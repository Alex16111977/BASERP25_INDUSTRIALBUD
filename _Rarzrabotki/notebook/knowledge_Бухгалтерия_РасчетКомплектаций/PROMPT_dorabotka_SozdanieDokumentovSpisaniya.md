## 3. Алгоритм — `СоздатьДокументыСписания(ИмяТЧ, НомераСтрок) Экспорт` (модуль обʼєкта)
Для кожного рядка з `НомераСтрок` і кожної колонки (`ДокументПоНормам`, `ДокументДодаткова`), де документ **порожній**:
пропуск із причиною, якщо порожній склад / немає потрібної дати / немає комплекту (комплектація); інакше створити, записати,
поставити посилання в рядок. Результат `Структура(Создано, Пропущено, Сообщения)`. Кожен документ — окрема спроба
(помилка одного не скасовує решту), помилка — в `Сообщения` + журнал реєстрації.
Форма: команди `СоздатьДокументыКомплектации` / `СоздатьДокументыМалоценки` («Створити документи») у командних панелях ТЧ;
`Элементы.<ТЧ>.ВыделенныеСтроки` → номери рядків (порожньо → поточний рядок); питання-підтвердження; сервер:
`РеквизитФормыВЗначение` → метод → `ЗначениеВРеквизитФормы` → `Записать()` розрахунку; повідомлення з підсумком.
