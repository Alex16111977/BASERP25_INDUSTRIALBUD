# 10. Форма документа

`Forms/ФормаДокумента` — единственная форма документа (`DefaultObjectForm`). Модуль `Ext/Form/Module.bsl` (465 строк) —
тонкий диспетчер: делегирует движку через `РеквизитФормыВЗначение("Объект")` / `ЗначениеВРеквизитФормы`.

## ⚠ Форма «живёт своей жизнью»

Пользователь открывал форму в Конфигураторе и сохранял — Designer её **нормализовал**: DataPath `Объект.Number`/
`Объект.Date`, дефолты `AutoTime`/`UsePostingMode`, переиндентация. **Дрейф принят.** Отсюда правила:

- **Build-генераторы формы (`doc_kompl_build_form.py`) БОЛЬШЕ НЕ ЗАПУСКАТЬ** — затрут «живую» форму. Только
  **точечные патчи** текущего `Form.xml` (образец `doc_kompl_patch_form_stdbar.py`, `doc_kompl_patch_canon.py`).
- **Перед ЛЮБОЙ правкой объекта — сверять дамп с базой** (`db-dump-xml` Partial объекта). ⚠ Changes-режим с
  подложенным `ConfigDumpInfo` НЕ работает (выгружает всё). ⚠ **Партиальный дамп объекта форму НЕ включает** — только Full / выгрузка пользователя.
- ⚠⚠ **Конфигуратор пользователя со старой копией в памяти ОТКАТЫВАЕТ загрузки** при «Обновить конфигурацию БД»
  (случилось дважды). Перед загрузкой — проверять процессы `1cv8.exe`.

## Стандартные кнопки и командная панель

«Записать и закрыть» / «Записать» = `ButtonGroup` c `<CommandSource>Form</CommandSource>` в `AutoCommandBar`
(рецепт типовых; при этом `Autofill=false`). Наши команды (Розрахувати, Заповнити документи ▾, 7 печатей) — там же.

## Канон «без прокрутки формы»

(исследование 16 типовых форм BASEBuh; применено `doc_kompl_patch_canon.py`.) Типовые формы **не задают высоту
ТЧ-таблице** — единственный вертикально-растягиваемый элемент (default stretch, скролл внутри неё), **всё прочее
жёстко фиксировано**:

- однострочные поля; `ShowTitle=false` у **всех** групп; `Комментарий` однострочный (`VerticalStretch=false` + ChoiceButton);
- большие таблицы (`ТаблицаАнализа`, списания, документы) — **без `HeightInTableRows`** (авто-растяжение + скролл внутри); настроечные ТЧ (склады/счета/этапы) — по 3 строки;
- итоги — **подвал таблицы** (`Footer` + `FooterDataPath = Объект.ТЧ.Total<Колонка>` — платформенный автоитог, высоту формы не ест) ЛИБО строка ReadOnly-полей (`TitleLocation=Left`, фон `style:ИтогиФонГруппы`);
- корень `VerticalScroll = useIfNecessary`.

⚠ **Высота `Pages` = МАКСИМУМ по всем страницам** — «толстая» страница настроек раздувает форму на всех вкладках
(лечение: мини-таблицы горизонтально + `stretch=false`). В `doc_kompl_patch_canon.py`: реквизиты/группы итогов
списаний и клиентский пересчёт **удалены** — итоги ушли в подвалы `Total*`.

## Вкладки и логика UI

| Вкладка / область | Что | Обработчики |
|---|---|---|
| Параметри | Спецификация/Период/Организация + ТЧ Склади/Рахунки/Рахунки малоцінки/Етапи + флаг ИсключатьЭтапы | — |
| Аналіз залишків | `ТаблицаАнализа` + відбір (ОтборСклад/ОтборЭталон/ТолькоПонадНорму) + Пошук + Підсумки | `*ПриИзменении` → `ПрименитьОтборИИтоги`; `ФильтрПоПолю`; `СброситьОтбор` |
| Списання (за нормами / понад норму) | `СписаниеПоНормам` (RO) + `СписаниеСверхНормы` (edit) | `СверхНормы*ПриИзменении` → пересчёт/автоподбор ([05](05_tablicy_spisaniya.md)) |
| Документи / Документи малоцінки | `ДокументиКомплектації` / `ДокументиМалоценки` | пользователь выбирает целевые документы |

### Відбір + пошук + підсумки (ValueTable-паттерн рабочего места)

`ТаблицаАнализа` — **реквизит формы** (ValueTable, копия `Объект.ТабличнаяЧастьОстатков`). `ПрименитьОтборИИтоги`
(&НаКлиенте) **перестраивает** её из полного `Объект.ТабличнаяЧастьОстатков` под предикат
Склад(==)/Эталон(==)/ТолькоПонадНорму(>0)/Пошук(substring по Номенклатура+Эталон+Склад+Счёт) и тут же копит 8 итогов
→ подсумки и футер совпадают с видимым набором. **Документы заполняются из полного набора отдельно** (через ТЧ
списания), фильтр — только для просмотра.

- `ПриОткрытии` → `ПрименитьОтборИИтоги()` — **восстановление рабочего места** из сохранённого расчёта.
- `ФильтрПоПолю` — быстрый фильтр по колонке под курсором: `ТАСклад`→ОтборСклад, `ТАОбщееНазвание`→ОтборЭталон, `ТАНоменклатура`→Пошук (числовые колонки игнорируются). Двойной клик НЕ навешан (конвенция «двойной клик = открыть»).

### Подсветка (`ПриСозданииНаСервере`)
- метрики: `Элементы.ИтогоВНорме.ЦветФона = Новый Цвет(214,240,214)` (зелёный), `Элементы.ИтогоПонад.ЦветФона = Новый Цвет(250,235,200)` (янтарный);
- строки таблицы: `УстановитьУсловноеОформлениеСтрок` — янтар `ПонадНорму>0`, розовый `РасхождениеЕдиниц` (позже → перекрывает) ([09](09_edinicy_rashozhdenie.md)).

## Грабли формы

- **UUID обёртки формы при частичной перезагрузке должен быть СТАБИЛЬНЫМ**: перегенерация обёртки с новым `uuid4`
  → «нельзя добавлять объекты метаданных без загрузки родительского объекта». Лечение: переиспользовать uuid из
  существующего файла; при смене — грузить ВМЕСТЕ с родительским `Documents/РасчетКомплектаций.xml`.
- **Designer задваивает id** при сохранении формы → перед сборкой прогонять проверку уникальности id.
- **uk-подписи**: при uk-интерфейсе `<v8:lang>ru</v8:lang>` без uk-сиблинга рендерится пусто (Designer хранит ru+uk парой).
- **Управляемую форму COM headless НЕ рендерит** → подсветку/колонки/раскладку проверять в клиенте BuhBud (движок — COM-smoke).
