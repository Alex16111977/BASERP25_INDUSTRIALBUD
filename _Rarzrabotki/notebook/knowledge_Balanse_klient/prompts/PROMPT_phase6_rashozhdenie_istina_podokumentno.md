Артефакты: `_artifacts/14_raskhozhdenie_*.csv`, `_artifacts/20v2_full_discovery.csv`, `_artifacts/25v2_*.csv`

#### Шаг 2: Подокументная сверка для каждой проблемной группы
Адаптировать паттерн **скрипта 11** на ВСЕ записи Расхождение=Истина из шага 1:
- для каждой группы `(Месяц, Подр, Статья, Source)` с Расхождение=Истина
- сделать FULL OUTER JOIN ПАП vs РСКПС/РСППС по `ДокументРегистратор`
- собрать первичные документы с `|Δ_doc| > 0.01`

#### Шаг 3: Анализ корневой причины каждой группы
Для каждого первичного документа из шага 2:
1. **drill-down**: какие движения он создаёт в ПАП vs в РСКПС/РСППС, в чём разница
2. **классификация** причины (как в `ANALYSIS_REPORT.md`):
   - C1: документ без РСКПС/РСППС (Регистратор не создан) — лечится **ручным перепроведением через UI**
   - C2: разница знаков/округлений
   - C3: документ работает с особой ХозОперацией (ВводОстатков, ВозвратДС и т.п.)
   - C4: данные документа неконсистентны (отсутствует Договор/Партнёр в АналитикеУчетаПоПартнерам)
3. **сравнение с эталоном** `BaseERPRazr` для конкретного документа (паттерн `33_compare_baserazr.py`)

#### Шаг 4: План фикса
Для каждой категории — отдельная стратегия:
- C1 → передать пользователю список документов для ручного перепроведения через UI
- C2 → если небольшое расхождение от округлений — допустимо, не лечить
- C3 → разобраться с конкретной ХозОперацией (отдельный CFE-фикс или пропуск)
- C4 → исправить данные документа (Договор/АналитикуУчетаПоПартнерам)

#### Шаг 5: Verify
После любых правок — `python 19_verify_raskhozhdenie.py VERIFY` → сравнение с baseline (`19_baseline.json` — snapshot до Фазы 6).

## Антипаттерны (НЕ повторять)

- ❌ Сверка по `Регистратор` для РСКПС/РСППС (там служебный РегистраторРасчётов). Используй `ДокументРегистратор`.
- ❌ Удаление документов в тестах. Перепроведение `Записать(РежимЗаписиДокумента.Проведение)`.
- ❌ Перепроведение массово через COM документов которые пишут в РСКПС/РСППС (это ломает РегистраторРасчётов). Только через UI Enterprise.
- ❌ Запросы без Python COM пре-теста (Rule #-1).
- ❌ Изменение типовых регистров (`feedback_no_typical_register_changes`).
- ❌ Reviewer subagents (`feedback_controller_verifies_no_reviewer_subagents`).
- ❌ `Удалить()` документы — оставляет сирот в `А_ОтчётБаланс_Свод` (memory `rs_otchetbalans_svod_orphans`).
