# knowledge_Balanse_klient — расследование расхождения "Задолженность клиентов" / Глобино-2 (декабрь 2025)

> **Назначение:** локальная база знаний по узкой задаче — найти причину
> расхождения между **Отчётом.УправленческийБаланс** (статья
> *"Задолженность клиентов"*) и **Отчётом.ВедомостьРасчетовСКлиентами**
> по подразделению "Глобино-2" на **31.12.2025**.
>
> На **30.11.2025** оба отчёта совпадают (НМ_дек = 43 998 627,87 UAH),
> на **31.12.2025** — расходятся. Задача — найти **какой документ
> декабря двигает разные суммы** в двух регистрах-источниках.

---

## TL;DR за 30 секунд

| Что | Где |
|---|---|
| Управленческий баланс «Задолженность клиентов» | `РегистрНакопления.ПрочиеАктивыПассивы` (ПАП), `Источник=РасчетыСКлиентамиПоСрокам` |
| Ведомость расчётов с клиентами | `РегистрНакопления.РасчетыСКлиентамиПоСрокам` (РСКПС), ресурс `ДолгУпр` |
| Подразделение в ПАП | прямое (вимір `Подразделение`) |
| Подразделение в РСКПС | через `ОбъектРасчетов.Подразделение` (fallback `Договор.Подразделение`) |
| Организация в РСКПС | через `АналитикаУчетаПоПартнерам.Организация` JOIN по `КлючАналитики` |

**🎯 ИТОГ (2026-05-23):** ✅ **РЕШЕНО** — после правки `DvAktPas` (удаление фильтра `<>ПереносАванса`) и перепроведения документов: Глобино-2 / 31.12.2025 / ЗадКл — ПАП = РСКПС = 44 258 878,85 UAH (Δ=0,00). См. [docs/VERIFY_REPORT.md](docs/VERIFY_REPORT.md).

**Изначальная находка (ред.3 от 2026-05-23):** расхождение **−7 194 594,73 UAH** на 31.12.2025 дают **РОВНО 2 документа**:

| Документ | Дата | Сумма |
|---|---|---:|
| Списание безналичных ДС **000Ц-000286** | 28.12.2025 19:01:15 | 5 194 594,73 |
| Списание безналичных ДС **000Ц-000287** | 28.12.2025 19:27:23 | 2 000 000,00 |

Оба — операция «**Возврат оплаты клиенту**» внутреннему партнёру-самопартнёру
«**Глобино-2**» по договору «Строительство внутр.(Реализация)».

**Корневая причина (асимметрия проводок):** документ при проведении пишет
в ПАП ОДНУ пару (`−Аванс / −Деньги`), но в РСКПС создаёт ТРИ движения
(включая `Перенос аванса → +ДолгУпр`). В ПАП этот «перенос аванса в долг»
**не отражается** проводкой `+ЗадКл / −Аванс`, поэтому статья
«Задолженность клиентов» в управ.балансе на 7,19М МЕНЬШЕ, чем в ВРСК.

**Σ-инвариант сохраняется**: ПАП(ЗадКл + ПолучАв) = РСКПС(ДолгУпр нетто).
Разница только в РАЗНЕСЕНИИ 7,19М между двумя статьями.

Подробный разбор — в [FINDINGS.md](FINDINGS.md) (включая 4 варианта решения).

> ❌ ред.1: «пустой ОбъектРасчетов в шапке» — опровергнуто (ТЧ заполнена)
> ❌ ред.2: «не пересчитан Регистратор расчётов» — опровергнуто (регламент пройден)
> ✅ ред.3: 2 документа «Возврат оплаты клиенту» с асимметричной проводкой ПАП

## Папка скриптов

`Python/test/` — 7 диагностических скриптов (см. [00_PLAN.md](00_PLAN.md)).

Каждый скрипт **самодостаточный**, подключается к ERP через COM,
печатает результат + сохраняет CSV/JSON артефакт в `Python/test/_artifacts/`.

## Дисциплина

- **Rule #-1**: все 1С-запросы предварительно проверены через COM (это и есть скрипты — они и есть проверка).
- **Период серверный**: даты передаются строкой `"01.12.2025 0:00:00"` в `SetParameter`, без `datetime.datetime` (memory `feedback_balans_etalon_period_serverside`).
- **Зарезервированные слова не алиасить**: ПО/ИЗ/КАК → используем `Подр`, `Орг`, `Аналит`.
- **Только чтение**: никаких CRUD по типовым регистрам (memory `feedback_no_typical_register_changes`).
