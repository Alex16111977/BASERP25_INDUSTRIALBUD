## Поведение "В ИЕРАРХИИ"

`СтруктураПредприятия` — справочник с иерархией ЭЛЕМЕНТОВ (не «групп и элементов»).
Любой элемент может быть родителем. На 23.05.2026 в иерархии Глобино-2 **только сам Глобино-2**
(нет потомков с `Родитель = Глобино-2`):

```sql
ВЫБРАТЬ П.Ссылка, П.Код, П.Наименование
ИЗ Справочник.СтруктураПредприятия КАК П
ГДЕ П.Ссылка В ИЕРАРХИИ (&Глобино2)
```
→ возвращает 1 запись (сам Глобино-2).

**Вывод:** в наших скриптах `В ИЕРАРХИИ (&ПодрГлобино2)` эквивалентно `= &ПодрГлобино2`.
Тем не менее **обязательно используем `В ИЕРАРХИИ`** — на случай если позже под Глобино-2
заведут дочерние, скрипты не сломаются.

## Однотипный фильтр в обоих регистрах

| Регистр | Поле подразделения | Фильтр |
|---|---|---|
| ПАП | `Подразделение` (прямое поле РН) | `ПАП.Подразделение В ИЕРАРХИИ (&ПодрГлобино2)` |
| РСКПС | производное (через ОбъектРасчетов) | `ВЫБОР КОГДА Р.ОбъектРасчетов.Подразделение = ПустаяСсылка ТОГДА Р.ОбъектРасчетов.Договор.Подразделение ИНАЧЕ Р.ОбъектРасчетов.Подразделение КОНЕЦ В ИЕРАРХИИ (&ПодрГлобино2)` |

> Различие в способе фильтрации — **главная гипотеза расхождения**.
> Если документ декабря записал ПАП с `Подразделение = Глобино-2`,
> но к этому моменту `ОбъектРасчетов.Подразделение` стало другим
> (или, наоборот, документ записал РСКПС с ОбъектРасчетов под Глобино-2,
> а ПАП — под другим подразделением) — суммы разойдутся.

## Передача параметра в Python COM

```python
# Глобино-2 — через ПолучитьСсылку по UUID:
uid = erp.NewObject("УникальныйИдентификатор", "9d2c9166-1ae7-11f0-80dc-00155d235309")
podr_globino2 = erp.Справочники.СтруктураПредприятия.ПолучитьСсылку(uid)
q.SetParameter("ПодрГлобино2", podr_globino2)

# ТОВ ІНДАСТРІАЛБУД:
uid_org = erp.NewObject("УникальныйИдентификатор", "80d3000c29bbac2311e653f06bee36b2")
tov = erp.Справочники.Организации.ПолучитьСсылку(uid_org)
q.SetParameter("ТОВ", tov)

# Источник = РасчетыСКлиентамиПоСрокам (enum):
q.SetParameter("ИсточникРСК", erp.Перечисления.ИсточникиУправленческогоБаланса.РасчетыСКлиентамиПоСрокам)

# Статья "Задолженность клиентов":
zad_klient = erp.ПланыВидовХарактеристик.СтатьиАктивовПассивов.НайтиПоКоду("00000000002")
q.SetParameter("СтатьяЗадКл", zad_klient)

# Даты (СЕРВЕРНО, без datetime → строка):
q.SetParameter("НачМес", "01.12.2025 0:00:00")   # 1С сам распарсит
q.SetParameter("КонМес", "31.12.2025 23:59:59")
```
