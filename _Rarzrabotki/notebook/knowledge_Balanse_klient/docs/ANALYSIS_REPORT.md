## 4. Scope clarification (важно)

**Полная Δ = −120,4 М** включает множество классов расхождений (ВводОстатков, ПреобретенияТоваров, ПКО Возврат поставщику и т.п.). **Только 24,9 М** из них объясняются фильтром `<>ПереносАванса` (наш bug).

Остальные ~95 М — **другие классы проблем** (асимметрия учёта по статьям, отсутствие проводок в ПАП для определённых ХозОпераций, особенности ВводОстатков и пр.), которые **вне scope** этой задачи. Они требуют отдельного аудита.

**Реальная цель текущего проекта**: устранить расхождение типа C1 (Глобино-2 декабрь 2025 = −7,2 М) для документов СписаниеБезналичных / РКО / ОПК + ХозОп ВозвратОплатыКлиенту.
