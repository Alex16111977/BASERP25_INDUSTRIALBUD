## Важные особенности

### Группа «Необоротные активы» (00000000039)

В отчёте Управленческий баланс эта группа группирует **Основные средства, Нематериальные активы, Расходы будущих периодов** — то есть всё, что не оборачивается в течение года.

В скриншоте «Управленческий баланс общий» за Март 2026 видна именно эта структура:
```
Активы:
  ...
  Необоротные активы           281 019,76
    Основные средства          281 019,76
```

### Статья «Налоги» (00000000035) — Актив/Пассив с конверсией

В функции `ПровестиБалансСвод` (ObjectModule.bsl:90-107) есть универсальная конверсия `АктивПассив → Пассив`:

```bsl
ВЫБОР КОГДА СА.АктивПассив = ВидыСтатейУправленческогоБаланса.АктивПассив
    ТОГДА ВидыСтатейУправленческогоБаланса.Пассив
    ИНАЧЕ СА.АктивПассив
КОНЕЦ КАК ТипПоказателя
```

Это значит — все статьи типа «Актив/Пассив» (как «Налоги») в Своде записываются как **Пассив** (т.е. кредиторская задолженность бюджету), а не как Дебет. Если у вас есть **переплата** (НДС к возмещению, например) — она будет отображена как **отрицательный Пассив**.

Это **штатное** поведение, скопировано из штатной СКД отчёта.

### Статья «Основные средства» (00000000045) — главная для нас

Когда документ записывает в РН.ПрочиеАктивыПассивы движение со Статья = «Основные средства»:
- **Приход** (Дт) = увеличение балансовой стоимости ОС (приём в эксплуатацию)
- **Расход** (Кт) = уменьшение балансовой стоимости (амортизация, продажа, списание)

В нашем кейсе АмортизацияОС 000Ц-000003 пишет только Расход (Кт ОС) на сумму амортизации, что правильно — оставшаяся стоимость ОС уменьшается.

### Статья «Расходы текущего периода» (00000000014)

Куда **попадает** амортизация в управ.балансе. Растёт за период (Приход = Дт), затем закрывается при формировании финансового результата.

В нашем кейсе АмортизацияОС пишет Приход (Дт Расходы) на сумму **управ.амортизации** (через штатную Обработку.ДвиженияАктивовПассивов), но Кт ОС — на сумму **регл.амортизации** (через кастомную процедуру). Отсюда **Δ = 102 060,55 = СуммаУпр − СуммаРегл**.

### Статья «Вложения собственных средств» (00000000040)

Это **пассивная** статья (источник средств для формирования ВНА). Не путать с **РН.ВложенияВНеоборотныеАктивы** — это разные сущности:
- **РН.ВложенияВНеоборотныеАктивы** — детальный регистр накопления капитальных вложений по объектам
- **ПВХ.СтатьиАктивовПассивов «Вложения собственных средств»** — пассивная статья баланса, показывает, какая часть собственного капитала направлена на ВНА
