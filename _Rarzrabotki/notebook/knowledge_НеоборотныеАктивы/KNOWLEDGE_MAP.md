## TL;DR (60 секунд) — для понимания ЧТО было решено

**Проблема (Март 2026):** Документ Амортизация ОС (2.1) 000Ц-000003 нарушает управ.баланс двумя способами:

| Сторона | Видно? | Сумма |
|---|---|---:|
| A. Задвоение Дт «Расходы» (4 ОС с УПР строкой) | ✓ Контроль баланса | **102 060,55** |
| B. Скрытый остаток НДС на ОС (8 ОС без УПР строки + 4 с УПР) | ✗ внутри баланса | **27 865,47** |

**Корневая причина (диагностировано 2026-05-25):**

Типовой механизм 2.1 непоследовательно работает с НДС:
1. Все 12 ОС оприходованы С НДС в РН.ПАП через Списание Товаров и ПринятиеКУчетуОС
2. Амортизация Кт пишет только сумму БЕЗ НДС (по бух.учёту)
3. Для **некоторых** ОС типовая логика добавляет «УПР строку» в РН.ПрочиеРасходы (Сумма_с_НДС, СуммаРегл=0)
4. Штатная Обработка.ДвиженияАктивовПассивов суммирует БОБА+УПР → задвоение Дт
5. Кастомная А_-процедура берёт только БОБА (СуммаРегл) → асимметрия Кт ОС

**Желаемое поведение для управ.баланса:** Амортизация = Остаток_ОС_с_НДС / СПИ_оставшийся, симметрично Дт=Кт, остаток после полной амортизации = 0.

**Решение — Вариант B v2 (рекомендую):** добавить **3 А_-процедуры** в `Documents/АмортизацияОС/Ext/ObjectModule.bsl`:

1. **`А_ПолучитьУправАмортизациюПоОС()`** — функция-расчёт: для каждого ОС из РН.ПрочиеРасходы получить «Доступная стоимость» = Σ всех Приход в РН.ПАП до КонМес − Σ Расход (амортизация) до НачМес (исключая свой регистратор). Амортизация = Доступная стоимость / СПИ_БУ.
2. **`А_СкорректироватьПрочиеРасходыНаНДС()`** — правка РН.ПрочиеРасходы: в БОБА строках обнулить **Сумма** и **СуммаУпр** (если есть УПР строка) или поменять на правильную с НДС (если УПР строки нет). **СуммаРегл не трогаем.**
3. **`А_СформироватьСимметричнуюАмортизациюВПАП()`** — Очистить РН.ПАП + симметричная пара Дт «Расходы» / Кт «ОС» на правильную сумму с НДС.

> 🚫 **Бухгалтерский и налоговый учёт НЕ трогается.** РБ.Хозрасчетный (Дт 92 Кт 131/1321 на сумму без НДС), СуммаРегл/СуммаРеглБезНДС/НДСРегл в РН.ПрочиеРасходы — остаются без изменений.

Полный готовый BSL-код всех 3-х процедур в [FINDINGS §6 Вариант B](FINDINGS.md).

> ⚠️ Миграция на версию 2_4 **исключена**: все 18 документов *ОС2_4/*НМА2_4 имеют пустые ObjectModule.bsl (нет процедур проведения).
