**Используется когда:** расширяете scope расследования за пределы Марта 2026, либо проверяете другую организацию.

| Случай | Что увидите | Действие |
|---|---|---|
| **0 асимметричных** | `Всего асимметричных: 0` в выводе | За период ОС амортизировались одинаково в упр/регл — фикс не нужен. Записать в FINDINGS. |

## Дополнительно: проверка по подразделениям

Чтобы найти **конкретные ОС** с расхождением — взять UUID асимметричного документа, запустить `02_compare_*.py` (предварительно адаптировав DOC_UUID) → вывод покажет:

```
=== РН.ПрочиеРасходы (Приход / СуммаРегл / СуммаУпр / Сумма) ===
  <Подразделение>  Приход  Амортизация ОЗ  С=12 345,67  Упр=12 345,67  Регл=5 678,90
                                                                       ↑↑↑↑↑↑↑↑↑
                                                                       Δ = 6 666,77
```

Эти строки = конкретные ОС с разными методами амортизации.

## Расширения

- **Per-год сводка**: запустить скрипт для каждого месяца 2025 и 2026, собрать в Excel месяц × подразделение × Δ
- **Top-10 ОС по Δ**: модификация скрипта чтобы группировать по Аналитика (объект эксплуатации) вместо подразделения → топ-10 самых "проблемных" ОС
- **Сверка с регл.отчётностью**: убедиться что в декларации по налогу на прибыль (или налогу на основные средства) числится та же сумма СуммаРегл — это поможет принять решение между Вариантами A/B/C
