# 03. Алгоритм распределения (ВНорме / ПонадНорму / Економія)

Ядро — `ЗаполнитьАнализ(ТЗОстатки, Нормы)`. **НЕ менять математику распределения** при доработках.

## Идея

Норма-кап считается на **общий остаток всех выбранных складов по эталону**. Внутри эталона строки (Номенклатура×Склад×Счёт) идут **по убыванию остатка** (из `УПОРЯДОЧИТЬ`), и жадно «съедают» норму:
- `ВНорме = мин(Остаток_строки, ОстатокНормы)` (остаток нормы, ещё не покрытый предыдущими строками эталона);
- `ПонадНорму = Остаток_строки − ВНорме`;
- `ОстатокНормы -= ВНорме`.

Эталон без нормы (`Нормы.Получить(ОбщееНазвание)=Неопределено`) или пустой `ОбщееНазвание` → `НормаЭталона=0` → всё в `ПонадНорму`.

## Економія (зеркало ПонадНорму)

`Економія = max(0, Норма − Σ Остаток_эталона)` = **неиспользованная норма**. Это ровно остаточный `ОстатокНормы` ПОСЛЕ обработки всех строк эталона. Пишется на **первую (представительную) строку эталона** (рядом с Нормой) через `ЗафиксироватьЭкономиюЭталона`.

**Инвариант:** для каждого эталона либо `ПонадНорму>0` (излишек), либо `Економія>0` (недобор), либо оба 0 (точное совпадение) — но не оба >0 одновременно.

## Код `ЗаполнитьАнализ` (актуальный)

```bsl
Процедура ЗаполнитьАнализ(ТЗОстатки, Нормы)

	ТабличнаяЧастьОстатков.Очистить();

	ТекЭталон = Неопределено;
	ОстатокНормы = 0;
	ПервыйРяд = Истина;
	ПерваяСтрокаЭталона = Неопределено;

	Для Каждого Стр Из ТЗОстатки Цикл

		НовыйЭталон = ПервыйРяд ИЛИ Стр.ОбщееНазвание <> ТекЭталон;
		Если НовыйЭталон Тогда
			ЗафиксироватьЭкономиюЭталона(ПерваяСтрокаЭталона, ОстатокНормы); // финал предыдущего эталона
			ТекЭталон = Стр.ОбщееНазвание;
			НормаЭталона = ?(ЗначениеЗаполнено(Стр.ОбщееНазвание), Нормы.Получить(Стр.ОбщееНазвание), Неопределено);
			Если НормаЭталона = Неопределено Тогда НормаЭталона = 0; КонецЕсли;
			ОстатокНормы = НормаЭталона;
			ПервыйРяд = Ложь;
		КонецЕсли;

		ВНорме = ?(Стр.Остаток < ОстатокНормы, Стр.Остаток, ОстатокНормы);
		Если ВНорме < 0 Тогда ВНорме = 0; КонецЕсли;
		ПонадНорму = Стр.Остаток - ВНорме;
		ОстатокНормы = ОстатокНормы - ВНорме;

		НоваяСтрока = ТабличнаяЧастьОстатков.Добавить();
		НоваяСтрока.Номенклатура = Стр.Номенклатура;
		НоваяСтрока.ОбщееНазвание = Стр.ОбщееНазвание;
		НоваяСтрока.Склад = Стр.Склад;
		НоваяСтрока.Счет = Стр.Счет;                       // счёт-на-строку (Фаза 4)
		НоваяСтрока.Остаток = Стр.Остаток;
		НоваяСтрока.Норма = ?(НовыйЭталон, НормаЭталона, 0); // норма только на первой строке эталона
		НоваяСтрока.ВНорме = ВНорме;
		НоваяСтрока.ПонадНорму = ПонадНорму;

		Если НовыйЭталон Тогда ПерваяСтрокаЭталона = НоваяСтрока; КонецЕсли;

	КонецЦикла;

	ЗафиксироватьЭкономиюЭталона(ПерваяСтрокаЭталона, ОстатокНормы); // финал последнего эталона

КонецПроцедуры

Процедура ЗафиксироватьЭкономиюЭталона(СтрокаЭталона, ОстатокНормы)
	Если СтрокаЭталона <> Неопределено Тогда
		СтрокаЭталона.Экономия = ?(ОстатокНормы > 0, ОстатокНормы, 0);
	КонецЕсли;
КонецПроцедуры
```

## Размещение метрик по строкам (важно для доработок печати/итогов)

- `Норма` и `Економія` — **только на ПЕРВОЙ строке эталона** (на остальных 0). Поэтому Σ по этим колонкам = сумма per-эталон значений (без задвоения). Итог `ИтогоНорма` в подсумках НЕ выводится; `ИтогоЭкономия` — выводится (суммирование по первым строкам корректно).
- `Остаток`, `ВНорме`, `ПонадНорму` — **на каждой строке** (аддитивны).

## Инварианты (проверяются в smoke)

- Глобально по эталонам/складам: `Σ Остаток = Σ ВНорме + Σ ПонадНорму` (баланс 0).
- На эталон: `НЕ (Економія>0 И Σ ПонадНорму_эталона>0)`.
- Эталон-фильтр инвариант: `Норма(include этап) + Норма(exclude этап) = Норма(все этапы)`.
