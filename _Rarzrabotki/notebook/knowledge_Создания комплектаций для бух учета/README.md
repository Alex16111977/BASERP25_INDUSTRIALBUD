## Краткое описание

Обработка-«рабочее место» бухгалтера: **раскладывает остатки материалов «під списання» (счета класса 2: 20/22/28 → 201/221/281/2051…) на документы `КомплектацияНоменклатуры` по нормам спецификации `СтруктураСебестоимости`**. Кап нормы — по эталону `ОбщееНазвание`; распределение жадное по убыванию остатка (норм-карточки первыми: ВНорме / ПонадНорму / Економія). Заполняет ТЧ `Комплектующие` выбранных пользователем документов; счёт компонента = счёт-источник остатка (per-row); **сумма в документ — себестоимость БЕЗ НДС**. Документы не создаёт и не проводит.

**Отчётность (Фазы 6-12):** 4 печатные формы — плоский «Друк» (программный `ТабличныйДокумент`) + 3 СКД («Аналіз СС», «План-факт», «з етапами»). **Норма отображается ПО КАРТОЧКЕ** (`НормаНоменкл`; норм-карточки без остатка тоже видны, субституты=0, эталон=Σ). **Суммы факта нормализованы к НДС** (себестоимость ×1.2, т.к. нормы введены с НДС). Traffic-light подсветка, динамический заголовок (подразделение/склады/дата).
