# 05. Заполнение документов (3 режима, транзакция, структура-результат, авто-склады)

## Целевые документы — ТЧ `ДокументиКомплектації`

Пользователь заводит пустые `Документ.КомплектацияНоменклатуры` сам и выбирает их в ТЧ `ДокументиКомплектації` (колонки: `Склад`, `ДокументПоНормам`, `ДокументДодаткова`). Обработка документы **НЕ создаёт и НЕ проводит** — только записывает их ТЧ `Комплектующие` (`РежимЗаписиДокумента.Запись`, без проведения).

Маршрутизация по складу: для строки анализа склада X — `ВНорме`→`ДокументПоНормам` склада X, `ПонадНорму`→`ДокументДодаткова` склада X. На 2 склада получается до 4 документов (2×{ПоНормам, Додаткова}).

## Авто-заполнение складов (после «Розрахувати»)

`РассчитатьАнализ` в конце вызывает `ДополнитьСкладыДокументов()` — добавляет в `ДокументиКомплектації` склады из `СкладыОстатков`, которых там ещё нет (документы юзер выбирает сам). Идемпотентно (Соответствие по ref-ключу склада; повтор не дублирует, существующие не трогает).

```bsl
Процедура ДополнитьСкладыДокументов()
	Существующие = Новый Соответствие;
	Для Каждого Стр Из ДокументиКомплектації Цикл
		Если ЗначениеЗаполнено(Стр.Склад) Тогда Существующие.Вставить(Стр.Склад, Истина); КонецЕсли;
	КонецЦикла;
	Для Каждого Стр Из СкладыОстатков Цикл
		Если ЗначениеЗаполнено(Стр.Склад) И Существующие.Получить(Стр.Склад) = Неопределено Тогда
			ДокументиКомплектації.Добавить().Склад = Стр.Склад;
			Существующие.Вставить(Стр.Склад, Истина);
		КонецЕсли;
	КонецЦикла;
КонецПроцедуры
```

## 3 режима заполнения

`ЗаполнитьДокументыПоАнализу(ЗаполнятьВНорме = Истина, ЗаполнятьПонад = Истина)` — **опц. булевы по умолчанию обе** (обратная совместимость со старыми smoke без аргументов). UI: выпадающее меню «Заповнити документи» (Popup) с 3 кнопками:
| Кнопка | Вызов | Что пишет |
|---|---|---|
| «В нормі + понад норму» | `(Истина, Истина)` | ВНорме→ПоНормам, ПонадНорму→Додаткова |
| «Тільки в нормі» | `(Истина, Ложь)` | только ВНорме→ПоНормам |
| «Тільки понад норму» | `(Ложь, Истина)` | только ПонадНорму→Додаткова |

Роутинг в `ПодготовитьСтрокиПоДокументам(Результат, ЗаполнятьВНорме, ЗаполнятьПонад)`:
```bsl
Если ЗаполнятьВНорме И Стр.ВНорме > 0 Тогда
	РаспределитьВДокумент(СтрокиПоДокументам, ПропущенныеСклады, ДокПоНормам.Получить(Стр.Склад),
		Стр.Склад, Стр.Номенклатура, Стр.ВНорме, Стр.Счет);
КонецЕсли;
Если ЗаполнятьПонад И Стр.ПонадНорму > 0 Тогда
	РаспределитьВДокумент(СтрокиПоДокументам, ПропущенныеСклады, ДокДоп.Получить(Стр.Склад),
		Стр.Склад, Стр.Номенклатура, Стр.ПонадНорму, Стр.Счет);
КонецЕсли;
```

## Транзакционный оркестратор (всё-или-ничего)

`ЗаполнитьДокументыПоАнализу` — тонкий: строит соответствие → одна транзакция → `СформироватьДокументыПоСоответствию` → фиксация; на сбое откат + журнал + структура.Помилки. **НЕ re-raise** (лог+возврат структуры — паттерн рабочего места `ПомощникПродаж`).

```bsl
НачатьТранзакцию();
Попытка
	СформироватьДокументыПоСоответствию(СтрокиПоДокументам, Результат);
	ЗафиксироватьТранзакцию();
Исключение
	ОтменитьТранзакцию();
	ЗаписьЖурналаРегистрации(ИмяСобытия, УровеньЖурналаРегистрации.Ошибка, , ,
		ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
	Результат = НовыйРезультатЗаполнения();
	Результат.Помилки.Добавить("Помилка запису, зміни скасовано: " + КраткоеПредставлениеОшибки(ИнформацияОбОшибке()));
КонецПопытки;
```

## Структура-результат

`{Заповнено, Пропущено, БезЕдиниці, Помилки(Массив)}` (builder `НовыйРезультатЗаполнения`). Форма форматирует в читаемое сообщение (`ВывестиРезультатЗаполнения`).
- `Заповнено` — число записанных документов.
- `Пропущено` — число складов без выбранного документа (считается явно через `ПропущенныеСклады`, см. грабли).
- `БезЕдиниці` — компонент записан, но `Номенклатура.БазоваяЕдиницаИзмерения` не задана → счётчик + лог-Предупреждение (НЕ пустой `Исключение`).

## Запись компонента (`СформироватьДокументыПоСоответствию`)

```bsl
НС = ДокОбъект.Комплектующие.Добавить();
НС.Номенклатура = СтрД.Номенклатура;
НС.Количество = СтрД.Количество;
НС.СчетУчетаБУ = СтрД.Счет;                           // ★ счёт-источник остатка (per-row)
ЕдиницаИзмерения = СтрД.Номенклатура.БазоваяЕдиницаИзмерения;
Если ЗначениеЗаполнено(ЕдиницаИзмерения) Тогда
	НС.ЕдиницаИзмерения = ЕдиницаИзмерения;
Иначе
	Результат.БезЕдиниці = Результат.БезЕдиниці + 1;
	ЗаписьЖурналаРегистрации(ИмяСобытия, УровеньЖурналаРегистрации.Предупреждение, , ДокСсылка, "Не задана базова одиниця…");
КонецЕсли;
// ... после цикла строк:
ДокОбъект.Комплектующие.Очистить();                   // идемпотентность — В НАЧАЛЕ, до добавления строк
ДокОбъект.Записать(РежимЗаписиДокумента.Запись);
```
- **`Комплектующие.Очистить()` перед добавлением** — повторное заполнение не задваивает.
- `КомплектацияНоменклатуры` — **нерасчётный** документ → `Курс/Кратность/А_`-флаги обмена НЕ нужны (в отличие от расчётных Реализация/ПКО — см. `knowledge/document_hidden_fields.md`).
