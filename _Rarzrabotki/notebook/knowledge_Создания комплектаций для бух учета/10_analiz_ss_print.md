|---|---|---|

| Сумма СС | `Сумма(НормаСуммаНоменкл)` | **план грн (N)** |

Інваріант: `O = K + L`; `Σ СуммаОстатка = Σ ВНормеСумма + Σ ПонадНормуСумма` (баланс по рядку — Фаза 6).

## Реалізація (клон рецепта Фази 7)

1. **`ДанныеВТаблицуПланФакт` (спільний білдер ТЗ) +2 колонки**: `ВНорме`, `ВНормеСумма` (копія з `ДанныеАнализа`; вони вже в `ТаблицаАнализа`). Старі макети `МакетПланФакт`/`…Етапи` зайві колонки **ігнорують** → регресії немає.
2. **Нова експортна** `СформироватьПечатьАнализСС(ДанныеАнализа)` = клон `СформироватьПечатьПланФакт` з `ПолучитьМакет("МакетАнализСС")`.
3. **Макет `МакетАнализСС`**: `skd-compile` JSON `Python/test/skd_analizss_def.json` → `Templates/МакетАнализСС/Ext/Template.xml`; метадані `Templates/МакетАнализСС.xml`; манифест `<Template>МакетАнализСС</Template>`. %-і Різниця — ресурси з агрегатним виразом; conditionalAppearance #HEX (зелений `#E2EFDA` план-в-нормі, янтар `#FFE699`/`#843C0C` перевитрата).
4. **Заголовки точно за Excel (uk)**: skd-compile НЕ задає `<title>` dataset-полів → Python-пост-інжект `<title xsi:type="v8:LocalStringType">…uk…</title>` між `<field>X</field>` і `<valueType>` + `ru→uk` для calc-заголовків; UTF-8 **без BOM**.
5. **Форма**: кнопка «Друк аналіз СС» (`Form.xml` id 273/274/275) + `&НаКлиенте ПечатьАнализСС` / `&НаСервере ПечатьАнализССНаСервере` (клон Етапи-хендлерів).

## 🪤 Граблі Фази 8 (доповнення до LESSONS)

- **UUID макета має бути УНІКАЛЬНИМ серед усіх `Templates/*.xml`.** Реюз `d4000000-…-002` (зайнятий `МакетПланФактЕтапи`) → колізія: `epf-build` exit 0, але макет МОВЧКИ випадає (`Метаданные().Макеты` = дубль Етапи), runtime `ПолучитьМакет("МакетАнализСС")` = «Недопустимое значение параметра №1». Діагностика — `обр.Метаданные().Макеты`. Перед білдом: `grep -o 'Template uuid' Templates/*.xml`.
- **Form.xml id**: реальний max був **272** (не 265) — фази 7b-7d додавали id. Завжди скан `grep -o 'id="[0-9]*"'` перед вставкою.
- **Заголовки колонок виводу** беруться з `<title>` dataset-поля; без інжекту — авто-рос. синонім поля.
