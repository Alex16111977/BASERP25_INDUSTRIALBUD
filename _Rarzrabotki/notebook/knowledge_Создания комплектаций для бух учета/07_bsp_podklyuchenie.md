# 07. Подключение как «Додаткова обробка» БСП

## Проблема

При подключении через **Адміністрування → Друковані форми, звіти і обробки → Додаткові звіти і обробки → Створити → Завантажити з файлу** БСП требует в модуле объекта экспортную функцию `СведенияОВнешнейОбработке()`. Без неё:

> Неможливо підключити додаткову обробку з файлу… Метод объекта не обнаружен **(СведенияОВнешнейОбработке)**

## Решение (эталон `Обработки/ПерепроведениеДокументов`)

3 функции в `ObjectModule.bsl`:

```bsl
// #Область ПрограммныйИнтерфейс
Функция СведенияОВнешнейОбработке() Экспорт
	ПараметрыРегистрации = Новый Структура;
	ПараметрыРегистрации.Вставить("Вид", "ДополнительнаяОбработка");
	ПараметрыРегистрации.Вставить("Наименование", "Створення комплектацій для бух обліку");
	ПараметрыРегистрации.Вставить("Версия", "1.0");
	ПараметрыРегистрации.Вставить("БезопасныйРежим", Ложь);    // нужен полный доступ (запросы/запись)
	ПараметрыРегистрации.Вставить("Информация", "Аналіз залишків (для списання) → документи КомплектаціяНоменклатури");
	ПараметрыРегистрации.Вставить("ВерсияБСП", "2.0.7.6");
	ТаблицаКоманд = ПолучитьТаблицуКоманд();
	ДобавитьКоманду(ТаблицаКоманд, "Створення комплектацій для бух обліку", "1", "ОткрытиеФормы", Истина, "");
	ПараметрыРегистрации.Вставить("Команды", ТаблицаКоманд);
	Возврат ПараметрыРегистрации;
КонецФункции

// #Область СлужебныеПроцедурыИФункции
Функция ПолучитьТаблицуКоманд()
	Команды = Новый ТаблицаЗначений;
	Команды.Колонки.Добавить("Представление", Новый ОписаниеТипов("Строка"));
	Команды.Колонки.Добавить("Идентификатор", Новый ОписаниеТипов("Строка"));
	Команды.Колонки.Добавить("Использование", Новый ОписаниеТипов("Строка"));
	Команды.Колонки.Добавить("ПоказыватьОповещение", Новый ОписаниеТипов("Булево"));
	Команды.Колонки.Добавить("Модификатор", Новый ОписаниеТипов("Строка"));
	Возврат Команды;
КонецФункции

Процедура ДобавитьКоманду(ТаблицаКоманд, Представление, Идентификатор, Использование, ПоказыватьОповещение = Ложь, Модификатор = "")
	НоваяКоманда = ТаблицаКоманд.Добавить();
	НоваяКоманда.Представление = Представление;
	НоваяКоманда.Идентификатор = Идентификатор;
	НоваяКоманда.Использование = Использование;
	НоваяКоманда.ПоказыватьОповещение = ПоказыватьОповещение;
	НоваяКоманда.Модификатор = Модификатор;
КонецПроцедуры
```

## Ключи

| Ключ | Значение | Примечание |
|---|---|---|
| `Вид` | `"ДополнительнаяОбработка"` | Открывает форму / выполняет команды |
| `БезопасныйРежим` | `Ложь` | Небезопасный режим — нужен для запросов и записи документов. БСП попросит подтверждение |
| `ВерсияБСП` | `"2.0.7.6"` | Версия БСП этой BuhBud |
| `Команды` | ТЗ с 1 командой | `Использование="ОткрытиеФормы"` открывает основную форму обработки; `Идентификатор="1"` |

## Проверка (COM)

`verify_svedeniya_bsp.py`: `ВнешниеОбработки.Создать(epf).СведенияОВнешнейОбработке()` → структура совпадает с эталоном `ПерепроведениеДокументов` (Вид/Версия/БезопасныйРежим/ВерсияБСП/1 команда ОткрытиеФормы). Это ровно то, что вызывает БСП при подключении.

## Сосуществование с COM-вызовом

`СведенияОВнешнейОбработке` — лишний экспорт, вызывается только БСП. COM-smoke (`ВнешниеОбработки.Создать` → `РассчитатьАнализ` и т.д.) не затрагивается. Обе точки входа сосуществуют.
