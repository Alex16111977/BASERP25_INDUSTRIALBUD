# 11. Фаза 9 — фікс «втрати норм»: норма ЕТАЛОННА, лише на рядку еталона

DONE 2026-06-30. Виправляє відображення норми у 3 СКД-звітах. Алгоритм розподілу/кап — НЕ змінено.

## Проблема (роль бухгалтера)

«Згідно СС» / «Норма» у звітах = `Сумма(НормаНоменкл)` (план **по картці номенклатури**) → губила
норматив, чия картка **не на складі**.

**Приклад «Профнастил»** (Структура Собівартості, норма еталона = 210):
| Норматив (картка плану) | Кількість |
|---|---|
| Профіль ПК-20 | 90 |
| Профнастил ПС-10 | 120 |

На складі лежать картки: `Профнастил ПС-10` (план є → 120) і `Профілі сталеві листові ПК-20 0,7 оц`
(**інша картка**, плану немає → 0). Звіт показував Σ НормаНоменкл = **120**, втрата 90; абсурд
«В нормі 210 > Згідно СС 120».

## Методична істина

Норма **еталонна, спільна (fungible)**: матеріали нормуються/закуповуються на рівні еталона (210),
картки складу споживають спільний кап. **Дробити норму по картках не можна.** Еталонна `Норма`/`НормаСумма`
вже пораховані (кап) і заштамповані **один раз на еталон** (`ЗаполнитьАнализ`:
`НоваяСтрока.Норма = ?(НовыйЭталон, НормаЭталона, 0)`), тому `Сумма(Норма)` на групі еталона **не
задвоюється** по складах/номенклатурах (перевірено 3 склади: Σ Норма = 210).

## Рішення (рішення замовника: норма лише на рядку еталона, усі 3 звіти)

1. **`ДанныеВТаблицуПланФакт`** +2 колонки `Норма`, `НормаСумма` (еталонні; копія з `ДанныеАнализа` —
   `ПрименитьОтборИИтоги` копіює `НС.Норма`/`НС.НормаСумма`).
2. **3 skd JSON** (`skd_analizss_def.json`, `skd_planfakt_def.json`, `skd_planfaktetapy_def.json`):
   норм-колонки і % від `Сумма(Норма)`/`Сумма(НормаСумма)` замість `НормаНоменкл`/`НормаСуммаНоменкл`.
3. **Per-group selection** — норма лише на рівні еталона (і Этап для з-етапами):
   - група `ОбщееНазвание` (та `Этап`) `selection` = **поле-групування** + усі норм-колонки;
   - група `(Номенклатура, Единица)` `selection` = `Номенклатура, Единица` + **НЕ-норм** колонки
     (Остаток/ВНорме/ПонадНорму/Економія/СуммаОстатка/ВНормеСумма/ПонадНормуСумма/ЕкономіяСума) — БЕЗ норм
     → норма порожня на номенклатурі.
   - `НормаНоменкл`/`НормаСуммаНоменкл` лишені в наборі лише для traffic-light (`НормаСуммаНоменкл > 0`).

## 🪤 ГРАБЛІ СКД «ресурс лише на одній групі» (важливо)

| Спроба | Результат |
|---|---|
| `totalField "group": ["ОбщееНазвание","ОбщийИтог"]` (Рассчитывать по групуваннях) | **НЕ гасить** ресурс на дочірній групі — показує значення представницького рядка (210 на ПС-10). |
| **per-group `selection`** (виключити норму з групи номенклатури) | **ГАСИТЬ** норму на номенклатурі ✅ — робочий механізм. |
| per-group selection БЕЗ поля групування | **зникають назви груп** (caption порожній): explicit selection заміняє `SelectedItemAuto`, який і давав caption. |
| per-group selection З полем групування (ОбщееНазвание/Номенклатура у selection) | назви + контроль ресурсів ✅ — фінальне рішення. |

**Перевірка — ТІЛЬКИ COM-рендер ТабДок** (`Область(r,c).Текст`): рядок-еталон має норму, рядок-номенклатура
порожній. Headless-метадані це не ловлять. Python COM не вміє `Тип()` → СКД лише build+COM-виклик.

## 🪤 З-етапами: норму НЕ виносити на рівень групи Этап (адверсативне ревʼю)

У звіті «План-факт (з етапами)» (`Этап → ОбщееНазвание → Номенклатура`) норм-колонки селектяться **ЛИШЕ на
групі `ОбщееНазвание`**, НЕ на `Этап`. **Чому**: норма еталона заштампована один раз на еталон (під першим
етапом представницького рядка). Якщо винести `Сумма(Норма)` на рівень `Этап`, то для **мультиетапних
еталонів** (номенклатури в різних етапах: «Брус» = Отделка+Монтаж, «Дошка») вся норма приписується одному
етапу, а під іншим — `Сумма(Норма)=0` при наявному факті → `% вик.=0%` (div/0-guard) — хибний план-факт.
Тест `smoke_komplektacii_planfaktetapy.py` цього НЕ ловив (перевіряв лише присутність колонок) — додано
COM-перевірку `verify_etapy_fix` (рядки-этапи мають порожню «Норму»).

**Залишкове обмеження (LOW, прийнятне)**: мультиетапний еталон показує норму під рядком-еталоном свого
представницького етапу; під іншими етапами рядок-еталон має норму=0 (наближення «перший етап на номенклатуру»,
Фаза 7b). Норма еталона неподільна по етапах. Глибший фікс (рознести норму по етапах компонентів СС) — лише
за окремим рішенням замовника.
