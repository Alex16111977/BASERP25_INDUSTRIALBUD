# 13. Фаза 11 — норма ПО КАРТЦІ (фінальне рішення відображення)

DONE 2026-06-30. Норма показується проти КОЖНОЇ номенклатурної картки (як у документі
`Справочник.СтруктураСебестоимости`), а не лише еталонним підсумком. **Це фінальний стан відображення норми**
(розворот Фази 9, що став коректним завдяки Фазі 10).

## Еволюція відображення норми (важливо для розуміння)
- **Фаза 7d**: норма по картці (`НормаНоменкл`) — але норм-картки без залишку НЕ виводились → еталон-Σ
  занижений (Профнастил 120 замість 210).
- **Фаза 9**: перейшли на еталонну `Норма` (210), лише на рядку еталона (per-group selection) — щоб прибрати
  втрату. Але по-карткова норма зникла.
- **Фаза 10**: додали норм-картки без залишку у звіт.
- **Фаза 11 (фінал)**: повернули по-карткову `НормаНоменкл` — тепер Σ по картках = еталонна (210), бо всі
  норм-картки є. Кожна картка показує свою норму; субститут (в залишках, не в нормах) = 0; еталон = Σ.

## Що показує (приклад «Профнастил»)
| Рядок | Норма |
|---|---|
| Профнастил ПС-10 (норм-картка) | 120 |
| Профіль ПК-20 (норм-картка без залишку) | 90 |
| Профілі сталеві листові ПК-20 (субститут, не в нормах) | 0 |
| Профнастил (еталон, СКД-підсумок) | 210 (Σ) |

## Реалізація — ТІЛЬКИ відображення (5 місць)
`НормаНоменкл`/`НормаСуммаНоменкл` вже коректно заштамповані в `ЗаполнитьАнализ` (один раз на номенклатуру,
`БаченіНоменклатури`; Σ по картках еталону = `НормыЭталон`). Алгоритм/кап НЕ чіпали (кап юзає локальну
`НормаЭталона`, не поле відображення).

1. **Форма** `Form.xml`: `ТАНорма`(id63) DataPath `ТаблицаАнализа.Норма`→`.НормаНоменкл`;
   `ТАНормаСумма`(id226) `.НормаСумма`→`.НормаСуммаНоменкл`. VT має колонки `НормаНоменкл`(270)/`НормаСуммаНоменкл`(271).
2. **Плоский «Друк»** `СформироватьПечать`: `Стр.Норма`→`Стр.НормаНоменкл` + `ИтНорма` Σ у «Разом».
3-5. **3 СКД JSON**: норм-колонки/%/Різниця від `НормаНоменкл`/`НормаСуммаНоменкл`; **прибрано per-group
   selection** (норма на картці + підсумок еталона Σ; структура — прості `groupFields`, Auto selection,
   назви груп лишаються); пост-інжект заголовків `НормаНоменкл`→«Згідно СС».

## Не зламано
Еталон-Σ=210, кольори (Фаза 10, `СуммаОстатка>0`/`ПонадНормуСумма>0`), заголовок, картки без залишку,
пріоритет (`ПорядокПлан`), баланси, документи (`ПодготовитьСтрокиПоДокументам` читає `ВНорме`/`ПонадНорму`,
не норму). `з етапами`: норма по картці → кожен етап показує норми своїх карток (знімає лампа-проблему Фази 9b).

## Субститути = 0
`НормаНоменкл=0` для не-норм карток → у формі/плоскому друку показується ПУСТО (конвенція `?(=0,"",..)`,
як інші нульові колонки). Якщо треба саме «0» цифрою — окремий формат.

## Smoke

Плоский Друк COM-перевірено (120/90/порожньо). Форма — лише клієнт BuhBud (керована форма headless не рендериться).
