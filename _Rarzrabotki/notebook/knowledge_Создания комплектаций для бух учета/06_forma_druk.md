# 06. Форма и печать

## Закладки (Pages)

1. **«Параметри»** — Період, Спеціфікація (норми), Організація, таблицы `СкладыОстатков`/`СчетаОстатков`(default 20/22/28)/`Этапы`, флаг `ИсключатьЭтапы`.
2. **«Аналіз залишків»** — группа «Відбір» (ОтборСклад/ОтборЭталон/Пошук/ТолькоПонадНорму + кнопки «Фільтр за полем»/«Скинути») + таблица `ТаблицаАнализа` (форм-ValueTable) + группа «Підсумки» (ИтогоЗалишок/ИтогоВНорме/ИтогоПонад/ИтогоЭкономия — read-only итоги).
3. **«Документи»** — таблица `ДокументиКомплектації` (Склад/ДокументПоНормам/ДокументДодаткова).

Командная панель: «Розрахувати», выпадающее меню «Заповнити документи ▾» (3 режима), «Друк».

## Форм-ValueTable `ТаблицаАнализа` vs объект-ТЧ `ТабличнаяЧастьОстатков`

- `Объект.ТабличнаяЧастьОстатков` (объект-ТЧ) — ПОЛНЫЙ результат `РассчитатьАнализ`; источник для заполнения документов И печати.
- `ТаблицаАнализа` (реквизит формы, ValueTable, копия колонок) — ОТОБРАЖАЕМОЕ подмножество под текущий отбор/поиск. Колонки: ОбщееНазвание, Номенклатура, Склад, Счет, Остаток, Норма, ВНорме, ПонадНорму, Экономия.

## `ПрименитьОтборИИтоги()` (&НаКлиенте)

Пересобирает `ТаблицаАнализа` из полного `Объект.ТабличнаяЧастьОстатков` под предикат (Склад==/Эталон==/ПонадНорму>0/Пошук-substring) и тут же копит итоги (ИтогоЗалишок/ВНорме/Понад/Экономия). &НаКлиенте — мгновенно, без сервера. Подсумки И футер таблицы совпадают с видимым набором («Підсумки по відбору»). Встроенный платформенный поиск таблицы НЕ даёт события → отдельное поле `Пошук`.

## УсловноеОформление строк (программно, в `ПриСозданииНаСервере`)

Строки `ПонадНорму > 0` — янтарный фон. Поле = `Элементы.ТаблицаАнализа.Имя` (вся строка), Отбор = `ПолеКомпоновкиДанных("ТаблицаАнализа.ПонадНорму") > 0`, `ЦветФона = Новый Цвет(250,235,200)`.
⚠️ `ЦветаСтиля.*` эталонных ERP-рабочих мест (ВысокийПриоритетДокумента и т.п.) в **BuhBud НЕ гарантированы** → использовать `Новый Цвет`. Цвет — только кодом (НЕ `<TextColor>` XML → XDTO-ошибка сборки .epf).

## Друк — программный `ТабличныйДокумент` (БЕЗ MXL-макета)

`СформироватьПечать(ДанныеАнализа) Экспорт` строит `ТабличныйДокумент` в коде (нет MXL-файла → нет XDTO-риска при сборке). Форма: `Печать(Команда)` → `ПечатьНаСервере()` → `ОбъектОбработки.СформироватьПечать(ТаблицаАнализа)` → `ТабДок.Показать()`. Тело = текущий вид (`ТаблицаАнализа`, с отбором). Пусто → подсказка.

Структура: шапка (4 объединённые строки: «Аналіз залишків…», Період, Склади, Специфікація) + строка-заголовок 9 колонок + строки данных + подвал «Разом».

### Стиль печати (всё COM-проверено)
| Элемент | Оформление |
|---|---|
| Заголовок (строка 1) | `Шрифт(,14,Истина)` + `ГоризонтальноеПоложение.Центр`, объединить 1-9 |
| Параметры (2-4) | `Шрифт(,9)`, объединить 1-9 |
| Заголовок таблицы (6) | жирный + `ЦветФона = Новый Цвет(210,224,240)` (голубой) + центр |
| Строки данных | рамка; текст слева (кол.1-4), числа справа (5-9) |
| «Разом» | жирный + `ЦветФона = Новый Цвет(232,232,232)` (серый) |
| Колонки | `ШиринаКолонки` = 22/45/26/8/14×5 |
| Лист | `ТабДок.АвтоМасштаб = Истина` (вписать по ширине), `ОриентацияСтраницы.Ландшафт` |

### Грабли печати (см. [LESSONS.md](LESSONS.md))
- `ОбластьТабличногоДокумента.Граница` НЕ существует/не ставится → границы по сторонам `ГраницаСверху/Снизу/Слева/Справа = Новый Линия(ТипЛинииЯчейкиТабличногоДокумента.Сплошная)`.
- `Область(r,1,r,9).Текст = X` на НЕобъединённой многоячеечной области ДУБЛИРУЕТ X в каждую из 9 ячеек (в печати 9 копий) → шапку-на-всю-ширину сначала `Объединить()`, потом `.Текст`.
- `ШиринаКолонки` ставится на ЛЮБОЙ ячейке колонки; `ЦветФона`/`Шрифт`/`АвтоМасштаб` работают.

## uk-подписи

Интерфейс BuhBud — украинский. Подписи элементов/колонок должны быть `<v8:lang>uk</v8:lang>`. `<v8:lang>ru</v8:lang>` при uk-интерфейсе рендерится ПУСТО (если нет uk-сиблинга). form-compile эмитит `ru` → нужна пост-замена `ru→uk` (UTF-8 без BOM). См. [LESSONS.md](LESSONS.md).
