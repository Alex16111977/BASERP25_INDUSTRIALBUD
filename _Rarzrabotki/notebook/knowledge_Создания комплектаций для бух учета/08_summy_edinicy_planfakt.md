# 08. Фаза 6 — суми + одиниця + звіт план-факт

Адитивне розширення Фаз 1-5 (DONE 2026-06-25). **Математику розподілу кількості, норму-по-еталону, субконто, оркестратор — НЕ змінювали.**

## Рішення замовника (зафіксовані)

1. Суми розподіляються **пропорційно кількості** (гроші слідують за кількістю).
2. «% перевищення в грошах» = **ПонадНорму_сума / План_сума × 100**.
3. Звіт план-факт — **вбудована друкована форма** (другий програмний `ТабличныйДокумент`), НЕ окремий `.erf`.

## A. Суми

### A1. Запит залишків (`ПолучитьОстатки`)
Додано в SELECT і GROUP BY:
- `СУММА(Ост.СуммаОстаток) КАК СуммаОстатка` (ресурс **Сумма** регістру Хозрасчетный → поле залишку `СуммаОстаток`).
- `ВЫРАЗИТЬ(Ост.Субконто1 КАК Справочник.Номенклатура).БазоваяЕдиницаИзмерения КАК Единица` (тип **`Справочник.КлассификаторЕдиницИзмерения`**).
- `Единица` у `СГРУППИРОВАТЬ ПО` — функціонально визначена номенклатурою (вже в групуванні), тому НЕ змінює гранулярність/суми. `СуммаОстатка` — агрегат, у GROUP не йде.

### A2. Запит норм (`ПолучитьНормы`)
`+ СУММА(К.Сумма) КАК НормаСум`. Повертає `Соответствие ОбщееНазвание → Структура("Кол, Сум")` (було число). `ЗаполнитьАнализ` читає `ДанныеНормы.Кол` / `.Сум`.

### A3. Маніфест ТЧ `ТабличнаяЧастьОстатков` +6 колонок
`Единица` (`CatalogRef.КлассификаторЕдиницИзмерения`), `СуммаОстатка`, `НормаСумма`, `ВНормеСумма`, `ПонадНормуСумма`, `ЕкономіяСума` (decimal **15,2**). UUID `a2000000-…-000000000010…015`.

### A4. Пропорційний розподіл сум (`ЗаполнитьАнализ`)
```bsl
ЦенаСтроки      = ?(Стр.Остаток <> 0, Стр.СуммаОстатка / Стр.Остаток, 0);
ВНормеСумма     = Окр(ВНорме * ЦенаСтроки, 2);
ПонадНормуСумма = Стр.СуммаОстатка - ВНормеСумма;   // баланс по рядку гарантований відніманням
```
- `НормаСумма` — лише на першому рядку еталону (як `Норма`).
- **`ЕкономіяСума = max(0, НормаСумЭталона − Σ СуммаОстатка_еталона)`** — окремий акумулятор `СуммаОстаткаЭталона`, пишеться у `ЗафиксироватьЭкономиюЭталона` (сигнатуру розширено: +`НормаСумЭталона`, +`СуммаОстаткаЭталона`). Кількісну `Економія` (остаточний `ОстатокНормы`) НЕ чіпали.

### A5. Заповнення документів
`Комплектующие.Сумма` (реквізит існує — FINDINGS) = `ВНормеСумма` (ПоНормам) / `ПонадНормуСумма` (Додаткова). Протягнуто параметром `Сумма` через `НакопитьСтроку`/`РаспределитьВДокумент` (ТЗ +колонка `Сумма`) → `НС.Сумма = СтрД.Сумма`.

### A6. Друк «Аналіз залишків» — 13 колонок
+Одиниця, +Сума залишку, +Сума понад, +Економія (грн). Шапка `Область(r,1,r,13)`. Ширини `22,30,22,8,8,13,13,11,11,13,13,11,13`. Підсумки +Σ суми.

### A7. Форма
`ТаблицаАнализа` +6 колонок (вкл. Единица), +4 форм-реквізити-підсумки (`ИтогоСуммаОстатка`, `ИтогоВНормеСума`, `ИтогоПонадСума`, `ИтогоЕкономіяСума`); `ПрименитьОтборИИтоги` копіює нові колонки + сумує підсумки. id Form.xml 206-251 (нові колонки/поля), 260-262 (кнопка/команда план-факт).

## B. Одиниця (discovery-gated)

**Discovery (`explore_edinicy_mismatch.py`): 0 розбіжностей `Комплектующие.Единица <> Номенклатура.БазоваяЕдиницаИзмерения` по ВСІХ специфікаціях** → норми вже в базовій одиниці. Реалізовано **мінімум** (YAGNI, без перерахунку):
- `КількістьРозбіжностейОдиниць()` (запит `КОЛИЧЕСТВО(*)` по поточній специфікації) + `ПопередитиПроРозбіжністьОдиниць()` (виклик з `РассчитатьАнализ`): при >0 — `ЗаписьЖурналаРегистрации` (Попередження), норму взято без перерахунку.
- Перерахунок `К.Количество × Коэффициент` (з `Номенклатура.ЕдиницыИзмерения`) — НЕ реалізовано (немає розбіжностей; ескалація лише якщо discovery дасть >0).

## C. Звіт «План-факт по матеріалах» (вбудована друк-форма)

`СформироватьПечатьПланФакт(ДанныеАнализа) Экспорт` → 2-й `ТабличныйДокумент`; форма: кнопка «Друк план-факт» → `ПечатьПланФактНаСервере()` → `Показать()`. Джерело — `ТаблицаАнализа` (поточний вид).

**Групування ОбщееНазвание (еталон) → Номенклатура, однопрохідне** (дані вже впорядковані по еталону; порядок номенклатур — масив `НоменКлючи`, НЕ покладатися на ітерацію `Соответствие`). `РендеритьЭталонБлок` рендерить рядок-еталон (жирний) + дочірні номенклатури + копить загальний `Итоги` (Структура — по посиланню).

10 колонок: Назва/Одиниця/Кільк.план/Кільк.факт/%вик.кільк/Сума план/Сума факт/%вик.сума/Понад(грн)/%перевищ.
- Рівень еталон: план=Σ`Норма`/Σ`НормаСумма` (на 1-му рядку), факт=Σ`Остаток`/Σ`СуммаОстатка`, понад=Σ`ПонадНормуСумма`.
- Рівень номенклатура: лише факт + понад (план «—»).
- `ФорматПроцента(Факт, База)` — захист `/0` → «—». %вик(сума)=Факт/План, %перевищ=Понад/План.
- Загальний підсумок «Разом» + загальний %.
