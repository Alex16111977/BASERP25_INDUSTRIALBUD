## TL;DR за 60 секунд

Обработка-«рабочее место» для бухгалтера: **раскладывает остатки материалов «під списання» на документы `КомплектацияНоменклатуры`** по нормам спецификации.

1. **Источник остатков** — `РегистрБухгалтерии.Хозрасчетный.Остатки` по счетам **класса 2** (20/22/28 и их субсчета: 201, 221, 281, 2051, 205…). Субконто1=**Номенклатура**, Субконто3=**Склад** (единая позиция для всех счетов кл.2). Товарного накопит.регистра в BuhBud НЕТ.
2. **Норма** — `Справочник.СтруктураСебестоимости` (реквизит обработки `Спецификация`), ТЧ `Комплектующие`. **Кап** (для розподілу) — **Σ `Количество` по `ОбщееНазвание` (эталон)**, НЕ по номенклатурі. Мост карточка→эталон: `Номенклатура.ОбщееНазваниеНоменклатуры`. Фильтр по `Этап`. ⚠️ **Відображення** норми у звітах/формі — **ПО КАРТЦІ** (`НормаНоменкл`=Σ `Количество` картки; Фаза 11); еталон-рядок СКД = Σ карток. Суми норми введені **з ПДВ**, факт приведено ×1.2 (Фаза 12).
3. **Алгоритм**: норма считается на ОБЩИЙ остаток всех выбранных складов по эталону; распределение строк (Номенклатура×Склад×Счёт) **жадно по убыванию остатка**: `мин(Остаток, ОстатокНормы)`→`ВНорме`, излишек→`ПонадНорму`; без эталона/нормы → всё в `ПонадНорму`. **`Економія = max(0, Норма − Σ Остаток)`** на эталон (зеркало ПонадНорму).
4. **Результат** — заполняет ТЧ `Комплектующие` выбранных документов: `ВНорме`→документ «ПоНормам», `ПонадНорму`→«Додаткова». **Счёт компонента = счёт-источник остатка** (per-row `СчётУчётаБУ = СтрД.Счет`). 3 режима заполнения (обе / только в норме / только понад). Документы **не создаются и не проводятся** — пользователь заводит пустые `КомплектацияНоменклатуры` сам и выбирает в ТЧ `ДокументиКомплектації`.
5. **Запись пакета — в одной транзакции** (всё-или-ничего) + структура-результат `{Заповнено, Пропущено, БезЕдиниці, Помилки}` + журнал регистрации.

**Архитектура:** тонкая форма-диспетчер ↔ движок в `Ext/ObjectModule.bsl` (экспорт `РассчитатьАнализ` / `ЗаполнитьДокументыПоАнализу` / `СформироватьПечать` / `СведенияОВнешнейОбработке`); мост через `РеквизитФормыВЗначение("Объект")` / `ЗначениеВРеквизитФормы`.

## Связанные объекты конфигурации (BuhBud)

| Объект | Роль |
|---|---|
| `РегистрБухгалтерии.Хозрасчетный` | Источник остатков (Остатки по счетам кл.2). Измерения: Организация, Счет, Субконто1-3, Валюта, НалоговоеНазначение |
| `ПланСчетов.Хозрасчетный` | Счета 20/22/28 (группы) → 201/221/281/2051… (субсчета) |
| `Справочник.СтруктураСебестоимости` | Спецификация-эталон. ТЧ `Комплектующие` (ОбщееНазвание, Номенклатура, Количество, Этап, Единица, Сумма) |
| `Справочник.Номенклатура` | реквизит `ОбщееНазваниеНоменклатуры` (мост карточка→эталон), `БазоваяЕдиницаИзмерения` |
| `Справочник.ОбщиеНазванияНоменклатуры` | Эталон (норма считается по нему) |
| `Справочник.ЭтапыРабот` (синоним «Етапи робіт») | Фильтр норм по этапам |
| `Справочник.Склады` | Субконто3 счетов кл.2 |
| `Справочник.Организации` | Измерение Хозрасчетный (фильтр остатков) |
| `Документ.КомплектацияНоменклатуры` | Цель заполнения. ТЧ `Комплектующие` (Номенклатура, ЕдиницаИзмерения, Количество, **СчетУчетаБУ**, Сумма, Коэффициент, ДоляСтоимости). **`Сумма` — собівартість БЕЗ ПДВ** (÷1.2 при заповненні, Фаза 12), як на рахунках |
