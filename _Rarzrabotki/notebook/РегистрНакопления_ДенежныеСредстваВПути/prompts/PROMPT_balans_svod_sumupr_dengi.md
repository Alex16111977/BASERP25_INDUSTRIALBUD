# Промт — Свод_ДенежныеСредства: правка ресурса Сумма* → СуммаУпр*

## TL;DR

В функции `Свод_ДенежныеСредства(СтруктураШапки, Отказ)` файла
`Documents/А_ФинРез_Баланс/Ext/ObjectModule.bsl` (стр. 621-887) — заменить
**`СуммаНачальныйОстаток` / `СуммаКонечныйОстаток` → `СуммаУпрНачальныйОстаток` / `СуммаУпрКонечныйОстаток`**
во всех 4 ветках UNION ALL.

**Бухгалтерский баг:** ПАП хранит суммы в **управленческой валюте (UAH)**, а регистры
РНДС.{Безнал,Налич,Подотч,ВПути} имеют 3 ресурса: `Сумма` (валюта операции — USD/EUR/UAH),
`СуммаУпр` (управленческая UAH), `СуммаРегл` (регламентированная UAH). Текущий код берёт
**`Сумма`** (валюта операции) → для USD-операций сравнение с ПАП.UAH даёт огромные плуги
курсовой разницы.

**Эмпирическое доказательство** (ПКО N0000023541 от 03.12.2025):
| Поле | Значение | Единица |
|---|---:|---|
| РН.Налич.**Сумма** | 70 000,00 | USD |
| РН.Налич.**СуммаУпр** | **2 953 496,00** | UAH |
| **ПАП.Сумма** | **2 953 496,00** | UAH ← пишет упр |

`ПАП.Сумма == РН.Налич.СуммаУпр` (не `РН.Налич.Сумма`).

## Структура правок (8 точечных замен)

### Ветка 1 — ДенежныеСредстваБезналичные (стр. 693-694)

```diff
- |	СУММА(Б.СуммаНачальныйОстаток) КАК СуммаНачальныйОстаток,
- |	СУММА(Б.СуммаКонечныйОстаток) КАК СуммаКонечныйОстаток
+ |	СУММА(Б.СуммаУпрНачальныйОстаток) КАК СуммаНачальныйОстаток,
+ |	СУММА(Б.СуммаУпрКонечныйОстаток) КАК СуммаКонечныйОстаток
```

### Ветка 2 — ДенежныеСредстваНаличные (стр. 712-713)

```diff
- |	СУММА(Н.СуммаКонечныйОстаток)
+ |	СУММА(Н.СуммаУпрНачальныйОстаток),
+ |	СУММА(Н.СуммаУпрКонечныйОстаток)
```

### Ветка 3 — ДенежныеСредстваУПодотчетныхЛиц (стр. 730-731)

```diff
- |	СУММА(П.СуммаНачальныйОстаток),
- |	СУММА(П.СуммаКонечныйОстаток)
+ |	СУММА(П.СуммаУпрНачальныйОстаток),
+ |	СУММА(П.СуммаУпрКонечныйОстаток)
```

### Ветка 4 — ДенежныеСредстваВПути (стр. 748-749)

```diff
- |	СУММА(ВП.СуммаНачальныйОстаток),
- |	СУММА(ВП.СуммаКонечныйОстаток)
+ |	СУММА(ВП.СуммаУпрНачальныйОстаток),
+ |	СУММА(ВП.СуммаУпрКонечныйОстаток)
```

⚠ **НИЧЕГО ДРУГОГО не менять.** Алиасы колонок `КАК СуммаНачальныйОстаток` оставить как есть
(это имена колонок результирующей ВТ, которые используются дальше в `втДССт` и финальном SELECT).

## Уникальная сложность

Это **исправление бухгалтерской ошибки** в коде написанном с предположением что все операции UAH.
Для UAH-операций Сумма==СуммаУпр, и формула работала. Для валютных (USD-кассы, USD-счета) — баг.
По диагностике за декабрь 2025 — 17 валютных регистраторов на 829 433 UAH плугов.
