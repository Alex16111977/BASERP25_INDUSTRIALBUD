# Промт — Доработка Свод_ДенежныеСредства (4-я ветка ДенежныеСредстваВПути)

## TL;DR

Добавить **4-ю ветку UNION ALL** в `втДС` функции `Свод_ДенежныеСредства(СтруктураШапки, Отказ)` файла
`Documents/А_ФинРез_Баланс/Ext/ObjectModule.bsl` (стр. 621-845). Цель — закрыть
**архитектурный БАГ** где статья «Денежные средства в пути» отсутствует в `втДС` (источник РСКПС-агрегатов),
но присутствует в `втПАП` → автоматически даёт `Расхождение=Истина` (~70-170 М UAH суммарно за дек25–апр26
по выгрузке пользователя).

**Симметричный паттерн** — копия ветки `ДенежныеСредстваНаличные` (стр. 696-710), но с регистром
`ДенежныеСредстваВПути` и группировкой по `(Орг, Подр, Получатель/Отправитель)`.

⚠ Зависимость: измерение `Подразделение` в `РН.ДенежныеСредстваВПути` уже добавлено пользователем
(2026-05-24), и **5 типов документов-источников** доработаны и провалидированы пилотами
(ПКО, РКО, СписаниеБезнал, ПостБезнал, РасчетКурсовых — все PASS).

## Антипаттерны

- ❌ **НЕ использовать `ВЫРАЗИТЬ(ВП.Получатель КАК Справочник.БанковскиеСчета)`** — потеряет строки с Кассой/ФизЛицом
- ❌ **НЕ группировать по `ВидПереводаДенежныхСредств`** — это усложнит расшифровку и нарушит симметрию с другими ветками
- ❌ **НЕ править `МассивИст`** — статья «в пути» там уже есть, добавление 4-й ветки в `втДС` симметризует
- ❌ **НЕ использовать подзапрос `(ВЫБРАТЬ ...)` в SELECT 1С** — НЕ работает (урок ПостБезнал)
- ❌ **НЕ пропускать Python COM pre-test** — Rule #-1 обязательно для запросов
- ⚠ Учитывать что **исторические записи РНДС.ВПути с пустым Подр** дадут пустую группу (Подразделение=ПустаяСсылка) — это by-design до перепроведения источников

## Уникальная сложность

Эта правка **закрывает архитектурный БАГ** существовавший с момента создания
`Свод_ДенежныеСредства` — автор формулы не включил `РН.ДенежныеСредстваВПути` в `втДС`, хотя
включил его статью в `втПАП.МассивИст`. Симптом проявлялся как ~100 строк
`Расхождение=Истина` за дек25–апр26 (по выгрузке пользователя).

После этой правки + перепроведения источников через `Перепровести_ДенежныеСредстваВПути.epf` —
**все 4 источника денежных средств работают симметрично** (Безнал/Налич/Подотч/В пути) и баланс
сходится per (Орг, Подр).
