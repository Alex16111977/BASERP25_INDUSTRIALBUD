# Промт — РасчетКурсовыхРазниц Безнал + Налич: заполнение Подразделение

## TL;DR

В функциях `РасчетКурсовыхРазниц/ManagerModule.bsl` **не заполняется Подразделение** при формировании движений курсовых разниц в `РН.ДенежныеСредстваБезналичные` и `РН.ДенежныеСредстваНаличные`. Из-за этого в Сводном балансе возникают плуги «Касса/Подгорцы ↔ (пусто) ±8 735,60».

**Подотч уже работает корректно** — там `Подразделение` использовалось с момента написания (стр. 1227, 4525, 4548, 4587).

## Параметры

| Параметр | Значение |
|---|---|
| Файл | `Documents/РасчетКурсовыхРазниц/Ext/ManagerModule.bsl` |
| Функции для правки | 4 (Безнал × 2 + Налич × 2) |
| Тестовые документы | 000Ц-000044 (декабрь 2025, Налич) + 000Ц-000007 (январь 2026, Безнал) |

## Архитектура правок

### Паттерн A — ТекстЗапросаВтТаблица* (read существующих движений переоценки)

| Функция | Стр | Замена |
|---|---|---|
| `…Безналичные` | 1136 | `БанковскийСчет.Подразделение` → `ЕСТЬNULL(ДенежныеСредства.Подразделение, ДенежныеСредства.БанковскийСчет.Подразделение)` |
| `…Наличные` | 1167 | `Касса.Подразделение` → `ЕСТЬNULL(ДенежныеСредства.Подразделение, ДенежныеСредства.Касса.Подразделение)` |

### Паттерн B — ТекстЗапросаКурсовыеРазницы* (формирование новых движений)

**Для Безнал** (`ТекстЗапросаКурсовыеРазницыДенежныеСредстваБезналичные` стр. 4012) — добавить колонку **Подразделение** во все 4 ВТ:

1. `СчетаЗаДень` (DISTINCT) — добавить `ОборотыЗаДень.Подразделение КАК Подразделение`
2. `втОстаткиБезналичных` (2 SELECT через UNION ALL) — добавить `ОстаткиНаДень.Подразделение КАК Подразделение`
3. ЛЕВОЕ СОЕДИНЕНИЕ — добавить условие `И ОстаткиНаДень.Подразделение = СчетаЗаДень.Подразделение`
4. `ТаблицаБезналичныхДС` (2 SELECT через UNION ALL) — добавить `Остатки.Подразделение КАК Подразделение`
5. Финальная ВТ `КурсовыеРазницыДенежныеСредстваБезналичные` — добавить `ТаблицаБезналичныхДС.Подразделение` в SELECT + GROUP BY

**Для Налич** (`…Наличные` стр. 4178) — аналогично (4 ВТ × паттерн B).

### Почему именно ЕСТЬNULL с fallback

- **Приоритет 1:** `ДенежныеСредства.Подразделение` — новое измерение регистра (заполняется при перепроведении источников через ПКО/РКО/Спис/Пост — все 5 пилотов PASS)
- **Fallback:** `БС.Подразделение` / `Касса.Подразделение` — из карточки (старая логика; работает если карточка заполнена)
- **Результат:** если ни первое ни второе не заполнено → пустая ссылка (текущее поведение)

## Антипаттерны

- ❌ Не использовать `replace_all` — функции большие, есть схожие участки в Безнал/Налич/ВПути
- ❌ Не путать ВТ `СчетаЗаДень` (Безнал) с `КассыЗаДень` (Налич) — разные имена ВТ
- ❌ Не пропустить ЛЕВОЕ СОЕДИНЕНИЕ — без обновления условий JOIN потеряются строки
- ❌ Не пропустить GROUP BY в финальной ВТ — без него агрегат сломается
- ❌ Урок ПостБезнал: НЕ подзапросы `(ВЫБРАТЬ …)` в SELECT — только ВТ-колонки
- ❌ Подотч (стр. 1217, 4515) НЕ трогать — там уже Подразделение работает
