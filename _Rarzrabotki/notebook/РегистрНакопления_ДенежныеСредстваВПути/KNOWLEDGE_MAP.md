## Ключевые принципы для доработки (по итогам 4 PASS пилотов)

1. **`feedback_no_typical_register_changes`** — НО! здесь explicit consent (пользователь сам добавил измерение в Конфигураторе).
2. **Подразделение — ИЗ ШАПКИ документа** (`ДанныеДокумента.Подразделение`). Не из `Касса.Подразделение` / `БанковскийСчет.Подразделение`. Это согласовано с типовым РНДС.Наличные.
3. **РасчетКурсовых** — особый: шапка БЕЗ Подразделения, тянуть **из самого регистра** (новое измерение, после миграции записей других пилотов).
4. **Подзапросы `(ВЫБРАТЬ ...)` в SELECT 1С НЕ работают** (урок ПостБезнал блоки 5-6). Использовать колонки ВТ.
5. **Edit с `replace_all: false`** + уникальный контекст по WHERE ХозОп — 19 блоков с похожей структурой.
6. **Конфигуратор закрыт** перед `db-load-xml` (даёт ошибку блокировки).
7. **Safety-check РСКПС/РСППС** в pilot_03 — для СписаниеБезнал/ПостБезнал с ХозОп типа Оплата поставщику COM-репост ОПАСЕН (только UI).
8. **Структура SELECT отличается** между документами:
   - ПКО/РКО/ПостБезнал — есть `&ХозяйственнаяОперация` → вставлять перед ней
   - СписаниеБезнал — нет `&ХозяйственнаяОперация` → вставлять перед `&СтатьяДвижения`

См. подробно: [`LESSONS.md`](LESSONS.md).
