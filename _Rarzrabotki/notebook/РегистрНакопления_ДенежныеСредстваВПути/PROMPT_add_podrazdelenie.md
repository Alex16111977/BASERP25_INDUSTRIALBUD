# Промт для новой ИИ-сессии — добавить измерение «Подразделение» в РН.ДенежныеСредстваВПути

## TL;DR (контекст за 30 секунд)

`РегистрНакопления.ДенежныеСредстваВПути` НЕ имеет измерения `Подразделение`. Это даёт ~170 М UAH плугов `Расхождение=Истина` в `А_ОтчётБаланс_Свод` по статье «Денежные средства в пути» (за период дек 2025 — апр 2026, 56 групп).

Задача: **добавить измерение `Подразделение`** в регистр + доработать процедуры проведения **5 документов** (минимум, для текущей базы) или **17 WRITE-точек в 16 документах** (для типовой полноты).

После доработки `Свод_ДенежныеСредства` сможет агрегировать «в пути» per (Орг, Подр) — плуги исчезнут.

```bsl
// Возвращает Подразделение для движения "Денежные средства в пути".
// Логика: Подразделение Отправителя (тот, кто инициировал транзит).
// Если Отправитель не определён (НЕОПРЕДЕЛЕНО) — берём Подразделение Получателя.
Функция ПолучитьПодразделение(Отправитель, Получатель) Экспорт
    Если Отправитель <> НЕОПРЕДЕЛЕНО И ЗначениеЗаполнено(Отправитель) Тогда
        Если ТипЗнч(Отправитель) = Тип("СправочникСсылка.БанковскиеСчетаОрганизаций") Тогда
            Возврат Отправитель.Подразделение;
        ИначеЕсли ТипЗнч(Отправитель) = Тип("СправочникСсылка.Кассы") Тогда
            Возврат Отправитель.Подразделение;
        ИначеЕсли ТипЗнч(Отправитель) = Тип("СправочникСсылка.КассыККМ") Тогда
            Возврат Отправитель.Подразделение;
        КонецЕсли;
    КонецЕсли;
    Если Получатель <> НЕОПРЕДЕЛЕНО И ЗначениеЗаполнено(Получатель) Тогда
        Если ТипЗнч(Получатель) = Тип("СправочникСсылка.БанковскиеСчетаОрганизаций") Тогда
            Возврат Получатель.Подразделение;
        ИначеЕсли ТипЗнч(Получатель) = Тип("СправочникСсылка.Кассы") Тогда
            Возврат Получатель.Подразделение;
        ИначеЕсли ТипЗнч(Получатель) = Тип("СправочникСсылка.КассыККМ") Тогда
            Возврат Получатель.Подразделение;
        КонецЕсли;
    КонецЕсли;
    Возврат Справочники.СтруктураПредприятия.ПустаяСсылка();
КонецФункции
```
