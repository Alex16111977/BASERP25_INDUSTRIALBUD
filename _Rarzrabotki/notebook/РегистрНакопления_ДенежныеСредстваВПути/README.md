# knowledge: РегистрНакопления.ДенежныеСредстваВПути

> **Назначение:** база знаний по типовому регистру `РегистрНакопления.ДенежныеСредстваВПути` (BAS ERP 2.5)
> для подготовки **доработки**: добавление измерения `Подразделение` в регистр (нужно для корректного
> свода управленческого баланса — статья «Денежные средства в пути»).

## 🎯 Цель доработки

В формуле `Свод_ДенежныеСредства` (`Documents/А_ФинРез_Баланс/Ext/ObjectModule.bsl` стр. 621-845) для статей
Безналичные/Наличные/Подотчётные есть парные источники в РНДС с измерением `Подразделение`. Для **«Денежные средства в пути»** парного источника **нет** — потому что в регистре `ДенежныеСредстваВПути` НЕТ измерения Подразделение.

Из-за этого:
- ПАП пишет «в пути» per-Подразделение (через документ-источник)
- РНДС.ВПути хранит сумму без Подразделения
- `Свод_` генерирует автоматические плуги `Расхождение=Истина` для всех записей по этой статье
- За дек 2025 — апр 2026: ~56 групп ΣABS ≈ 170 М UAH плугов

Решение: добавить **`Подразделение`** как измерение в регистр + доработать процедуры проведения **5 фактических документов** (на текущей базе) или **16 теоретических** (для типовой полноты).
