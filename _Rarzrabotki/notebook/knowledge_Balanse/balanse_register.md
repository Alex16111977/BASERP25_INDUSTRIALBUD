- `РегНакопл.ПрочиеАктивыПассивы` (ПАП) — **первинний** регістр балансу. Містить підсумок «Расходы тек.пер.»/«Доходы тек.пер.» per (Орг, Подр).
- `РегНакопл.ПрочиеРасходы` (Balance) — **розшифровує** первинний регістр для статті «Расходы текущего периода». Вимір `СтатьяРасходов` (ПВХ.СтатьиРасходов) — реальна стаття затрат.
- `РегНакопл.ПрочиеДоходы` (Balance) — **розшифровує** для статті «Доходы текущего периода». Вимір `СтатьяДоходов` (ПВХ.СтатьиДоходов).

**Правило відбору (бухгалтерське):**

Із `.ОстаткиИОбороты(&НачМес, &КонМес)` розшифровуючого регістра пишемо в свод **лише** рядки де:
- `НачальныйОстаток ≠ 0` (стаття переходить з минулого місяця), **АБО**
- `КонечныйОстаток ≠ 0` (стаття не закрита на кінець місяця)

Якщо **І НО=0 І КО=0** (навіть якщо всередині місяця Прихід=Расход) — рядок не пишемо: статті закрилися всередині періоду і в балансі їх немає.

**Заповнення вимірів у РС для цих статей:**

| Вимір | Значення |
|---|---|
| `Статья` | «Расходы текущего периода» (Актив) або «Доходы текущего периода» (Пассив) |
| `СтатьяДоходыРасходы` | ПрочиеРасходы.СтатьяРасходов або ПрочиеДоходы.СтатьяДоходов |
| `Аналитика1` | `ПРЕДСТАВЛЕНИЕ(СтатьяДоходыРасходы)` |
| `Source` | `ПустаяСсылка` (НЕ розрізаємо по Источник — як штатний УпрБаланс) |
| `Подразделение` | з розшифровуючого регістра |
| `СуммаНачальныйОстаток` | НО з регістра-розшифровки |
| `СуммаКонечныйОстаток` | КО з регістра-розшифровки |
| `СуммаПриход`/`СуммаРасход` | 0 (канон §2 — тільки залишки) |
| `Расхождение` | ЛОЖЬ для деталей; ИСТИНА для плугів |

**Інваріант (Σ свод == ПАП):**
- `Σ свод.КО per (Орг,Подр,Статья=Расх.тек.пер.)` = `ПАП.ОстаткиИОбороты.КО per same` до 0.01
- `Σ свод.НО per (Орг,Подр,Статья=Расх.тек.пер.)` = `ПАП.ОстаткиИОбороты.НО per same` до 0.01
- Плуг (Расхождение=Истина, СтатьяДоходыРасходы=NULL, Аналитика1="") компенсує різницю — для випадків де ПАП має руху не покриті регістром-розшифровкою (наприклад Амортизація ОС пише в ПАП з Источник=ПустаяСсылка, але не в РегНакопл.ПрочиеРасходы)

**Виключення з `Свод_ПрочиеАктивыПассивы_Прямой`:** ці 2 статті тепер обробляються ТІЛЬКИ `Свод_ПрочиеРасходыДоходы` ветви A/B (через спеціалізовані регістри). У `Свод_ПрочиеАктивыПассивы_Прямой` додано фільтр `Т.Статья <> &РасхТекПер И Т.Статья <> &ДохТекПер`.
