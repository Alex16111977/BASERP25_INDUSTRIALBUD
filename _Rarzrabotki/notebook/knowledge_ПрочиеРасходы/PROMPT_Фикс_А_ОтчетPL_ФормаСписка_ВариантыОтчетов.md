## 1. Симптом и корень

При открытии формы списка `Документ.А_ОтчетPL` падает:
```
Не удалось перейти по ссылке "e1cib/list/Документ.А_ОтчетPL":
{ОбщийМодуль.ВариантыОтчетов.Модуль(7123)}: Метод объекта не обнаружен (ДобавитьКомандыОтчетов)
  СведенияОбОбъекте.Менеджер.ДобавитьКомандыОтчетов(Команды, НастройкиФормы);
...
{Документ.А_ОтчетPL.Форма.ФормаСписка.Форма(16)}: ПодключаемыеКоманды.ПриСозданииНаСервере(ЭтотОбъект);
```

**Причина (диагностировано):**
- `Документ.А_ОтчетPL` **зарегистрирован** в `ВариантыОтчетовПереопределяемый.ОпределитьОбъектыСКомандамиОтчетов`
  (`Объекты.Добавить(Метаданные.Документы.А_ОтчетPL)`, ~стр. 443) — рядом с `А_ФинРез_PL`, `А_ФинРез_DDS`,
  `А_ОтражениеЗПпоКазне` и др.
- НО у `Документ.А_ОтчетPL` **НЕТ модуля менеджера** (есть только `Ext/ObjectModule.bsl` + 2 модуля форм).
- БСП (форма списка → `ПодключаемыеКоманды.ПриСозданииНаСервере` → `ВариантыОтчетов.ПриОпределенииКомандПодключенныхКОбъекту`)
  вызывает `Менеджер.ДобавитьКомандыОтчетов(...)` → метода нет → исключение, форма не открывается.

**НЕ трогать** (корректны): модуль формы `ФормаСписка` (штатный БСП-бойлерплейт со строкой 16
`ПодключаемыеКоманды.ПриСозданииНаСервере(ЭтотОбъект)`) и регистрацию в `ОпределитьОбъектыСКомандамиОтчетов`.

## 2. Правка (Fix A) — создать модуль менеджера документа

Создать `Documents/А_ОтчетPL/Ext/ManagerModule.bsl` **1:1 как у sibling `А_ФинРез_PL`**
(`Documents/А_ФинРез_PL/Ext/ManagerModule.bsl` — эталон):

```bsl
#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

#Область ПрограммныйИнтерфейс

Процедура ДобавитьКомандыОтчетов(КомандыОтчетов, Параметры) Экспорт

	ВариантыОтчетовУТПереопределяемый.ДобавитьКомандуСтруктураПодчиненности(КомандыОтчетов);

КонецПроцедуры

#КонецОбласти

#КонецЕсли
```

- Кодировка файла — **UTF-8 с BOM** (как у других .bsl).
- Модуль менеджера документа подключается **по факту наличия файла** `Ext/ManagerModule.bsl` —
  правка `Documents/А_ОтчетPL.xml` НЕ требуется (в отличие от форм). Если Конфигуратор/загрузка попросит —
  сверить с тем, как оформлен `А_ФинРез_PL` (там XML тоже без спец-объявления модуля).
- Результат: метод `ДобавитьКомандыОтчетов` появляется → БСП успешно добавляет штатную команду
  «Связанные документы / структура подчинённости» (как у остальных А_-документов) → форма списка открывается.
