## 1. Правило Rule #-1 (обязательно)

**Любой запрос 1С для .bsl сначала прогнать через Python COM**, и только после успеха — переносить в BSL.
Подключение к BaseERP:
```python
import win32com.client, sys
if sys.stdout.encoding != 'utf-8':
    sys.stdout.reconfigure(encoding='utf-8')
v8 = win32com.client.Dispatch("V83.COMConnector")
erp = v8.Connect('Srvr="localhost";Ref="BaseERP";Usr="Администратор";Pwd="24043"')
```
Запуск скриптов: писать .py в `_Rarzrabotki/Python/test/`, запускать `python <путь>` (НЕ inline — Cyrillic
в `python -c` портится; и runner исполняет shell, не Python).

> COM-ловушка: `Метаданные…Регистраторы` не резолвится через COM (`AttributeError`). Список регистраторов —
> grep `AccumulationRegister.ПрочиеРасходы<` по `Documents/*.xml` или Конфигуратор.

## 2. Эталон Σ (pre-test ДО правок)

Снять **до** любых изменений и сохранить как baseline. Период границами — серверно (НачалоПериода/КонецПериода),
чтобы не словить tz-сдвиг naive datetime (memory `feedback_balans_etalon_period_serverside`).

```python
q = erp.NewObject("Запрос")
q.Text = """
ВЫБРАТЬ
    Об.Организация КАК Организация,
    СУММА(Об.СуммаПриход) КАК СуммаПриход,
    СУММА(Об.СуммаУпрПриход) КАК СуммаУпрПриход,
    СУММА(Об.СуммаРеглПриход) КАК СуммаРеглПриход
ИЗ
    РегистрНакопления.ПрочиеРасходы.Обороты(&Нач, &Кон, Регистратор, ) КАК Об
СГРУППИРОВАТЬ ПО
    Об.Организация
"""
q.SetParameter("Нач", дата_нач)   # ДатаВремя начала месяца
q.SetParameter("Кон", дата_кон)   # конец месяца (КонецМесяца серверно)
r = q.Execute().Выгрузить()
# Сохранить r как эталон: {Организация: (СуммаПриход, СуммаУпрПриход, СуммаРеглПриход)}
```

> Имена ресурсов в `.Обороты`: `<Ресурс>Приход` / `<Ресурс>Расход` / `<Ресурс>Оборот`. Для P&L — `СуммаПриход`
> (НЕ `СуммаОборот`), см. [architecture_invariants.md §3](architecture_invariants.md).
