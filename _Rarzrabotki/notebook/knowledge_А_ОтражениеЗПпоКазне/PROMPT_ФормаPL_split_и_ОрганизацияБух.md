## 1. Задача в одном абзаце

Для физлиц, у которых `НачисленияУпр.Сумма ≠ 0`, переделать формирование ТЧ `НачисленнаяЗарплатаИВзносыПоФизлицам` так, чтобы: **(A)** строки-начисления («Зарплата управленческого персонала», `СпособОтражения.А_ЭтоУдержание = Ложь`) делились на **Ф1 = `НачисленияБух.Сумма − НалогиБухгалтерия.СуммаНДФЛ`** (официальный NET «на руки») и **Ф2 = `НачисленияУпр.Сумма − Ф1`** (управленческий остаток), причём `Ф1 + Ф2 = НачисленияУпр.Сумма` (инвариант), а строки-удержания («Удержание с админ зарплату», `А_ЭтоУдержание = Истина`) — **всегда целиком Форма1**; **(B)** заполнять новый реквизит `ОрганизацияБухгалтерия` (для Ф1-строк — из `РаспределениеКазна.Организация`, для Ф2 — пусто); **(C)** перевести документ `ПередачаНачисленийМеждуПодразделениями` на единый источник — читать NET / ОрганизациюБухгалтерия / подразделение прямо из `НачисленнаяЗарплатаИВзносыПоФизлицам` нашего документа (а не из дочернего ОЗФУ + РаспределениеКазна).

## 2. Проблема (что не так сейчас) — на примере Постернак Андрій Володимирович

Текущая разметка `_ОтрЗП_РазметитьФормаPL` делит **каждую** строку (и NET, и удержание) единым коэффициентом `коэф = GROSS / total`. Это даёт бухгалтерски неверную картину:

| N | Форма | Способ | Сумма (СЕЙЧАС, неверно) |
|---|---|---|---:|
| 308 | Ф1 | Зарплата управл. | 34 800,54 |
| 309 | Ф1 | Удержание | 1 450,80 |
| 911 | Ф2 | Зарплата управл. | 165 199,46 |
| 912 | **Ф2** | **Удержание** | **6 887,01** ← удержание не может быть Ф2! |

Проблемы:
1. **Удержание (налоги) попало в Ф2** — налоги всегда официальные (Ф1).
2. **Ф1 «Зарплата управл» = 34 800,54** не равна официальной зарплате на руки (27 913,53) — смешаны базы (NET управленческий 200 000 и налог от официального GROSS 36 251,34).

## 3. Бухгалтерская модель (правильное поведение)

### 3.1 Главный инвариант (только для ФЛ с `НачисленияУпр.Сумма ≠ 0`)
```
Σ НачисленнаяЗарплата.Сумма (по строкам где СпособОтражения.А_ЭтоУдержание = Ложь)
    = Σ НачисленияУпр.Сумма (по ФЛ)
```
То есть управленческое начисление сохраняется ЦЕЛИКОМ, меняется только раскладка по формам.

### 3.2 Разбивка строк-начислений («Зарплата управленческого персонала»)
```
Ф1 (официальная «на руки») = Σ НачисленияБух.Сумма(ФЛ) − Σ НалогиБухгалтерия.СуммаНДФЛ(ФЛ)
Ф2 (управленческий остаток) = Σ НачисленияУпр.Сумма(ФЛ) − Ф1
```
- `НачисленияБух.Сумма` — официальный GROSS (zup_1, счёт 661).
- `НалогиБухгалтерия.СуммаНДФЛ` — НДФЛ + Военный сбор (ТипНалога НДФЛ или ВоенныйСбор).
- **Защита от минуса:** если `Ф1 > НачисленияУпр.Сумма` (официальный NET больше управленческого) → `Ф1 = НачисленияУпр.Сумма`, `Ф2 = 0`. Если `Ф1 < 0` (НДФЛ > GROSS, аномалия) → `Ф1 = 0`, `Ф2 = НачисленияУпр.Сумма`.

### 3.3 Удержание («Удержание с админ зарплату», `А_ЭтоУдержание = Истина`)
- **Всегда Форма1, одной (или по подразделениям) строкой.** Сумма = `Σ НалогиБухгалтерия.СуммаНДФЛ(ФЛ)`. В инвариант §3.1 НЕ входит.

### 3.4 ЕСВ («Начисления на админ зарплату», `А_ЭтоУдержание = Ложь`, поле `ВзносыВсего`)
- Остаётся Форма1, без изменений (поле `Сумма = 0`, поэтому в инвариант §3.1 не влияет).

### 3.5 Распределение по подразделениям (когда у ФЛ их несколько)
- **Ф1-сумма** (§3.2) распределяется по коэффициентам **Форма1-строк начислений** `РаспределениеКазна` (`ФормаPL = Форма1`, способ с `А_ЭтоУдержание = Ложь`).
- **Ф2-сумма** распределяется в два прохода:
  - **Премии** — `РаспределениеКазна` Форма2-строки, у которых `ДокРаспределениеЗП` это `Документ.РаспределениеФ2` с `А_Начисление = Истина`: берутся **как есть** (фактические суммы по их подразделениям).
  - **Остаток** `= Ф2 − Σ(премий)` — распределяется по коэффициентам **остальных** Форма2-строк (`РаспределениеФ2` с `А_Начисление = Ложь`); «довесок» округления оседает здесь.
- **Удержание** распределяется по подразделениям пропорционально `НачисленныйНДФЛ` (Ф1) / или Форма1-строк удержания `РаспределениеКазна`.

### 3.6 Реквизит `ОрганизацияБухгалтерия`
- **Ф1-строки** («Зарплата управл» и «Удержание»): `= РаспределениеКазна.Организация` соответствующей Форма1-строки (юр.лицо, где официально начисляли — напр. «ІНДЕПТ СТІЛ ТОВ»).
- **Ф2-строки**: **пусто** (`Справочники.Организации.ПустаяСсылка()`) — управленческая часть в перенос не идёт.
- Поле `Организация` (существующее) во ВСЕХ строках остаётся = организация документа (не трогать — оно копируется в дочерний ОЗФУ и нужно типовому проведению).

## 5. Часть A — переделка разметки (Op2 + `_ОтрЗП_РазметитьФормаPL`)

**Архитектура:** новый алгоритм применяется ТОЛЬКО к ФЛ с `НачисленияУпр.Сумма ≠ 0`. Для остальных ФЛ (которые попадают только через Op 2b из `РаспределениеКазна`) — оставить текущую коэффициентную разметку без изменений.

Рекомендуемая реализация (системно, без заплаток):
1. В `_ОтрЗП_ЗаполнитьНачисленияЗП` (Op 2a, ветка ФЛ из `НачисленияУпр`): вместо одной NET-суммы строить строки сразу с правильной формой:
   - вычислить `Ф1 = GROSS_бух − СуммаНДФЛ` (с защитой §3.2), `Ф2 = NET − Ф1`;
   - строки «Зарплата управл» **Ф1** — распределить `Ф1` по коэф. Форма1-начислений `РаспределениеКазна`, проставить `ОрганизацияБухгалтерия` из `РаспределениеКазна.Организация`;
   - строки «Зарплата управл» **Ф2** — премии как есть + остаток по коэф. не-премий (§3.5), `ОрганизацияБухгалтерия` пусто;
   - строки «Удержание» — `СуммаНДФЛ`, **Ф1**, по подразделениям, `ОрганизацияБухгалтерия` из Казны.
2. `_ОтрЗП_РазметитьФормаPL` для NET-ФЛ больше не дробит коэффициентом (строки уже размечены); оставить её ТОЛЬКО для не-NET строк (Op 2b / прочие) и для `НачисленныйНДФЛ` (весь Ф1).
3. Хелперы `_ОтрЗП_РаспределитьNETПоПодр` / `_ОтрЗП_ЗаполнитьСтрокуНачисленияЗП_ПоФизЛицу` расширить параметром `ОрганизацияБухгалтерия` и `ФормаPL`.

**Справочные данные** (`_ОтрЗП_ПодготовитьСправочныеДанные`) дополнить мапами per-ФЛ: `GROSSбухПоФизЛицу` (Σ `НачисленияБух.Сумма`) и коэффициенты Форма1/Форма2-распределения из `РаспределениеКазна` (подразделение → доля + организация + признак премии).

## 7. Часть C — переделка `ПередачаНачисленийМеждуПодразделениями` на единый источник

**Сейчас:** `_ПНМП_ПостроитьВеса` берёт веса/ОргБух/целевое из `РаспределениеКазна`; `_ПНМП_ЗаполнитьНачисления/Налоги/Удержания` берут суммы из **дочернего ОЗФУ** (`ОтражениеЗарплатыВФинансовомУчете`). Двойной источник.

**Станет:** всё из `А_ОтражениеЗПпоКазне.НачисленнаяЗарплатаИВзносыПоФизлицам` нашего документа (Ф1-строки):
- **`Начисления`** ← строки «Зарплата управл» **Ф1** (`А_ЭтоУдержание = Ложь`): `Сумма` берётся **напрямую** (это уже take-home NET, без вычитания НДФЛ!), `ИсходноеПодразделение = ПодразделениеПредприятия`, `ОрганизацияБухгалтерия = ОрганизацияБухгалтерия`, `ЦелевоеПодразделение = ОрганизацияБухгалтерия.А_ПодразделениеЗарплатаБух`.
- **`Налоги`** ← НДФЛ/ВС из ТЧ `НачисленныйНДФЛ` (Ф1, по типам) + ЕСВ из строк `НачисленнаяЗарплата` Ф1 с `Налог ПОДОБНО "ЕСВ%"` (`ВзносыВсего`). ОргБух/исходное/целевое — аналогично.
  > ⚠️ Строки «Удержание с админ зарплату» в `НачисленнаяЗарплата` в `Налоги` **НЕ брать** — это управленческое отражение тех же НДФЛ+ВС, иначе задвоение. Налоги — только из `НачисленныйНДФЛ`.
- **`Удержания`** ← ТЧ `УдержанияБухгалтерия` (Ф1) — прочие удержания (если есть).
- **Веса больше не нужны:** целевое подразделение определяется per-строка через `ОрганизацияБухгалтерия.А_ПодразделениеЗарплатаБух`. Перенос: `ИсходноеПодразделение → ЦелевоеПодразделение`. Если `ОрганизацияБухгалтерия` пусто или у неё нет `А_ПодразделениеЗарплатаБух` — строка в перенос не идёт (остаётся на исходном).
- `_ПНМП_ПостроитьВеса` либо удалить, либо переписать на «карту ОргБух → целевое подразделение». `СоздатьПередачуНачисленийМеждуПодразделениями` оставить идемпотентной (Find-Or-Create по `А_ДокументОснование`).

**Целевые подразделения (проверено):** ТОВ ІНДАСТРІАЛБУД → «Строительство»; ІНДЕПТ СТІЛ ТОВ → «Производство».

## 8. Edge cases (системно, не заплатки)

## 12. TL;DR для исполнителя

1. **Discovery (§9):** подтвердить числа §4 и `А_ЭтоУдержание` / `А_ПодразделениеЗарплатаБух`.
2. **Часть A (§5):** для ФЛ с `НачисленияУпр≠0` — Ф1=`НачисленияБух−СуммаНДФЛ`, Ф2=`НачисленияУпр−Ф1`; «Зарплата управл» делится Ф1/Ф2 (Ф2 = премия как есть + остаток по коэф); удержание целиком Ф1; защита от минуса.
3. **Часть B (§6):** `ОрганизацияБухгалтерия` для Ф1 из `РаспределениеКазна.Организация`, для Ф2 пусто.
4. **Часть C (§7):** ПНМП → единый источник `НачисленнаяЗарплата` нашего документа; целевое подр. = `ОргБух.А_ПодразделениеЗарплатаБух`; налоги только из `НачисленныйНДФЛ`+ЕСВ.
5. **Приёмка (§11):** Постернак 4 строки, Шишкіна 8 строк (в памяти), инвариант, глобальный регресс; копия в основную конфигурацию + загрузка.

**Главные ловушки:** удержание никогда не Ф2; ОргБух только Ф1; не перезаписывать `Организация`; налоги в ПНМП не задваивать; scope только `НачисленияУпр≠0`; приёмка в памяти, не COM-перепроведением.
