# 05. Блок 4а — Создание Документа.НачислениеЗарплаты (ЗУП-документ)

> Главная процедура: `СоздатьДокументНачисления()` (BSL 1734-2119)
> + 5 утилей `_НЗ_*` (кеш, очистка, добавление с распределением)

---

## 1. Назначение

Find-or-Create подчинённого **ЗУП-документа** `Документ.НачислениеЗарплаты`, заполненного из ТЧ родителя `А_ОтражениеЗПпоКазне`.

Документ привязывается к родителю через реквизит **`А_ДокОтражениеЗПпоКазне = Ссылка`** (на родителя). Это позволяет:
- Найти существующий документ (если был создан ранее, и пользователь нажал «Создать» ещё раз → перезаполнение)
- Сохранить ссылку родитель→дитя для отчётов

Образец-шаблон: документ `НачислениеЗарплаты 000Ц-000002` от 28.02.2026 (ТОВ ІНДАСТРІАЛБУД).

---

## 2. Guard и Find-or-Create

```bsl
// Guard: батько має бути проведений
Если НЕ Проведен Тогда
    Сообщить("А_ОтражениеЗПпоКазне не проведений — НачислениеЗарплаты не створюється.");
    Возврат;
КонецЕсли;

// Find-or-Create по реквизиту А_ДокОтражениеЗПпоКазне
ЗапросНЗ = Новый Запрос;
ЗапросНЗ.Текст =
"ВЫБРАТЬ ПЕРВЫЕ 1 НЗ.Ссылка КАК Ссылка
|ИЗ Документ.НачислениеЗарплаты КАК НЗ
|ГДЕ НЗ.А_ДокОтражениеЗПпоКазне = &Осн И НЕ НЗ.ПометкаУдаления";
ЗапросНЗ.УстановитьПараметр("Осн", Ссылка);
РезНЗ = ЗапросНЗ.Выполнить();

Если НЕ РезНЗ.Пустой() Тогда
    // Найден — снять пометку, отменить проведение, очистить все 4 ТЧ
    Выб = РезНЗ.Выбрать(); Выб.Следующий();
    НЗ = Выб.Ссылка.ПолучитьОбъект();
    НЗ.УстановитьПометкуУдаления(Ложь);
    Если НЗ.Проведен Тогда
        Попытка НЗ.Записать(РежимЗаписиДокумента.ОтменаПроведения);
        Исключение Сообщить("Не вдалося розпровести: " + ОписаниеОшибки());
        КонецПопытки;
    КонецЕсли;
    НЗ.Начисления.Очистить();
    НЗ.Удержания.Очистить();
    НЗ.НДФЛ.Очистить();
    НЗ.ВзносыФОТ.Очистить();
    НЗ.ФизическиеЛица.Очистить();
Иначе
    НЗ = Документы.НачислениеЗарплаты.СоздатьДокумент();
КонецЕсли;
```

⚠️ **Pattern:** Cleanup → Guard → Get-or-Create → Fill → Write.Проведение.

## 4. Кеши и константы (до циклов)

```bsl
// Начисления + Удержания
ВидНачисленияОсновний = ПланыВидовРасчета.Начисления.НайтиПоНаименованию("Оклад (Зарплата)");  // = "Оклад" в ЗУП-контексте
ВидНачисленияШтраф    = ПланыВидовРасчета.Начисления.НайтиПоНаименованию("Штраф (упр)");
ВидУдержанияАлименты  = ПланыВидовРасчета.Удержания.НайтиПоНаименованию("Алименты бух");
                       // fallback: ПланыВидовРасчета.Удержания.НайтиПоКоду("УША")

// НДФЛ
ВидСтавкиНДФЛОсновная    = Перечисления.ВидыСтавокНДФЛ.Основная;       // 18%
ВидСтавкиНДФЛУвеличенная = Перечисления.ВидыСтавокНДФЛ.Увеличенная;
ВидСтавкиНДФЛВоенныйСбор = Перечисления.ВидыСтавокНДФЛ.ВоенныйСбор;    // 5%
КодДоходаЗарплата = Справочники.ВидыДоходовНДФЛ.НайтиПоКоду("101");
КодДоходаВЗ       = Справочники.ВидыДоходовНДФЛ.НайтиПоКоду("ВЗ");

// ВзносыФОТ (ЕСВ)
ВидЕСВОсновной       = Перечисления.ВидыЕСВ.ОсновнаяЗарплата;
КатЕСВРаботник       = Справочники.КатегорииЗастрахованныхЛицЕСВ.НайтиПоНаименованию("Наемный работник на общих основаниях");
СтатьяНД22           = Справочники.СтатьиНалоговыхДеклараций.НайтиПоНаименованию("Начисление ЕСВ работодателями (22 %)");
НалогЕСВФОТРаботники = Справочники.Налоги.НайтиПоНаименованию("ЕСВ ФОТ (работники)");

// Константы расчёта
СтавкаНДФЛОсновная = 0.18;   // 18%
СтавкаНДФЛВС       = 0.05;   // 5%
СтавкаЄСВ          = 0.22;   // 22%
МинЗПдляЕСВ        = 8000;   // мин.зарплата
ПределЕСВ          = 160000; // макс.база ЕСВ
```

## 5. ТЧ Начисления (3 шага)

### Шаг 1: НачисленияУпр → Начисления («Оклад (Зарплата)»)

```
Для каждой строки НачисленияУпр:
  Сотр = КешСотрПоФизЛицу[СтрНач.ФизЛицо]   // 1 запрос на все ФизЛица
  Если Сотр не найден → Сообщить и пропустить
  _НЗ_ДодатиРядкиНачисленияПоПодразделениях(НЗ, Сотр, ВидНачисленияОсновний,
      СтрНач.Сумма, МапПодразОргПоСотруднику[Сотр], НачПер, КонПер, СтрЛічильник)
```

### Шаг 2: РаспределениеКазна → Начисления (fallback для НЕ обработанных в Шаге 1)

Для ФизЛица, у которых нет записи в zup_2 — берём `РаспределениеКазна.СуммаНачисления` (агрегированно).

### Шаг 3: УдержанияУпр → Начисления (Штраф (упр) со знаком МИНУС)

```
Для каждой строки УдержанияУпр:
  _НЗ_ДодатиРядкиНачисленияПоПодразделениях(НЗ, Сотр, ВидНачисленияШтраф,
      -СтрУд.Сумма, МапПодразОргПоСотруднику[Сотр], НачПер, КонПер, СтрЛічильник)
```

⚠️ Штрафы идут НЕ в ТЧ Удержания, а в ТЧ Начисления со знаком МИНУС. Это особенность управленческой ЗП — штраф = отрицательное начисление (а не удержание).

## 6. ФильтрФЛ — обязательная множество для последующих ТЧ

После заполнения Начислений:

```bsl
ФЛВНачисленияхСет = Новый Соответствие;
Для Каждого СтрН Из НЗ.Начисления Цикл
    Если ЗначениеЗаполнено(СтрН.Сотрудник) Тогда
        ФЛ = СтрН.Сотрудник.ФизическоеЛицо;
        Если ЗначениеЗаполнено(ФЛ) Тогда
            ФЛВНачисленияхСет.Вставить(ФЛ, Истина);
        КонецЕсли;
    КонецЕсли;
КонецЦикла;
```

⚠️ **КРИТИЧНО:** все следующие ТЧ (Удержания, НДФЛ, ВзносыФОТ) обязаны фильтроваться по `ФЛВНачисленияхСет`:

```bsl
Если ФЛВНачисленияхСет[СтрУдБ.ФизическоеЛицо] = Неопределено Тогда
    Продолжить;
КонецЕсли;
```

**Иначе** регистр `ВзаиморасчетыССотрудниками` падает при проведении с ошибкой «Сотрудник пустой» — потому что для ФизЛица без записи в Начислениях нет соответствующего Сотрудника.

## 7. ТЧ Удержания (алименты)

```bsl
ЛічильникИдУд = 2000000;
Для Каждого СтрУдБ Из УдержанияБухгалтерия Цикл
    Если НЕ ЗначениеЗаполнено(СтрУдБ.ФизическоеЛицо) Тогда Продолжить; КонецЕсли;
    Если СтрУдБ.Сумма = 0 Тогда Продолжить; КонецЕсли;
    Если ФЛВНачисленияхСет[СтрУдБ.ФизическоеЛицо] = Неопределено Тогда Продолжить; КонецЕсли;

    ЛічильникИдУд = ЛічильникИдУд + 1;
    НР = НЗ.Удержания.Добавить();
    НР.ФизическоеЛицо                 = СтрУдБ.ФизическоеЛицо;
    НР.Удержание                      = ВидУдержанияАлименты;   // "Алименты бух" / код "УША"
    НР.Результат                      = СтрУдБ.Сумма;
    НР.ДатаНачала                     = НачПер;
    НР.ДатаОкончания                  = КонПер;
    НР.ИдентификаторСтрокиВидаРасчета = ЛічильникИдУд;
    // Субконто1 = Контрагент-Получатель
    Если ЗначениеЗаполнено(СтрУдБ.Субконто1)
        И ТипЗнч(СтрУдБ.Субконто1) = Тип("СправочникСсылка.Контрагенты") Тогда
        НР.Получатель = СтрУдБ.Субконто1;
    КонецЕсли;
КонецЦикла;
```

## 8. ТЧ НДФЛ + ВзносыФОТ из НалогиБухгалтерия

Перед циклом — собираем Сумму_Начислено по ФизЛица (для НДФЛ.ДоходПолный):

```bsl
СуммаНачПоФЛ = Новый Соответствие;
Для Каждого СтрНач Из НЗ.Начисления Цикл
    Если СтрНач.Начисление <> ВидНачисленияОсновний Тогда Продолжить; КонецЕсли;  // только основные, без штрафов
    ФЛ = СтрНач.Сотрудник.ФизическоеЛицо;
    Поточна = СуммаНачПоФЛ[ФЛ];
    СуммаНачПоФЛ.Вставить(ФЛ, ЕстьNULL(Поточна, 0) + СтрНач.Результат);
КонецЦикла;
```

### НДФЛ

```bsl
Для Каждого СтрНБ Из НалогиБухгалтерия Цикл
    Если НЕ ЗначениеЗаполнено(СтрНБ.Сотрудник) Тогда Продолжить; КонецЕсли;
    ФЛСотр = СтрНБ.Сотрудник.ФизическоеЛицо;
    Если ФЛВНачисленияхСет[ФЛСотр] = Неопределено Тогда Продолжить; КонецЕсли;

    Если СтрНБ.СуммаНДФЛ > 0 Тогда
        НР = НЗ.НДФЛ.Добавить();
        НР.ФизическоеЛицо  = ФЛСотр;
        НР.НалоговыйПериод = НачПер;
        НР.Налог           = СтрНБ.СуммаНДФЛ;        // утриманий податок
        НР.Доход           = СтрНБ.СуммаДохода;     // база (ВзаиморасчетыПоНДФЛ.ДоходПриход)
        НР.ДоходПолный     = СтрНБ.СуммаДохода;
        НР.ИдентификаторСтрокиНДФЛ = ЛічильникИдНДФЛ;

        Если СтрНБ.ТипНалога = Перечисления.ТипыНалогов.ВоенныйСбор Тогда
            НР.ВидСтавки         = ВидСтавкиНДФЛВоенныйСбор;
            НР.УвеличеннаяСтавка = ВидСтавкиНДФЛВоенныйСбор;
            Если НЕ ЗначениеЗаполнено(НР.КодДохода) Тогда НР.КодДохода = КодДоходаВЗ; КонецЕсли;
        Иначе
            НР.ВидСтавки         = ВидСтавкиНДФЛОсновная;
            НР.УвеличеннаяСтавка = ВидСтавкиНДФЛУвеличенная;
            Если НЕ ЗначениеЗаполнено(НР.КодДохода) Тогда НР.КодДохода = КодДоходаЗарплата; КонецЕсли;
        КонецЕсли;
    КонецЕсли;
КонецЦикла;
```

## 9. Запись с проведением + fallback

```bsl
Попытка
    НЗ.Записать(РежимЗаписиДокумента.Проведение);
    Сообщить("НачислениеЗарплаты створено/оновлено: " + Строка(НЗ.Ссылка)
        + " (Нач=" + НЗ.Начисления.Количество()
        + ", Уд=" + НЗ.Удержания.Количество()
        + ", НДФЛ=" + НЗ.НДФЛ.Количество()
        + ", ВзносыФОТ=" + НЗ.ВзносыФОТ.Количество() + ")");

    // Очистить РегистрСведений.ПерерасчетЗарплаты — документ кодом → перерасчёт не нужен
    _НЗ_ОчиститиПерерасчетЗарплаты(Организация, НачПер, КонПер);
Исключение
    Сообщить("Помилка запису НачислениеЗарплаты: " + ОписаниеОшибки());
    // Fallback — сохранить БЕЗ проведения, чтобы пользователь видел заполненные ТЧ
    Попытка
        НЗ.Записать(РежимЗаписиДокумента.Запись);
        Сообщить("НачислениеЗарплаты збережено БЕЗ проведення: " + Строка(НЗ.Ссылка));
    Исключение
        Сообщить("Не вдалося зберегти НачислениеЗарплаты взагалі: " + ОписаниеОшибки());
    КонецПопытки;
КонецПопытки;
```

## 10. Утилитные процедуры `_НЗ_*`

### `_НЗ_ОчиститиПерерасчетЗарплаты` (BSL 2126-2165)

Очищает `РегистрСведений.ПерерасчетЗарплаты` для (Орг, Период) — запись через пустой набор с отбором.

**Зачем:** документ НЗ создаётся кодом, ручных правок нет → нет смысла генерировать «требуется доначисление» от ПриёмаНаРаботу / КадровогоПеревода. Иначе в форме НЗ появляется предупреждение «Требуется доначисление».

### `_НЗ_ПобудуватиКешСотрудникПоФизЛицу` (BSL 2169-2227)

Один запрос к `Справочник.Сотрудники` для всех ФизЛица из ТЧ родителя. Возвращает мапу `ФизЛицо → Сотрудник` (если у ФЛ несколько Сотрудников — берётся первый).

### `_НЗ_ПобудуватиМапПодразОргПоСотруднику` (BSL 2291-2336)

Конвертирует `СтруктураПредприятия` (из РаспределениеКазна) → `ПодразделенияОрганизаций` (для ЗУП-документа) через привилегированную процедуру `А_Привилегированный.ОбеспечитьПодразделенияОрганизацийПоПодразделению`.

Возвращает: `Соответствие(Сотр → Структура(Подразделения=Соответствие(ПодрОрг→Сумма), Итого))`.

### `_НЗ_ДодатиРядкиНачисленияПоПодразделениях` (BSL 2352-2414)

Универсальная процедура добавления N строк начисления с пропорциональным распределением:

```bsl
Процедура _НЗ_ДодатиРядкиНачисленияПоПодразделениях(НЗ, Сотр, ВидРасч, ЗагальнаСума,
    ДанПоСотр, НачПер, КонПер, СтрЛічильник)

    Если ЗагальнаСума = 0 Тогда Возврат; КонецЕсли;

    НемаРозподілу = (ДанПоСотр = Неопределено)
        ИЛИ (ДанПоСотр.Подразделения.Количество() = 0)
        ИЛИ (ДанПоСотр.Итого = 0);

    Если НемаРозподілу Тогда
        // Fallback: 1 строка без подразделения
        НР = НЗ.Начисления.Добавить();
        НР.Сотрудник = Сотр;
        НР.Начисление = ВидРасч;
        НР.Результат = ЗагальнаСума;
        // ... + Идентификатор через СтрЛічильник.Значение (pass-by-ref через структуру)
        Возврат;
    КонецЕсли;

    // Пропорциональный split — последний компенсирует копейки округления
    Остаток = ЗагальнаСума;
    КолПодр = ДанПоСотр.Подразделения.Количество();
    Счетчик = 0;
    Для Каждого КЗ Из ДанПоСотр.Подразделения Цикл
        Счетчик = Счетчик + 1;
        Если Счетчик = КолПодр Тогда
            СумДляПодр = Остаток;
        Иначе
            Доля = ПідрСум / Итого;
            СумДляПодр = Окр(ЗагальнаСума * Доля, 2);
            Остаток = Остаток - СумДляПодр;
        КонецЕсли;
        // ... создать строку с этим подразделением
    КонецЦикла;
КонецПроцедуры
```

⚠️ **СтрЛічильник** — это структура с одним полем `Значение`, потому что в BSL нет pass-by-ref для примитивов. Через структуру можно мутировать счётчик in-place.

### `_НЗ_ОбчислитиСуммаНДФЛПоФизЛицу` (BSL 2233-2276)

Дубль логики из Блока 3 (`_ОтрЗП_ОбчислитиСуммаНДФЛПоФизЛицу`) — для контекста `СоздатьДокументНачисления` (если нужно).

## 11. ТЧ ФизическиеЛица

```bsl
Для Каждого КЗ Из УникальныеФЛ Цикл
    НР = НЗ.ФизическиеЛица.Добавить();
    НР.ФизическоеЛицо = КЗ.Ключ;
КонецЦикла;
```

`УникальныеФЛ` собирается в ходе заполнения Начислений, Удержаний и НДФЛ — добавляются при каждой обработанной ФЛ.
