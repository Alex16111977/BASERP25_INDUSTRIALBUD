# MCP discovery: структуры ERP-документов выплаты ЗП (2026-05-26)

## 1. Документ.А_РаспределениеЗаработнойПлаты (ERP, зеркало Казны)

Синоним: «Распределение заработной платы»

**Реквизиты:**
- `Организация` — Справочник.Организации
- `Комментарий` — Строка
- `Ответственный` — Справочник.Пользователи
- `КассаДатаС` — Дата
- `КассаДатаПо` — Дата
- `ОтбиратьТабельПоОрганизации` — Булево
- `Направление` — Справочник.НаправленияДеятельности
- `ОпределятьНаправлениеПоТабелю` — Булево
- `УчитыватьАванс` — Булево

**Табличные части:**
- `Сотрудники`: `Сотрудник`, `СуммаНачисления`, `СуммаФОТ`, `СуммаНалогов`, `ИНН`, `ФИО`, `КодСотрудникаКазна`
- `Распределение`: `Сотрудник`, **`Подразделение`** (СтруктураПредприятия!), `ОтработаноЧасов`, `СуммаЗатрат`, `СуммаНачисления`, `СуммаФОТ`, `СуммаНалогов`, `Направление`
- `СотрудникиИсключения`: `Сотрудник`, `СуммаНачисления`, `СуммаФОТ`, `СуммаНалогов`, **`СуммаВыплаты`**

## 2. Документ.РаспределениеФ2 (ERP, зеркало Казны)

Синоним: «Распределение ф2»

**Реквизиты:** те же что у А_РаспределениеЗП

**Табличные части:**
- `Сотрудники`: `Сотрудник`, `СуммаНачисления` (синоним «Перечисления»), `ФИО`, `ИНН`, `КодСотрудникаКазна`
- `Распределение`: `Сотрудник`, **`Подразделение`** (СтруктураПредприятия), `ОтработаноЧасов`, `СуммаЗатрат`, `СуммаНачисления`, `Направление`

⚠️ Нет `СотрудникиИсключения`, нет `СуммаФОТ`/`СуммаНалогов` — упрощённая версия для авансов.

## 3. Документ.ВедомостьНаВыплатуЗарплатыВКассу (ERP)

Синоним: «Ведомость в кассу»

**Шапка (избранные реквизиты):**
- `ПериодРегистрации` — Дата (тип «Месяц»)
- **`Организация`** — Справочник.Организации
- **`Подразделение`** — Справочник.ПодразделенияОрганизаций ⚠️ (НЕ СтруктураПредприятия!)
- `СтатьяФинансирования` — Справочник.СтатьиФинансированияЗарплата
- `СтатьяРасходов` — Справочник.СтатьиРасходовЗарплата
- **`Касса`** — Справочник.Кассы
- **`СпособВыплаты`** — Справочник.СпособыВыплатыЗарплаты
- `СуммаПоДокументу` — Число (Σ КВыплате)
- `ПорядокЗаполненияНалогов` — Перечисление (БезНалогов / НДФЛИВзносы / НДФЛ / Взносы)
- Подписанты: `Руководитель`, `ГлавныйБухгалтер`, `Кассир`, `Бухгалтер`, `Составил`, `Проверил`, `Раздатчик` (все — ФизическиеЛица + Должности)

**Главная ТЧ `Зарплата`:**
- `ИдентификаторСтроки` — УникальныйИдентификатор
- `Сотрудник` — Справочник.Сотрудники
- **`ФизическоеЛицо`** — Справочник.ФизическиеЛица
- **`Подразделение`** — Справочник.ПодразделенияОрганизаций (= шапке)
- `ПериодВзаиморасчетов` — Дата
- `СтатьяФинансирования`, `СтатьяРасходов`
- **`ДокументОснование`** — composite ref включает `Документ.НачислениеЗарплаты` (наш ключ связи!)
- **`КВыплате`** — Число
- `ГруппаУчетаНачислений` — Справочник.ГруппыУчетаНачисленийИУдержаний

**Прочие ТЧ:** `Состав` (уникальные ФЛ), `Основания` (расширенный список документов), `НДФЛ`, `ВзносыФОТ`, `ФизическиеЛица`, `ДополнительныеРеквизиты`.

## 4. РегистрНакопления.ЗарплатаКВыплате (КЛЮЧЕВОЙ для задачи!)

Синоним: «Зарплата к выплате»

**Измерения:**
- `Организация` — Справочник.Организации
- `ФизическоеЛицо` — Справочник.ФизическиеЛица
- `СтатьяФинансирования` — Справочник.СтатьиФинансированияЗарплата
- `СтатьяРасходов` — Справочник.СтатьиРасходовЗарплата
- **`Сотрудник`** — Справочник.Сотрудники
- **`Подразделение`** — Справочник.ПодразделенияОрганизаций
- `ПериодВзаиморасчетов` — Дата
- `ДокументОснование` — composite ref (включает НачислениеЗарплаты)
- `ГруппаУчетаНачислений` — Справочник.ГруппыУчетаНачисленийИУдержаний

**Ресурс:** `СуммаКВыплате` — Число

**Регистраторы (+СуммаКВыплате):**
`НачислениеЗарплаты`, `Премия`, `Отпуск`, `Командировка`, `Увольнение`, `БольничныйЛист`, `МатериальнаяПомощь`, `ОплатаПоСреднемуЗаработку`, `ПерерасчетНДФЛ`, `РазовоеНачисление`, `КомпенсацияЗаЗадержкуЗарплаты`, ... (всего ~25 типов)

**Регистраторы (−СуммаКВыплате):**
`ВедомостьНаВыплатуЗарплатыВКассу`, `ВедомостьНаВыплатуЗарплатыВБанк`, `ВедомостьНаВыплатуЗарплатыПеречислением`, `ВедомостьНаВыплатуЗарплатыРаздатчиком`, `ПодтверждениеЗачисленияЗарплаты`, `ДоходВНатуральнойФорме`, `СторнированиеНачислений`, ...

**Реквизит `Сторно`** (Булево) — для перепроведения.

## 5. Логика проведения РаспределениеЗП в Казне (BSL анализ)

См. `_Rarzrabotki/Kazna/Documents/РаспределениеЗаработнойПлаты/Ext/ObjectModule.bsl` (143 строки).

ОбработкаПроведения для каждой строки ТЧ Распределение пишет **3 движения** в `РегистрНакопления.БДДС`:
1. **Начислено (NET)** = `СуммаНачисления − СуммаНалогов`, статья = `Сотрудник.СтатьяЗарплата`, ВидОплаты=Безналичные
2. **Удержано** = `СуммаНалогов`, статья = `Сотрудник.СтатьяУдержанияСЗарплаты`
3. **ФОТ** = `СуммаФОТ`, статья = `Сотрудник.СтатьяНачисленияНаЗарплату`

Дополнительно для строк `СотрудникиИсключения` — пропорциональное сторно `СуммаВыплаты` по подразделениям.

## 6. Логика проведения РаспределениеФ2 в Казне (BSL анализ)

См. `_Rarzrabotki/Kazna/Documents/РаспределениеФ2/Ext/ObjectModule.bsl`.

ОбработкаПроведения для каждой строки Распределение пишет **1 движение** в БДДС:
- **Начислено** = `СуммаНачисления`, статья = `Сотрудник.СтатьяЗарплата`, ВидОплаты=**Наличные**

Все остальные движения (Удержано/ФОТ) и блок СотрудникиИсключения **закомментированы**.

## 7. Логика ОбработкаЗаполнения РКО Казны на основании РаспределениеФ2

См. `_Rarzrabotki/Kazna/Documents/РасходныйКассовыйОрдер/Ext/ObjectModule.bsl` строки 45-79.

Запрос группирует ТЧ Распределение Ф2 по `(Подразделение × Направление × Сотрудник.СтатьяЗарплата)` и заполняет ТЧ Расшифровка РКО. `СуммаДокумента = Σ` всех сумм.

⚠️ В Расшифровке РКО **нет сотрудника** — только подразделение + статья.
