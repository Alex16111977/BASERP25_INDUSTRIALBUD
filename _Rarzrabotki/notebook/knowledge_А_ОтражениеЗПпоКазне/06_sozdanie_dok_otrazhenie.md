# 06. Блок 4б — Создание Документа.ОтражениеЗарплатыВФинансовомУчете

> Главная процедура: `СоздатьДокументОтражениеЗарплатыВФинансовомУчете()` (BSL 2433-2641)

---

## 1. Назначение

Find-or-Create типового документа `Документ.ОтражениеЗарплатыВФинансовомУчете`, заполненного из ТЧ родителя.

Привязка к родителю через реквизит **`А_ДокОтражениеЗПпоКазне = Ссылка`**.

Образец-шаблон: документ `ОтражениеЗарплатыВФинансовомУчете 000Ц-000002` от 31.12.2025 (ручной ввод).

---

## 2. Find-or-Create + шапка

```bsl
// Guard
Если НЕ Проведен Тогда
    Сообщить("А_ОтражениеЗПпоКазне не проведений — ОтражениеЗарплатыВФинансовомУчете не створюється.");
    Возврат;
КонецЕсли;

// Find-or-Create
ЗапросОЗ = Новый Запрос;
ЗапросОЗ.Текст =
"ВЫБРАТЬ ПЕРВЫЕ 1 ОЗ.Ссылка КАК Ссылка
|ИЗ Документ.ОтражениеЗарплатыВФинансовомУчете КАК ОЗ
|ГДЕ ОЗ.А_ДокОтражениеЗПпоКазне = &Осн И НЕ ОЗ.ПометкаУдаления";
ЗапросОЗ.УстановитьПараметр("Осн", Ссылка);

// ... либо найти и очистить, либо создать новый

// Шапка
ОЗ.Дата                    = Дата;
ОЗ.Организация             = Организация;
ОЗ.ПериодРегистрации       = НачалоМесяца(Дата);
ОЗ.Сводно                  = Ложь;             // НЕ сводно — по работникам
ОЗ.ПроводкиПоРаботникам    = Истина;
ОЗ.А_ДокОтражениеЗПпоКазне = Ссылка;
```

## 3. Заполнение 5 ТЧ дочернего документа

### 3.1 `НачисленнаяЗарплатаИВзносыПоФизлицам` — копия 1-в-1

```bsl
Для Каждого СтрБ Из НачисленнаяЗарплатаИВзносыПоФизлицам Цикл
    Если СтрБ.Сумма = 0 И СтрБ.ВзносыВсего = 0 Тогда Продолжить; КонецЕсли;
    НоваяСтр = ОЗ.НачисленнаяЗарплатаИВзносыПоФизлицам.Добавить();
    ЗаполнитьЗначенияСвойств(НоваяСтр, СтрБ);
    НоваяСтр.Организация = Организация;  // всегда из шапки родителя
КонецЦикла;
```

### 3.2 `НачисленнаяЗарплатаИВзносы` — **СВЁРТКА**

Группируется по 6 ключам, суммируются `Сумма` + `ВзносыВсего`:

```
Ключ свёртки:
  Организация,
  ПодразделениеПредприятия,
  ВидОперации,
  СпособОтраженияЗарплатыВБухучете,
  ГруппаУчетаНачислений,
  Налог
```

Реализация — через `ТаблицаЗначений.Свернуть`:

```bsl
ТЗСвертка = Новый ТаблицаЗначений;
ТЗСвертка.Колонки.Добавить("Организация");
ТЗСвертка.Колонки.Добавить("ПодразделениеПредприятия");
ТЗСвертка.Колонки.Добавить("ВидОперации");
ТЗСвертка.Колонки.Добавить("СпособОтраженияЗарплатыВБухучете");
ТЗСвертка.Колонки.Добавить("ГруппаУчетаНачислений");
ТЗСвертка.Колонки.Добавить("Налог");
ТЗСвертка.Колонки.Добавить("Сумма");
ТЗСвертка.Колонки.Добавить("ВзносыВсего");

Для Каждого СтрПоФЛ Из ОЗ.НачисленнаяЗарплатаИВзносыПоФизлицам Цикл
    НоваСвер = ТЗСвертка.Добавить();
    // ... копирование 6 ключей + Сумма + ВзносыВсего
КонецЦикла;

ТЗСвертка.Свернуть(
    "Организация, ПодразделениеПредприятия, ВидОперации, СпособОтраженияЗарплатыВБухучете, ГруппаУчетаНачислений, Налог",
    "Сумма, ВзносыВсего");

Для Каждого СтрС Из ТЗСвертка Цикл
    Если СтрС.Сумма = 0 И СтрС.ВзносыВсего = 0 Тогда Продолжить; КонецЕсли;
    НоваяСвр = ОЗ.НачисленнаяЗарплатаИВзносы.Добавить();
    ЗаполнитьЗначенияСвойств(НоваяСвр, СтрС);
КонецЦикла;
```

Это типовой паттерн ERP — есть две ТЧ: «по физлицам» (детально) и «свёртка» (для бухгалтерских проводок).

### 3.3 `НачисленныйНДФЛ` — копия 1-в-1

```bsl
Для Каждого СтрБ Из НачисленныйНДФЛ Цикл
    Если СтрБ.Сумма = 0 Тогда Продолжить; КонецЕсли;
    НоваяСтр = ОЗ.НачисленныйНДФЛ.Добавить();
    ЗаполнитьЗначенияСвойств(НоваяСтр, СтрБ);
    НоваяСтр.Организация = Организация;
    // СпособОтражения ОБНУЛЯЕМ — как в эталоне 000Ц-000002
    НоваяСтр.СпособОтраженияЗарплатыВБухучете = Справочники.СпособыОтраженияЗарплатыВБухучете.ПустаяСсылка();
КонецЦикла;
```

⚠️ Способ отражения **обнуляется** в дочке (в родителе он был распределён по подр./статье).

### 3.4 `УдержаннаяЗарплата` ← `УдержанияБухгалтерия`

Дополнительная сложность — `ПодразделениеПредприятия` в источнике часто пустое. Заполняем по правилу «max начисления»:

```bsl
// Построить мапу ФизЛица → Подразделение (max Сумма из НачисленнаяЗПпоФизлицам)
ТЗПодрПоФЛ = Новый ТаблицаЗначений;
ТЗПодрПоФЛ.Колонки.Добавить("ФизическоеЛицо");
ТЗПодрПоФЛ.Колонки.Добавить("Подразделение");
ТЗПодрПоФЛ.Колонки.Добавить("Сумма");
Для Каждого СтрНач Из НачисленнаяЗарплатаИВзносыПоФизлицам Цикл
    Если НЕ ЗначениеЗаполнено(СтрНач.ФизическоеЛицо) Тогда Продолжить; КонецЕсли;
    Если НЕ ЗначениеЗаполнено(СтрНач.ПодразделениеПредприятия) Тогда Продолжить; КонецЕсли;
    НовСтрПодр = ТЗПодрПоФЛ.Добавить();
    НовСтрПодр.ФизическоеЛицо = СтрНач.ФизическоеЛицо;
    НовСтрПодр.Подразделение  = СтрНач.ПодразделениеПредприятия;
    НовСтрПодр.Сумма          = СтрНач.Сумма;
КонецЦикла;
ТЗПодрПоФЛ.Свернуть("ФизическоеЛицо, Подразделение", "Сумма");
ТЗПодрПоФЛ.Сортировать("Сумма УБЫВ");

МапПодразПоФЛ = Новый Соответствие;
Для Каждого СтрМ Из ТЗПодрПоФЛ Цикл
    Если МапПодразПоФЛ[СтрМ.ФизическоеЛицо] = Неопределено Тогда
        МапПодразПоФЛ.Вставить(СтрМ.ФизическоеЛицо, СтрМ.Подразделение);
    КонецЕсли;
КонецЦикла;
```

После сортировки по Сумме УБЫВ — первая запись по каждой ФЛ имеет max начисление → берём её подразделение.

### Подмена группы «Прочие пассивы» (КРИТИЧНО)

В ТЧ родителя `УдержанияБухгалтерия.СтатьяАктивовПассивов` иногда оказывается **ГРУППА** «Прочие пассивы» (баг исходных данных). В дочке должен быть **ПРЕДОПРЕДЕЛЁННЫЙ ЭЛЕМЕНТ** (не группа), иначе ERP видит группу и проведение падает:

```bsl
ПрочиеПассивыЭлемент = ПланыВидовХарактеристик.СтатьиАктивовПассивов.ПрочиеПассивы;  // предопределённый

Для Каждого СтрБ Из УдержанияБухгалтерия Цикл
    Если СтрБ.Сумма = 0 Тогда Продолжить; КонецЕсли;
    НоваяСтр = ОЗ.УдержаннаяЗарплата.Добавить();
    ЗаполнитьЗначенияСвойств(НоваяСтр, СтрБ);
    НоваяСтр.Организация = Организация;

    // Подразделение из мапы max-начисления, если в источнике пусто
    Если НЕ ЗначениеЗаполнено(НоваяСтр.ПодразделениеПредприятия) Тогда
        ПодрЗНач = МапПодразПоФЛ[СтрБ.ФизическоеЛицо];
        Если ПодрЗНач <> Неопределено Тогда
            НоваяСтр.ПодразделениеПредприятия = ПодрЗНач;
        КонецЕсли;
    КонецЕсли;

    // Подмена группы → элемент
    Если ЗначениеЗаполнено(НоваяСтр.СтатьяАктивовПассивов)
        И НоваяСтр.СтатьяАктивовПассивов.ЭтоГруппа Тогда
        НоваяСтр.СтатьяАктивовПассивов = ПрочиеПассивыЭлемент;
    КонецЕсли;
КонецЦикла;
```

### 3.5 `ФизическиеЛица` — уникальные из 3-х ТЧ

```bsl
НаборФЛ = Новый Соответствие;
Для Каждого Стр Из ОЗ.НачисленнаяЗарплатаИВзносыПоФизлицам Цикл
    НаборФЛ.Вставить(Стр.ФизическоеЛицо, Истина);
КонецЦикла;
Для Каждого Стр Из ОЗ.НачисленныйНДФЛ Цикл
    НаборФЛ.Вставить(Стр.ФизическоеЛицо, Истина);
КонецЦикла;
Для Каждого Стр Из ОЗ.УдержаннаяЗарплата Цикл
    НаборФЛ.Вставить(Стр.ФизическоеЛицо, Истина);
КонецЦикла;
Для Каждого КлЗн Из НаборФЛ Цикл
    ОЗ.ФизическиеЛица.Добавить().ФизическоеЛицо = КлЗн.Ключ;
КонецЦикла;
```

## 5. Запись с проведением + fallback

```bsl
Попытка
    ОЗ.Записать(РежимЗаписиДокумента.Проведение);
    Сообщить("ОтражениеЗарплатыВФинансовомУчете створено/оновлено: " + Строка(ОЗ.Ссылка)
        + " (Нач=" + ОЗ.НачисленнаяЗарплатаИВзносы.Количество()
        + ", НачПоФЛ=" + ОЗ.НачисленнаяЗарплатаИВзносыПоФизлицам.Количество()
        + ", НДФЛ=" + ОЗ.НачисленныйНДФЛ.Количество()
        + ", Удерж=" + ОЗ.УдержаннаяЗарплата.Количество()
        + ", ФЛ=" + ОЗ.ФизическиеЛица.Количество() + ")");
Исключение
    Сообщить("Помилка проведення ...");
    // Fallback — Запись без проведения
    Попытка
        ОЗ.Записать(РежимЗаписиДокумента.Запись);
    Исключение
        Сообщить("Не вдалося зберегти взагалі: " + ОписаниеОшибки());
    КонецПопытки;
КонецПопытки;
```

## 6. Финальная картинка после полного цикла

После выполнения всех 4-х блоков документ `А_ОтражениеЗПпоКазне` имеет:
- 7 ТЧ родителя — заполнены данными из 3-х внешних баз
- 2 подчинённых документа созданы:
  - `Документ.НачислениеЗарплаты` (ЗУП-документ) — наполняет регистры ЗУП (ПерерасчетЗарплаты очищен)
  - `Документ.ОтражениеЗарплатыВФинансовомУчете` (типовой документ) — наполняет регистры бухгалтерского отражения зарплаты:
    - `РегНакопл.А_НачисленнаяЗарплатаИВзносыПоФизлицам`
    - `РегНакопл.НачисленнаяЗарплатаИВзносы`
    - `РегНакопл.НачисленныйНДФЛ`
    - `РегНакопл.УдержаннаяЗарплата`
    - + Бух.проводки через `Хозрасчетный` (Дт расходов / Кт 661, Дт 661 / Кт 6411, Дт 661 / Кт 6853 и т.д.)
