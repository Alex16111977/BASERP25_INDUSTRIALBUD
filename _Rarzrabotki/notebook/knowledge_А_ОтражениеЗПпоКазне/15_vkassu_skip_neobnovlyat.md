## 1. Что было сделано

В функцию `_ОЗП_СоздатьВКассуИзФ2` добавлен ранний-возврат гард: если найденная ВКассу имеет реквизит `А_Необновлять = Истина` — её **не модифицируем** (не распроводим, не очищаем ТЧ, не перезаписываем). Это защищает «занятые» ВКассу, по которым уже выпущен и проведён РКО, от случайной перезаписи при повторном нажатии кнопки «Создать ведомости в кассу».

| # | Объект | Изменение |
|---|---|---|
| 1 | `Documents/А_ОтражениеЗПпоКазне/Ext/ObjectModule.bsl` | Find-or-create запрос расширен полем `А_Необновлять`. После `Выб.Следующий()` — гард `Если Выб.А_Необновлять Тогда Возврат "Пропущено"`. **Процедура `_ОЗП_СоздатьВКассуИзФ2` сменена на Функцию** — возвращает строковый код. |
| 2 | `Documents/А_ОтражениеЗПпоКазне/Ext/ObjectModule.bsl` | В вызывающей `СоздатьВедомостиВКассуПоОтражениюЗП` добавлен счётчик `КолПропущеноБлок` и switch по коду. Итоговая строка дополнена фрагментом `, пропущено заблокированных (А_Необновлять) N`. |

**Файлы XML / реквизиты — не трогали.** Реквизит `А_Необновлять` (Булево, uuid `7093b0ea-8f60-4699-b97a-9c11d0eeb563`) уже существовал в метаданных `Документ.ВедомостьНаВыплатуЗарплатыВКассу.xml:1779-1791`.

## 2. Контракт строковых кодов

`Функция _ОЗП_СоздатьВКассуИзФ2(Ф2Ссылка, СтрокиРК)` возвращает один из четырёх кодов:

| Код | Когда | Счётчик в вызывающей |
|---|---|---|
| `"Создано"` | ВКассу по этой Ф2 не было — создан с нуля и проведён. | `КолОбработано += 1` |
| `"Обновлено"` | ВКассу была, флаг `А_Необновлять = Ложь` — распровели, очистили ТЧ, переписали, провели. | `КолОбработано += 1` |
| `"Пропущено"` | ВКассу была, `А_Необновлять = Истина` — гард, ничего не модифицируем. | `КолПропущеноБлок += 1` |
| `"Ошибка"` | Поймали исключение на `ОтменаПроведения` или финальном `Записать(Проведение)`. | `КолОшибок += 1` |

Альтернатива (параметр byref `Структура`) была рассмотрена и отвергнута — строковый код проще читать в вызывающей и не имеет побочного состояния.

## 4. Связь с РКО.ПриЗаписи (где ставится флаг)

Флаг `А_Необновлять` ставится в `Истина` процедурой [`Documents/РасходныйКассовыйОрдер/Ext/ObjectModule.bsl:1127-1131`](../../../Documents/РасходныйКассовыйОрдер/Ext/ObjectModule.bsl):

```bsl
Если Источник.ХозяйственнаяОперация = Перечисления.ХозяйственныеОперации.ВыплатаЗарплатыЧерезКассу Тогда
    Если ЗначениеЗаполнено(Источник.Ведомость) Тогда
        Если Источник.Ведомость.А_Необновлять <> Источник.Проведен Тогда
            ДокВедомость = Источник.Ведомость.ПолучитьОбъект();
            ДокВедомость.ОбменДанными.Загрузка = Истина;
            ДокВедомость.А_Необновлять = Источник.Проведен;   ← ИСТИНА когда РКО проведён
            ДокВедомость.Записать();
            // Также: Ф2.А_Необновлять = Источник.Проведен, Ф2.Закрытый = Истина
        КонецЕсли;
    КонецЕсли;
КонецЕсли;
```

Формула `А_Необновлять = Источник.Проведен` означает:
- РКО **проведён** → ВКассу заблокирована.
- РКО **распровели** → флаг автоматически сбрасывается в Ложь.

Это даёт **обратимость** без какого-либо явного кода с нашей стороны: распроведение РКО возвращает ВКассу в редактируемое состояние, и следующий запуск кнопки в А_ОтражениеЗПпоКазне обновит её как раньше (`КодРезультата = "Обновлено"`).

## 6. Уроки

### Урок №1: гард ставится ДО любых модификаций

Гард должен быть **первым** действием после `Выб.Следующий()` — до `УстановитьПометкуУдаления(Ложь)`, до `Записать(РежимЗаписиДокумента.ОтменаПроведения)`, до `Очистить()` трёх ТЧ. Иначе даже при возврате `"Пропущено"` мы успеем сделать необратимые изменения (снятие пометки удаления, распроведение).

```bsl
Если НЕ Результат.Пустой() Тогда
    Выб = Результат.Выбрать(); Выб.Следующий();

    // === ПЕРВОЕ ДЕЙСТВИЕ ПОСЛЕ Следующий() ===
    Если Выб.А_Необновлять Тогда
        Сообщить("Ф2 ... → ВКассу ... пропущена (А_Необновлять=Истина, занята РКО)");
        Возврат "Пропущено";
    КонецЕсли;

    // только после гарда — модификации
    ВыкВКассу = Выб.Ссылка.ПолучитьОбъект();
    ...
```

### Урок №2: смена `Процедура → Функция` со строковым кодом — лёгкий способ сообщить вызывающему процесс

Параметр byref `Структура` тоже работает, но строковый код:
- не имеет побочного состояния (легче рассуждать),
- одной строкой описывает результат в логе,
- идеально ложится в switch (`Если Код = "X" Тогда ... Иначе ... КонецЕсли`).

Когда нужно 3-4 разных кода результата — функция предпочтительнее.

### Урок №3: единственный вызов → безопасная смена сигнатуры

Перед сменой `Процедура → Функция` обязательно убедиться грепом, что у функции **ровно один вызов**. Если бы где-то ещё в коде было `_ОЗП_СоздатьВКассуИзФ2(...)` без присваивания — после смены сигнатуры там осталась бы потерянная return-value (и потенциальный warning «возвращаемое значение не используется»).

Грепы для проверки в плане:
```
pattern: _ОЗП_СоздатьВКассуИзФ2  → должно быть 3 попадания (комментарий, определение, вызов)
pattern: ^\s*Возврат\s+          → ровно 4 выхода функции (Пропущено, 2×Ошибка, КодРезультата)
```

### Урок №4: «занятая ВКассу» означает «РКО проведён», не «РКО существует»

Связь делается через `А_Необновлять = Источник.Проведен`, а не через факт наличия РКО.Ссылки. То есть:
- РКО создан, но не проведён → флаг = Ложь → ВКассу можно обновлять.
- РКО проведён → флаг = Истина → ВКассу заблокирована.
- РКО распровели → флаг = Ложь → ВКассу снова обновляется.

Это удобно: распроведение РКО автоматически «открывает» ВКассу для повторного формирования из А_ОтражениеЗПпоКазне без правки нашего кода.

### Урок №5: расширение итоговой строки — без ломки существующего формата

Старая итоговая строка содержала «создано/обновлено N, ошибок K, пропущено А_РаспределениеЗаработнойПлаты строк P». Новый фрагмент `, пропущено заблокированных (А_Необновлять) M` вставлен **между** базовыми и существующим «пропущено А_РаспределениеЗП», и **только если M > 0**, чтобы не загромождать лог в типовых прогонах:

```bsl
ИтогТекст = "ОтражениеЗПпоКазне → ВКассу: создано/обновлено " + КолОбработано
    + ", ошибок " + КолОшибок;
Если КолПропущеноБлок > 0 Тогда
    ИтогТекст = ИтогТекст + ", пропущено заблокированных (А_Необновлять) " + КолПропущеноБлок;
КонецЕсли;
Если ПропускТипов > 0 Тогда
    ИтогТекст = ИтогТекст + ", пропущено А_РаспределениеЗаработнойПлаты строк " + ПропускТипов;
КонецЕсли;
Сообщить(ИтогТекст);
```
