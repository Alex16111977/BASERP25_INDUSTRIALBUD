```

     ├─ 3. Guard: Проведен
     ├─ 4. Шапка: Подразделение=ЦО, Касса=*Орг.А_ОсновнаяКасса, СпособВыплаты="Через кассу"
     ├─ 5. Кеши: КешФЛ + КешПодрОрг
     ├─ 6. ТЧ Зарплата ← ТЧ Сотрудники Ф2 (21 строк, КВыплате = СуммаНачисления)

     ├─ 8. ТЧ Состав ← уникальные ФЛ (21)
     ├─ 9. СуммаПоДокументу = Σ ТЧ Зарплата = 348 800
     ├─ 10. ВыкВКассу.ОбменДанными.Загрузка = Истина  ← БЛОКИРУЕТ ТИПОВУЮ ЛОГИКУ
     │     ВыкВКассу.Записать(РежимЗаписиДокумента.Запись)  ← без проведения
     └─ 11. Обратная ссылка: Ф2.А_ВедомостьВКассу = ВыкВКассу.Ссылка (через ОбменДанными.Загрузка)

   Пользователь вручную проводит ведомость в UI когда нужно
```

## 3. Критичные находки и уроки

### Урок №1: типовая ОбработкаПередЗаписью ВКассу очищает ТЧ Зарплата

При вызове `ВыкВКассу.Записать(Запись)` типовая БСП-логика ВедомостьНаВыплатуЗарплатыВКассу автоматически пытается перезаполнить ТЧ Зарплата по остаткам `РегНакопл.ЗарплатаКВыплате` для шапки `Подразделение`. Поскольку у нас `Подразделение=ЦО`, а реальные начисления сидят на других подразделениях — типовая логика **полностью очищала наши строки**.

**Решение:** установить `ВыкВКассу.ОбменДанными.Загрузка = Истина` ПЕРЕД `Записать()`. Это **блокирует все типовые обработчики**, оставляя ТЧ как есть.

**Как обнаружили:** добавили DBG-вывод в `Комментарий` ведомости: `"DBG6: ТЧСотр=21 кеш=21 добавлено=21 ... ТЧЗарплата.после=21"` (после нашего цикла) — но при чтении ТЧ через query получали 0 строк. Значит после нашего цикла → перед записью → 21 строк, после записи → 0. Это сужает локацию проблемы до типовой логики записи.

### Урок №2: запись БЕЗ проведения

`РежимЗаписиДокумента.Проведение` (даже с `ОбменДанными.Загрузка`) тоже опасен — может срабатывать ОбработкаПроведения с похожей логикой. Сейчас используется `РежимЗаписиДокумента.Запись` — пользователь проводит вручную в UI.

### Урок №3: алиас `КАК В` зарезервирован

В Python тесте `idempotency` запрос `ВЫБРАТЬ КОЛИЧЕСТВО(*) КАК Кол ИЗ Документ.ВКассу КАК В` падал с «Ожидается имя». Буква `В` — оператор `В ИЕРАРХИИ` / `В` (in-list). Использовать `КАК Вед` / `КАК Док`.

### Урок №4: COM-объекты в Python нельзя сравнивать через `str()`

`str(vk.Подразделение)` всегда возвращает `<COMObject <unknown>>`. Нужно:
- Для имени: `vk.Подразделение.Наименование`
- Для пустоты: `vk.Подразделение.Пустая()`
- Для сравнения ссылок: `erp.string(ref.УникальныйИдентификатор())` → UUID-строка

### Урок №5: doctype в `-Files` для db-load-xml

При попытке `-Files "Forms/ФормаДокумента/Ext/Form.xml,Forms/ФормаДокумента/Ext/Form/Module.bsl"` 1С падает с «Неизвестный объект метаданных Document.РаспределениеФ2.Form.ФормаДокумента.Ext». Правильно: `-Files "Forms/ФормаДокумента.xml"` — это метаданное формы, 1С сам подцепляет Ext/* как часть формы.
