### 2.2 `НалогиБухгалтерия` — налоги из zup_1 (НДФЛ + ВС + ЕСВ)

| Реквизит | Тип | Источник в zup_1 |
|---|---|---|
| `Организация` | СправОрганизации | По `КодыОрганизации.СрезПоследних.КодПоЕДРПОУ` |
| `Сотрудник` | СправСотрудники | По `ВзаиморасчетыПоНДФЛ.Сотрудник.Физлицо.КодПоДРФО` через `А_КодПоДРФО` |
| `КодДохода` | СправВидыДоходовНДФЛ | По `ВзаиморасчетыПоНДФЛ.ДоходНДФЛ.Код` |
| `КодДоходаСтрока` | Строка | Код дохода как строка (для парсинга цифр→НДФЛ/ВС) |
| `ТипНалога` | ПеречислениеТипыНалогов | Определяется по `КодДоходаСтрока`: цифры→НДФЛ, иначе→ВоенныйСбор |
| `Налог` | СправНалоги | По `КодНалога` |
| `КодНалогаСтрока` | Строка | Технический код налога |
| `НалогСтатьяДвиженияДенежныхСредств` | СправНалоги | По `КодНалогаСтатьяДенег` (`"ВоенныйСбор"` или `"ЕСВФОТРаботники"`) |
| `Сумма` | Число | Налог или ФОТ (см. ниже) |
| `СуммаНДФЛ` | Число | `ВзаиморасчетыПоНДФЛ.НалогПриход` (для НДФЛ/ВС) |
| `СуммаФОТ` | Число | `ВзносыВФонды.Результат` (для ЕСВ) |
| `СуммаДохода` | Число | `ВзаиморасчетыПоНДФЛ.ДоходПриход` |
| `База` | Число | `ВзносыВФонды.База` |

**Правило заполнения `Сумма`:** `Сумма = СуммаНДФЛ` если СуммаНДФЛ ≠ 0, иначе `Сумма = СуммаФОТ`. Это позволяет одной ТЧ обслуживать и НДФЛ/ВС, и ЕСВ — отличие через `ТипНалога` + `СуммаНДФЛ` vs `СуммаФОТ`.
