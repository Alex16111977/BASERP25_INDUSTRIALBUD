# 19 — Форма2 начальная задолженность по зарплате из zup_2 (`А_НачальнаяЗадолженностьПоЗарплатеФорма2`)

> **🟢 РЕАЛИЗОВАНО + verify PASS 2026-06-02.** Внешняя обработка-«брат» 661/663-варианта (Форма1, из BuhBud).
> Грузит управленческие (Форма2) начальные остатки ЗП из **zup_2** и перезаписывает выбранный документ
> `НачальнаяЗадолженностьПоЗарплате` (ФормаPL=Форма2 → питает `РегистрНакопления.А_ВзаиморасчетыССотрудниками`).

---

## 1. Бизнес-смысл

Полное управленческое обязательство перед ФЛ = **Форма1 + Форма2** (инвариант, сверяется отчётом
«Взаиморасчёты с сотрудниками для баланса»). Форма1 (официальная/бух) — из дока-источника
`ДокНачальнаяЗадолженностьПоЗарплатеБух` (601/663-перенос). Форма2 (управленческая/ЦПХ-остаток) = **Общий − Форма1**.

## 2. ⚠️ Формула «Общего» — НЕ голое сальдо!

```
Общий(ФЛ) = ВзаиморасчетыСРаботниками.Остатки(КонецДня(ДатаОстатков)).СуммаУпрОстаток   (zup_2)
          + Σ(Начисления.Результат − Удержания.Результат_ВСЕ) за месяц(ДатаОстатков)      (zup_2)
            из Документ.НачислениеЗарплатыРаботникам (проведённые)
```

**Смысл:** управленческое сальдо МИНУС свежее начисление месяца = **начальная (перенесённая) задолженность**
(остаток, не объяснённый зарплатой самого месяца). Начисление месяца обычно датировано последним днём
месяца (напр. 30.11 23:59:59), поэтому `Остатки(КонецДня)` его уже включает — а формула его «вычитает».

**Эталон Буша** (ДРФО 2888011632, 30.11.2025): сальдо −35153,00 + (52000 − 16940) = Общий **−93,00**
→ Форма2 = −93,00 − 0,01 = **−93,01**; подразделение **Строительство**; ГруппаУчета «Зарплата (661)»; ОргБух пусто.

### Грабли (стоили расследования)
- ❌ Голое `Остатки(КонецДня)` = ВСЁ накопленное сальдо (Буша −35153, по 63 ФЛ −1,86 млн), **не −93**.
  Регистр `ВзаиморасчетыСРаботниками` в zup_2: единственное измерение `Физлицо`, ресурс `СуммаУпр`
  (в Остатках колонка `СуммаУпрОстаток`) — срезать не по чему.
- Удержания берём **ВСЕ** (включая «Утримано по бухгалтерії», код 00001). Это ОТЛИЧАЕТСЯ от
  `ЗаполнитьНачисленияУпризЗуп2` (там код 00001 EXCLUDE'ится для НачисленияУпр) — см. [04](04_zapolnenie_nachisleniy.md).
- Источник чтения zup_2 (`Документ.НачислениеЗарплатыРаботникам.Начисления/Удержания`, по месяцу даты) —
  тот же паттерн, что `Documents/А_ОтражениеЗПпоКазне/Ext/ObjectModule.bsl::ЗаполнитьНачисленияУпризЗуп2`.

## 3. Резолв и подразделение

- ФЛ zup_2↔ERP: по `КодПоДРФО`. Сотрудник: первый по ФЛ (приоритет `ГоловнаяОрганизация`=упр.орг).
- Подразделение: первая `ВедомостьНаВыплатуЗарплатыВКассу` (Проведён) с (ДатаОстатков+1 день),
  ТЧ `А_РасшифровкаВыплатыЗарплатаПоФизлицам.Подразделение` → `.А_Подразделение` (СтрПредпр) → подъём
  по `Родитель` до корня → **реверс** ПодрОрг (Владелец=упр.орг, `.А_Подразделение`=корень). Fallback корень «Строительство».
- ОргБухгалтерия у Форма2 **НЕ заполняется** (только у Форма1).
