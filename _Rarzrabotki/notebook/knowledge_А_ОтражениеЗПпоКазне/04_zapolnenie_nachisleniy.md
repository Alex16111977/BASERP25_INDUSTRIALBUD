# 04. Блок 3 — Заполнение начислений и НДФЛ

> Главные процедуры:
> - `ЗаполнитьНачисленияУпризЗуп2()` (BSL 772-913) — загрузка ТЧ `НачисленияУпр` + `УдержанияУпр` из zup_2
> - `ЗаполнитьДляОтражения_ДокументОтражениеЗарплатыВФинансовомУчете()` (BSL 933-955) — entry point для 5 процедур `_ОтрЗП_*`

---

## 1. Часть А: Загрузка из zup_2 (управленческий ЗУП)

### 1.1 Назначение

Заполнить 2 ТЧ из управленческого ЗУП:
- **`НачисленияУпр`** ← `Документ.НачислениеЗарплатыРаботникам.Начисления` (документы за месяц + Проведен + Результат ≠ 0)
- **`УдержанияУпр`** ← `Документ.НачислениеЗарплатыРаботникам.Удержания` (БЕЗ `ВидРасчета.Код = "00001"` — это «Утримано по бухгалтерії», техническая запись)

Connection: `Srvr="localhost";Ref="zup2";Usr="cfo";Pwd="2442"`.

### 1.2 Структура zup_2 (discovery)

**Документ.НачислениеЗарплатыРаботникам:**
- Реквизиты: `ПериодРегистрации`, `Подразделение`, `Комментарий`, `Ответственный`, `КраткийСоставДокумента`, `ПоВременнойСхемеМотивации`, `ВидСхемыМотивации`
- ТЧ `Начисления`: `ВидРасчета`, `ДатаНачала`, `ДатаОкончания`, `Показатель1..6`, `Подразделение`, `Результат`, `ОтработаноДней`, `ОтработаноЧасов`, `Физлицо`, `Сотрудник`, `Авторасчет`
- ТЧ `Удержания`: тот же набор + без `Сотрудник`
- ТЧ `ПогашениеЗаймов`: `ФизЛицо`, `ДоговорЗайма`, `НачисленоПроцентов`, `ПогашеноПроцентов`, `ПогашеноЗайма` (не используется)

### 1.3 Локальный кеш ФизЛица (ERP-side)

Перед COM-запросами строится кеш `КодПоДРФО → СправочникСсылка.ФизическиеЛица` в ERP:

```bsl
СоответствиеФизЛиц = Новый Соответствие;
ЗапросФЛ = Новый Запрос;
ЗапросФЛ.Текст =
"ВЫБРАТЬ ФизическиеЛица.Ссылка КАК Ссылка, ФизическиеЛица.КодПоДРФО КАК КодПоДРФО
|ИЗ Справочник.ФизическиеЛица КАК ФизическиеЛица
|ГДЕ ФизическиеЛица.КодПоДРФО <> """"";
ВыборкаФЛ = ЗапросФЛ.Выполнить().Выбрать();
Пока ВыборкаФЛ.Следующий() Цикл
    КодДРФО = СокрЛП(ВыборкаФЛ.КодПоДРФО);
    Если НЕ ПустаяСтрока(КодДРФО) Тогда
        СоответствиеФизЛиц.Вставить(КодДРФО, ВыборкаФЛ.Ссылка);
    КонецЕсли;
КонецЦикла;
```

Это критично для производительности — заменяет N COM-запросов на 1 локальный SQL.

### 1.4 Запрос к zup_2.НачислениеЗарплатыРаботникам.Начисления

```sql
ВЫБРАТЬ
    Начисления.Физлицо.КодПоДРФО КАК КодПоДРФО,
    Начисления.Физлицо.Наименование КАК ФизЛицоНаименование,
    Начисления.ВидРасчета.Наименование КАК ВидРасчета,
    Начисления.ВидРасчета.Код КАК КодВидРасчета,
    Начисления.Результат КАК Сумма
ИЗ
    Документ.НачислениеЗарплатыРаботникам.Начисления КАК Начисления
ГДЕ
    Начисления.Ссылка.Дата МЕЖДУ &НачалоПериода И &КонецПериода
    И Начисления.Ссылка.Проведен = ИСТИНА
    И Начисления.Результат <> 0
```

Запрос к ТЧ Удержания — аналогичный, но с дополнительным фильтром `И Удержания.ВидРасчета.Код <> &КодВидУтрБух` (значение `"00001"`).

### 1.5 Прямой обход результата (без сериализации)

Поскольку из zup_2 берутся только примитивные поля (КодПоДРФО строка, Наименование строка, Результат число) — можно обходить COM-result напрямую через `.Выбрать().Следующий()` и заполнять ТЧ:

```bsl
ВыборкаНач = ЗапросНач.Выполнить().Выбрать();
Пока ВыборкаНач.Следующий() Цикл
    КодДРФО = СокрЛП("" + ВыборкаНач.КодПоДРФО);
    ФизЛицо = СоответствиеФизЛиц[КодДРФО];
    Если ФизЛицо = Неопределено Тогда
        ФизЛицо = Справочники.ФизическиеЛица.ПустаяСсылка();
        КолНачБезФизЛица = КолНачБезФизЛица + 1;
    КонецЕсли;

    НоваяСтрока = НачисленияУпр.Добавить();
    НоваяСтрока.ФизЛицо       = ФизЛицо;
    НоваяСтрока.ФИО           = СокрЛП("" + ВыборкаНач.ФизЛицоНаименование);
    НоваяСтрока.Сумма         = ВыборкаНач.Сумма;
    НоваяСтрока.ВидРасчета    = СокрЛП("" + ВыборкаНач.ВидРасчета);
    НоваяСтрока.КодВидРасчета = СокрЛП("" + ВыборкаНач.КодВидРасчета);
КонецЦикла;
```

Diagnostic:
- `"НачисленияУпр: N рядків без ФізОсоби (заповнено лише ФИО)"` (если КодПоДРФО есть, но не маппится — заполнено только текстовое ФИО)

## 2. Часть Б: Заполнение НачисленнаяЗП и НачисленныйНДФЛ (5 процедур _ОтрЗП_*)

### 2.1 Логика на высоком уровне

Каркас — `ЗаполнитьДляОтражения_ДокументОтражениеЗарплатыВФинансовомУчете` (BSL 933-955):

```bsl
Процедура ЗаполнитьДляОтражения_ДокументОтражениеЗарплатыВФинансовомУчете() Экспорт
    Если НЕ ЗначениеЗаполнено(Дата) Тогда
        ВызватьИсключение "У документі не заповнено Дата!";
    КонецЕсли;

    Справочные = _ОтрЗП_ПодготовитьСправочныеДанные();

    НачисленнаяЗарплатаИВзносыПоФизлицам.Очистить();
    НачисленныйНДФЛ.Очистить();

    // Op 1: НалогиБухгалтерия → НачЗП.ВзносыВсего (ФОТ/ЕСВ)
    _ОтрЗП_ЗаполнитьНачисленияИзНалогов(Справочные);

    // Op 2: NET из НачисленияУпр+СуммаНДФЛ → НачЗП.Сумма
    _ОтрЗП_ЗаполнитьНачисленияЗП(Справочные);

    // Op 3: НалогиБухгалтерия.СуммаНДФЛ → НачисленныйНДФЛ
    _ОтрЗП_ЗаполнитьНДФЛИзНалогов(Справочные);
КонецПроцедуры
```

### 2.2 `_ОтрЗП_ПодготовитьСправочныеДанные` (BSL 964-1033)

Строит структуру `Справочные`, которая используется во всех 3-х Op:

| Ключ | Тип | Что внутри |
|---|---|---|
| `ФизЛица` | Соответствие | Сотрудник → ФизическоеЛицо (из ТЧ РаспределениеКазна + НалогиБухгалтерия) |
| `СотрудникПоФизЛицу` | Соответствие | ФизическоеЛицо → Сотрудник (обратная мапа для Op 2) |
| `РаспредПоПодразделениям` | 3-уровневое Соответствие | Сотр→Налог→Структура(Подразделения, Итого), Подразделения = Соответствие(Подр→Структура(Сумма, СпособОтражения)) |
| `РаспредНалоговПоСотрудникам` | Соответствие | Сотр→Структура(Подразделения, Итого) — только для рядков с СуммаНалогов>0 |
| `NETПоФизЛицу` | Соответствие | ФизЛицо→Сумма (сумма НачисленияУпр.Сумма по ФизЛица) |
| `СуммаНДФЛПоФизЛицу` | Соответствие | ФизЛицо→Сумма (НДФЛ+ВС из НалогиБухгалтерия) — для валоризации gross |
| `ГруппаУчетаЗарплата` | СправСсылка | Константа |
| `ВидОперацииНачислено` | Перечисление | `НачисленоДоход` |
| `ВидОперацииВоенныйСбор` | Перечисление | `ВоенныйСбор` |
| `ВидОперацииНДФЛ` | Перечисление | `НДФЛ` |
| `ТипНалогаВС` | Перечисление | `ВоенныйСбор` |
| `ТипНалогаНДФЛ` | Перечисление | `НДФЛ` |
| `СпособОтраженияПоУмолчанию` | СправСсылка | «Зарплата производственного персонала» |
| `НалогЕСВФОТ` | СправСсылка | «ЕСВ ФОТ» |
| `КлючБазовые` | Строка | `"БазовыеНачисления"` — псевдо-ключ для базового распределения |
| `ПодразделениеЦО` | СправСсылка | СтруктураПредприятия.НайтиПоНаименованию/КодПоКоду «ЦО» — fallback |

### 2.3 Op 1: `_ОтрЗП_ЗаполнитьНачисленияИзНалогов` (BSL 1225-1267)

**Назначение:** ФОТ/ЕСВ из НалогиБухгалтерия → строки `НачисленнаяЗПпоФизлицам` с заполненным `ВзносыВсего` (не `Сумма`).

```
Для каждой строки НалогиБухгалтерия:
  Если СуммаФОТ = 0 Тогда Продолжить.  // только ФОТ-строки

  СуммаДляРаспределения = СтрокаНалога.СуммаФОТ;
  НалогДляПоиска = СтрокаНалога.НалогСтатьяДвиженияДенежныхСредств;

  ДанныеНалога = _ОтрЗП_ПолучитьДанныеРаспределения(Сотрудник, НалогДляПоиска, Справочные);
  // FALLBACK 1: если по конкретному налогу нет → берём БазовыеНачисления распределение
  // FALLBACK 2: если даже базы нет → 1 строка с ПодразделениемЦО

  // Распределение пропорционально по подразделениям через
  _ОтрЗП_РаспределитьПоПодразделениям(СтрокаНалога, СуммаДляРаспределения, ДанныеНалога, ЭтоФОТ=Истина, Справочные);
```

### 2.4 Op 2: `_ОтрЗП_ЗаполнитьНачисленияЗП` (BSL 1345-1534) — самая сложная

**Назначение:** gross-начисления → строки `НачисленнаяЗПпоФизлицам` с заполненной `Сумма`.

**Алгоритм:**

```
ШАГ 2a — ФизОсобы из НачисленияУпр (есть запись в zup_2):
  Для каждой записи NETПоФизЛицу (NET = сумма НачисленияУпр.Сумма по ФизЛица):
    НДФЛдляФЛ = СуммаНДФЛПоФизЛицу[ФизЛицо]
    Если NET=0 И НДФЛдляФЛ=0 → пропустить
    Пометить ФизЛицо как «обработана»

    Найти Сотрудника по ФизЛица (через СотрудникПоФизЛицу)
    Получить РаспредПоПодразделениям[Сотрудник][КлючБазовые]

    --- Распределение NET ---
    Если нет распределения → 1 строка на «ЦО»
    Иначе → пропорциональный split NET по подразделениям

    --- Отдельные строки НДФЛ/ВС (НДФЛдляФЛ) ---
    Найти НалогКлюч в РаспредПоПодразделениям[Сотрудник]:
      пропускаем КлючБазовые и НалогЕСВФОТ
    Если есть → распределить НДФЛдляФЛ по тому же распределению
    Если нет ДанныхСотрудника → fallback на «ЦО»

ШАГ 2b — ФизОсобы из РаспределениеКазна, НЕ обработанные в 2a:
  Аналогично, но Сумма берётся из РаспределениеКазна.СуммаНачисления (агрегированно по Сотруднику)
```

⚠️ **Бухгалтерская логика валоризации:**

```
GROSS (валовая) = NET (чистое) + НДФЛ + ВС
```

NET — это то, что человек получает на руки (из НачисленияУпр или РаспределениеКазна).
НДФЛ + ВС — то, что удержано из gross в пользу бюджета (из НалогиБухгалтерия.СуммаНДФЛ).

Раньше эта валоризация делалась слиянием в одну сумму, но **с 2026-05 разделено** на 2 строки:
- Чистый NET (с Способом «Зарплата производственного персонала» или из СтатьяДДС)
- Отдельно НДФЛ+ВС (с Способом из НалогиБухгалтерия)

Это позволяет правильно показать в бухгалтерском учёте раздельно: «Начислено к выплате» vs «Удержано НДФЛ/ВС».

### 2.5 Op 3: `_ОтрЗП_ЗаполнитьНДФЛИзНалогов` (BSL 1593-1652)

**Назначение:** НДФЛ/ВС → ТЧ `НачисленныйНДФЛ`.

```
Для каждой строки НалогиБухгалтерия:
  Если СуммаНДФЛ = 0 Тогда Продолжить.  // только НДФЛ/ВС-строки (НЕ ЕСВ!)

  Если ТипНалога = ВС → ВидОперации=ВоенныйСбор, ТипНалога=ВС
  Иначе → ВидОперации=НДФЛ, ТипНалога=НДФЛ

  ДанныеНалога = _ОтрЗП_ПолучитьДанныеРаспределения(...)

  Если нет распределения → 1 строка без подразделения
  Иначе → пропорциональный split СуммаНДФЛ по подразделениям с заполнением:
    .ВидОперации, .ТипНалога, .КодДохода, .Сумма, .Подразделение, .СпособОтражения
```

⚠️ **Критичная фильтрация:** `СуммаНДФЛ ≠ 0` (НЕ `Сумма ≠ 0`!) — иначе ЕСВ-строки с `Сумма = СуммаФОТ` через fallback ошибочно попадают в НДФЛ.

### 2.6 `_ОтрЗП_ПолучитьДанныеРаспределения` (BSL 1677-1715) — 3-уровневый fallback

```
1. Точный налог (НалогДляПоиска) — если найдено в РаспредПоПодразделениям[Сотр][Налог], вернуть
2. ЕСВ ФОТ — если НалогДляПоиска.Имя начинается с "ЕСВ ФОТ", искать по ключу НалогЕСВФОТ
3. БазовыеНачисления (КлючБазовые) — последний fallback
4. Если ничего — вернуть Неопределено (вызывающий код делает 1 строку без подразделения)
```

## 3. Поток данных Блока 3

```
[zup_2.НачислениеЗПР]──▶ НачисленияУпр (gross/NET)
                       └▶ УдержанияУпр (штрафы)

[РаспределениеКазна]──▶ пропорции по подразделениям
                     └▶ Сумма (fallback для людей без NET в zup_2)
                     └▶ СуммаНалогов (для распределения НДФЛ по подразделениям)

[НалогиБухгалтерия]──▶ СуммаФОТ ─Op1─▶ НачЗП.ВзносыВсего
                    └▶ СуммаНДФЛ ─Op3─▶ НачисленныйНДФЛ
                    └▶ СуммаНДФЛ (валоризация) ─Op2─▶ НачЗП.Сумма (отдельная строка)
```
