## Як зроблено

Свій генератор xlsx (Office Open XML) у **модулі менеджера** документа — `ДвоичныеДанныеКнигиExcel(Модель)`;
модель аркуша будує модуль об'єкта — `МодельКнигиExcel()`, експорт `ДвоичныеДанныеExcel()`. Причина: платформа
8.3.20 при `ТабличныйДокумент.Записать(XLSX)` не пише формул, не переносить закріплення, згорнутість груп і розмір
вікна приміток, числа з `ЧРГ` пише текстом.

**Макет** (як директорський «Финансовый_отчет Производства»): аркуш «дд.мм.гггг»; рядки 1–3 приховані; шапка 4–5
(тексти, об'єднання, кольори #C3D69B/#003F2F, примітки E5/F5/H5), закріплено до рядка 5; рядок 6 — роздільник;
блок підрозділу (порядок ТЧ «Підрозділи»): об'єкт (A:B, #92CDDC) → сума (#D7E4BD) → договори (рівень групування 1)
→ «Итого» (#D6E5CB) → порожній рядок. Ширини A 42,16 / B 34,5 / C–F, H–K 18,5 / G 20,33. Формат
`#,##0.00_ ;[Red]\-#,##0.00\ ` (у договорах нуль порожній).

**Формули** (кожна з кешем значення документа; `fullCalcOnLoad`):

| Де | Формула |
|---|---|
| G договору, «Итого» | `=E−F` |
| I | `=-ROUND(MIN(утримання,MAX(0,G+H)),2)` — лише коли в регістрі є сума утримання |
| J | за `ПравилоНДС`: `ROUND(-H/6,2)`; для P — `ROUND(-(H-MIN(A_ост,H*p))/6,2)`; `ОтЗадолженности` — `ROUND(-MAX(0,G)/6,2)`; `НеУчитывать` — порожньо |
| K | Z `ROUND(MAX(0,G+I+J+H*(1-p)),2)`; V `ROUND(MAX(0,(E+H)*(1-p)+J-F+I),2)`; P `ROUND(MAX(0,G+A_ост+H-MIN(A_ост,H*p)+J+I),2)`; ТолькоРучной — порожньо |
| Сума блоку | `=SUM(перший:останній договір)`; об'єкт і «Итого» — посилання на рядок суми |

`A_ост` — число на дату розрахунку (новий реквізит `Расчет.ОстатокАванса`).

**Примітки договору**: `<вид> <номер> від дд.мм.гггг — 1 234,56[ (не проведено)| (не підписано)]`, «Итого: …».
Скорочення видів: «Реаліз. послуг з переробки», «Реаліз. товарів і послуг», «Надання вир. послуг», «Реаліз. буд. робіт»,
«Надходження на б/р». Для договорів зі строком оплати оплати гасять акти за датою (FIFO); до неоплаченого акта —
«— оплата до дд.мм.гггг» або «— прострочено N дн. (строк …)»; без дати підписання — «строк оплати: N дн. після …».
Вікно примітки — під довжину тексту.

## Доповнення 29.09 (друга половина дня): управління складом звіту, умови договору, ПН

Рішення користувача: умови і статус — у регістрі параметрів; статус + авто-правило; реєстрація ПН — з
документа «Реєстрація вхідного податкового документа» (проведений = зареєстровано).

- **Регістр**: +`УсловияДоговора` Строка(1000), +`СтатусВОтчете` Строка(10): «» авто / «Всегда» / «Закрыт»;
  ресурс `НеПоказыватьВОтчете` прибрано (ООН 2022-DEC-178 і «Договір МД ООН» → «Закрыт»). `ПравилоНДС` +
  значення `ПослеРегистрацииПН`.
- **Авто-правило**: договір у звіті, якщо |G| ≥ 1, |H| ≥ 1, незачтений аванс ≥ 1, рух у місяці розрахунку або ручний
  рядок «Договори додатково»; інакше не показується — К26 (кількість, E/F, перші 3). «Закрыт» — К24; якщо
  E + H − F ≠ 0 — К25 (Попередження). Підрозділ, у якого все сховано, лишається нульовим рядком.
- **План-факт казни**: при розрахунку підрозділи `РН.БюджетыНаМесяц` (напрям «Производство», місяць розрахунку) без
  «Главный офис»/«Цех металлоконструкций» додаються увімкненими (П35); вимкнені вручну не чіпаються. Блок без договорів
  у Excel виводиться; на рядку об'єкта — примітка план/факт надходжень, витрат, маржі.
- **Підпис блоку**: «Підрозділ (контрагент взаєморозрахунків; …)».
- **Примітка договору (A)**: № і дата (з довідника), організація → контрагент, сума угоди, строк оплати, аванс/зачёт,
  утримання, правило ПДВ, ПН (к-сть, ПДВ, зареєстровано / не зареєстровано / немає даних), текст умов.
- **ПН**: `Документ.НалоговаяНакладная` (основа = акт); реєстрація — проведена `РегистрацияВходящегоНалоговогоДокумента`
  організації-покупця (збіг ЄДРПОУ контрагента з `Организации.КодПоЕДРПОУ`) з тією ж датою і сумою ПДВ; дата —
  `ДатаВключенияВЕдиныйРеестрНалоговыхНакладных`. Зовнішні покупці — «регистрация: нет данных в 1С». На 25.09: 145 ПН,
  73 внутрішні зареєстровані (+3 без дати), 3 внутрішні не зареєстровані (напр. СТ00-НАв000000003 від 13.08 — 37 541,43).
- **ПДВ `ПослеРегистрацииПН`**: J = −Σ min(ПДВ ПН (або акт/6 без ПН); неоплачений залишок акта) по актах з
  незареєстрованою ПН; оплати гасять акти за датою. У Excel J — значення без формули.
- Не зроблено: контроль строку реєстрації ПН (К27) — лише статус у примітках.
