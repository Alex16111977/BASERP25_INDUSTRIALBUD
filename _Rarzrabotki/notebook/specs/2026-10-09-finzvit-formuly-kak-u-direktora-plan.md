### Task 3: Код — форма формули K директора

**Files:** Modify `ObjectModule.bsl`, функція `ФормулаКолонкиДоговора`, гілка `ИначеЕсли Вариант = "ЗачетПредоплаты"` колонки K.

- [ ] Перед загальною формою:
```bsl
		ИначеЕсли Вариант = "ЗачетПредоплаты" Тогда
			// Форма директора (Кривий Ріг: «((E+H)*0,85+J−F+1194270)»): без дати заліку й поки залишок авансу
			// покриває p % поданих актів, G + A_ост + H − H×p = (E + H)×(1 − p) − F + A_факт, де A_факт = A_ост + E×p.
			ДатаЗачетаДиет = ЗначениеЗаполнено(ПараметрыДог.ДатаЗачетаПредоплаты)
				И ПараметрыДог.ДатаЗачетаПредоплаты <= МоментРасчета();
			Если НЕ ДатаЗачетаДиет И Доля > 0 И Доля < 1 И СтрокаРасчета.ОстатокАванса > 0
				И СтрокаРасчета.ОстатокАванса >= СтрокаРасчета.АктыПоданные * Доля Тогда
				АвансФакт = ЧислоФормулы(Окр(СтрокаРасчета.ОстатокАванса + СтрокаРасчета.ВыполненныеРаботы * Доля, 2));
				Возврат "ROUND(MAX(0,(" + E + "+" + H + ")*" + ЧислоФормулы(1 - Доля) + "+" + J + "-" + F + "+"
					+ АвансФакт + "+" + I + "),2)";
			КонецЕсли;
			Сире = ... (без змін)
```
