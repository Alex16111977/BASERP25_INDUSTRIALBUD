Завантаження виконання робіт

Зворотний хід звіту «Звіт з виконання робіт по домах і модулях»: вивантажений у Excel звіт з правками виконроба завантажується назад у документи «Виконання робіт модулів». За один раз — один файл: один проєкт на одну дату, документ на кожен дім.

Де відкрити
Усі функції → Обробки → Завантаження виконання робіт
Джерело даних
звіт «Звіт з виконання робіт по домах і модулях», .xlsx
Що створює
документи «Виконання робіт модулів»

Крок за кроком

Порядок роботи

  1. Сформувати звіт. Зі списку документів «Виконання робіт модулів» — команда відкриття звіту по поточному рядку (структура собівартості береться з документа, період — з початку місяця по дату документа). Зберегти як .xlsx. Придатні обидва варіанти звіту — короткий і повний.
  2. Віддати файл виконробу. Він править лише клітинки відсотків. Не додавати й не видаляти рядки та колонки, не перейменовувати роботи: обробка звіряє назви зі складом робіт структури собівартості.
  3. Закрити файл в Excel перед завантаженням. Відкритий файл дає «Помилка спільного доступу до файлу».
  4. Обрати файл у формі обробки. Шапка заповнюється сама з файлу: структура собівартості й дата. Дату змінити, якщо вантажимо іншим числом.
  5. Розшифрувати файл → перевірити три матриці → Створити документи. Прапорець «Провести» ввімкнено за замовчуванням.

Три матриці та таблиця проблем

БлокУ клітинціЗаливка
БУДЕ ЗАВАНТАЖЕНО (з файлу) відсоток з файлу; 0 — порожньо як у звіті: 100 % зелене, 1…99 жовте, проблемна клітинка червона
БУЛО В БАЗІ на <дата> що зараз у документах на цю дату те саме, без червоного
ЗМІНИ +20, −50; порожньо — без змін зростання зелене, відкат червоний
ПРОБЛЕМИ (N) Робота · Дім · М · У файлі · Що не так з'являється лише за наявності помилок

У блоці «ЗМІНИ» лишаються тільки роботи зі змінами — решта рядків прибрана. Порожня матриця означає, що завантаження нічого не змінить (так буває, коли той самий файл вантажать удруге). Лічильники — у заголовку блоку, підсумок по документах — у рядку під кнопками.

«БУЛО В БАЗІ» згорнуто за замовчуванням: розгорнути, коли треба звірити очима повну картину.

Людський фактор

Як читаються клітинки

Файл заповнює людина, тому кожне відхилення називається явно. Принцип: «не розпізналося» ніколи не дорівнює нулю — інакше години мовчки зникають з документа.

Помилки блокують створення документів. Виправити файл і розшифрувати ще раз — правильний шлях. Прапорець «Завантажити попри помилки» пропускає проблемні клітинки й вантажить решту: це усвідомлений обхід, а не норма. Відкати не блокують — вони видні червоним у матриці «ЗМІНИ».

Запис

Що потрапляє в документи

  • Документ на кожен дім (дім = підрозділ). Повторне завантаження того самого дня оновлює ті самі документи, а не плодить нові.
  • Кількість модулів у документі береться зі структури собівартості; рядок = робота × номер модуля. У проєкті «30 м» на кожну роботу два рядки — М1 і М2.
  • Планові години на модуль = норма роботи поділена на модулі (не на доми): дім при 100 % по всіх модулях набирає повну норму.
  • Пишуться всі роботи файлу, включно з 0 % — це повний знімок. Без явного нуля обнулена робота не зменшить виконання у звітах.
  • Усі доми записуються однією операцією: збій на будь-якому домі скасовує все, напівзавантаженого знімка не буває.
  • Коментар «Завантажено з файлу …» ставиться лише новому документу — ваш текст у наявному не затирається.

Контроль після завантаження 12.08.2026: «15 м» — 6 документів по 44 рядки, «30 м» — 7 документів по 88 рядків (44 роботи × 2 модулі), усі проведені.

Граблі

Що знати заздалегідь

СитуаціяЩо робити
Дата у файлі ≠ дата завантаження Обробка підставляє дату звіту з файлу. Вантажимо іншим числом — змінити «На дату» до розшифровки: від неї залежить і «БУЛО В БАЗІ», і дата документів.
Перезавантаження того самого дня «БУЛО» береться на дату включно, тобто з документів цього ж дня — «ЗМІНИ» показують саме те, що правиться зараз, а не тижневий приріст.
Робота без норми в структурі собівартості Відсоток запишеться, але годин не додасть — виконання у звіті не зміниться. Причина не в обробці: у складі робіт не заповнена кількість.
Файл сформовано для іншого проєкту Розшифровка зупиниться: «У файлі модулів у домі N, а в структурі собівартості M». Звірити структуру собівартості в шапці файлу.
Дім є у файлі, але не знайдений у базі Доми беруться з наявних документів цього проєкту (за номером після «№»). Для нового дому спершу має з'явитися хоча б один документ.
Пізніші знімки того ж дому Документ сам попередить, що їх треба перепровести: виконання пізнього знімка рахується від раннього.
