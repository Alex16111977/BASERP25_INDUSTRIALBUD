# 05. Постобработки: Етап/Категорія для факт-материалов

После выполнения запроса `ПолучитьДанные` мутирует ТЗ двумя процедурами (порядок важен):
`ЗаполнитьЭтапФактМатериалов(ТЗ, СС)` → `ЗаполнитьПланНаФакт(ТЗ)` (см. 04).

## ЗаполнитьЭтапФактМатериалов — зачем

Факт-закупки (ветка 5) не знают этапа: в `РН.СебестоимостьТоваров` нет ни Етапа, ни привязки
к плану. Разнос делается через **общую назву номенклатуры**: у плановой строки
`Комплектующие` есть и `Номенклатура.А_ОбщееНазваниеНоменклатуры`, и `Этап` — строим карту
и применяем её к факту.

## МаппингОбщееНазваниеЭтап(СС) — карта «имя общей назвы → {Етап, Категорія}»

```bsl
ВЫБРАТЬ К.Номенклатура.А_ОбщееНазваниеНоменклатуры.Наименование КАК ОбщееНазвание,
        К.Этап,
        ВЫБОР КОГДА К.Этап.Наименование ПОДОБНО "%Монтаж%" ТОГДА "Монтаж" ИНАЧЕ "Виробництво" КОНЕЦ КАК Категория
ИЗ Справочник.А_СтруктураСебестоимости.Комплектующие КАК К
ГДЕ К.Ссылка.Наименование = &Имя  // ← по ИМЕНИ СС, не по ссылке!
  И <общая назва заполнена> И <этап заполнен>
```

Ключевые решения:
- **Ключ карты — нормализованное ИМЯ** (`СокрЛП`) общей назвы, не ссылка: в справочнике
  `А_ОбщиеНазванияНоменклатуры` есть дубли карточек с одним именем; по ссылке план и факт
  могут указывать на разные карточки и не сойтись.
- **Отбор по ИМЕНИ СС** (`К.Ссылка.Наименование = &Имя`): дубли карточек самой СС с одним
  именем объединяются в одну карту.
- При нескольких этапах одного имени берётся МАКСИМУМ (`Строка(Этап)` сравнение) — детерминизм.
- Категорія считается ТЕМ ЖЕ выражением, что у плана (`ПОДОБНО "%Монтаж%"`) — план и факт
  гарантированно попадают в одну категорию.

## Применение к строкам факта

Для строк `Блок="2. Матеріали"` с пустым Етапом и Аналитикой типа Номенклатура:
`ОбщееНазвание = Аналитика.А_ОбщееНазваниеНоменклатуры` → ключ → из карты ставятся
`Этап` И `Категория`. Несопоставленные строки (нет общей назвы или её нет в плане) остаются
с пустым Етапом и категорией-плейсхолдером «Виробництво».

## Пустые уровни в выводе

У строк труда пустые ОбщееНазвание/Единица/Документ, у несопоставленных материалов — Етап:
СКД рисует пустые узлы-строки (без подписи) — это норма архитектуры, не дефект.
Аналогично «Виконання» и факт-табель живут на РАЗНЫХ строках одной группировки
(Работа vs ФизЛицо в Аналитике) — сходятся только на итогах уровня Категорія/Підрозділ.
