# 03. Показатели и формулы итогов

Колонки отчёта = только РЕСУРСЫ (числа). Итоги на группировках считает СКД по `totalField`
из Template.xml — формулы ниже. На строках грейна те же выражения посчитаны запросом.

**С 16.07.2026 ПЛАН = НОРМА × КоличествоДомов**: нормы ТЧ СС (`Работы.Количество/Сумма`,
`Комплектующие.Количество/Сумма`) заносятся НА ОДИН ДОМ; ветки плана умножают их на
`ВТ_СС.Домов` = `ВЫБОР КОГДА СС.КоличествоДомов > 0 ТОГДА СС.КоличествоДомов ИНАЧЕ 1 КОНЕЦ`
(IRS15=6, IRS30=7, все прочие СС=1). Умножаются ПланЧасы, ПланГрн (работ и материалов), ПланКол;
все производные (Отклонение*/Процент*/ПланНаФакт/Прогноз) подхватывают множитель автоматически.
Факт и ЕV НЕ умножаются (собираются по иерархии/регистрам как есть).

**С 16.07.2026 (2) план труда — ТОЛЬКО «чол/год»**: строки ТЧ Работы с иной единицей («шт»)
исключаются из отчёта ЦЕЛИКОМ (решение пользователя: ни в часы, ни в грн — бухгалтер сравнивает
часы с часами). Фильтр по НАИМЕНОВАНИЮ единицы (`СокрЛП(...) = "чол/год"`, не по ссылке — дубли
карточек единиц). Живые данные: единиц в ТЧ всего две («чол/год», «шт»), пустых нет; шт-строки
были у ВСЕХ СС (ОРІЛЬ 4 шт/20 800 грн, ВООЗ 759 шт/265 650 грн, IRS по 1 шт/6 500 грн на дом).
⚠️ Работа может встречаться и в «чол/год», и в «шт» — критерий строго ЕДИНИЦА, не название
(у ВООЗ «монжа кондиціонеру» заведена в чол/год 5 год — легитимно остаётся).

## Группа «Години» (труд)

| Колонка (титул укр) | Поле | Формула итога |
|---|---|---|
| План, год | ПланЧасы | `Сумма(ПланЧасы)` |
| Факт, год | ФактЧасы | `Сумма(ФактЧасы)` (табель) |
| Відхилення, год | ОтклонениеЧасы | `Сумма(ФактЧасы) - Сумма(ПланЧасы)` |
| % вик. (год) | ПроцентЧасы | `ФактЧасы/ПланЧасы*100` (0 при плане 0), формат ЧДЦ=1 |

## Группа «Виконання» (EV из документов А_ВыполнениеРаботМодулей)

| Колонка | Поле | Формула итога |
|---|---|---|
| Виконання, год | ВиконанняЧасы | `Сумма(ВиконанняЧасы)` — дельта-обороты РН за период |
| Відхилення табель-виконання, год | ОтклонениеВиконання | `Сумма(ФактЧасы) - Сумма(ВиконанняЧасы)` |
| % виконання | ПроцентВиконання | `Сумма(ВиконанняЧасы)/Сумма(ПланЧасы)*100`, ЧДЦ=1 |
| **% виконання до факту** | **ПроцентВиконанняФакт** | `ВЫБОР КОГДА Сумма(ФактЧасы)=0 ТОГДА 0 ИНАЧЕ Сумма(ВиконанняЧасы)/Сумма(ФактЧасы)*100 КОНЕЦ`, ЧДЦ=1 (добавлен 25.07.2026) |

Семантика: Виконання = «заработанные» часы (готовность×план). Відхилення>0 — табель опережает
готовность (переработка/непроизводительное время); <0 — готовность без табеля.

**«% виконання до факту» (EV/AC)** — процентный аналог «Відхилення табель-виконання»: сколько часов
освоено на каждый отработанный час табеля. В терминах EVM это **CPI по труду** (продуктивність):
100% — освоено ровно столько, сколько отработано; <100% — часы потрачены сверх освоенного
(перевитрата праці); >100% — освоено больше отработанного. Связь с абсолютным показателем:
`% виконання до факту + Відхилення/Факт×100 = 100`. Отличать от «% виконання» (Виконання/**План**) —
тот меряет готовность к плану, новый — эффективность к затраченному. Замер 25.07.2026: «МД IRS 2026»
EV 1 066,81 / Факт 1 299,00 = **82,1%**. Включён в вариант «Звіт з виконання СС».

## Группа «Кількість» (материалы; СКРЫТА из вывода по умолчанию с 06.07.2026)

Поля ПланКол/ФактКол/ОтклонениеКол/ПроцентКол и их totalField в схеме ЕСТЬ (данные считаются),
но исключены из `selection` — пользователь может вернуть их через «Настройки». Не удалять
из схемы: на них опирается расчёт «План на факт».

## Группа «Грн» (ТОЛЬКО материалы — с вечера 16.07.2026)

Блок «1. Праця» живёт ТОЛЬКО в часах: ПланГрн работ = 0, ветка ЗП/ФОТ (ОЗФУ) УДАЛЕНА.
Все грн-колонки (План/Факт/Відхилення/%/Прогноз) — исключительно материалы.

| Колонка | Поле | Формула итога |
|---|---|---|
| План, грн | ПланГрн | `Сумма(ПланГрн)` (только материалы) |
| Факт, грн | ФактГрн | `Сумма(ФактГрн)` (только закупки) |
| Відхилення, грн | ОтклонениеГрн | `Сумма(ФактГрн) - Сумма(ПланГрн)` |
| % вик. (грн) | ПроцентГрн | `ФактГрн/ПланГрн*100`, ЧДЦ=1 |

## Группа «Прогноз» (EAC, только материалы)

| Колонка | Поле | Формула итога |
|---|---|---|
| План на факт, грн | ПланНаФактГрн | `Сумма(ПланНаФактГрн)` — живёт ТОЛЬКО на синтетических строках (BSL) |
| Прогноз, грн | ПрогнозГрн | `Сумма(ФактГрн) + Сумма(ПланНаФактГрн)` |
| Відхилення прогнозу, грн | ОтклонениеПрогнозГрн | `Сумма(ФактГрн) + Сумма(ПланНаФактГрн) - Сумма(ПланГрн)` (+ = перевитрата) |
| % вик. прогнозу | ПроцентПрогнозГрн | `(ФактГрн+ПланНаФактГрн)/ПланГрн*100`, ЧДЦ=1 |

Финансовый смысл (cost-control): План на факт = **ETC** (estimate-to-complete — некупленный
остаток плана по плановой цене), Прогноз = **EAC = AC + ETC**. % > 100 — ранний сигнал
перерасхода бюджета материалов. Правила расчёта ETC — файл 04.

## Служебные поля (не колонки)

- `Работа` (CatalogRef.Номенклатура) — отдельное измерение работы (план/EV несут работу,
  табель/материалы — пустую ссылку); в структуру по умолчанию НЕ входит, доступно
  в настройках для группировки/отбора.
- `НоменклатураНаименование` (Строка 150) — текстовое имя номенклатуры закупки (ветка 5),
  для сортировки/поиска.
