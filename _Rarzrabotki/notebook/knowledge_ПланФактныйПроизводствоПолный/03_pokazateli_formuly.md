# 03. Показатели и формулы итогов

Колонки отчёта = только РЕСУРСЫ (числа). Итоги на группировках считает СКД по `totalField`
из Template.xml — формулы ниже. На строках грейна те же выражения посчитаны запросом.

## Группа «Години» (труд)

| Колонка (титул укр) | Поле | Формула итога |
|---|---|---|
| План, год | ПланЧасы | `Сумма(ПланЧасы)` |
| Факт, год | ФактЧасы | `Сумма(ФактЧасы)` (табель) |
| Відхилення, год | ОтклонениеЧасы | `Сумма(ФактЧасы) - Сумма(ПланЧасы)` |
| % вик. (год) | ПроцентЧасы | `ФактЧасы/ПланЧасы*100` (0 при плане 0), формат ЧДЦ=1 |

## Группа «Виконання» (EV из документов А_ВыполнениеРаботМодулей)

| Колонка | Поле | Формула итога |
|---|---|---|
| Виконання, год | ВиконанняЧасы | `Сумма(ВиконанняЧасы)` — дельта-обороты РН за период |
| Відхилення табель-виконання, год | ОтклонениеВиконання | `Сумма(ФактЧасы) - Сумма(ВиконанняЧасы)` |
| % виконання | ПроцентВиконання | `Сумма(ВиконанняЧасы)/Сумма(ПланЧасы)*100`, ЧДЦ=1 |

Семантика: Виконання = «заработанные» часы (готовность×план). Відхилення>0 — табель опережает
готовность (переработка/непроизводительное время); <0 — готовность без табеля.

## Группа «Кількість» (материалы; СКРЫТА из вывода по умолчанию с 06.07.2026)

Поля ПланКол/ФактКол/ОтклонениеКол/ПроцентКол и их totalField в схеме ЕСТЬ (данные считаются),
но исключены из `selection` — пользователь может вернуть их через «Настройки». Не удалять
из схемы: на них опирается расчёт «План на факт».

## Группа «Грн» (материалы + ФОТ труда)

| Колонка | Поле | Формула итога |
|---|---|---|
| План, грн | ПланГрн | `Сумма(ПланГрн)` |
| Факт, грн | ФактГрн | `Сумма(ФактГрн)` (закупки + ФОТ) |
| Відхилення, грн | ОтклонениеГрн | `Сумма(ФактГрн) - Сумма(ПланГрн)` |
| % вик. (грн) | ПроцентГрн | `ФактГрн/ПланГрн*100`, ЧДЦ=1 |

## Группа «Прогноз» (EAC, только материалы)

| Колонка | Поле | Формула итога |
|---|---|---|
| План на факт, грн | ПланНаФактГрн | `Сумма(ПланНаФактГрн)` — живёт ТОЛЬКО на синтетических строках (BSL) |
| Прогноз, грн | ПрогнозГрн | `Сумма(ФактГрн) + Сумма(ПланНаФактГрн)` |
| Відхилення прогнозу, грн | ОтклонениеПрогнозГрн | `Сумма(ФактГрн) + Сумма(ПланНаФактГрн) - Сумма(ПланГрн)` (+ = перевитрата) |
| % вик. прогнозу | ПроцентПрогнозГрн | `(ФактГрн+ПланНаФактГрн)/ПланГрн*100`, ЧДЦ=1 |

Финансовый смысл (cost-control): План на факт = **ETC** (estimate-to-complete — некупленный
остаток плана по плановой цене), Прогноз = **EAC = AC + ETC**. % > 100 — ранний сигнал
перерасхода бюджета материалов. Правила расчёта ETC — файл 04.

## Служебные поля (не колонки)

- `Работа` (CatalogRef.Номенклатура) — отдельное измерение работы (план/EV несут работу,
  табель/ЗП/материалы — пустую ссылку); в структуру по умолчанию НЕ входит, доступно
  в настройках для группировки/отбора.
- `НоменклатураНаименование` (Строка 150) — текстовое имя номенклатуры закупки (ветка 5),
  для сортировки/поиска.
