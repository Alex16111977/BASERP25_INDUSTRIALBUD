# 04. «План на факт, грн» — методология ETC/EAC (утверждена бухгалтером)

Процедура `ЗаполнитьПланНаФакт(ТЗ)` + `КлючГруппыПланНаФакт(...)` в ObjectModule.bsl.
Считается ТОЛЬКО по блоку «2. Матеріали». Результат добавляется в ТЗ **синтетическими
строками** (грейн их не содержит), ресурс `ПланНаФактГрн`.

## Гранулярность нетто

Группа = **(Подразделение, «Загальна назва»)** — строковый ключ по НОРМАЛИЗОВАННОМУ ИМЕНИ
общей назвы (`СокрЛП(Наименование)`), потому что в `А_ОбщиеНазванияНоменклатуры` есть дубли
карточек с одинаковым именем (сопоставление по ссылке не сводит план с фактом).
**Fallback без общей назвы:** группа по самой Номенклатуре строки (`НОМ|<UUID>`).
**Етап и Категорія в ключе НЕ участвуют** — иначе перерасход одного этапа не гасит остаток
плана другого, и ETC завышается (ревью-находка 06.07.2026: завышение 31 932 грн / 5.1%).

## Правила расчёта (по приоритету)

Для каждой группы нетто: ПланКол, ФактКол, ПланГрн, ФактГрн (суммы по строкам группы за период).

1. `ПланГрн <= 0` → группы нет в прогнозе (прогнозировать нечего).
2. `ПланКол <= 0` (план суммой без количества) → **стоимостное нетто**:
   `ПланНаФакт = Макс(0, ПланГрн − ФактГрн)`.
3. `ФактКол <= 0` (закупок не было) → **ровно сумма плана**: `ПланНаФакт = ПланГрн`.
   ⚠️ Именно сумма, БЕЗ пересчёта «кол-во × средняя цена» — round-trip через цену теряет
   копейки, а бухгалтеру нужен точный отчёт («не играться с копейками», требование 10.07.2026).
   Следствие-инвариант: **нет закупок вообще → Σ План на факт = Σ План, Прогноз = План, % = 100**.
4. Иначе (частичный факт) → количественное нетто по средней плановой цене:
   `ПланНаФакт = Макс(0, ПланКол − ФактКол) × (ПланГрн / ПланКол)`.
   Overrun (ФактКол > ПланКол) → 0, Прогноз группы = Факт.

## Синтетическая строка «залишок плану»

- `Блок = "2. Матеріали"`, `ПланНаФактГрн = ПрогнозГрн = ОтклонениеПрогнозГрн = ПланНаФакт`
  (прочие ресурсы NULL — `Сумма()` их игнорирует, двойного счёта нет).
- **Размещение**: Категорія/Етап/ОбщееНазвание берутся с ПЛАНОВОЙ строки группы с максимальным
  ПланГрн (группа легитимно может охватывать Виробництво+Монтаж — остаток кладётся на
  доминирующий этап). С общей назвой → уровень ОбщееНазвание, Аналитика/Единица —
  ТИПИЗИРОВАННЫЕ пустые ссылки (иначе расшифровка плодит пустые строки-дубли). Без назвы →
  Аналитика = Номенклатура плана, Единица плана.
- `Работа` = пустая Номенклатура, `Документ` = пустая ссылка ПриобретениеТоваровУслуг.
