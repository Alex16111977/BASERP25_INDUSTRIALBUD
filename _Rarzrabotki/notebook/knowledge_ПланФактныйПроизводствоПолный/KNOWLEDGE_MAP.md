## 🚨 КРИТИЧЕСКИЕ ИНВАРИАНТЫ — НЕ МЕНЯТЬ ПРИ ДОРАБОТКЕ

> ⚠️ **AI/разработчик: ПРОЧИТАЙ ПЕРЕД ЛЮБОЙ ПРАВКОЙ ЗАПРОСА ОТЧЁТА.** Эти инварианты уже нарушались и ломали отчёт в бою.

1. **🔴 ФАКТ ПО МАТЕРИАЛАМ — ВСЕГДА «С НДС» (брутто). НИКОГДА не возвращать на «без НДС».**
   Ветка 5 (факт-закупки) ОБЯЗАНА тянуть ресурс **`РегистрНакопления.СебестоимостьТоваров.Стоимость`** (с НДС).
   **ЗАПРЕЩЕНО** менять его на `СтоимостьБезНДС`, `СтоимостьРегл`, `СтоимостьРеглБезНДС`, `СтоимостьУпр` — все они
   БЕЗ НДС. Причина: план (`Комплектующие.Сумма`) заведён **с НДС**, поэтому факт обязан быть с НДС — иначе
   план↔факт, «Відхилення» и прогноз EAC некорректны. Сверка (копейка в копейку):
   `Стоимость` = `Документ.ПриобретениеТоваровУслуг.Товары.СуммаСНДС` = `СтоимостьБезНДС + НДСРегл`.
   **⚠️ Эта ошибка УЖЕ ДОПУСКАЛАСЬ и исправлялась (факт тянулся без НДС).** Если правишь ветку 5 — оставь `Стоимость`.
   Детали: [FINDINGS.md](FINDINGS.md) §23, [02_istochniki_vetok.md](02_istochniki_vetok.md) ветка 5.

2. **🔴 ФАКТ НЕ ДВОИТЬ при нескольких активных СС в подразделении.** Фактовые ветки (табель/закупки) соединяются
   с `ВТ_Подр1` (ОДНА строка на подразделение), НЕ с `ВТ_СС` (много строк) — иначе `ПО ИСТИНА` умножает факт ×N.
   `В ИЕРАРХИИ (столбец)` в СОЕДИНЕНИИ запрещён платформой. Детали: FINDINGS §22.

3. **🔴 Факт материалов = ЗАКУПКИ, НЕ списание/остатки** (`Приход` / `Регистратор ССЫЛКА ПриобретениеТоваровУслуг`).
   Подразделение закупок = реквизит `СС.ПодразделениеЗакупки` (fallback `Подразделение`), `В ИЕРАРХИИ`. FINDINGS §21.

4. **🔴 План материалов строится ТОЛЬКО из ТЧ `А_СтруктураСебестоимости.Комплектующие` (обращения
   к карточке номенклатуры в плановой ветке ЗАПРЕЩЕНЫ), факт-материалов классифицируется ТОЛЬКО
   карточкой (`Номенклатура.А_ОбщееНазваниеНоменклатуры`).** С 04.09.2026 это решение принято
   ОСОЗНАННО (отменяет прежнюю осторожность FINDINGS §18): приоритет отдан четырём рабочим
   структурам (МД ООН 2026, МД ООН Админ, МД IRС 2026 15 м, МД IRС 2026 30 м) — у них эффект
   нулевой/положительный. 69 строк в неприоритетных ВООЗ/ПРООН/ОРІЛЬ сознательно НЕ занеттуются
   в «План на факт» — это НЕ баг. Детали: FINDINGS §24, [02](02_istochniki_vetok.md) ветки 2 и 5,
   [05](05_postobrabotki.md).

## TL;DR за 60 секунд

1. **Что это.** Внешний СКД-отчёт с **программной компоновкой**: данные строит BSL-функция
   `ПолучитьДанные(Период, СС)` (UNION-запрос 5 веток + 2 постобработки) и передаёт в СКД
   **внешним набором `"Детали"`** (`DataSetObject`). Причина программности — маппинг
   факт-материалов на Етап через `Номенклатура.А_ОбщееНазваниеНоменклатуры` невозможен
   в чистом СКД-запросе на этой базе (1С-квирк соединения) + синтетические строки EAC.

2. **Два блока строк.** `Блок = "1. Праця"` — **ТОЛЬКО ЧАСЫ** (план работ из СС + факт по табелю +
   EV-виконання из `РН.А_ВыполнениеРаботМодулей`; грн = 0, ветка ФОТ/ОЗФУ удалена вечером 16.07.2026)
   и `Блок = "2. Матеріали"` (план из СС.Комплектующие + факт-ЗАКУПКИ из `РН.СебестоимостьТоваров`
   Приход/ПриобретениеТоваровУслуг — НЕ списание!). Все грн-колонки отчёта = только материалы.
   Категорія `Виробництво`/`Монтаж`. **С 16.07.2026 факт табеля/ЗП — ПО ИЕРАРХИИ подразделения СС**
   (табелируют на вложенные «№1..№N»); «Підрозділ» у всех строк = подразделение СС, реальное
   подразделение факта — в измерении **«Підрозділ-виконавець»** (`ПодразделениеИсполнитель`,
   в дефолтную структуру не входит). **ПЛАН = норма × `СС.КоличествоДомов`** (нормы ТЧ — на один
   дом; 0→1; IRS15=6, IRS30=7, прочие=1). **План труда — только работы с единицей «чол/год»**
   (шт-работы исключаются целиком). **Факт часов расшифровывается до документа-табеля**
   (измерение «Документ» у строк табеля = регистратор `А_ТабельУчетаРабочегоВремени`).
   См. [02](02_istochniki_vetok.md), [03](03_pokazateli_formuly.md), [06](06_razrezy_gruppirovki.md).

3. **🔑 «План на факт, грн» (ETC) и «Прогноз, грн» (EAC)** — прогноз бюджета материалов:
   Прогноз = Факт + План-на-факт. Инвариант бухгалтера: **нет закупок → План на факт = План
   копейка в копейку** (правило «без игры с копейками»). Методология — [04_plan_na_fakt_eac.md](04_plan_na_fakt_eac.md).

4. **🔑 «Виконання, год» (EV)** — «заработанные» часы из документа
   `А_ВыполнениеРаботМодулей` (снимки % по модулям × план часов). Сверка с табелем валидна
   на итогах (в табеле нет разреза «Работа»). См. [07_svyazannye_obekty.md](07_svyazannye_obekty.md).

5. **Питфол №1 этого отчёта:** в программной компоновке КОЛОНКАМИ рендерятся ТОЛЬКО ресурсы;
   поле-измерение колонкой поставить нельзя (только уровнем группировки). Питфол №2: сохранённый
   пользовательский вариант прячет новые поля — «Ещё → Установить стандартные настройки».
   Полный список граблей — [LESSONS.md](LESSONS.md).

6. **🔑 С 04.09.2026: план материалов — ТОЛЬКО из ТЧ СС, факт материалов — ТОЛЬКО из карточки
   номенклатуры.** Разные источники общей назвы для плана и факта — сознательный выбор, не
   рассинхрон. Приоритет — четыре рабочие структуры (МД ООН 2026, МД ООН Админ, МД IRС 2026
   15 м/30 м); неприоритетные ВООЗ/ПРООН/ОРІЛЬ теряют часть неттинга «План на факт» — принято.
   Новое измерение «Номенклатура» (грейн — 20 колонок). См. п. 4 инвариантов выше, FINDINGS §24.
