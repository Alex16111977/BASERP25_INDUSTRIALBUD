## TL;DR за 60 секунд

1. **Что это.** Внешний СКД-отчёт с **программной компоновкой**: данные строит BSL-функция
   `ПолучитьДанные(Период, СС)` (UNION-запрос 6 веток + 2 постобработки) и передаёт в СКД
   **внешним набором `"Детали"`** (`DataSetObject`). Причина программности — маппинг
   факт-материалов на Етап через `Номенклатура.А_ОбщееНазваниеНоменклатуры` невозможен
   в чистом СКД-запросе на этой базе (1С-квирк соединения) + синтетические строки EAC.

2. **Два блока строк.** `Блок = "1. Праця"` — **ТОЛЬКО ЧАСЫ** (план работ из СС + факт по табелю +
   EV-виконання из `РН.А_ВыполнениеРаботМодулей`; грн = 0, ветка ФОТ/ОЗФУ удалена вечером 16.07.2026)
   и `Блок = "2. Матеріали"` (план из СС.Комплектующие + факт-ЗАКУПКИ из `РН.СебестоимостьТоваров`
   Приход/ПриобретениеТоваровУслуг — НЕ списание!). Все грн-колонки отчёта = только материалы.
   Категорія `Виробництво`/`Монтаж`. **С 16.07.2026 факт табеля/ЗП — ПО ИЕРАРХИИ подразделения СС**
   (табелируют на вложенные «№1..№N»); «Підрозділ» у всех строк = подразделение СС, реальное
   подразделение факта — в измерении **«Підрозділ-виконавець»** (`ПодразделениеИсполнитель`,
   в дефолтную структуру не входит). **ПЛАН = норма × `СС.КоличествоДомов`** (нормы ТЧ — на один
   дом; 0→1; IRS15=6, IRS30=7, прочие=1). **План труда — только работы с единицей «чол/год»**
   (шт-работы исключаются целиком). **Факт часов расшифровывается до документа-табеля**
   (измерение «Документ» у строк табеля = регистратор `А_ТабельУчетаРабочегоВремени`).
   См. [02](02_istochniki_vetok.md), [03](03_pokazateli_formuly.md), [06](06_razrezy_gruppirovki.md).

3. **🔑 «План на факт, грн» (ETC) и «Прогноз, грн» (EAC)** — прогноз бюджета материалов:
   Прогноз = Факт + План-на-факт. Инвариант бухгалтера: **нет закупок → План на факт = План
   копейка в копейку** (правило «без игры с копейками»). Методология — [04_plan_na_fakt_eac.md](04_plan_na_fakt_eac.md).

4. **🔑 «Виконання, год» (EV)** — «заработанные» часы из документа
   `А_ВыполнениеРаботМодулей` (снимки % по модулям × план часов). Сверка с табелем валидна
   на итогах (в табеле нет разреза «Работа»). См. [07_svyazannye_obekty.md](07_svyazannye_obekty.md).

5. **Питфол №1 этого отчёта:** в программной компоновке КОЛОНКАМИ рендерятся ТОЛЬКО ресурсы;
   поле-измерение колонкой поставить нельзя (только уровнем группировки). Питфол №2: сохранённый
   пользовательский вариант прячет новые поля — «Ещё → Установить стандартные настройки».
   Полный список граблей — [LESSONS.md](LESSONS.md).
