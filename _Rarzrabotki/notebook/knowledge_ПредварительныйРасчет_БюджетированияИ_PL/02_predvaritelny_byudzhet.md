🔴 `ВидПериода = `**`Месяц`**, а не `Объект` (бюджет на весь жизненный цикл) и не `Фиксы`

PL, где горизонт задавали продажи домиков.

Обработка **ДОПОЛНЯЕТ** существующие «Загрузка работ/материалов в СС», а не заменяет:
те останавливают чтение на разделе «Загальновиробничі витрати». Эта делает две вещи,
которых не делают они:
1. грузит **раздел IX** (позиции «9.1.N») в ТЧ `Общепроизводственные`;
2. **дозаполняет `СтатьяДДС` из колонки B** в уже загруженных строках ТЧ
   `Комплектующие` и `Работы`.

Материалы и работы заново НЕ грузятся, карточки и статьи ДДС НЕ создаются.

🔴 **Ключ сопоставления — ПО ПОЗИЦИИ в отборе** (`ДозаполнитьСтатьюВТЧ`, :482–559):
`Всего = Мин(СтрокиТЧ.Количество(), СтрокиФайла.Количество())`, цикл по индексу.
Наименование и сумма служат **ПРОВЕРКОЙ**, не ключом:

```
СовпалоИмя   = (НормализоватьИмя(ИмяТЧ) = НормализоватьИмя(СтрокаФайла.Имя));
Отклонение   = Окр(СтрокаТЧ.Сумма, 2) - Окр(СтрокаФайла.Сумма, 2);
СовпалаСумма = (Макс(Отклонение, -Отклонение) <= 0.02);
Если НЕ СовпалоИмя ИЛИ НЕ СовпалаСумма Тогда … Продолжить;
```

Не совпало — строка НЕ пишется, уходит в протокол с обеими сторонами пары.
🔴 Отсюда «позиционный сдвиг сопоставления»: один лишний/пропущенный ряд в файле
рассинхронизирует ВЕСЬ хвост.

Разбор листа:
* `ЭтоПозицияНорматива(Ном)` (:143–161) — `Лев(Ном,4) = "9.1."`, хвост только цифры;
* `НомерРаздела(Ном)` (:164–185) — римские цифры в шаблоне набраны **вперемешку**:
  «І» украинская U+0406, «IV/V/IX» латиница; без транслитерации разделы I–III не находятся;
* `ЭтоКоэффициент(Текст)` (:187–202) — 🔴 у позиций **9.1.1 / 9.1.3 / 9.1.18 / 9.1.19**
  в колонке «Од. вим.» лежит не единица, а КОЭФФИЦИЕНТ: **0.05 / 0.005 / 0.03 / 0.15**;
* `ПостроитьКэшСтатей` (:323–358) — кеш «нормализованное наименование → ссылка» по
  неГруппам, непомеченным, **вне ветки УТ-000965**; без этого фильтра поиск по имени
  натыкается на **13 коллизий**. Повторное имя → в `Неоднозначные`, статья не подставляется.

Дополнительный срез — `ОтобратьСтрокиТЧ` (:396–427): фильтр по реквизиту `Модуль` строк ТЧ,
если в шапке задан `Модуль > 0`. Учтено, что `Комплектующие.Модуль` — Строка(2),
а `Работы.Модуль` — Число(2,0) (`МодульСтрокиТЧ`, :373–394). 🔴 Если карточку грузили
однофайловым загрузчиком, `Модуль` пуст у ВСЕХ строк, и отбор отсёк бы всю ТЧ — тогда
**исключение с внятным текстом**, а не тихий пустой массив.

Запись — в транзакции с послезаписной сверкой (`ПроверитьКонтрольныеИтоги`, :649–703):
количество и сумма строк `Общепроизводственные` (допуск 0,005) и количество строк
со статьёй ДДС в `Комплектующие` и `Работы`. Расхождение → `ВызватьИсключение
"КОНТРОЛЬ ЗАГРУЗКИ НЕ ПРОЙДЕН: …"` → `ОтменитьТранзакцию` + запись в журнал регистрации
`А_ЗагрузкаНормативаСС.Ошибка`. 🔴 `ЗафиксироватьТранзакцию()` — ПОСЛЕДНИЙ оператор
в `Попытка`: бросить исключение после фиксации значило бы позвать `ОтменитьТранзакцию`
вне транзакции.

Точка входа — `ОбработатьЛист(СырыеСтроки, Записывать)` (:730–851);
«Прочитать и показать» = `(…, Ложь)`, «Записать в карточку» = `(…, Истина)`.
