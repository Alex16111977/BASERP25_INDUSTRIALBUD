# Задача: Реализация процедуры заполнения документа А_ОтражениеЗПпоКазне из базы Казна

## Что делаем

В конфигурации появился **новый документ** `Документ.А_ОтражениеЗПпоКазне`. Нужно реализовать процедуру `ЗаполнитьА_ОтражениеЗПпоКазнеИзБазЗП() Экспорт` в модуле объекта этого документа — **по аналогии** с уже работающей процедурой `ЗаполнитьОтражениеЗарплатыВФинансовомУчетеИзБазЗП()` в документе `ОтражениеЗарплатыВФинансовомУчете`.

**Источник данных:** только база Казна (BuhKazn), документы `РаспределениеЗаработнойПлаты` и `РаспределениеФ2`. Больше никаких баз (не zup_1, не zup_2, не BuhBud).

## Эталонная процедура (рабочая — копировать логику отсюда)

**Файл:** `Documents/ОтражениеЗарплатыВФинансовомУчете/Ext/ObjectModule.bsl`

Процедура: `ЗаполнитьОтражениеЗарплатыВФинансовомУчетеИзБазЗП() Экспорт`

Делает 4 операции:
1. Загружает А_РаспределениеКазна из Казны (процедура `ЗагрузитьА_РаспределениеКазна_ОтражениеЗП`)
2. Подготавливает справочные данные (процедура `ПодготовитьСправочныеДанные_ОтражениеЗП`) — привязка сотрудников, кеш ФизЛиц, распределение по подразделениям
3. Заполняет целевые таблицы:
   - Операция 1: А_РаспределениеНалоги → НачисленнаяЗарплатаИВзносыПоФизлицам
   - Операция 2: регистр ВзаиморасчетыССотрудниками → НачисленнаяЗарплатаИВзносыПоФизлицам
   - Операция 3: А_РаспределениеНалоги → НачисленныйНДФЛ
4. Формирует сводную таблицу НачисленнаяЗарплатаИВзносы (свертка)

#### Главная процедура (упрощённая без свертки)

```bsl
Процедура ЗаполнитьА_ОтражениеЗПпоКазнеИзБазЗП() Экспорт

    // Проверяем наличие исходных данных
    Если А_НалогиБухгалтерия.Количество() = 0 Тогда
        ВызватьИсключение "Таблица А_НалогиБухгалтерия пуста!";
    КонецЕсли;

    // Подготовка справочных данных (внутри выполнится перезагрузка РаспределениеКазна из Казны)
    СправочныеДанные = ПодготовитьСправочныеДанные_ОтражениеЗППоКазне();

    Если РаспределениеКазна.Количество() = 0 Тогда
        ВызватьИсключение "Таблица РаспределениеКазна пуста после загрузки из Казны!";
    КонецЕсли;

    // Очищаем целевые таблицы
    НачисленнаяЗарплатаИВзносыПоФизлицам.Очистить();
    НачисленныйНДФЛ.Очистить();

    // 1. НАЧИСЛЕНИЯ ИЗ НАЛОГОВ: А_НалогиБухгалтерия → НачисленнаяЗарплатаИВзносыПоФизлицам
    ЗаполнитьНачисленияИзНалогов_ОтражениеЗППоКазне(СправочныеДанные);

    // 2. НАЧИСЛЕНИЯ ЗП: ВзаиморасчетыССотрудниками → НачисленнаяЗарплатаИВзносыПоФизлицам
    ЗаполнитьНачисленияЗПИзРегистра_ОтражениеЗППоКазне(СправочныеДанные);

    // 3. НДФЛ: А_НалогиБухгалтерия → НачисленныйНДФЛ
    ЗаполнитьНДФЛИзНалогов_ОтражениеЗППоКазне(СправочныеДанные);

    // Свёртка НЕ нужна — нет ТЧ НачисленнаяЗарплатаИВзносы

КонецПроцедуры
```

#### Вспомогательные процедуры/функции (копировать из эталона с переименованием)

Все функции эталона имеют суффикс `_ОтражениеЗП`. В новом модуле использовать суффикс `_ОтражениеЗППоКазне`:

1. **Загрузка из Казны** (`ЗагрузитьРаспределениеКазна_ОтражениеЗППоКазне`):
   - Запрос к БДДС Казны с фильтром по `КассаДатаС >= &НачПериода И КассаДатаПо <= &КонПериода`
   - Фильтр: `(Регистратор ССЫЛКА Документ.РаспределениеЗаработнойПлаты И Регистратор.Организация.А_ПереносЕРП) ИЛИ (Регистратор ССЫЛКА Документ.РаспределениеФ2)`
   - Параметры: `НачПериода = НачалоМесяца(Дата)`, `КонПериода = КонецМесяца(Дата)`
   - Сериализация через `ЗначениеВСтрокуВнутр`
   - Очистка `РаспределениеКазна.Очистить()`
   - Заполнение новых строк (поиск подразделения, статьи, направления, организации, сотрудника по ИНН)

2. **Подготовка справочных данных** (`ПодготовитьСправочныеДанные_ОтражениеЗППоКазне`):
   - Вызов загрузки из Казны в начале
   - Привязка сотрудников с пустым `Сотрудник` (кеш ФИО → поиск по ИНН → поиск по КодКазна → автосоздание через `А_Привилегированный.СоздатьСотрудникаИзКазны(ФИО, ИНН, КодКазна)`)
   - Сбор всех сотрудников из `РаспределениеКазна` + `А_НалогиБухгалтерия` + регистра `ВзаиморасчетыССотрудниками`
   - Построение кеша ФизЛица
   - Построение `РаспределениеПоПодразделениям` и `РаспределениеНалоговПоСотрудникам`
   - Возврат структуры `Данные`

3. **Операция 1 — Начисления из налогов** (`ЗаполнитьНачисленияИзНалогов_ОтражениеЗППоКазне`):
   - Источник: `А_НалогиБухгалтерия` (не `А_РаспределениеНалоги`!)
   - Логика идентична эталону

4. **Операция 2 — ЗП из регистра** (`ЗаполнитьНачисленияЗПИзРегистра_ОтражениеЗППоКазне`):
   - Запрос к `РегистрНакопления.ВзаиморасчетыССотрудниками` за месяц `Дата` (НЕ `ПериодРегистрации`)
   - Логика идентична

5. **Операция 3 — НДФЛ** (`ЗаполнитьНДФЛИзНалогов_ОтражениеЗППоКазне`):
   - Источник: `А_НалогиБухгалтерия`
   - Заполняет `НачисленныйНДФЛ`

6. **Поиск распределения** (копировать все функции):
   - `ПолучитьДанныеРаспределения_ОтражениеЗППоКазне`
   - `ПолучитьДанныеРаспределенияБазовые_ОтражениеЗППоКазне`
   - `ПолучитьДанныеРаспределенияНалогов_ОтражениеЗППоКазне`

7. **Построение распределений** (копировать):
   - `ПодготовитьРаспределениеПоПодразделениям_ОтражениеЗППоКазне` (из `РаспределениеКазна`)
   - `ПодготовитьРаспределениеНалоговПоСотрудникам_ОтражениеЗППоКазне` (из `РаспределениеКазна` где `СуммаНалогов > 0`)
   - `ПодготовитьРаспределениеПоФИО_ОтражениеЗППоКазне` (fallback по ФИО)

8. **Вспомогательная функция** (копировать):
   - `А_НайтиПоНомеруРаспределение_ОтражениеЗППоКазне(НачПериода, КонПериода, Номер, ВидДокумента)` — поиск документа ERP по номеру

## Критические правила (из опыта эталонной процедуры)

1. **Подключение только к BuhKazn**: `Srvr="SQLSERVER";Ref="BuhKazn";Usr="cfo";Pwd="2442"`. Никаких zup_1, zup_2, BuhBud.

2. **Фильтр периода**: по `КассаДатаС/КассаДатаПо` **документов-регистраторов** (не по периоду БДДС!). Это важно — документ от 10.12.2025 может относиться к ноябрьской зарплате (КассаДатаС=01.11).

3. **Сериализация COM таблицы**: `V83.ЗначениеВСтрокуВнутр(ТЗ)` в Казне → `ЗначениеИзСтрокиВнутр(стр_ТЗ)` в ERP.

4. **Очищение перед загрузкой**: `РаспределениеКазна.Очистить()` — обязательно, иначе будут дубликаты.

5. **Преобразование строк из COM**: `СокрЛП("" + Выборка.ФИО)` — через конкатенацию с пустой строкой, чтобы форсировать преобразование COM-значения в 1С-строку, и `СокрЛП` для обрезки пробелов.

6. **Ключ кеша ФИО** — всегда `СокрЛП("" + значение)`. И при вставке, и при поиске.

7. **Привязка сотрудников**:
   - Шаг 1: поиск в кеше ФИО (из А_НалогиБухгалтерия и РаспределениеКазна с уже заполненным Сотрудник)
   - Шаг 2: поиск по ИНН через `НайтиПоРеквизиту("А_КодПоДРФО", ИНН)`
   - Шаг 3: автосоздание через `А_Привилегированный.СоздатьСотрудникаИзКазны(ФИО, ИНН, КодКазна)` (поддерживает создание по КодКазна даже без ИНН)

8. **Fallback по ФИО в распределении**: если по ключу Сотрудник не нашли распределение — пробовать через `РаспределениеПоФИО` (из строк РаспределениеКазна с пустым Сотрудник).

9. **Округление**: `Окр(Сумма * Доля, 2)`, последнее подразделение = остаток (для точного совпадения итогов).

10. **ЕСВ fallback**: точный налог → "ЕСВ ФОТ" → "БазовыеНачисления".
