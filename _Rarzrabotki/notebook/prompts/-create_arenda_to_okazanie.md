# Промт: Створити код в А_АрендаТехники для автоматичного створення А_ОказаниеУслугМеждуПодразделениями

Скопіюй і вставь в чат Claude Code:

---

Мені потрібно написати код в документі А_АрендаТехники який при проведенні автоматично створює (або оновлює) підлеглий документ А_ОказаниеУслугМеждуПодразделениями.

Спочатку проконсультуйся з NotebookLM (notebook_id="3303acdb-2d7f-4879-9f13-78705ab3fb8c"):

1. Запитай: "Як документ А_ОказаниеУслугМеждуПодразделениями створюється автоматично з грошових документів через А_СобытияОбъектов? Яка процедура СоздатьДокументОказаниеУслугМеждуПодразделениямиПоРаспределению використовується як приклад? Які реквізити обов'язково заповнювати?"

2. Запитай: "Як в А_ОказаниеУслугМеждуПодразделениями заповнюється табличні частина Услуги? Які поля потрібні: Номенклатура, Сумма, ПодразделениеПродавец, ПодразделениеПокупатель, ФормаОплаты, ПродавецСДД, ПокупательСДД, СтатьяЗатрат?"

Потім вивчи структуру обох документів через MCP:
- get_metadata_structure(metaType="Documents", name="А_АрендаТехники")
- get_metadata_structure(metaType="Documents", name="А_ОказаниеУслугМеждуПодразделениями")

Також прочитай існуючий код:
- ObjectModule.bsl документа А_АрендаТехники
- ObjectModule.bsl документа А_ОказаниеУслугМеждуПодразделениями (як приклад — процедури СоздатьДоговорПокупателя, СоздатьДоговорПоставщика, НачислитьУслуги)

Вивчи приклад як вже створюються підлеглі документи — процедура СоздатьДокументОказаниеУслугМеждуПодразделениямиПоРаспределению в А_СобытияОбъектов (прочитай код).

Потім знайди через MCP дані реального документа А_АрендаТехники:
- execute_query: "ВЫБРАТЬ ПЕРВЫЕ 1 Ссылка, Дата, Номер, Организация ИЗ Документ.А_АрендаТехники ГДЕ Проведен"
- Подивись табличну частину з підрозділами і сумами

Логіка створення:

1. Пошук існуючого А_ОказаниеУслугМеждуПодразделениями по реквізиту АрендаТехники = Ссылка (А_АрендаТехники)
   - Якщо знайдено — оновити (відмінити проведення, очистити ТЧ Услуги)
   - Якщо не знайдено — створити новий

2. Заповнення шапки:
   - Дата = Дата документа А_АрендаТехники
   - Организация = Организация
   - АрендаТехники = Ссылка (А_АрендаТехники) — зв'язок з батьківським документом

3. Заповнення табличної частини Услуги з рядків А_АрендаТехники:
   - Кожен рядок = послуга між підрозділами
   - ПодразделениеПродавец = підрозділ що надає техніку (наприклад Телескоп 1)
   - ПодразделениеПокупатель = підрозділ об'єкта (наприклад Астарта. Тищенки)
   - НаправлениеРасхода = "Строительство" (з рядка А_АрендаТехники)
   - Сумма = сума з рядка (наприклад 92 334,90)
   - Номенклатура = "Фінансова послуга для звіту P&L"
   - ФормаОплаты = Перечисления.ФормыОплаты.Безналичная
   - СтатьяЗатрат = знайти по коду "УТ-001130" (Аренда техники)
   - ПродавецСДД = СтатьяЗатрат.СтатьяДвиженияДенежныхСредствПродавец (стаття руху грошей продавця)
   - ПокупательСДД = СтатьяЗатрат.СтатьяДвиженияДенежныхСредствПокупатель (стаття руху грошей покупця)
   - Додумай по логіці інших прикладів в ObjectModule А_ОказаниеУслугМеждуПодразделениями решту полів

4. Провести документ А_ОказаниеУслугМеждуПодразделениями

5. Розмістити виклик процедури в ПриЗаписи або ОбработкаПроведения документа А_АрендаТехники

ВАЖЛИВО:
- Використовуй паттерн з СоздатьДокументОказаниеУслугМеждуПодразделениямиПоРаспределению як зразок
- Перед записом підлеглого документа — протестуй логіку через Python COM скрипт (_Rarzrabotki/Python/test/)
- Якщо NotebookLM не знає деталей по А_АрендаТехники — додай знання про цей документ в custom_objects_guide.md і перезавантаж в NotebookLM
