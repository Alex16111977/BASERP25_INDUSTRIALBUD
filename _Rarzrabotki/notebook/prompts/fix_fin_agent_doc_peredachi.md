# Промт: Дописати код пошуку ДокументПередачи в А_ПриходДенегОтФинАгента

Скопіюй і вставь в чат Claude Code:

---

Мені потрібно доробити код в документі А_ПриходДенегОтФинАгента — процедура ОбновитьПриходДенегОтФинАгентаПослеОбмена().

Проблема: Після обміну з Казни поле А_РасшифровкаФинАгент.ДокументПередачи може бути ПУСТИМ (платіжка СписаниеБезналичныхДС не знайдена при обміні). Через це РасшифровкаПлатежа не заповнюється і документ працює неправильно.

Спочатку проконсультуйся з NotebookLM (notebook_id="3303acdb-2d7f-4879-9f13-78705ab3fb8c"):

1. Запитай: "Як працює потік грошей через фінансового агента? Яка роль ДокументПередачи в А_РасшифровкаФинАгент? Як регістр А_ДенежныеСредстваФинАгенты пов'язує платіжки з приходом від фінагента?"

2. Запитай: "Як знайти платіжку (СписаниеБезналичныхДенежныхСредств) для А_ПриходДенегОтФинАгента по регістру А_ДенежныеСредстваФинАгенты? Який запит використати щоб знайти платіжку по ФинАгенту і даті?"

3. Запитай: "Які прапорці критично ставити при програмному створенні підлеглих документів з А_ПриходДенегОтФинАгента? А_ОбработанКазна, А_ВведенВЕРП — для яких документів?"

Потім вивчи:
- get_metadata_structure(metaType="AccumulationRegisters", name="А_ДенежныеСредстваФинАгенты")
- Прочитай ObjectModule.bsl документа А_ПриходДенегОтФинАгента
- Знайди реальні документи з пустим ДокументПередачи через Python COM тест

Логіка доробки:
В процедурі ОбновитьПриходДенегОтФинАгентаПослеОбмена() — якщо СтрокаТЗ.ДокументПередачи пустий:

1. Шукаємо ПЕРШУ платіжку по регістру А_ДенежныеСредстваФинАгенты:
   - ФинАгент = СтрокаТЗ.ФинАгент
   - Подразделение = Подразделение з шапки документа (розрахований через А_ПолучитьПодразделениеПоНаправлениюИПодразделениюКазны)
   - ВидДвижения = Приход (гроші пішли фінагенту — це СписаниеБезналичныхДС)
   - ДокументПередачи <> ПустаяСсылка
   - Период >= Дата документа А_ПриходДенегОтФинАгента (дивимось "в майбутнє")
   - УПОРЯДОЧИТЬ ПО Период — беремо ПЕРВУЮ знайдену (найближчу за датою)
   - Суму НЕ перевіряємо — беремо першу яка підходить по ФинАгент + Подразделение

   Контекст: Приход грошей в касу часто відбувається РАНІШЕ ніж банківська платіжка.
   Фінагент бере гроші у клієнта і віддає в касу одразу, а по банку платіжка проходить пізніше.
   Тому платіжка (СписаниеБезналичныхДС) за датою ПІСЛЯ документа А_ПриходДенегОтФинАгента.
   Оскільки банк вже звірений (рознесений до 31.03.2026) — платіжка гарантовано існує.

2. Якщо знайдена — підставляємо в СтрокаТЗ.ДокументПередачи
   Далі стандартна логіка: цикл по ДокументПередачи.РасшифровкаПлатежа заповнить РасшифровкаПлатежа

3. Якщо не знайдена — Сообщить() з номером документа і ФинАгентом, продовжити цикл

Спочатку напиши Python тест (_Rarzrabotki/Python/test/) який:
- Знаходить документи А_ПриходДенегОтФинАгента з пустим ДокументПередачи в А_РасшифровкаФинАгент
- Для кожного шукає платіжку по регістру А_ДенежныеСредстваФинАгенты (ФинАгент + Подразделение + Период >= Дата)
- Показує: знайдено чи ні, номер платіжки, дату, суму
- Підтверджує що логіка пошуку працює

Потім допиши код в ObjectModule.bsl — додай блок пошуку ПЕРЕД циклом по ДокументПередачи.РасшифровкаПлатежа.
