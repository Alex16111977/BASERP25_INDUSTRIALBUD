Структура процедури (копіювати логіку з обробки):

**1. Підготовка довідкових даних:**
- Кеш Сотрудник → ФізОсоба (запит з НЕ ПометкаУдаления)
- ГрупаОбліку = Справочники.ГруппыУчетаНачисленийИУдержаний.Зарплата

**2. Підготовка розподілу по підрозділам:**
- З А_РаспределениеКазна побудувати вкладену структуру:
  Соответствие(Сотрудник → Соответствие(Налог/Ключ → Структура(Подразделения, Итого)))
- Де Подразделения = Соответствие(Подразділ → Структура(Сумма, СпособОтражения))
- Ключ "БазовыеНачисления" для рядків де А_Налог порожній

**3. Операція 1: А_РаспределениеНалоги → НачисленнаяЗарплатаИВзносыПоФизлицам**
- Для кожного рядка А_РаспределениеНалоги:
  - Якщо Сумма > 0 І СуммаФОТ = 0 → ПДФО/ВЗ: взяти дані розподілу для податків
  - Якщо СуммаФОТ > 0 → ЕСВ: взяти дані розподілу з fallback (ЕСВ ФОТ → базовий)
  - Розподілити суму по підрозділам пропорційно
  - Останній підрозділ = залишок (для точності округлення)
  - Заповнити: Організація, ФізОсоба, Підрозділ, ВидОперації, СпосібВідображення, Сума/ВнескиВсього, Податок, ГрупаОбліку

## Критичні правила (з досвіду НачислениеЗарплаты)

1. **БЕЗ `Сообщить()` в циклах** — ламає форму при масовому виклику
2. **`А_Обработан = Истина`** встановити ДО заповнення цільових ТЧ
3. **Кеш Сотрудників** з запиту `ГДЕ НЕ ПометкаУдаления` — гарантовано валідні ссилки
4. **`СоздатьСотрудникаИзФизическогоЛица()`** для відсутніх + `ПолучитьОбъект() <> Неопределено`
5. **`Попытка/Исключение`** у формі навколо виклику — щоб не крашити форму
6. **Немає `Записать()`** у клієнтському обробнику — уникаємо фонових завдань
7. **Округлення**: `Окр(Сума × Доля / Ітого, 2)`, останній підрозділ = залишок
8. **ЕСВ fallback**: "ЕСВ ФОТ Работників" → "ЕСВ ФОТ" (базовий) → базовий розподіл
