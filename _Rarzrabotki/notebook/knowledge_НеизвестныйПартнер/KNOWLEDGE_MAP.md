## Объекты конфигурации (карта)

| Объект | Роль |
|---|---|
| `Справочник.Партнеры` (предопр. `НеизвестныйПартнер`) | партнёр-заглушка |
| `Справочник.Контрагенты` (реквизит `Партнер`) | первоисточник связи (N:1) |
| `Справочник.ДоговорыКонтрагентов` (реквизит `Партнер`) | договоры |
| `Справочник.КлючиАналитикиУчетаПоПартнерам` | ключ-носитель партнёра для 23 регистров |

| `Справочник.ОбъектыРасчетов` (реквизит `Партнер`) | объекты расчётов (2 вида) |
| `РегистрСведений.АналитикаУчетаПоПартнерам` | кэш (Партнёр-измерение + КлючАналитики) |
| `РегистрСведений.АналитикаУчетаПартий` (`Поставщик`) | партийный кэш |
| `РегистрСведений.РеестрДокументов` (`Партнер`-измерение) | навигационный реестр |
| `CommonModule.ДенежныеСредстваСервер` | `ПолучитьПартнераПоКонтрагенту` (стр.1517) |
| `CommonModule.ОбъектыРасчетовСервер` | `НайтиНовыйОбъектРасчетов`, `НайтиОбъектРасчетовПоАналитикеУчетаПоПартнерам` |
| `CommonModule.ОбщегоНазначения` | `ЗаменитьСсылки`, `ПараметрыЗаменыСсылок` (движок свёртки) |

| `CommonModule.А_СобытияОбъектов` | Часть A: `КонтрагентыПередЗаписью`, `ДоговорыКонтрагентовПередЗаписью`, `А_ИсправитьНеизвестногоПартнераВДокументе` |
| `EventSubscription.А_ДоработкаСправочникиПередЗаписью` / `А_ДоработкаДокументыПередЗаписью` | подписки (BeforeWrite) |

| `_Rarzrabotki/ExChange/ПравилаОбменаДаннымиЕРПБух/ExchangeRules.xml` | правила обмена (первопричина, стр.1313) |

## Хронология (2026-06-16)

| Время/этап | Результат |
|---|---|
| Срез НайтиПоСсылкам | 305-306 ссылок в 16 объектах; ключи/реестр/кэш — основная масса |
| Архитектура ключей | 23 регистра через `КлючиАналитикиУчетаПоПартнерам` |
| Связь Партнёры↔Контрагенты | `Контрагент.Партнер`, N:1; 15 битых контрагентов, 2 тёзки/1 ЕДРПОУ/12 создать |
| Первопричина | PCR обмена `ExchangeRules.xml:1313` (хардкод заглушки) |
| Часть A внедрена | `А_СобытияОбъектов` + резолвер `А_Привилегированный` загружены, smoke PASS |
| Обработка-чистка | `Обработки.А_ОбработкаНеизвестногоПартнера`: движок + свёртка через `ЗаменитьСсылки` |
| Свёртка дублей | 12 ключей слиты на «ФОП Чміль»; фикс кэша `КлючАналитики`→канонический; удаление освобождённых |
| Остаток | платежи без контрагента + навигационный РеестрДокументов — не выводятся (roadmap §06) |
