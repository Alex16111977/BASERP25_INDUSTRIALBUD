# 05. Обработка «А_ОбработкаНеизвестногоПартнера» (чистка истории)

**Объект:** `Обработки.А_ОбработкаНеизвестногоПартнера` (встроена в конфигурацию; ранее — внешняя `.epf`).
Синоним «Обработка неизвестного партнера». Вся логика — в **модуле формы** (`Forms.Форма`), UI в стиле «СинхронизироватьДеньгиКасса».
Исходники: `_Rarzrabotki/Обработки/ОбработкаНеизвестногоПартнера/`.

## UI / реквизиты формы

- Реквизиты: `НеизвестныйПартнер`, `НадписьРезюме` (сводка), ТЧ `ТаблицаКонтрагентов` (Контрагент, ЦелевойПартнер, Создавать, КолвоСсылок, Статус), ТЧ `ТаблицаОбъектов` (Объект, ТипОбъекта, Контрагент, Статус, Ошибка).
- Команды: **Проаналізувати** / **Замінити всі** (с `ПоказатьВопрос`) / **Замінити рядок** (по строке).
- Master-detail: активный контрагент сверху фильтрует объекты снизу. Условное оформление: серый (обработан), красный (ошибка), синий (будет создан партнёр).

## Алгоритм

### Проанализировать (`ПроанализироватьНаСервере`)
1. `Источники = НайтиПоСсылкам([Неизвестный])`.
2. По каждому источнику:
   - **пропустить** помеченные на удаление (`Данные.ПометкаУдаления`) — уйдут штатной «Видалення помічених»;
   - **пропустить** служебные `РегистрСведений.РеестрДокументов` / `ИерархияПартнеров` (партнёр не выводится, считаются отдельно как «службові»);
   - определить контрагент-контекст (`ОпределитьКонтрагентаКонтекста`);
3. Сгруппировать по контрагенту → `ТаблицаКонтрагентов`; целевой партнёр = резолвер (без создания на этом шаге: тёзка/головной/ЕДРПОУ → иначе «буде створено»).

### Заменить всё / по строке (`ВыполнитьЗаменуНаСервере` → `ОбработатьКонтрагента`)
Каскад для одного контрагента `C` → цель `P` (порядок важен):
1. `Контрагент.Партнер = P`;
2. `ДоговорыКонтрагентов` контрагента → Партнер=P;
3. **Ключи** `КлючиАналитикиУчетаПоПартнерам` (поле Партнер) и `КлючиАналитикиУчетаПартий` (поле **Поставщик**): для каждого дубля найти эталон (`НайтиЭталонКлюча`); есть → `ЗаменитьСсылки(дубль→эталон, RAW)` + пометить; нет → правка поля на месте (становится каноническим);
4. **ОбъектыРасчетов** (`СвернутьОбъектыРасчетов`): эталон через `ОбъектыРасчетовСервер.НайтиНовыйОбъектРасчетов` / `НайтиОбъектРасчетовПоАналитикеУчетаПоПартнерам`; есть → `ЗаменитьСсылки` + пометить; нет → на месте;
5. **Кэш** `АналитикаУчетаПоПартнерам` (`ПеренестиКэшАналитики`): Партнёр — измерение → удалить старую запись + записать новую с `Партнер=P` И `КлючАналитики = НайтиКлючПоИзмерениям(P, измерения)` — **канонический ключ** (иначе кэш держит старый ключ → его не удалить);
6. **Кэш** `АналитикаУчетаПартий` (`ПеренестиКэшПартий`): то же по полю `Поставщик`;
7. **Документы** (`ОбработатьДокументы` → `ЗаменитьПартнераВОбъекте`): обойти реквизиты шапки + строки всех ТЧ типа Партнеры → P, записать `ОбменДанными.Загрузка=Истина` (без проведения);
8. **`УдалитьОсвобождённыеДубли`**: помеченные дубли (ключи/ОР) с `НайтиПоСсылкам()=0` → физически `Удалить()`; ещё держащиеся (напр. помеченными документами) — остаются помеченными (уйдут штатной чисткой).

Гейт по контрагенту: `ОстатокПоКонтрагенту` (непомеченные ссылки) = 0 → статус «Обработан».

## Ключевые серверные функции движка (модуль формы)

| Функция | Назначение |
|---|---|
| `ОбеспечитьРеальногоПартнераПоКонтрагенту` | резолвер (копия А_Привилегированного, самодостаточность) |
| `НайтиЭталонКлюча` | эталон ключа по (цель + измерения), ≠ сам |
| `НайтиКлючПоИзмерениям` | канонический НЕпомеченный ключ для (цель + измерения) — для кэша |
| `СвернутьКлючи` / `СвернутьОбъектыРасчетов` | свёртка дублей через `ЗаменитьИПометить` |
| `ЗаменитьИПометить` | `ЗаменитьСсылки(RAW)` + `ПометкаУдаления` |
| `ПеренестиКэшАналитики` / `ПеренестиКэшПартий` | перезапись кэш-записи (Партнёр-измерение) на цель + канонический ключ |
| `УдалитьОсвобождённыеДубли` | удалить помеченные дубли с 0 ссылок |
| `ОстатокПоКонтрагенту` / `СчётСсылок` | гейт |

## Принципы безопасности (встроены)
- `ЗаменитьСсылки` всегда с `ВключатьБизнесЛогику = Ложь` → **без перепроведения** (вариант «заменить ссылку в ТЧ/регистрах», а не «перепровести»).
- Прямые поля документов пишутся `ОбменДанными.Загрузка = Истина` — без движений.
- Суммы регистров не меняются (замена рефов/атрибутов).

## Проверено (на живой базе, без перепроведения)
- Каскад на контрагенте «ФОП Чміль І.М» (31 ссылка): 12 дубль-ключей слиты, остаток по контрагенту = 0.
- Исправление кэша (`КлючАналитики`→канонический) освобождает застрявшие ключи → удаление (валидировано на одном ключе: 1→0 ссылок → удалён).

## Что обработка НЕ доделывает автоматически
Платежи без контрагента (`РасшифровкаПлатежа.Партнер` без контрагента/ОР) и навигационный `РеестрДокументов` — см. [06_ostatok_i_roadmap.md](06_ostatok_i_roadmap.md).
