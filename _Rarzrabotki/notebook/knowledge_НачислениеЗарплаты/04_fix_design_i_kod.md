## Принцип (зеркало ОЗФУ)

Дословно из ОЗФУ-спеки (`docs/superpowers/specs/2026-06-08-ozfu-raspredelenie-nachisleniy-iz-buh-design.md`, §4):
> «Итог больничного — только из бухгалтерии (обе закладки `НачисленияБух` + `НачисленияБухЗасчетФондов`).
> Казна — только структура распределения (по каким подразделениям разложить), устойчивая к отрицательным весам.»

Аналог в ОЗФУ: процедура `_ОтрЗП_ЗаполнитьБольничныеИзФондов` (`ObjectModule.bsl` ≈1211).
Аналог в НачислениеЗарплаты: новая процедура **`_НЗ_НормалізуватиБольничные`**.

**Алгоритм:** для каждого ФЛ с `Σ НачисленияБухЗасчетФондов > 0`:
1. `target = Σ НачисленияБух(ФЛ) + Σ НачисленияБухЗасчетФондов(ФЛ)` (= bukhGROSS = ОЗФУ Ф1);
2. снести ВСЕ его текущие строки в `НЗ.Начисления` (плуг-«Оклад» + штраф-хак);
3. добавить `target` положительными строками по подразделению из структуры Казны (robust к 0/минус-весам).

**Эффект:** Григоренко −240.69 → 5370.57; Ямковий 5202.45 → 13923.97; Горбачова — net инвариантен
(17543.40 до=после), но композиция чистая (без плюс-штрафа). Остальные ~187 ФЛ не затронуты.
НДФЛ/ВзносыФОТ ТЧ не трогаются (они уже корректны из `НалогиБухгалтерия`).

## Полный код процедуры

```bsl
// Нормалізує «оклад» больничних «за счёт фондов»: для ФЛ з НачисленияБухЗасчетФондов>0
// Казна дає сміттєвий результат (плуг −240,69 у Григоренка / неповний оклад у Ямкового),
// бо НачислениеЗарплаты бере «оклад» з Казни (СуммаНачисления), а не з бухгалтерії.
// Рішення (дзеркало ОЗФУ _ОтрЗП_ЗаполнитьБольничныеИзФондов): итог больничного ФЛ =
//   bukhGROSS = Σ НачисленияБух + Σ НачисленияБухЗасчетФондов,
// розкладений по підрозділах Казни (robust до 0/мінус-ваг), позитивними рядками.
// Знести існуючі рядки больничного ФЛ (плуг-«Оклад» + штраф-хак) і додати GROSS.
// Net Горбачової інваріантний (17543,40 до=після); Григоренко/Ямковий виправляються;
// решта ФЛ (без ФСС) не зачіпаються — регресія нульова.
Процедура _НЗ_НормалізуватиБольничные(НЗ, ВидРасч, КешСотрПоФизЛицу,
	МапПодразОргПоСотруднику, НачПер, КонПер, СтрЛічильник)

	// 1. Σ ФСС («за счёт фондов») по ФізЛицу — маркер больничного «за рахунок фондів».
	ФондыПоФЛ = Новый Соответствие;
	Для Каждого Стр Из НачисленияБухЗасчетФондов Цикл
		Если НЕ ЗначениеЗаполнено(Стр.ФизЛицо) ИЛИ Стр.Сумма = 0 Тогда Продолжить; КонецЕсли;
		Тек = ФондыПоФЛ[Стр.ФизЛицо];
		ФондыПоФЛ.Вставить(Стр.ФизЛицо, ?(Тек = Неопределено, 0, Тек) + Стр.Сумма);
	КонецЦикла;
	Если ФондыПоФЛ.Количество() = 0 Тогда Возврат; КонецЕсли;

	// 2. bukhGROSS = Σ НачисленияБух + Σ ФСС (тільки по больничним ФЛ).
	GROSSПоФЛ = Новый Соответствие;
	Для Каждого Стр Из НачисленияБух Цикл
		Если ФондыПоФЛ[Стр.ФизЛицо] = Неопределено Тогда Продолжить; КонецЕсли;
		Тек = GROSSПоФЛ[Стр.ФизЛицо];
		GROSSПоФЛ.Вставить(Стр.ФизЛицо, ?(Тек = Неопределено, 0, Тек) + Стр.Сумма);
	КонецЦикла;
	Для Каждого КЗ Из ФондыПоФЛ Цикл
		ФЛ  = КЗ.Ключ;
		Тек = GROSSПоФЛ[ФЛ];
		GROSSПоФЛ.Вставить(ФЛ, ?(Тек = Неопределено, 0, Тек) + КЗ.Значение);
	КонецЦикла;

	// 3. ФЛ до перезбору: є валідний Сотрудник і сума<>0 (інакше не чіпаємо рядки).
	ФЛдоПерезбору = Новый Соответствие;
	Для Каждого КЗ Из GROSSПоФЛ Цикл
		Если КЗ.Значение = 0 Тогда Продолжить; КонецЕсли;
		Сотр = КешСотрПоФизЛицу[КЗ.Ключ];
		Если ЗначениеЗаполнено(Сотр) Тогда
			ФЛдоПерезбору.Вставить(КЗ.Ключ, Сотр);
		Иначе
			Сообщить("Больничні: не знайдено Сотрудника для " + Строка(КЗ.Ключ) + " — нормалізацію пропущено.");
		КонецЕсли;
	КонецЦикла;
	Если ФЛдоПерезбору.Количество() = 0 Тогда Возврат; КонецЕсли;

	// 4. Знести існуючі рядки Начисления цих ФЛ (плуг-«Оклад» + штраф-хак больничного).
	і = НЗ.Начисления.Количество() - 1;
	Пока і >= 0 Цикл
		СтрН = НЗ.Начисления[і];
		Если ЗначениеЗаполнено(СтрН.Сотрудник) Тогда
			ФЛ = СтрН.Сотрудник.ФизическоеЛицо;
			Если ФЛдоПерезбору[ФЛ] <> Неопределено Тогда
				НЗ.Начисления.Удалить(і);
			КонецЕсли;
		КонецЕсли;
		і = і - 1;
	КонецЦикла;

	// 5. Додати bukhGROSS позитивними рядками по підрозділах Казни (структура take-home).
	Для Каждого КЗ Из ФЛдоПерезбору Цикл
		ФЛ   = КЗ.Ключ;
		Сотр = КЗ.Значение;
		_НЗ_ДодатиРядкиНачисленияПоПодразделениях(НЗ, Сотр, ВидРасч, GROSSПоФЛ[ФЛ],
			МапПодразОргПоСотруднику[Сотр], НачПер, КонПер, СтрЛічильник);
	КонецЦикла;

КонецПроцедуры
```

> Имена хелперов/ТЧ — точные (сверены с `ObjectModule.bsl`): `_НЗ_ДодатиРядкиНачисленияПоПодразделениях`,
> `НачисленияБух`, `НачисленияБухЗасчетФондов`, `МапПодразОргПоСотруднику`, `КешСотрПоФизЛицу`.

## Решённые при реализации детали (без доп. вопросов)

- **Вид расчёта для больничного:** оставлен «Оклад (Зарплата)» (единый вид документа). Сумма корректна;
  отдельный «Больничный» вид НЕ вводился, чтобы не менять типовое проведение/НДФЛ-кодирование. При желании
  показать больничный отдельной строкой — тривиальный follow-up.
- **Распределение по подразделению:** через существующий `_НЗ_ДодатиРядкиНачисленияПоПодразделениях`
  (веса = `РаспределениеКазна.Сумма` take-home). У всех 3 ФЛ — одно подразделение, GROSS целиком туда.
- **Горбачова (декрет):** нормализуется тоже (решение пользователя «нормализовать все 3»); net инвариантен.
