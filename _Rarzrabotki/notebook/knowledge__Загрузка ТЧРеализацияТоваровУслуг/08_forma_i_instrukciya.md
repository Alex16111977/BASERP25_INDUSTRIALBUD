## Командная панель

`AutoCommandBar` с `Autofill=false`: стандартные кнопки не добавляются, только эти пять.

| Кнопка (заголовок) | Команда / процедура | Картинка | Что делает |
|---|---|---|---|
| **1. Прочитати і зіставити** | `ПрочитатьФайл` | `StdPicture.Reread` | файл уже выбран → `ПрочитатьФайлНаСервере` + `ПоказатьВарианты`; не выбран → диалог `ВыбратьФайл` |
| **Підтвердити схожі ≥ 85 %** | `ПодтвердитьСхожие` → `ПодтвердитьСхожиеНаСервере` | `StdPicture.CheckAll` | ставит ✓ строкам «Схоже — перевірте» со схожестью ≥ 85; оповещение «Підтверджено рядків: N» |
| **2. Завантажити в документ** | `ЗагрузитьВДокумент` → `ЗагрузитьВДокументНаСервере` | `StdPicture.ExecuteTask` | кнопка по умолчанию (`DefaultButton`); проверки на клиенте, затем сервер |
| **Excel з кодами 1С** | `ВыгрузитьВExcel` → `АдресExcelСКодами` (сервер) → `ВыгрузитьВExcelЗавершение` (Экспорт, оповещение) | `StdPicture.SaveFile` | xlsx с кодами подтверждённых карточек ([07](07_vlozheniya_i_zhurnal.md)) |
| **Забути вибір рядка** | `ЗабытьСоответствие` → `ЗабытьСоответствиеНаСервере` | `StdPicture.InputFieldClear` | удаляет из общей памяти оба ключа названия; строка → «Знято бухгалтером» |

- `ЗабытьСоответствиеНаСервере(Наименование)` только вызывает экспортную `ЗабытьСоответствие` модуля объекта
  (`РеквизитФормыВЗначение("Объект")`). Остальное — на клиенте: ✓ снимается, способ «Знято бухгалтером», итоги
  пересчитываются, оповещение «Вибір для «<до 40 символів назви>» забуто». Карточка и «Схожість» в строке остаются.
- `ВыгрузитьВExcelЗавершение(ПолученныеФайлы, ДополнительныеПараметры)` — обработчик `НачатьПолучениеФайлов`. Если
  файл сохранён (`ПолученныеФайлы <> Неопределено`), показывает оповещение «Файл збережено. Код 1С — лише для рядків з ✓.
  Для завантаження за кодом: назва 2, кількість 3, од. 4, ціна 5, код 1С 6, сума 7.» Отмену диалога молча пропускает.

Подсказки (ToolTip) команд — в `Form.xml`, например «Поставити ✓ жовтим рядкам зі схожістю 85 % і вище».

**Картинки** взяты только из проверенных по типовым формам: `Reread`, `CheckAll`, `ExecuteTask`, `SaveFile`,
`InputFieldClear`, `ListViewMode`, `ReportSettings`, `Information`. Другие имена `StdPicture` не проверялись: новое
имя сначала найти в типовой форме BASEBuh.

**Проверки `ЗагрузитьВДокумент` на клиенте** (до сервера):
- нет документа — «Виберіть документ реалізації.»;
- таблица пуста — «Спершу прочитайте і зіставте файл (кнопка «1. Прочитати і зіставити»).»;
- `ГотовоСтрок = 0` — «Немає рядків з ✓ — підтвердіть картки в таблиці.».

После успеха: `ОповеститьОбИзменении(Объект.Документ)` и предупреждение «Завантажено в документ рядків: N на суму S без
ПДВ.» К нему добавляются:
- «Не завантажено (без ✓): K» — если были пропуски. K = `Пропущено` из `ЗаполнитьТоварыДокумента`: туда входят и
  строки с ✓, у которых количество после пересчёта кг → т округлилось до 0 ([06](06_zagruzka_v_dokument.md)), хотя
  надпись говорит «без ✓». Такие строки названы в предупреждениях ниже;
- «Попередні товари документа замінено.» — если `ОчиститьТовары`;
- предупреждения загрузки;
- «Вибір запам'ятовано… Якщо документ відкрито — закрийте і відкрийте його знову.»

- **`Документ`** (`Объект.Документ`, «Реалізація», ширина 38). Если форма открыта командой из документа, заполняется
  из `Параметры.ОбъектыНазначения[0]` в `ПриСозданииНаСервере` ([01](01_naznachenie_i_scenariy.md)).
- **`ИмяФайла`** («Файл накладної», ширина 50, растягивается).
  - `ChoiceButton=true`, `TextEdit=false` — вручную путь не ввести, только кнопкой выбора.
  - Подсказка ввода: «Виберіть файл Excel (xls, xlsx)…».
  - `ИмяФайлаНачалоВыбора` → `ВыбратьФайл` → `НачатьПомещениеФайла(…, УникальныйИдентификатор)`. Адрес живёт, пока
    открыта форма.
- **`НадписьРезюме`** — подсказка «что делать дальше». Текст собирает `ОбновитьИтогиФормы`:
  - строк нет — «Виберіть документ і файл накладної, натисніть «1. Прочитати і зіставити». Як користуватися — закладка
    «Інструкція».»;
  - всё подтверждено — «Усі N рядків підтверджено — натисніть «2. Завантажити в документ».»;
  - иначе — «Підтверджено X з N рядків. Потребують рішення: R (жовті й помаранчеві), не знайдено: F (червоні).
    Завантажуються лише рядки з ✓.»

## Закладка «Зіставлення»

### Фильтр-переключатель и колонка `Группа`

**`Показать`** — `RadioButtonField`, вид `Tumbler`, реквизит-строка, событие `ПоказатьПриИзменении` → `ПрименитьФильтр`.

| Значение | Надпись |
|---|---|
| `Все` | Усі |
| `Решение` | Потребують рішення |
| `НеНайдено` | Не знайдено |
| `Подтверждено` | Підтверджені |

`ПрименитьФильтр(Форма)`: при `Все` или пустом — `Элементы.Распознавание.ОтборСтрок = Неопределено`. Иначе —
`Новый ФиксированнаяСтруктура("Группа", Форма.Показать)`. Фильтр работает **на клиенте**, без сервера. При открытии
`ПриСозданииНаСервере` ставит `Показать = "Все"`.

**`Группа`** — служебная колонка таблицы, её ставит `ОбновитьИтогиФормы` при каждом пересчёте:
- `Подтверждено` — строка с ✓;
- `Решение` — ✓ нет, карточка есть (жёлтые, оранжевые, «Знято»);
- `НеНайдено` — карточки нет.

В таблице колонки не видно: элемента у неё нет. **Колонка обязана быть и в ТЗ модуля объекта**
(`НоваяТаблицаРаспознавания`), иначе `ЗначениеВРеквизитФормы` падает ([LESSONS](LESSONS.md), [09](09_sborka_testy_priemka.md)).

### Легенда и условное оформление (цвета RGB)

Легенда — пять `LabelDecoration` в той же группе, что и тумблер. Фон легенды и фон строк задаёт **один и тот же код**
в `ПриСозданииНаСервере`, так что они не расходятся. Те же цвета — в CSS инструкции.

| Состояние | Условие оформления | Функция цвета | RGB | CSS инструкции |
|---|---|---|---|---|
| Підтверджено | `Подтверждено = Истина` | `ЦветПодтверждено` | 220, 245, 220 | `.ok #dcf5dc` |
| Схоже — перевірте | `Способ = СпособПохоже()` и ✓ нет | `ЦветПохоже` | 255, 240, 200 | `.sim #fff0c8` |
| Поза залишками | `Способ = СпособВнеОстатков()` и ✓ нет | `ЦветВнеОстатков` | 255, 225, 180 | `.out #ffe1b4` |
| Не знайдено | `Способ = СпособНеНайдено()` и ✓ нет | `ЦветНеНайдено` | 255, 215, 215 | `.no #ffd7d7` |
| Знято | `Способ = СпособСнято()` и ✓ нет | `ЦветСнято` | 236, 236, 236 | `.off #ececec` |

**Механика:**
- `ОформитьСпособ(Способ, ЦветФона, ЭлементЛегенды)` добавляет элемент `УсловноеОформление` с двумя отборами
  (`Распознавание.Способ` = текст способа, `Распознавание.Подтверждено` = Ложь) и ставит тот же цвет фону легенды;
- `ОформитьПодтвержденные` — один отбор `Подтверждено = Истина`;
- `ДобавитьПоляОформления` красит **четыре колонки**, а не всю строку: `РаспознаваниеПодтверждено`,
  `РаспознаваниеНоменклатура`, `РаспознаваниеСходство`, `РаспознаваниеСпособ`.

**Условие — по тексту способа.** Тексты «Не знайдено — виберіть», «Схоже — перевірте», «Поза залишками — перевірте»
берутся из экспортных функций модуля объекта (`СпособНеНайдено()` и т.д.). «Знято бухгалтером» и «Вибрано вручну» —
из функций **модуля формы** `СпособСнято()`, `СпособВручную()` (`&НаКлиентеНаСервереБезКонтекста`).
→ Меняя текст способа, менять его в одном месте — в функции. Литералов в отборах нет.

**Цвет — только кодом.** `<TextColor>style:…</TextColor>` в `Form.xml` внешней обработки валит загрузку с
«Исключение XDTO» ([LESSONS](LESSONS.md)).

Что ещё ставится кодом в `ПриСозданииНаСервере`:
- жирный шрифт (`Новый Шрифт(, , Истина)`) — у `ГотовоСумма`, `ФайлСумма`, `КонтрольИтога`;
- `ЦветаСтиля.ПоясняющийТекст` — у `ПодсказкаВарианты` и `ПодсказкаСклады`.

### Колонки кода (запрос пользователя 09.10, коммит `ea3812bffc`)

Запрос: «где номенклатура 1С выводи рядом код 1С — чтобы бухгалтер видел код, если загрузка по коду, и код карточки,
чтобы быстро найти карточку и построить остатки по оборотке».

- **«Код 1С» (`КодКарточки`)** стоит сразу после «Номенклатура 1С» — в главной таблице и в вариантах. Подсказка: «Код
  картки: за ним швидко знайти картку в довіднику або в оборотно-сальдовій відомості». Видна всегда.
  - Главная таблица: заполняет `УстановитьВыбор` (`Номенклатура.Код`) в модуле объекта; при ручном выборе —
    `ДанныеКарточкиНаСервере` (возвращает `КодКарточки`).
  - Варианты: код из запросов кандидатов (`ВТ.Номенклатура.Код` в `КандидатыИзОстатков`, `Н.Код` в
    `КандидатыИзСправочника`).
- **«Код з накладної» (`Код`)** стоит после названия. Это код из колонки кода файла. Видимость —
  `Элементы.РаспознаваниеКод.Видимость = Объект.КолонкаКод > 0`, ставится в `ПриСозданииНаСервере` и в
  `ПрочитатьФайлНаСервере`. Если поменять номер колонки на «Налаштуваннях», видимость обновится после «1. Прочитати».

Проверка 09.10: у 69 строк с карточкой и у 310 вариантов код совпал с `Номенклатура.Код`. Основные форматы кодов в
базе — `00000019663` и `00-00019346`; реже `БП-…` и `SKU nn` ([FINDINGS](FINDINGS.md)).

### Итоги и контроль «Разом»

Три группы с заголовком (`Representation=NormalSeparation`, `ShowTitle=true`). Поля только для чтения, заголовок
сверху (`TitleLocation=Top`):

| Группа | Поля | Что считается |
|---|---|---|
| **Усього в накладній** | Рядків · Кількість · Сума без ПДВ · «Разом» у накладній · `КонтрольИтога` | все строки таблицы; «Разом» = `ИтогФайла` из файла |
| **Готово до завантаження ✓** | Рядків · Кількість · Сума без ПДВ | строки с ✓ |
| **Не підтверджено** | Рядків · Кількість · Сума без ПДВ | разность первых двух |

**Сумма строки в итогах** = `Сумма`, а если она 0 — `Окр(Количество × Цена, 2)`. Так же сумму строки берёт загрузка
([06](06_zagruzka_v_dokument.md)). Количество суммируется как есть, в единицах файла (т, шт, л вперемешку). Это
ориентир для сверки с накладной, а не физическая величина.

**`КонтрольИтога`** (LabelField, жирный, цвет текста ставится кодом):

| Ситуация | Текст | Цвет RGB |
|---|---|---|
| строк нет | пусто | — |
| в файле нет строки итога (`ФайлРазом = 0`) | «У накладній немає рядка «Разом» — звірте суму вручну» | 150, 110, 0 |
| `ФайлРазом = ФайлСумма` (точное равенство) | «✓ Сума рядків = «Разом»» | 30, 130, 60 |
| иначе | «⚠ Різниця з «Разом»: <ФайлРазом − ФайлСумма> — перевірте пропущені рядки» | 200, 40, 40 |

`ФайлРазом` ставит `ПрочитатьФайлНаСервере` из `Результат.ИтогФайла` (Неопределено → 0). Как находится строка итога —
в [02](02_chtenie_fayla_i_nastroyki.md). На накладной АСУБЗ «Разом» = **5 731 100,43**, сумма строк совпадает,
контроль зелёный (09.10.2026).

### Варианты для строки (`Кандидаты`)

- Декорация `ПодсказкаВарианты`: «Варіанти для виділеного рядка — двічі клацніть, щоб підставити картку:».
- Таблица `Кандидаты`: `ReadOnly`, `HeightInTableRows=5`, `VerticalStretch=false`, без командной панели.
- Колонки: Номенклатура 1С (40) · Код 1С (11) · Схожість, % (5) · Залишок (9) · Склад залишку (24) · Чому
  запропоновано (50).

**Откуда данные.** Сервер возвращает **все** варианты файла в реквизит `Варианты` (до 5 на строку, колонка
`НомерСтроки`; на АСУБЗ — 310). На клиенте `ПоказатьВарианты` копирует в `Кандидаты` варианты активной строки.
Вызывается:
- из `РаспознаваниеПриАктивизацииСтроки` через `ПодключитьОбработчикОжидания("ПоказатьВарианты", 0.1, Истина)` —
  дебаунс при листании;
- после чтения файла.

**У «зелёных» строк вариантов нет.** `Сопоставить` пишет варианты только на шаге сходства. Строки, найденные по коду
1С, по памяти («Вибрано раніше») или по точному названию среди остатков, выходят раньше (`Продолжить`), и таблица
вариантов у них пустая. На АСУБЗ: 62 строки (45 + 2 + 15) × 5 = 310, у 22 строк «Вибрано раніше» вариантов нет. Чтобы
заменить такую карточку, её выбирают в колонке «Номенклатура 1С» или жмут «Забути вибір рядка» и читают файл заново.

**Выбор варианта** — двойной клик или Enter, событие `Selection` → `КандидатыВыбор`:
- `Номенклатура` = вариант, данные карточки — `ДанныеКарточкиНаСервере`;
- `Сходство` и `Пояснение` — из варианта; ✓; способ «Вибрано вручну».

`Пояснение` варианта перезаписывает пояснение о единицах, которое вернула `ДанныеКарточкиНаСервере`.

## Закладка «Налаштування»

- **«Номери колонок у файлі Excel (A = 1, B = 2, C = 3 …)»** — семь полей шириной 9, заголовок сверху: Перший рядок
  даних, Назва товару, Кількість, Одиниця, Ціна без ПДВ, Сума без ПДВ, «Код 1С (0 — немає)». Это реквизиты объекта;
  умолчания и сохранение — [02](02_chtenie_fayla_i_nastroyki.md).
- **«Пошук і завантаження»** — два флажка, заголовок справа:
  - «Шукати в довіднику, якщо на складах не знайдено» (`ИскатьВнеОстатков`);
  - «Очищати товари документа перед завантаженням (рекомендовано: повторне завантаження замінює, а не дублює)»
    (`ОчиститьТовары`). При каждом открытии `ЗаполнитьНастройки` ставит его в Истина.
- **Склады** — таблица `Объект.Склады` (4 строки, своя командная панель: склады можно добавлять и удалять).
  - Подсказка: «Картки товарів шукаються серед залишків цих складів. Склад документа додається автоматично.
    Налаштування запам'ятовуються.»
  - Склад документа добавляется в список при открытии и при следующем чтении файла сохраняется вместе со списком
    (`СохранитьНастройки`).

## Закладка «Інструкція»: макет TextDocument → поле HTML-документа

**Цепочка:**
1. Макет `Инструкция`, `TemplateType = TextDocument`, синоним «Інструкція (HTML)». Текст лежит в
   `Templates/Инструкция/Ext/Template.txt`: HTML, **UTF-8 с BOM**, ~9 КБ.
2. `ПриСозданииНаСервере`: `ТекстИнструкции = Обработка.ПолучитьМакет("Инструкция").ПолучитьТекст();`.
3. Реквизит-строка `ТекстИнструкции` → `HTMLDocumentField` `ПолеИнструкции` (`TitleLocation=None`, без событий и без
   `Height`). Поле растягивается и прокручивается само.

**Почему так** (исследование 09.10, [FINDINGS](FINDINGS.md)):
- TextDocument — один файл, удобный diff, Конфигуратор его не переформатирует.
- Макет HTMLDocument хранит страницы ru/uk, а его WYSIWYG-редактор переписывает разметку.
- С 8.3.14 тонкий клиент Windows рисует поле через **WebKit** уровня Safari 12–13. Надёжны блочная вёрстка, таблицы,
  `border-radius`, `linear-gradient`. `<meta charset="utf-8">` обязателен.
- Внешних ресурсов нет: ни CDN, ни веб-шрифтов, ни относительных картинок. Ссылок `<a>` нет, поэтому перехват `OnClick`
  не нужен.
- HTML присваивается **один раз** при создании формы.

**Содержание** (на украинском, коротко для бухгалтера):
- шапка с градиентом `#1b6b93 → #4fc0d0`;
- «Як завантажити — 4 кроки» (кружки-номера на `display:table`, без flex);
- «Що означають кольори» — таблица с теми же фонами, что в форме;
- строка про перемикач;
- «Підсумки під таблицею»;
- «Корисно знати»: «Код 1С» и «Код з накладної», запоминание выбора и «Забути вибір рядка», повторная загрузка,
  сумма из накладной и т ↔ кг, приєднані файли, «Excel з кодами 1С» (колонка кода 6);
- жёлтая карточка: документ не проведён, номера колонок на «Налаштуваннях».

**Расхождение текста.** Инструкция называет первую группу итогов «Усього у файлі», в форме она «Усього в накладній».
При правке инструкции — выровнять.

## Обработчики событий

| Событие | Элемент | Процедура | Контекст |
|---|---|---|---|
| `OnCreateAtServer` | форма | `ПриСозданииНаСервере` | сервер |
| `StartChoice` | `ИмяФайла` | `ИмяФайлаНачалоВыбора` → `ВыбратьФайл` → `ВыбратьФайлЗавершение` (Экспорт) | клиент |
| `OnChange` | `Показать` | `ПоказатьПриИзменении` → `ПрименитьФильтр` | клиент |
| `OnActivateRow` | `Распознавание` | `РаспознаваниеПриАктивизацииСтроки` → `ПоказатьВарианты` (Экспорт, ожидание 0,1 с) | клиент |
| `OnChange` | `РаспознаваниеПодтверждено` | `РаспознаваниеПодтвержденоПриИзменении` | клиент |
| `OnChange` | `РаспознаваниеНоменклатура` | `РаспознаваниеНоменклатураПриИзменении` | клиент + `ДанныеКарточкиНаСервере` |
| `Selection` | `Кандидаты` | `КандидатыВыбор` | клиент + `ДанныеКарточкиНаСервере` |
| оповещение `НачатьПомещениеФайла` | — | `ВыбратьФайлЗавершение` (Экспорт) → `ПрочитатьФайлНаСервере` + `ПоказатьВарианты` | клиент |
| оповещение `НачатьПолучениеФайлов` | — | `ВыгрузитьВExcelЗавершение` (Экспорт) | клиент |

Команды формы (`<Action>`) — в таблице «Командная панель» выше.

**Логика флажка ✓ (`РаспознаваниеПодтвержденоПриИзменении`):**
- поставили ✓ без карточки — ✓ снимается, предупреждение «Спершу виберіть картку в колонці «Номенклатура 1С».»;
- сняли ✓ — способ «Знято бухгалтером». Такую строку «Підтвердити схожі» не трогает (находка ревью №11);
- поставили ✓ строке «Знято» — способ «Вибрано вручну».

**Ручной выбор карточки (`РаспознаваниеНоменклатураПриИзменении`):**
- карточка выбрана — ✓, «Вибрано вручну», 100 %;
- карточка очищена — ✓ снят, способ пуст, 0 %.

`ДанныеКарточкиНаСервере(Номенклатура, ЕдиницаФайла)` возвращает `Структура(КодКарточки, ЕдиницаКарточки, Остаток,
СкладОстатка, Пояснение)`. Остаток берётся экспортной `ДанныеОстатка` модуля объекта. Пояснение:
- «немає залишку на складах пошуку»;
- «одиниця файлу «X», картки «Y» (т ↔ кг перераховується)». Здесь единицы сравниваются **сырыми строками**
  (`НРег(СокрЛП(…))`), без `КлючЕдиницы`. Пояснение появится и для «шт.»/«шт», и для «т»/«м», хотя пересчитываются
  только т ↔ кг.

**Повторное чтение (`ПрочитатьФайлНаСервере`).** Сохраняет ручной выбор: строки со способом «Вибрано вручну»
запоминаются по ключу `НомерСтроки|Наименование`. После нового `ПрочитатьИСопоставить` они восстанавливаются с ✓ и 100 %.
Затем идут `ЗначениеВРеквизитФормы` для `Распознавание`, `Варианты`, `Объект`. Ошибки и предупреждения чтения выводятся
через `Сообщить`.

**После загрузки (`ЗагрузитьВДокументНаСервере`).** Все подтверждённые строки, кроме «За кодом 1С», получают способ
«Вибрано раніше». Так форма показывает, что выбор теперь в памяти.

`ЗаполнитьЗначенияСвойств` и этому условию не подчиняется.

## `ОбновитьИтогиФормы(Форма)` — общий код клиента и сервера

`&НаКлиентеНаСервереБезКонтекста Процедура ОбновитьИтогиФормы(Форма)`. Вызывается как `ОбновитьИтогиФормы(ЭтотОбъект)`:
- с сервера — в `ПриСозданииНаСервере`, `ПрочитатьФайлНаСервере`, `ПодтвердитьСхожиеНаСервере`,
  `ЗагрузитьВДокументНаСервере`;
- с клиента — в обработчиках ✓, выбора карточки, выбора варианта, «Забути».

Один проход по `Форма.Распознавание`:
- считает три блока итогов;
- выставляет `Группа`;
- пишет `КонтрольИтога` и его цвет, `НадписьРезюме`;
- вызывает `ПрименитьФильтр(Форма)`, чтобы фильтр учёл новые группы.

**Почему не `&НаКлиентеНаСервере`.** Эта директива в формах BuhBud/ERP не встречается ни разу. Использован приём БСП:
`БезКонтекста` плюс форма параметром. Изнутри доступны реквизиты (`Форма.ФайлСумма`) и элементы
(`Форма.Элементы.КонтрольИтога.ЦветТекста`).

## Украинские заголовки

Язык интерфейса BuhBud — **uk**. В первой версии `Form.xml` у заголовков был только `<v8:lang>ru</v8:lang>`. Для uk
текста не было, и платформа показывала **имена элементов**: ПрочитатьФайл, НомерСтроки, ИмяФайла.

→ Каждый `Title`, `ToolTip`, `InputHint` и `Presentation` тумблера содержит **оба** языка, ru и uk, с **одинаковым
украинским** текстом (79 пар в `Form.xml`).
- Синоним корня обработки: ru — русский, uk — «Завантаження з Excel ТЧ Реалізація (зіставлення з залишками)».
- `form_xcheck.py` ловит `Title` без uk.

## Порядок свойств в `Form.xml`

Выведен из типовых форм BASEBuh. Генератор пишет свойства только в этом порядке. Если загрузка падает с «Исключение
XDTO», ошибка не называет ни тег, ни строку — искать бисекцией ([LESSONS](LESSONS.md)).

| Элемент | Порядок |
|---|---|
| `Table` | Representation → CommandBarLocation → ReadOnly → ChangeRowSet → ChangeRowOrder → HeightInTableRows → VerticalStretch → DataPath |
| `InputField` | DataPath → Title → ReadOnly → EditMode → TitleLocation → ToolTip → Width → AutoMaxWidth → HorizontalStretch → ChoiceButton → TextEdit → InputHint |
| `CheckBoxField` | DataPath → Title → TitleLocation → ToolTip → EditMode → CheckBoxType |
| `UsualGroup` | Title → Group → Behavior → Representation → ChildItemsWidth → ShowTitle |
| `Pages` / `Page` | PagesRepresentation / Title → Picture |
| `RadioButtonField` (Tumbler) | DataPath → TitleLocation → RadioButtonType → ChoiceList (`xr:Item` / `FormChoiceListDesTimeValue`) |
| `Button` в `AutoCommandBar` | Type → Representation → DefaultButton → CommandName → Picture |
| `Command` | Title → ToolTip → Action |
| `HTMLDocumentField` | DataPath → TitleLocation |

`ChildItemsWidth` допустимы `Equal` и `LeftNarrowest`. `LeftWidest` в формах не встречается.

**Компоновка без прокрутки** (`bas-form-layout`):
- один растягиваемый элемент на странице (`Распознавание`);
- мини-таблицы с `HeightInTableRows` и `VerticalStretch=false`;
- ряды итогов с `TitleLocation=Top`;
- `ShowTitle=false` у групп раскладки;
- `CommandBarLocation=None` у таблиц только для чтения;
- у формы `VerticalScroll=useIfNecessary`.

## Генератор `gen_form.py`

`python _Rarzrabotki/Python/test/zagruzka_realizacii/gen_form.py "<каталог Загрузка ТЧРеализацияТоваровУслуг>"`

Что делает:
- перезаписывает **только** `Forms/Форма/Ext/Form.xml` — UTF-8 с BOM, CRLF;
- корень `.xml`, `Forms/Форма.xml`, GUID и `ClassId` не трогает;
- печатает «OK Form.xml, останній id 298».

Проверено 09.10: вывод генератора совпадает с текущим `Form.xml`.

**Устройство:**
- функции-построители с фиксированным порядком свойств: `поле`, `прапорець`, `напис_поле`, `напис`, `група`,
  `сторінка`, `таблиця`, `перемикач`, `html_поле`, `кнопка_панелі`;
- `текст(...)` пишет ru и uk одинаковым текстом;
- id выдаёт сквозной счётчик `Ід`;
- данные — списки `КОМАНДИ` (имя, заголовок, подсказка, картинка, по умолчанию), `КОЛОНКИ_РАСП`, `КОЛОНКИ_ВАР`,
  `ПІДСУМКИ`.

**Правила:**
- Форму менять только через генератор: правка → запуск → `form_xcheck.py` → сборка ([09](09_sborka_testy_priemka.md)).
- Добавляя колонку в `КОЛОНКИ_РАСП`/`КОЛОНКИ_ВАР`, добавить её и в `НоваяТаблицаРаспознавания`/`НоваяТаблицаВариантов`
  модуля объекта.
- Комментарий у `Группа` в `КОЛОНКИ_РАСП` — «лише у формі» — **устарел** после `70449f2a9d`: теперь колонка есть и в
  модуле объекта.
