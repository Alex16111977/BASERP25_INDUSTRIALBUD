# 04. Метрика сходства (`ОценкаСходства`)

Код — модуль объекта `_Rarzrabotki/temp/Загрузка ТЧРеализацияТоваровУслуг/Ext/ObjectModule.bsl`:
- область «Нормализация»: `КлючНазвания`, `КлючНазванияДо0910`, `РазмерыЕстьВНазвании`, `ПризнакиНазвания`,
  `ЛексемыНазвания`, `НайтиСловоПеред`, `НормализованноеЧисло`, `ДобавитьТриграммы`, словари `СтопСлова`, `СловаСтандартов`,
  `СловаМарок`, `КлассыМицности`, `ЕдиныеБуквы`, `ДобавитьУникально`, проверки символов `ЭтоБуква` и `ЕстьКириллица`;
- область «Сопоставление»: `ИндексКандидатов`, `ОценкаСходства`, `ВсеЕсть`, `ЕстьСловоСОсновой`, `КосинусТриграмм`;
- экспорт для диагностики: `ОценкаПары`.

Как балл используется в конвейере — [03](03_algoritm_sopostavleniya.md). Почему формула такая — [05](05_issledovanie_metodov.md).

## Формула за минуту

Балл «Схожість, %» (0–100) — гибрид: **T** сравнивает слова, **N** сравнивает размеры, потом множители и «судьи»-стели.

```
T = косинус TF-IDF символьных триграмм СЛОВ файла и карточки          (0..1; числа в T не входят)
N = совпавшие размеры / размеры файла × (1 − 0,05 × min(лишние размеры карточки, 4))
    у файла нет размеров: N = T, если и у карточки нет; иначе N = 0,7
Множитель = 0,8 (другой стандарт) × 0,9 (другая марка);  Стеля = 75, если сработал хоть один, иначе 100
Сходство = min(Стеля, Окр(100 × (0,5·T + 0,5·N) × Множитель))
затем:  ≤ 49 — размер файла не найден в карточке (у карточки свои размеры)
        ≤ 70 — у файла размеры есть, у карточки нет
        ≤ 40 — другой тип изделия
        ≤ 49 — правые ≠ левые
```

Зоны: **≥ 85** — кнопка «Підтвердити схожі ≥ 85 %» (только строки «Схоже — перевірте», не «Поза залишками»); **60–84** — подставляется для проверки; **< 60** — не подставляется;
**< 20** — даже в варианты не попадает.

## 1. Нормализация

### `ЕдиныеБуквы` — «скелет» строки (идея Unicode TR39)

Применяется после `НРег`:
- латинские двойники → кириллица: `aceiopxykmtbh` → `асеіорхукмтвн` (`i` → украинская `і`);
- `ё` → `е`;
- `ø` → пробел (`Ø` после `НРег` становится `ø`);
- `г/к` → `гк`, `х/к` → `хк`.

Остальная латиница (`d f g j l n q r s u v w z`) остаётся латиницей. Поэтому DIN → `dіn`, ISO → `іsо`, S235 → `s235`,
SP → `sр`, Hilti → `ніlті`. Словари стандартов и марок прогоняются через ту же функцию при создании, поэтому сравнение
идёт в одном алфавите. `×` (знак умножения) не заменяется — это просто разделитель.

### `ЛексемыНазвания` — лексер без регулярных выражений

Один проход по символам. Символы трёх классов:
- цифра;
- буква (`ЭтоБуква`: латиница a–z и кириллица, включая ґ є і ї ё ъ ы э);
- всё остальное — разделитель.

Лексема — `Структура(Вид, Значение, Слитно, Разделитель)`:
- `Вид`: «с» — слово, «ч» — число;
- `Слитно`: лексема прилегает к предыдущей без разделителя и без пробела;
- `Разделитель`: непробельные символы между предыдущей лексемой и этой.

Правила лексера:
- `,` или `.` между цифрами — часть числа и превращается в `.`: «1,5» → `1.5`, «8.8» остаётся;
- пробел — не лексема и не входит в `Разделитель`, но разрывает `Слитно`.

Пример: «М16х55» → `м`(с) · `16`(ч, слитно) · `х`(с, слитно) · `55`(ч, слитно).

### `НормализованноеЧисло`

- Есть точка → срезаются хвостовые нули, потом висящая точка: `4.0` → `4`, `12.00` → `12`, `12.050` → `12.05`. `8.8`
  не меняется.
- Ведущие нули срезаются, кроме `0.`: `09` → `9`, `0.7` остаётся.

### `КлючНазвания` — ключ точного совпадения и памяти

- Лексемы `ЕдиныеБуквы(НРег(СокрЛП(Текст)))` через один пробел, числа нормализованы.
- «х» между двумя числами выбрасывается.
- Разделители исчезают сами: они не лексемы.
- **Стоп-слова остаются, порядок не меняется.**

Проверено через `ОценкаПары` 09.10.2026:

| Название | Ключ |
|---|---|
| Болт M16*55 / Болт М16х55 | `болт м 16 55` |
| Лист 8,0 мм / Лист 8мм | `лист 8 мм` |
| Лист г/к 1,5*1250*2500 ст3пс | `лист гк 1.5 1250 2500 ст 3 пс` |
| Лист 1/2 | `лист 1 2` (≠ `лист 12`) |
| Шайба М10 DIN 125-1 | `шайба м 10 dіn 125 1` |
| Гайка М16 S24 (ISO4032) | `гайка м 16 s 24 іsо 4032` |
| Ёлка Ø12 | `елка 12` |

**`КлючНазванияДо0910` — старый ключ, только для чтения памяти.** Строится так:
1. `ЕдиныеБуквы(НРег(СокрЛП(Текст)))`.
2. Удаляются пробел и символы `№ - ( ) " ' . , « » _ / * × ø : ;`, неразрывный пробел и табуляция.

«Лист 1,5» и «Лист 15» дают один и тот же `лист15`, поэтому старую запись берут только с проверкой
`РазмерыЕстьВНазвании` ([03](03_algoritm_sopostavleniya.md)).

## 2. `ПризнакиНазвания` — разбор на поля

Результат — `Структура`:

| Поле | Тип | Смысл |
|---|---|---|
| `Размеры` | Массив, **мультимножество** | числа-размеры, резьба `м16`, под ключ `s24`, профиль `12п` |
| `Марки` | Массив без повторов | марка или класс: `245`, `ст3`, `а500`, `8.8`, `s235`, `еі30` |
| `Стандарты` | Массив без повторов | номер после DIN/ISO/ДСТУ/ГОСТ/EN/ТУ/ОСТ |
| `Слова` | Массив | значимые слова |
| `Триграммы` | Соответствие триграмма → счётчик | для T |
| `Тип` | Строка | основа (4 буквы) типа изделия |
| `Сторона` | «п» / «л» / «» | праві / ліві |

### Слова — правила по порядку

1. **«х» между двумя числами** (даже с пробелами: «34 х 38») — знак умножения, пропуск.
2. **Сторона.** Слово начинается с «прав» → `п`; с «лів» или «лев» → `л`. Побеждает последнее: «ліві праві» → `п`.
3. **Буква профиля.** Одна буква из `пубкшед`, прилегает к числу, ушедшему в размеры, → дописывается к размеру:
   «12П» → `12п`, «20Б1» → `20б`. После этого «1» с префиксом «б» уходит в марки как `б1`.
4. **Короче 2 букв или стоп-слово** → пропуск. `СтопСлова`: мм ст см кг шт та для на до из із за згідно по вид тип
   марка з і й в у ос.
5. Иначе слово идёт в `Слова`, его триграммы — в `Триграммы`.
6. **Тип.** Первое слово длиной от 3 букв, которое не входит в словари стандартов и марок и содержит кириллицу
   (`ЕстьКириллица`: хотя бы одна кириллическая буква) → `Тип` = первые 4 буквы. Проверка идёт после `ЕдиныеБуквы`, где
   латинские двойники уже стали кириллицей: «Hilti» → `ніlті` её проходит, а слово только из «чистой» латиницы
   (`d f g j l n q r s u v w z`) — нет. Примеры:
   - «Арматура» → `арма`;
   - «DIN933 Болт» → `болт` (`dіn` — слово стандарта);
   - «Сталь 09Г2С» → типа нет: «сталь» — слово марки.

### Числа — классификация

Перед проверками считаются:
- `Префикс` — предыдущее слово, если число к нему **прилегает**. «х» после числа префиксом не считается: «960х2050»,
  «м16х100».
- `СловоПеред` — предыдущая лексема, если это слово, даже через пробел или точку. Через другое число не ищется
  (`НайтиСловоПеред`): в «ГОСТ 8732 57х3,5» число 57 — размер, в «DIN 933 8.8» 8.8 — класс прочности.
- `ЧерезДефис` — предыдущая лексема число, разделитель ровно `-`.
- `СуффиксМарки` — следующая лексема — прилегающее слово из `СловаМарок` («3пс»).

Первое сработавшее правило определяет класс:

| # | Условие | Класс | Примеры |
|---|---|---|---|
| 1 | через дефис после **стандарта** | пропуск (год, часть) | «ДСТУ 10704-91» → 10704; «DIN 125-1» → 125; «ГОСТ 8732-78» → 8732 |
| 2 | через дефис после марки **с буквенным префиксом** | марка | «А2-70» → `а2`, `70`; «ст1-3» → `ст1`, `3` |
| 3 | префикс ф, d, dn, ду, дн | размер (без префикса) | «ф12» = «Ø12» = «12»; «DN50» → `50` |
| 4 | префикс м | размер `м`+число (резьба) | «М16» → `м16` |
| 5 | префикс s/с и число < 100 | размер `s`+число (под ключ) | «S24» → `s24` |
| 6 | префикс — слово стандарта, или без префикса, но `СловоПеред` — слово стандарта | стандарт | «DIN 933» → 933, «ISO4032» → 4032 |
| 7 | есть префикс, или `СловоПеред` — слово марки, или `СуффиксМарки`, или класс прочности | марка (префикс+число) | «А500С» → `а500`; «ст.245» → `245`; «3пс» → `3`; «8.8»; «С245» → `с245`; «S235» → `s235`; «ЕІ30» → `еі30` |
| 8 | иначе | размер | «1150», «0,7» в «ПС-20-1150-0,7» |

- **Словари:** `СловаСтандартов` — din iso дсту гост en ту ост; `СловаМарок` — ст кл клас сталь марка пс сп кп пс5 сп5
  кат; `КлассыМицности` — 4.6 4.8 5.6 5.8 6.8 8.8 10.9 12.9.
- **Добавление.** Размер добавляется как есть, повторы сохраняются. Стандарт и марка — `ДобавитьУникально`.
- **Цепочка марки.** `МаркаСПрефиксом` = класс «м» и (есть префикс или (через дефис и предыдущее тоже с префиксом)).
  Поэтому «ПС-20-1150-0,7» даёт марку `20` и размеры 1150 и 0,7, а «А2-70» — две марки.
- `КлассПредЧисла` — класс предыдущего числа. На пропуске по правилу 1 он не меняется (остаётся «с»), поэтому в
  «ГОСТ 10704-91-…» стандартом становится только 10704, а все дальнейшие числа через дефис тоже пропускаются.

## 3. T — косинус TF-IDF триграмм

- **Триграммы — только из `Слова`.** Числа, марки и стандарты в T не попадают: размеры судит N. Каждое слово обрамляется
  пробелами отдельно (`" " + слово + " "`), слово из L букв даёт L триграмм. «болт» → « бо», «бол», «олт», «лт ». TF —
  сырой счётчик.
- **IDF** (`ИндексКандидатов`): `IDF(g) = ln((1 + N) / (1 + df(g))) + 1`. N — число кандидатов (минимум 1), df — в
  скольких кандидатах есть триграмма. Это сглаженный IDF, как в sklearn/string_grouper.
- **Индексов три:**
  - по остаткам — один на файл, 429 кандидатов на 09.10;
  - по кандидатам справочника — свой на каждую строку, дошедшую до шага 5б ([03](03_algoritm_sopostavleniya.md));
  - в `ОценкаПары` — по одной карточке, там все веса = 1.
- **`КосинусТриграмм`:**
  - вес = IDF × счётчик;
  - триграмма, которой нет в индексе, получает IDF = **1** — минимальный вес, как у самой частой;
  - `cos = Σ wф·wк / √(Σwф² · Σwк²)`;
  - у одной из сторон нет триграмм → 0.
- **Что даёт T:**
  - не важны порядок слов и регистр («Настил решітковий» = «Решітковий настил» → 100);
  - латиница-двойник не мешает;
  - словоформы частично прощаются: «Плити мінераловатні 50» vs «Плита мінераловатна 50» → 89 (слова 78 %).

## 4. N — размеры

**Мультимножество.** Каждый размер файла ищет равный среди размеров карточки, найденный вычёркивается из копии.
Сравниваются строки после нормализации, поэтому `м16` ≠ `16`, `12п` ≠ `12`, `s24` ≠ `24`.

```
N = |совпавшие| / |размеры файла| × (1 − 0,05 × min(невычеркнутые размеры карточки, 4))
```

Проверено через `ОценкаПары` 09.10.2026:

| Файл | Карточка | Балл | Почему |
|---|---|---|---|
| Лист 8 | Лист 8*1500*6000 | 95 | N = 1 × (1 − 0,1) |
| Болт М16*55 | Болт М16*55*55 | 98 | одна лишняя 55 у карточки |
| Болт М16*55 55 | Болт М16*55 | 49 | вторая 55 файла не нашлась |
| Лист 1250*2500*5 | Лист 5*1250*2500 | 100 | порядок не важен (ключи при этом разные) |
| Болт М16х55 | Болт М16х60 | 49 | главный случай исследования |
| Двері 780*2080 | Двері 880*2080 | 49 | |

**У файла нет размеров:**
- у карточки тоже нет → `N = T` («Кріплення для сходинок» сама с собой → 100; строка KNZ накладной АСУБЗ → 70 = «слова
  70 %»);
- у карточки есть → `N = 0,7` («Кріплення для сходинок» vs «Кріплення 14» → 71).

## 5. Множители и стели («судьи»)

| Условие | Действие | В пояснении | Пример (`ОценкаПары`) |
|---|---|---|---|
| Стандарты с обеих сторон, не все стандарты файла есть в карточке | ×0,8 и стеля 75 | «інший стандарт (стандарты карточки)» | «Болт М16 DIN 931» vs «Болт М16 DIN 933» → 75 |
| Марки с обеих сторон, не все марки файла есть в карточке | ×0,9 и стеля 75 | «інша марка (марки карточки)» | «Болт М16 8.8» vs «Болт М16 10.9» → 75; «Кутник 75х75х6 ст.3» vs «…S235» → 75 |
| Марка или стандарт только с одной стороны | ничего | — | «Лист 8 S235» vs «Лист 8» → 100, и наоборот |
| Размер файла не найден, у карточки есть свои | ≤ 49 | «НЕМАЄ розмірів: …» | «Гайка М16 S24» vs «Гайка М24 S16» → 49 |
| У файла размеры есть, у карточки нет | ≤ 70 | «у картці немає розмірів» | «Труба 57х3» vs «Труба сталева» → 32 |
| Тип изделия не совпал | ≤ 40 | «інший тип виробу» | «Анкер хімічний Hilti HIT-RE 500» vs «Капсула хімічна …» → 40 |
| Стороны разные | ≤ 49 | «інша сторона (праві/ліві)» | «Двері 880*2080 праві» vs «…ліві» → 49 |

- **`ВсеЕсть`: все значения файла должны быть в карточке.** До ревью было «хоть одно общее» (`ЕстьПересечение`): общий
  «8732» или «а500» снимал штраф, ф16 вместо ф12 давал 100 (ревью №2, №3).
- **Совпадение типа двустороннее** (`ЕстьСловоСОсновой`). Тип пуст хотя бы с одной стороны (проверки нет), или типы
  равны, или у карточки есть слово на основу типа файла **и** у файла есть слово на основу типа карточки. «Швелер 14П» vs «Кріплення гакове до швелера 14»: у карточки
  «швелера» есть, у файла слова на «кріп» нет → ≤ 40 (итог 22).
- **Почему 75:** < 85 — кнопка такую строку не подтвердит; ≥ 60 — подсказка всё же видна как «перевірте». До ревью
  другая марка давала только ×0,9, это 88–90 и массовое подтверждение не той марки (ревью №5).
- **Почему 49:** < 60 — в строку не подставляется, видно только в вариантах.
- Стели не складываются: берётся минимум. «Швелер 14П» vs «Кріплення…» попадает под 49 и под 40, итог 22 по самой
  формуле.

**Пояснение** собирается так: «слова T %» + «; розміри збіглися: …» + «; НЕМАЄ розмірів: …» + «; <примечания>». Варианты
из справочника начинаются с «без залишку; ». У строки «Не знайдено» — «найкращий N %: …» ([03](03_algoritm_sopostavleniya.md)).

## 8. `ОценкаПары` — диагностика одной пары

```
Функция ОценкаПары(НазваниеФайла, НазваниеКарточки) Экспорт
// → Структура(Сходство, Пояснение, КлючФайла, КлючКарточки)
```

- Разбирает обе строки, строит индекс по **одной** карточке и вызывает ту же `ОценкаСходства`.
- IDF по одной карточке = 1 для всех триграмм, поэтому T здесь — обычный косинус счётчиков. В таблице сопоставления IDF
  считается по 429 кандидатам, и «слова %» может отличаться на несколько пунктов. Стели и N — те же.
- Зачем:
  - объяснить бухгалтеру конкретный балл;
  - регрессия;
  - проверить правило до правки.
- Вызов из Python COM: `обр = c.ВнешниеОбработки.Создать(EPF, False)`; `обр.ОценкаПары("Болт М16х55", "Болт М16х60")` →
  49, «слова 100 %; розміри збіглися: м16; НЕМАЄ розмірів: 55».

## 9. Ограничения (на 09.10.2026)

Все примеры проверены через `ОценкаПары`.

- **Числа в скобках — полноценные размеры.** «Лист ПВЛ №506 1250*2500*5 (32*85)» не находит карточку без «(32*85)»:
  49, «Не знайдено». `№506` тоже размер.
- **После «/» номер стандарта не продолжается.** «ГОСТ 5915/5927» → стандарт 5915, а 5927 уходит в размеры. Продолжение
  стандарта — только через «-».
- **«ст 1-3» с пробелом:** «1» — марка, «3» — второй размер «3». Слитно «ст1-3» разбирается правильно.
- **Нет пересчёта мм↔м.** «Лист 1500*6000» vs «Лист 1,5*6» → 49.
- **Нет синонимов типа.** «Кутик 50х50х5» vs «Кутник 50х50х5» → 40 (основы `кути` ≠ `кутн`). «Плити/Плита» и
  «Сходи/Сходинки» проходят: первые 4 буквы равны.
- **Покрытие не атрибут.** «Болт M16*100 н/ж» vs «Болт М16х100 цб» → **91**: однобуквенные «н», «ж» отброшены. Такую
  подсказку кнопка ≥ 85 подтвердит. Нержавейку проверяйте глазами. На АСУБЗ строка 59 «… н/ж» → «… 8.8 цб» получила
  84, на волосок ниже порога.
- **Нет эквивалентов стандартов.** «Болт ISO 4017 М16х50» vs «DIN933 Болт М16х50» → 63, «інший стандарт (933)», хотя
  ISO 4017 ≡ DIN 933.
- **Тип — первое кириллическое слово от 3 букв.** Если название начинается с другого слова («Сталевий лист»), тип
  будет «стал». Тогда двусторонняя проверка решает по словам.
