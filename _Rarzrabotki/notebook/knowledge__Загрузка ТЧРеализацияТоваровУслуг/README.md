# knowledge__Загрузка ТЧРеализацияТоваровУслуг

База знаний по внешней обработке BAS Бухгалтерія **«Завантаження з Excel ТЧ Реалізація (зіставлення з залишками)»**,
имя объекта `ЗагрузкаТЧРеализацияТоваровУслуг`. Сделана 09.10.2026.

Поставщик присылает накладную Excel **без кодов 1С** и со своими названиями («Болт M16\*55 (DIN 933) оц.» против
карточки «DIN933 Болт М16х55 8.8 цб пр»). Обработка:
- **сама подбирает карточку номенклатуры** к каждой строке — среди остатков складов «Чорноморськ» и «Чорноморськ
  Списання»;
- показывает бухгалтеру **таблицу сопоставления** с цветами, пояснениями и вариантами;
- **загружает в товары документа `РеализацияТоваровУслуг` только подтверждённые (✓) строки**, сумма строки — точно из
  накладной;
- запоминает выбор и прикрепляет к документу накладную и журнал сопоставления.

База **BuhBud** (BAS Бухгалтерія): `Srvr="localhost";Ref="bas_industrialbud"`, пользователь `cfo` (Python COM, креды —
`.v8-project.json`, id=buhbud). Не BaseERP. Язык интерфейса базы — **украинский**.

## Коротко для пользователя

Четыре шага. Та же памятка на украинском — на закладке «Інструкція» в самой обработке.

1. Открыть **непроведённый** документ «Реалізація товарів і послуг» → «Заповнити» → **«Завантажити з Excel
   (зіставлення з залишками)»**. Документ подставится сам.
2. В поле «Файл накладної» выбрать xls или xlsx. Анализ начнётся сразу; кнопка **«1. Прочитати і зіставити»**
   перечитывает файл (например, после правки номеров колонок на «Налаштування»).
3. **Проверить таблицу по цвету и поставить ✓.** Другую карточку выбрать в колонке «Номенклатура 1С» или двойным
   кликом по варианту в нижней таблице. Кнопка «Підтвердити схожі ≥ 85 %» ставит ✓ очень похожим жёлтым строкам.
4. Сверить итоги под таблицей с накладной и нажать **«2. Завантажити в документ»**. В документ попадут **только строки
   с ✓**; документ записывается **без проведения**. Закрыть и открыть документ заново, чтобы увидеть товары.

**Цвета строк:**

| Цвет | «Як знайдено» | Что делать |
|---|---|---|
| зелёный | любая строка с ✓: «За кодом 1С», «Вибрано раніше», «Точна назва», «Вибрано вручну» | ничего |
| жёлтый | «Схоже — перевірте» | сверить название, размеры, марку; верно — ✓ |
| оранжевый | «Поза залишками — перевірте» | карточка есть в справочнике, но **не на складах** — проверять особенно |
| красный | «Не знайдено — виберіть» | выбрать карточку вручную или из вариантов внизу |
| серый | «Знято бухгалтером» | ✓ сняли или нажали «Забути вибір рядка»; строка не загрузится |

**Итоги под таблицей:**
- «Усього в накладній» — строки, количество, сумма без ПДВ и сумма строки «Разом» самой накладной. **«✓ Сума рядків =
  «Разом»»** — прочитаны все строки; «⚠ Різниця з «Разом»» — часть строк пропущена (проверить номера колонок и первой
  строки).
- «Готово до завантаження ✓» — что попадёт в документ.
- «Не підтверджено» — что осталось решить. Здесь 0 — накладная загрузится целиком.

**Полезно знать:**
- **«Код 1С»** рядом с «Номенклатура 1С» — код карточки: по нему карточку быстро найти в справочнике или в
  оборотно-сальдовой ведомости. Если в накладной есть колонка кода 1С (номер — на «Налаштування»), видна ещё колонка
  «Код з накладної», и карточка находится однозначно.
- **Выбор запоминается** — для всех бухгалтеров. Запомнилось неверно — выделить строку → «Забути вибір рядка».
- **Загружать повторно можно.** Флажок «Очищати товари документа перед завантаженням» включён всегда: товары
  заменяются, а не дублируются. Вложений не прибавляется: одна накладная и один «Журнал зіставлення <файл>.xlsx» в
  «Приєднаних файлах».
- Тонны и килограммы пересчитываются сами. Другие разные единицы (т против м) — нет: обработка предупредит, количество
  исправить вручную.
- **После каждой новой версии `.epf` — перезагрузить файл в карточке обработки** («Додаткові звіти й обробки» →
  карточка → загрузить файл → записать). База хранит старую копию у себя.
