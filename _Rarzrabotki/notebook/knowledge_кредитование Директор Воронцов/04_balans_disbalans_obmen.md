# 04. Баланс, обработка дисбаланса, обмен с BuhBud

## Управленческий баланс (`Reports/А_УправленческийБалансЕРП`)

- Суммы — только из регистра `ПрочиеАктивыПассивы`. Типовые регистры расчётов дают детализацию по договорам
  (`РасчетыСКлиентами/ПоставщикамиПоСрокам`, процедура `Свод_РасчетыСПартнерами`).
- Подразделение строки расчётов: `ОбъектРасчетов.Подразделение`, а если пусто — `Договор.Подразделение`.
  Подразделение документа **не используется**, поэтому у каждого проекта свой договор.
- Статья по умолчанию зависит от ресурса:
  - тело (договор `СПокупателем`, деньги получены) → «Полученные авансы»;
  - проценты (`СПоставщиком`) → «Задолженность перед поставщиками».
- `Договор.А_СтатьяБаланса = Задолженность по кредитам` переносит детальные строки в «Задолженность по кредитам»
  (процедура `ПрименитьСтатьюИзДоговора`, параметр варианта `ПрименятьСтатьюБалансаИзДоговора = Истина`).
  - Подмена — только в отчёте. ПАП и штатный «Управленческий баланс» видят исходную статью.
  - Строки-досверки («плуги») не подменяются.
- `А_ВидКонтрагента = Собственники` — аналитика 1 (разрез «Собственники»), на статью не влияет.

**Сверка (схема А):** сумма остатков договоров вида «Тело кредита» по всем подразделениям = сумма уменьшения по
договорам вида «Нераспределенная прибыль». Проценты сверяются отдельно (начисление − выплата, подпроект 2).
При переходе к схеме Б понадобится сверочная статья «Прибыль, размещённая во внутренние займы» на уровне 441.

## Обработка дисбаланса (`DataProcessors/А_ОбработкаДисбалансаПоПодразделениям`)

- Сводит ПАП **внутри одного регистратора** по подразделениям и создаёт `ВзаимозачетЗадолженности` между
  **внутренними** контрагентами (`Партнеры.А_Подразделение`) по договорам `X внутр.`.
- Кредитные платёжки не затрагиваются:
  - списание ЦО и поступление проекта — разные регистраторы;
  - каждый сходится внутри своего подразделения (деньги ↔ аванс);
  - Воронцов не внутренний партнёр (`А_Подразделение` пусто).
- Риск появится, если смешать Воронцова с договорами `X внутр.`, как в ручных правках 581–583.
