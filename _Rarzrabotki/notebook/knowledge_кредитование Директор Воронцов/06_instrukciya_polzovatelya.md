# 06. Инструкция пользователя (HTML) — как поддерживать

Правило проекта: документация = технические `.md` + **инструкция пользователя на украинском в HTML**
`Інструкція_Кредитування_Воронцов.html` (фото встроены base64, один файл). Меняются форма, колонки, поведение
«Создать оплаты» → инструкция обновляется в том же заходе.

| Что | Где |
|---|---|
| Инструкция | `knowledge_кредитование Директор Воронцов/Інструкція_Кредитування_Воронцов.html` |
| Генератор (текст в `TEXT`, CSS, встраивание фото) | `_Rarzrabotki/Python/test/oump_kredit/instrukciya_html.py` |
| Фото | `knowledge_кредитование Директор Воронцов/фото/` |

**Фото:**
- `bylo_*.png`, `rko_procenty_56114.png` — снимки пользователя 14.10.2026, состояние **до** доработки.
- `web_*.jpg` — сняты в веб-клиенте BaseERP (`http://localhost/BaseERP/ru_RU/`).

Маркер в тексте: `[[img:файл|підпис]]`. Нет файла — генерация падает.

**Пересборка:** `python -X utf8 _Rarzrabotki/Python/test/oump_kredit/instrukciya_html.py` → скопировать HTML и новые
фото в основной каталог → коммит.

## Как снимать фото в веб-клиенте ЕРП

1. Пароль ИИ не вводит: пользователь входит во встроенном браузере сам.
2. ОУМП нет в меню разделов и в «Поиске по функциям» (подсистема `А_ДоработкаТорговля`). Навигационные ссылки
   `#e1cib/...` в сессии не открываются. Документ открывает пользователь, дальше — клики по закладкам.
3. Только смотреть: ничего не записывать и не нажимать «Создать оплаты».
4. Скриншоты лежат в `tool-results/mcp-Claude_Browser-blob-*.jpg` → скопировать в `фото/` как `web_*.jpg`.
