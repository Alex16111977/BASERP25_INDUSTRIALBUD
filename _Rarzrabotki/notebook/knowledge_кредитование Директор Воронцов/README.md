## Коротко для пользователя

0. В шапке ОУМП флаг **«Кредитование»**. Без него колонки скрыты, всё идёт по-старому. При заполнении из Казны
   флаг ставится сам, если есть кредитная статья.
1. Кредитные статьи ДДС настроены: у статьи заданы **«Партнер расчетов»** (Воронцов) и **«Вид кредитного договора»**.
2. ОУМП заполняется из Казны как раньше. При записи колонки **«Контрагент»** и **«Вид договора»** в ТЧ «Деньги»
   подставляются из статей сами. Руками их можно поменять — правка не затирается.
   Контрагент расхода (ЦО) — Воронцов, контрагент прихода (проект) — контрагент подразделения (как плательщик во
   входящей платёжке). При возврате — зеркально.
3. **«Создать оплаты»**: для кредитной стороны договор берётся из цепочки договоров контрагента стороны по подразделению.
   Если договора нет — создаётся.

| Вид договора | Договор (на подразделение) | Где в балансе |
|---|---|---|
| Тело кредита (Воронцов, ЦО) | `Кредит: <ЦО> → <заёмщик>` — получатель в «Підрозділ-отримувач» | Задолженность по кредитам (ЦО) |
| Тело кредита (заёмщик) | `Кредитование от кредитора -- <подр>` у контрагента подразделения | Задолженность по кредитам |
| Проценты | `%% за использование от кредитора -- <подр>` | Задолженность по кредитам |
| Нераспределенная прибыль | `Нераспределенная прибыль -- <подр>` | **сейчас не используется** (14.10.2026: обе стороны — «Тело кредита») |
