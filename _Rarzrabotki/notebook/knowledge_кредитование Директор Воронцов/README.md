# knowledge_кредитование Директор Воронцов

База знаний по кредитованию проектов (подразделений) собственником и директором
**Воронцов Олександр Володимирович** в BAS ERP 2.5 (`BaseERP`): цепочка кредитных договоров на каждое подразделение
и формирование платежей документом **«Оказание услуг между подразделениями»** (ОУМП).

База: `Srvr="localhost";Ref="BaseERP";Usr="Администратор";Pwd="24043"`.

## Статус (14.10.2026)

✅ **Подпроект 1 работает в рабочей BaseERP:** кредитные договоры в ОУМП.
- Перечисление `А_ВидыКредитныхДоговоров`. Реквизит вида — у договора и у статьи ДДС.
- 4 колонки в ТЧ `Деньги`: контрагент и вид договора для расхода и для прихода.
- «Создать оплаты» ведёт кредитные строки по цепочке договоров Воронцова. Обычные строки идут прежним путём на `X внутр.`.
- Приёмка — 3 Python COM теста, 25 проверок, 0 провалов ([05](05_priemka_i_testy.md)).
- Коммиты ветки `claude/credit-agreement-structure-923b15`: `05a7481cf8`, `0c1350eff9`, `9f5ff5bf10`.

⏳ **Ждёт пользователя:** перепровести в UI («Создать оплаты») документы ОУМП 000000575, 000000581, 000000582, 000000583.
Через COM нельзя: не создаётся `РегистраторРасчетов`.

## Коротко для пользователя

0. В шапке ОУМП флаг **«Кредитование»**. Без него колонки скрыты, всё идёт по-старому. При заполнении из Казны
   флаг ставится сам, если есть кредитная статья.
1. Кредитные статьи ДДС настроены: у статьи заданы **«Партнер расчетов»** (Воронцов) и **«Вид кредитного договора»**.
2. ОУМП заполняется из Казны как раньше. При записи колонки **«Контрагент»** и **«Вид договора»** в ТЧ «Деньги»
   подставляются из статей сами. Руками их можно поменять — правка не затирается.
   Контрагент расхода (ЦО) — Воронцов, контрагент прихода (проект) — контрагент подразделения (как плательщик во
   входящей платёжке). При возврате — зеркально.
3. **«Создать оплаты»**: для кредитной стороны договор берётся из цепочки договоров контрагента стороны по подразделению.
   Если договора нет — создаётся.

| Вид договора | Договор (на подразделение) | Где в балансе |
|---|---|---|
| Тело кредита | `Кредитование от кредитора -- <подр>` | Задолженность по кредитам |
| Проценты | `%% за использование от кредитора -- <подр>` | Задолженность по кредитам |
| Нераспределенная прибыль | `Нераспределенная прибыль -- <подр>` | расчёты с собственником |
