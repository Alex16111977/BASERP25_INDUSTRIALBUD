## Код — `Documents/А_ОказаниеУслугМеждуПодразделениями/Ext/ObjectModule.bsl`

Область `КредитныеДоговоры` (в конце модуля):

| Метод | Что делает |
|---|---|
| `А_ЗаполнитьКредитныеКолонкиДеньги()` | пустой вид стороны ← `Статья.А_ВидКредитногоДоговора`; при заданном виде пустой контрагент ← `А_КонтрагентКредитаПоСтатье`. Заполненное не трогает. Вызывается из `ПередЗаписью` после цикла по `Деньги` |
| `А_ИмяКредитногоДоговора(Вид, Подразделение, ТипДоговора)` | имя по серии + суффикс типа, если тип ≠ тип серии; 150 символов |
| `А_НайтиИлиСоздатьКредитныйДоговор(Контрагент, Организация, Подразделение, Вид, ТипДоговора)` | поиск по ключу `Контрагент + Организация + Подразделение + А_ВидКредитногоДоговора + ТипДоговора + НЕ ПометкаУдаления`, сортировка `Дата, Наименование`; дубль → сообщение; нет → создание (вид, `А_ВидКонтрагента = Собственники`, `А_СтатьяБаланса = ЗадолженностьПоКредитам` для тела и процентов, ГФУ по типу, грн, «По договорам») |
| `А_КонтрагентКредитаПоСтатье(Статья)` | контрагент партнёра `Статья.А_ПартнерРасчетов`; среди тёзок первым идёт тот, у кого есть договоры с видом |
| `А_КредитнаяСторона(СтрокаДеньги, ЭтоРасход, ТипДоговора)` | `Неопределено` — вида нет, работает прежний подбор; иначе `Структура(Ошибка, Контрагент, Партнер, Договор, ГруппаФинансовогоУчета, НаправлениеДеятельности, ВалютаВзаиморасчетов)`; нет контрагента → `Ошибка = Истина` + сообщение |

Встраивание в `СоздатьОплатыНаСервере()` (цикл по `Деньги`):
1. После проверки формы оплаты вычисляются `ЭтоВозврат`, `КредитРасход`, `КредитПриход`.
   - Тип для расхода: `СПокупателем` при возврате, иначе `СПоставщиком`.
   - Для прихода — наоборот.
   - `Ошибка` у любой стороны → строка пропускается.
2. Прежние блоки «поиск партнёра/контрагента» и «поиск договора» (и для возврата) обёрнуты в
   `Если КредитРасход = Неопределено` / `Если КредитПриход = Неопределено`.
3. После «МАППИНГ ПО ТИПУ РАСЧЁТА» кредитная сторона перезаписывает `Контрагент…`, `Партнер…`, `Договор…`,
   `ГруппаФинУчета…`, `Направленность…`, `ВалютаДоговора…`.

Партнёр стороны — **партнёр договора**, а не контрагента: у одной карточки Воронцова два партнёра
(«Воронцов Олександр Володимирович» и «Воронцов О.В. ФОП » с пробелом).

## Загрузка

`Configuration.xml` грузить только после гейта `_Rarzrabotki/Python/test/erp_preflight_config.py`
(`EXPECTED_NEW` содержит `("Enum", "А_ВидыКредитныхДоговоров")`, код выхода 0). Частичная загрузка:
```
db-load-xml -Mode Partial -Files "Configuration.xml,Enums/А_ВидыКредитныхДоговоров.xml,…,Documents/…/Forms/ФормаДокумента.xml"
db-update -Dynamic "+" -Server
```
Новые реквизиты требуют исключительной блокировки. При открытом тонком клиенте `db-update` падает с
«Ошибка исключительной блокировки» — нужно, чтобы пользователь закрыл клиент.

## Изменения 14.10.2026 (после уточнения пользователя)

| Где | Что |
|---|---|
| `Документ…Реквизиты.Кредитование` (Булево) | реквизит шапки, добавлен пользователем в Конфигураторе; поле на форме документа (id 268) и колонка в списке |
| `А_ЗаполнитьКредитныеКолонкиДеньги` | работает только при `Кредитование`; контрагент стороны — `А_КонтрагентСтороныКредита` |
| `А_КонтрагентСтороныКредита(Вид, Статья, Подразделение)` | статья кредитора (`А_ЭтоСтатьяКредитора`: задан `А_ПартнерРасчетов`) → кредитор из статьи; иначе → `А_КонтрагентПодразделения` |
| `А_КонтрагентПодразделения(Подразделение)` | контрагент партнёра с `А_Подразделение = Подразделение`, сортировка по ссылке |
| Тип расчёта строки | при `Кредитование`, если кредитор на стороне прихода, а заёмщик на стороне расхода (заёмщик отдаёт тело), `А_ЗаполнитьКредитныеКолонкиДеньги` ставит «Возврат денежных средств» — заполнение по Казне ставит всем «Расход» |
| `А_ОтметитьКредитованиеПоСтатьям()` | вызывается в конце `НачислитьУслугиНаСервере`: ставит флаг, если есть кредитная статья; только включает |
| `А_КредитнаяСторона` | без `Кредитование` → `Неопределено` (прежний подбор) |
| Модуль формы, область `Кредитование` | `УстановитьВидимостьКредитования` (`&НаКлиентеНаСервереБезКонтекста`) — 4 колонки видны только при флаге; вызывается в `ПриСозданииНаСервере`, после «Заполнить», в `КредитованиеПриИзменении` |
| Закладка «Услуги» (`ГруппаОсновная`) | при `Кредитование` скрыта; таблица `Услуги` очищается в `ПередЗаписью` и после «Заполнить» (сумма документа — по «Деньгам»). Существующие 11 кредитных документов перезаписаны без перепроведения — `Услуги` пусты |
| `ДоговорыКонтрагентов` / `ФормаЭлемента` | поле «Вид кредитного договора» (id 1077–1079) после `А_ВидКонтрагента`; синонимы реквизитов без «А_» |

Реквизит пользователя сначала выгружен из базы (`db-dump-xml -Mode Partial`), потом правился: иначе частичная
загрузка из файлов удалила бы его.
