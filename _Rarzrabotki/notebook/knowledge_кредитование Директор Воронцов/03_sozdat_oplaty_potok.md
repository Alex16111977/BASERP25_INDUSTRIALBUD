# 03. Поток «Казна → ОУМП → Создать оплаты»

```
Закладка «Казна» (СоставБДДС)
    ↓ «Заполнить» → НачислитьУслугиНаСервере()          ТЧ Деньги: подразделения, статьи, суммы
    ↓ запись документа → ПередЗаписью → А_ЗаполнитьКредитныеКолонкиДеньги()
ТЧ Деньги: + Контрагент/Вид договора по сторонам (из статей, если пусто)
    ↓ «Создать оплаты» → СоздатьОплатыНаСервере()
сторона с видом  → А_КредитнаяСторона → цепочка договоров Воронцова
сторона без вида → прежний подбор: партнёр подразделения → договор X внутр.(…)
безнал → Списание + Поступление;  наличка → РКО + ПКО
```

## Настройка статей ДДС (что даёт автозаполнение)

Состояние на 14.10.2026:

| Статья | Код | Партнер расчетов | Вид кредитного договора | Где стоит в ОУМП |
|---|---|---|---|---|
| Финансовая помощь | УТ-001144 | Воронцов Олександр Володимирович | Тело кредита | расход ЦО (кредитор) |
| Получение финансовой помощи | УТ-001181 | — (контрагент подразделения) | Тело кредита | приход проекта (заёмщик) |
| Возврат Финансовой помощи | УТ-001195 | — (контрагент подразделения) | Тело кредита | возврат, сторона проекта |
| Возврат поворотной Финансовой помощи | УТ-001149 | Воронцов Олександр Володимирович | Тело кредита | возврат, сторона ЦО (кредитор) |

Одноимённая **группа** «Финансовая помощь» (УТ-001143) — не статья. Кредитная настройка у неё не нужна.

Список кредитных статей в коде не зашит: новая статья (например, «Сплата відсотків») становится кредитной, как только у
неё заполнены «Партнер расчетов» и «Вид кредитного договора».

## Пример: ОУМП 000000581 от 08.07.2026 (1 426 060,23)

| | Расход | Приход |
|---|---|---|
| Подразделение | Строительство | МД IRC 2026 |
| Статья | Финансовая помощь | Получение финансовой помощи |
| Вид договора (авто) | Тело кредита | Тело кредита |
| Контрагент (авто) | Воронцов Олександр Володимирович (кредитор) | МД IRS 2026 (контрагент подразделения) |
| Договор | `Кредитование от кредитора -- Строительство (Закупка)` у Воронцова | `Кредитование от кредитора -- МД IRC 2026` у контрагента МД IRS 2026 (СПокупателем, создан 14.10.2026) |
| Документ | Списание, ОплатаПоставщику | Поступление, ПоступлениеОплатыОтКлиента |

**Было (ручные правки до доработки):**
- в списании получатель Воронцов, но договор внутренний «МД IRC 2026 внутр.(Закупка)»;
- поступление пришло от внутреннего «МД IRS 2026».

В `Хозрасчетный` это дало Дт 3711 Воронцов 2 275 732 (581+582+583) по чужому договору. После перепроведения
пользователем в UI этот остаток должен стать 0.

## Как работает возврат

`ТипыРасчетаДенежнымиСредствами = ВозвратДенежныхСредств`: проект X (расход) возвращает Воронцову по договору тела.
- Тип `СПокупателем` → операция `ВозвратОплатыКлиенту`, договор «Кредитование от кредитора -- X».
- ЦО (приход) получает по НП: тип `СПоставщиком` → `ВозвратДенежныхСредствОтПоставщика`, договор
  «Нераспределенная прибыль -- ЦО».

## Сообщения пользователю

| Сообщение | Причина |
|---|---|
| «Создан кредитный договор: …» | договора нужного вида и типа не было |
| «Несколько кредитных договоров «…» по подразделению …, взят «…»» | дубль; лишний пометить на удаление |
| «Строка N: не задан контрагент для кредитного договора «…» (…) — документы оплат по строке не созданы.» | вид есть, контрагента нет |
