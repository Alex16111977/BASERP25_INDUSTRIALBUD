Сверка остатков налогов по счетам: ЕРП ↔ BAS Бухгалтерия

Отчёт сверяет регламентированный бухучёт обеих баз по налоговым счетам: РегистрБухгалтерии.Хозрасчетный в ЕРП (локально) против РегистрБухгалтерии.Хозрасчетный в базе BAS Бухгалтерия (BuhBud) (через COM). Счета 641x / 642 / 651.

Сравнение строится по счёту (Счёт.Код), без разреза по организации. Колонка «Вид налога» — справочная метка по карте счёт→налог. По каждому из четырёх показателей выводятся колонки ЕРП, Бухгалтерия и Разница (= ЕРП − Бухгалтерия): Нач.остаток, Начислено (оборот Кт), Уплачено (оборот Дт), Кон.остаток. Знак выровнен к пассив = плюс (сальдо Кт − Дт).

Как обмениваются счета. Правила обмена (правило конвертации «Хозрасчетный») синхронизируют план счетов 1:1 по Коду + GUID (поле поиска — Код, идентичная таблица предопределённых счетов, без перекодировки). Поэтому счёт 6411 в ЕРП и 6411 в Бухгалтерии — гарантированно один и тот же счёт, а сверка по Счёт.Код идёт по штатному ключу обмена.

Смысл отчёта. Регл. Хозрасчетный ЕРП в норме отражает (мирорит) данные BuhBud. Поэтому Разница ≠ 0 по счёту, либо счёт, присутствующий только в одной базе, = пробел загрузки/обмена между базами (а не «разные планы счетов»). Это и есть рабочий сигнал для разбора. Организации берутся по флагу А_ВБалансе (есть только в ЕРП); связка между базами — по КодПоЕДРПОУ.
