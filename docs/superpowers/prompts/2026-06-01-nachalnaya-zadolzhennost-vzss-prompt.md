## 📋 Бизнес-цель

`Документ.НачальнаяЗадолженностьПоЗарплате` (синоним «Начальная задолженность по зарплате») — документ ввода **начального остатка** долга по зарплате (используется при старте учёта/переносе). Его ТЧ `ЗадолженностьПоЗарплате` хранит per (Сотрудник × Подразделение × ФормаPL × ОрганизацияБухгалтерия) сумму долга.

**Цель:** при проведении документ должен писать движения в `РегистрНакопления.А_ВзаиморасчетыССотрудниками`:
- начальный долг (Сумма > 0) → **ВидДвижения = Приход** (прямой долг работодателя перед ФЛ растёт);
- отрицательная сумма (переплата) → **Расход** (как в остальных процедурах).

**Источник истины — собственная ТЧ документа** (`ЗадолженностьПоЗарплате.Сумма`). Документ **НЕ пишет** `ПрочиеАктивыПассивы` (ПАП) — проверено: ПАП-движений по нему нет. Поэтому Σ-инвариант **self-contained** (vs ТЧ документа), а НЕ vs ПАП(ОТ) как у других регистраторов.

## 🔢 Σ-инвариант и семантика знака

```
Σ signed А_ВзСС per (Орг, Подр, ФЛ) per Регистратор
        = Σ ЗадолженностьПоЗарплате.Сумма per (ФЛ, А_Подразделение)
```
где `Σ signed = Σ(Приход) − Σ(Расход)`. Инвариант self-contained (документ — единственный источник; ПАП(ОТ) этот документ не пишет).

Знак: начисление долга (Сумма > 0) → **Приход** (как `начисление = ДобавитьПриход` в типовом ВзаиморасчетыССотрудниками и как `ЗаполнитьИзОтраженияЗП`). Сумма < 0 → Расход.
