## Как устроены образцы (изучено — проверь и опирайся)

### Образец 1 — «Загрузка работ в СС» (ERP)
- `Ext\ObjectModule.bsl`: экспортная `ЗагрузитьРаботыИзМассива(СтруктураСеб, МассивСтрок)`
  — транзакция, `ОбъектСеб.Работы.Очистить()` + перезапись, протокол
  {Загружено, СозданоРабот, СозданоЭтапов, Пропущено, Ошибка, ТекстОшибки} без re-raise.
- Get-or-create (кэши по `НРег(НормализоватьНаименование(...))`, нормализация =
  СокрЛП + схлопывание двойных пробелов, симметрично базе и Excel):
  - Этап → `Справочник.А_ЭтапыРабот` (неиерархический);
  - Работа → `Справочник.Номенклатура`, группа **`_Роботи` код `0Ц-00000016`**;
    не найдена → **клон образца с артикулом `1.1.1`** через
    `ЗаполнитьЗначенияСвойств(Новый, ОбъектОбразца, , "Код,Артикул,Наименование,НаименованиеПолное,Ссылка,Родитель,Владелец,ПометкаУдаления,Предопределенный,ИмяПредопределенныхДанных")`
    — наследует все обязательные реквизиты (вид Послуга, ед. чол-год, НДС 20%).
- Форма: клиент читает Excel `WorkSheets(1)` колонки A-E — ЭТО УСТАРЕЛО, у новой
  обработки чтение по образцу 2.
- Реквизит обработки `ДокСтруктураСебестоимости` типа `cfg:CatalogRef.А_СтруктураСебестоимости` (ERP, с префиксом А_!).

### Образец 2 — «Загрузка материалов в СС» (BuhBud)
- Клиент: лист **ПО ИМЕНИ** `Excel.WorkSheets("Проект СС")`, последняя строка через
  `SpecialCells(11)`, фильтр по колонке C, счётчики чтения
  («строк = N, взято = M, пропущено пустых = K»), корректное закрытие Excel.
- Движок: **контроль в момент загрузки** — при заполнении копит Excel-итоги
  (построчно `Окр(Количество,3)` / `Окр(Сумма,2)` под квалификаторы ТЧ!), после
  `Записать()` и ДО `ЗафиксироватьТранзакцию()` сверяет запросом с БД: строк,
  Σ Количество, Σ Сумма, Σ Сумма по каждому этапу (двусторонне); расхождение →
  `ВызватьИсключение` → откат. Протокол: `КонтрольПройден`, массивы `Контроль`/`Инфо`.
  В BSL НЕТ функции `Макс()` — модуль разницы через `?(А>Б, А-Б, Б-А)`.

## Работы

### 1. Чистка клона (грабля проекта — ловилась 4 раза)
- Определи, чьей копией является клон (grep GUID обоих образцов), **регенерируй ВСЕ
  GUID** (внешний uuid, ObjectId, TypeId/ValueId, uuid реквизитов, uuid форм(ы);
  ClassId `c3831ec8-d8d5-4f93-8a22-f9bfae07327f` НЕ трогать). Изоляция: пересечение
  множеств uuid клона с ОБОИМИ образцами = только ClassId.
- Внутреннее имя → `ЗагрузкаРаботВССДляЕРП` синхронно везде (Name, GeneratedType,
  DefaultForm, тип главного реквизита формы; grep старых имён по каталогу = 0).
  Синоним «Загрузка работ в СС для базы ЕРП».
- Тип реквизита `ДокСтруктураСебестоимости` = `cfg:CatalogRef.А_СтруктураСебестоимости`
  (как в образце 1 — ERP).

### 2. Движок (ObjectModule)
За основу — образец 1 (`ЗагрузитьРаботыИзМассива` с get-or-create работ/этапов),
добавить контроль в момент загрузки по образцу 2 (адаптировать: ТЧ `Работы`, поля
Количество/Сумма; проверь квалификаторы ТЧ через get_metadata_structure и округляй
Excel-итоги под них). Протокол объединённый: {Загружено, СозданоРабот, СозданоЭтапов,
Пропущено, КонтрольПройден, Контроль[], Инфо[], Ошибка, ТекстОшибки}.

### 3. Форма
