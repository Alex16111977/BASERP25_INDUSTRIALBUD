## Как устроен образец (уже изучено — проверь и опирайся)

- **БСП-обработка «ЗаполнениеОбъекта»**: `Ext\ObjectModule.bsl` — `СведенияОВнешнейОбработке()`
  с Назначением `Документ.ТребованиеНакладная`, команда «Загрузить из Exel»
  (`ВызовКлиентскогоМетода` → `ВыполнитьКоманду` в модуле основной формы).
- **Формы**: `Форма` (главная логика) и `ЗапросПараметров` (ПерваяСтрока, КолонкаКод,
  КолонкаКоличество, выбор файла → временное хранилище). Настройки сохраняются в
  `ХранилищеОбщихНастроек` под ключом `НастройкаЗагрузкиТЧКомплектация`.
- **Чтение Excel на клиенте** (`Forms\Форма\Ext\Form\Module.bsl`): COM Excel, СПИСОК
  ЛИСТОВ с выбором пользователем, скан строк до 50 пустых подряд по колонке кода;
  код номенклатуры: строка как есть, число → `Прав("00000000000"+Формат(...,"ЧДЦ=; ЧГ="),11)`
  (11 знаков с ведущими нулями); Количество>0 → строки во внутреннюю ТЧ `ТчЗагрузка`.
- **`ЗагрузитьТЧ()`** (серверная): `Справочники.Номенклатура.НайтиПоКоду` → строка ТЧ
  документа: Номенклатура, Количество, Коэффициент=1,
  ЕдиницаИзмерения=БазоваяЕдиницаИзмерения, счёт через `ОпределитьСчетУчетаБУ` —
  **по остаткам** `РегистрБухгалтерии.Хозрасчетный.Остатки(, Счет В (&СпСчетов), , Субконто1 = &Номенклатура)`
  со списком счетов 201/203/205/206/207/209/221/281 и кэш-таблицей. Ненайденные коды —
  `Сообщить`. `ДокОбъект.Записать()`.

## Работы

### 1. Чистка клона (КРИТИЧНО — грабля ловилась в проекте многократно)
- Клон = байт-копия: **регенерируй ВСЕ GUID** (внешний uuid обработки, ObjectId,
  TypeId/ValueId, uuid реквизитов и ОБЕИХ форм в их .xml-обёртках; `ClassId
  c3831ec8-d8d5-4f93-8a22-f9bfae07327f` — фиксированный, НЕ трогать). Проверка
  изоляции: пересечение множеств uuid клона и образца = только ClassId.
- `Name` → `ЗагрузкаПередачаМалоценныхАктивовВЭксплуатацию` синхронно во всех местах
  (корневой XML: Name, GeneratedType, DefaultForm; **плюс захардкоженная строка**
  `ОткрытьФорму("ВнешняяОбработка.ЗагрузкаТЧТребованиеНакладная.Форма.ЗапросПараметров"...)`
  в модуле основной формы — без замены форма параметров НЕ ОТКРОЕТСЯ; grep по всему
  каталогу клона на `ЗагрузкаТЧТребованиеНакладная` = 0 после правок).
- Синоним: «Загрузка ПередачаМалоценныхАктивовВЭксплуатацию».
- Ключи `ХранилищеОбщихНастроек` в `СохранитьНастройкиНаСервере` → свои
  (`НастройкаЗагрузкиПередачаМалоценки`), чтобы не пересекаться с образцом.

### 2. ObjectModule (БСП-регистрация)
- Назначение → `Документ.ПередачаМалоценныхАктивовВЭксплуатацию`;
  Наименование → «Загрузка из Excel ТЧ Передача малоценных активов»; Вид оставить
  «ЗаполнениеОбъекта».

### 3. Логика заполнения
- ТЧ → `МалоценныеАктивы`; поле счёта → `СчетУчетаБУ` (в образце ветка выбора
  Товары/Материалы — упрости под один документ).
- **Список счетов подбора**: у малоценки остатки обычно НЕ на 20х. До правки кода
  выясни запросом (Rule #-1!), на каких счетах реально лежат остатки номенклатур из
  тестовых файлов (кандидаты: «22» МШП, «112» МНМА, «153»; смотри
  `ПланыСчетов.Хозрасчетный`). Собери итоговый список счетов по факту + покажи
  пользователю в отчёте. Если остатка нет ни на одном счёте — строка грузится без
  счёта + `Сообщить` (как образец с ненайденным кодом).
- `НазначениеИспользования`, `ФизЛицо`, `НалоговоеНазначение` — НЕ заполнять
  (пользователь заполняет сам). НО: проверь на тестовом документе, что `Записать()`
  без них не падает; если падает — доложи пользователю и предложи вариант
  (например, НалоговоеНазначение из настроек).
- **Рефакторинг для тестируемости** (стиль проекта): серверную логику заполнения
  вынеси в `Ext\ObjectModule.bsl` экспортной функцией
  `ЗаполнитьМалоценныеАктивы(ДокСсылка, ТаблицаКодов)` → структура-протокол
  {Загружено, НеНайденоКодов, БезСчета, Ошибка, ТекстОшибки}; модуль формы зовёт её.
  Тогда возможен win32com-smoke без UI.
