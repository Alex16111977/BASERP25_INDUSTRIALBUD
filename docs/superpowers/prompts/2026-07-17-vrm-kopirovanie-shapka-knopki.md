# Промт: ВРМ — починить копирование, открыть шапку, вывести кнопки заполнения

## Задача

Документ `Документы.А_ВыполнениеРаботМодулей`, форма `Forms/ФормаДокумента` (динамическая матрица «работа × модули», см. память vrm_vypolnenie_rabot_modulej):

1. **Починить копирование (F9)**: копия должна нести ВСЮ шапку (СтруктураСебестоимости, Подразделение, КоличествоМодулей, Ответственный) и ВСЮ ТЧ Работы — матрица копии = матрице исходника (все модули, все проценты). Рабочий сценарий пользователя: новый документ = копия предыдущего + доввод процентов по модулям.
2. **Открыть реквизиты шапки**: снять ReadOnly с `КоличествоМодулей` и `Подразделение` (Номер оставить типовым read-only — платформенный автономер). При ручном изменении КоличествоМодулей матрица должна пересоздаваться с сохранением введённых процентов.
3. **Вывести кнопки заполнения**: команда «Заполнить из СС» (ТЧ по работам из `Объект.СтруктураСебестоимости` = СправочникСсылка.А_СтруктураСебестоимости) уже реализована, но кнопки НЕТ на форме — добавить кнопки для всех трёх команд.

Работать в worktree; Rule #4 — перенос в `C:\Configuration_downloads\BASERP25`; перед правкой формы — навык `bas-bsp-form`; финал — `bas-verify`.

## Диагностика уже сделана (2026-07-17) — корни найдены, перепроверить и чинить их

### Корень 1 — копирование ломает сама форма (ObjectModule чист)

`Module.bsl` формы, `ПриСозданииНаСервере` (~стр. 10-25):
```bsl
Если Объект.Ссылка.Пустая() И ЗначениеЗаполнено(Объект.СтруктураСебестоимости) Тогда
    ОбновитьПараметрыСтруктуры();   // ← выполняется И ПРИ КОПИРОВАНИИ
КонецЕсли;
```
`ОбновитьПараметрыСтруктуры()` (~стр. 256) ПЕРЕТИРАЕТ скопированные значения из СС:
`Объект.Подразделение = СС.Подразделение; Объект.КоличествоМодулей = Макс(СС.А_КоличествоМодулей, 1)`.
Если в СС `А_КоличествоМодулей` = 0 или меньше, чем в исходном документе → копия получает N=1 (или меньше), затем `ЗаполнитьМатрицуИзРабот` (~стр. 345) отсекает клетки `НомерМодуля > Объект.КоличествоМодулей`, а `ПередЗаписьюНаСервере` (unpivot по матрице) при записи копии ФИЗИЧЕСКИ теряет эти строки ТЧ.

**Фикс**: при копировании не перетирать заполненное. Минимальный вариант — в `ПриСозданииНаСервере` вызывать `ОбновитьПараметрыСтруктуры()` только когда `Объект.КоличествоМодулей = 0` (новый документ / ввод по СС); альтернатива — внутри `ОбновитьПараметрыСтруктуры()` заполнять Подразделение/КоличествоМодулей только если пустые. Интерактивная смена СС (`СтруктураСебестоимостиПриИзмененииНаСервере`, ~стр. 239) должна работать как сейчас — там перезаполнение корректно (матрица намеренно перезаполняется).

Проверить также свёртку `ЗаполнитьМатрицуИзРабот`: строки группируются по Работе (Соответствие) — дубли работ с разными Этапами свернутся (МАКСИМУМ Этап при заполнении из СС); для копии это ок, но зафиксировать поведение в тесте.
