# ПРОМТ: восстановить системную учётную запись почты в BuhBud после перезагрузки базы

Скопируй всё ниже линии в новую сессию Claude Code (каталог `C:\Configuration_downloads\BASERP25`).

---

База `Srvr="SQLSERVER";Ref="bas_industrialbud";` перезагружена из рабочей. Нужно снова настроить в ней
предопределённую «Системную учетную запись» почты так же, как в Казне (`Srvr="SQLSERVER";Ref="kazna";`):
`notifications@iengineering.com.ua`, SMTP `mail.iengineering.com.ua:587`, IMAP 143, только отправка.
Казну не менять. Работай автономно, отвечай по-русски.

Готовые скрипты (оба в репозитории, `localhost` на этой машине = `SQLSERVER`, вход `cfo`/`2442`):
- `_Rarzrabotki/Python/kopiya_uchetki_pochty_kazna_buhbud.py` — настройки без пароля;
- `_Rarzrabotki/Python/parol_pochty_kazna_v_buhbud.py` — пароль из безопасного хранилища Казны в хранилище BuhBud.

## Шаг 1 — настройки (делаешь ты)

1. Пробный запуск, без записи:
   `python _Rarzrabotki/Python/kopiya_uchetki_pochty_kazna_buhbud.py`
   Покажи пользователю список отличий «было -> стало». Если скрипт падает с «непримитивное заполненное значение»
   — в Казне заполнилось перечисление; добавь маппинг по имени значения, не выдумывай.
2. Запись: `python _Rarzrabotki/Python/kopiya_uchetki_pochty_kazna_buhbud.py --write`
   Должно быть: `Расхождений после записи: 0` и `Регистрации обмена (.Изменения): было N, стало N` (N одинаковые).
   Иначе остановись и разберись (skill `superpowers:systematic-debugging`).
3. Контроль: повторный пробный запуск — `отличаются: 0`.

Запись идёт с `ОбменДанными.Загрузка` и `ОтключитьМеханизмРегистрацииОбъектов`: справочник входит в планы обмена
BuhBud (`Полный`, `ПоОрганизации`, `АвтономнаяРабота` и др.), регистрировать изменения нельзя.

## Шаг 2 — пароль (запускает пользователь)

Пароль сам не читай, не выводи и не записывай. Дай пользователю команду, пусть запустит сам:

```bash
python "C:/Configuration_downloads/BASERP25/_Rarzrabotki/Python/parol_pochty_kazna_v_buhbud.py"
```

Ожидаемый вывод: по ключам `Пароль` и `ПарольSMTP` — «записан в BuhBud, совпадает с Казной: да»
(или «в Казне пусто — пропущено»). Пароль в выводе не появляется.

Запасной вариант без скрипта: пользователь вставляет пароль из `_Rarzrabotki\Пароль\пароль почта.txt` в форму
учётной записи BuhBud (вкладка «Отправка писем») и нажимает «Записать». Папка `_Rarzrabotki/Пароль/` в `.gitignore`.

## Шаг 3 — проверка (пользователь)

BuhBud → «Учетные записи электронной почты» → «Системная учетная запись» → «Проверить настройки».
Если отправка проходит — готово. Если нет — сверь в форме сервер/порт/«Безопасная проверка пароля»/SSL с Казной.
