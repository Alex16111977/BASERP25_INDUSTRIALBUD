# ПРОМТ: «Розбіжності одиниць» у документі РасчетКомплектаций (bas_industrialbud)

Дата: 2026-07-16. Дизайн утверждён («Да, выполняй»). База: `Srvr="SQLSERVER";Ref="bas_industrialbud";Usr="cfo";Pwd="2442"`, конфигурация `_Rarzrabotki/BASEBuh`. Базовый объект: Документ.РасчетКомплектаций (см. `2026-07-16-dokument-raschet-komplektacij.md`).

## Цель

Бухгалтер должен видеть, где расходятся единицы измерения между тремя источниками, и по группе (эталону) решать, что править: единицу в норме СС, базовую единицу карточки номенклатуры или единицу эталона в справочнике.

Сравниваются на строке анализа (`ТабличнаяЧастьОстатков`):
1. `ЕдиницаСС` — единица нормы (`СтруктураСебестоимости.Комплектующие.Единица`);
2. `Единица` — базовая единица номенклатуры (= единица остатков);
3. `ОбщееНазвание.Единица` — реквизит `Единица` справочника `ОбщиеНазванияНоменклатуры` (единица эталона).

## Правило расхождения (решение заказчика)

`РасхождениеЕдиниц = Истина`, если:
- среди ЗАПОЛНЕННЫХ из трёх единиц есть различные (сравнение по ссылке), ИЛИ
- `ОбщееНазвание` заполнено, а `ОбщееНазвание.Единица` — ПУСТАЯ (незаполненный эталон — тоже проблема).

Пустая `ЕдиницаСС` (субституты) сама по себе — НЕ расхождение. Строки без эталона по критерию «пустого эталона» не срабатывают.

## Изменения

1. **Метаданные**: колонка `РасхождениеЕдиниц` (Булево, синоним uk «Розбіжність одиниць») в ТЧ `ТабличнаяЧастьОстатков`.
2. **Движок** (модуль объекта):
   - `ЕдиницыЭталонов(ТЗОстатки)` — кэш единиц эталонов ОДНИМ запросом (`Ссылка В (&Эталоны)` по различным заполненным ОбщееНазвание);
   - `ЕстьРасхождениеЕдиниц(ЕдиницаСС, ЕдиницаОстатков, ЕдиницаЭталона, ЕстьЭталон)` — правило выше;
   - в `ЗаполнитьАнализ`: кэш перед циклом (якорь `ТабличнаяЧастьОстатков.Очистить();`), флаг после `НоваяСтрока.ПонадНормуСумма = ...;`;
   - `СформироватьПечатьРозбіжностіОдиниць() Экспорт` — программный ТабДок.
3. **Форма**:
   - колонка VT `ТаблицаАнализа.РасхождениеЕдиниц` (Boolean) + CheckBoxField «Розбіжність од.» в таблице (после ТАЕкономіяСума);
   - `ПрименитьОтборИИтоги`: перенос колонки;
   - `УстановитьУсловноеОформлениеСтрок`: второе правило — розовый фон `Новый Цвет(250, 215, 215)` по `РасхождениеЕдиниц = Истина` (после янтарного понаднормы — перекрывает);
   - `РассчитатьНаСервере`: `Сообщить("Розбіжностей одиниць: N рядків ...")` при N>0;
   - кнопка «Друк розбіжностей одиниць» + команда + обработчики (клон Акта).
4. **Печатная форма «Розбіжності одиниць (норми ↔ фактичний прихід)»**:
   - шапка: заголовок + Період/Специфікація/Склади/Організація (как Акт);
   - колонки: `Загальна назва | Залишок | Одиниця виміру залишків | Згідно з СС | Одиниця виміру СС`;
   - попадают ТОЛЬКО эталоны, где ≥1 строка с `РасхождениеЕдиниц`; внутри эталона — ВСЕ его карточки (полная картина группы), свёрнутые по номенклатуре (Σ Залишок по складам/счетам; «Згідно з СС» = НормаНоменкл — штампуется 1× на номенклатуру);
   - строка эталона (жирная, серый фон): «Назва [од. еталона: X]» или «[⚠ од. еталона не заповнена]» (красным), Залишок=Σ, Згідно з СС=Σ НормаНоменкл;
   - строки карточек: Номенклатура (отступ), Залишок, Единица, НормаНоменкл, ЕдиницаСС; у карточек с расхождением ячейки единиц — янтарные `(255, 230, 153)`;
   - подвал: «Еталонів з розбіжностями: N, номенклатур з розбіжністю: M».
5. **Не трогаем**: `КількістьРозбіжностейОдиниць`/`ПопередитиПроРозбіжністьОдиниць` (сравнение внутри СС — дополняем, не заменяем), математику распределения, остальные печати.

## Реализация (пайплайн)

meta-edit add-ts-attribute + uk-патч → правки генераторов `doc_kompl_build_module.py`/`doc_kompl_build_form.py` (идемпотентная перегенерация; uuid обёртки формы уже стабильный) → частичная загрузка (`Documents/РасчетКомплектаций.xml` + модуль + форма) + db-update → smoke `smoke_doc_kompl_edinicy.py` (Rule #-1 для запроса кэша; флаг вычислен и совпадает с наивной проверкой; в отчёте только расходящиеся эталоны; COM-инспекция ТабДок: заголовок, счётчики) → регрессия 5 существующих smoke + smoke обработки.

## Критерии приёмки

1. После «Розрахувати» строки с расхождением подсвечены розовым, колонка-флажок заполнена, сообщение с количеством.
2. Флаг = Истина ровно по правилу (включая пустую единицу заполненного эталона).
3. Печать выводит только эталоны с расхождениями, карточки свёрнуты по номенклатуре, единицы и числа рядом.
4. Все существующие smoke зелёные; обработка-исходник не тронута.
