**Goal:** Заменить блок 1 ОТ типовой функции `Documents/РасходныйКассовыйОрдер/Ext/ManagerModule.bsl.ТекстЗапросаТаблицаПрочиеАктивыПассивы` (line 3040-3058) на UNION ALL с гардом по типу Ведомости — для нашей ВКассу детализировать Подразделение и НаправлениеДеятельности из `Ведомость.А_РасшифровкаВыплатыЗарплатаПоФизлицам`, чтобы типовая обработка `DataProcessors.ДвиженияАктивовПассивов` не писала плуги Вывод/Вложения собственных средств.

**Architecture:** Точка интеграции — типовой интерфейс BAS ERP: документ через свой ManagerModule контролирует первичные движения ПАП. Если в первичных движениях `Σ per (Регистратор, НаправлениеДеятельности) = 0`, балансировка плуги не пишет. Конвертация типа `Справочник.ПодразделенияОрганизаций → Справочник.СтруктураПредприятия` через кастомный реквизит `.А_Подразделение`. Направление берётся через `СтрПредпр.А_НаправлениеДеятельности` (для всех 12 СтрПредпр нашего РКО = Спецтехника — подтверждено диагностикой).
