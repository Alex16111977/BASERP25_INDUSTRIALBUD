> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Новый управленческий документ `А_ПередачаНачисленийМеждуПодразделениями` переносит обязательства ЗП (Оплата труда + Налоги + Удержания) с реального подразделения работы на целевое подразделение юр.лица-плательщика, в регистрах `ПрочиеАктивыПассивы` (ПАП) и `А_ВзаиморасчетыССотрудниками` (А_ВзСС), net-zero по организации.

**Architecture:** Кнопка в форме `А_ОтражениеЗПпоКазне` → Find-Or-Create нового документа (ключ `А_ДокументОснование`=родитель) → заполнение 3 ТЧ из **дочернего** `ОтражениеЗарплатыВФинансовомУчете` (он постит ПАП) → `ОбработкаПроведения` нового документа пишет ПАП (реверс на исходном / копия на целевом) + вызывает `А_ВзСС.ЗаполнитьИзПередачиНачислений`. Модель «3 ТЧ ↔ 3 статьи ПАП»: Начисления→Оплата труда(+А_ВзСС per ФЛ), Налоги→Налоги(Аналитика=ТипНалога), Удержания→Прочие пассивы.

**Tech Stack:** 1С:Підприємство 8.3.20 (BAS ERP 2.5), BSL, управляемые формы; скилы `meta-compile`/`meta-edit`/`form-edit`/`db-load-xml`/`db-update`; Python 3.13 + pywin32 (`V83.COMConnector`) для тестов.
