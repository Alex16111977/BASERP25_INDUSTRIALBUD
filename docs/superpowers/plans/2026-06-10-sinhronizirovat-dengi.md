# СинхронизироватьДеньги — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Внешняя обработка `СинхронизироватьДеньги` — контроль синхронизации безналичных денег ERP↔BuhBud, чистый денежный срез обработки `СинхронизироватьТовары`.

**Architecture:** Три фазы (сравнение остатков → анализ документов → синхронизация), перенос денежных функций исходника 1:1 с предметными именами колонок, два инженерных исправления обратной проверки BuhBud-only документов. Исходник не модифицируется.

**Tech Stack:** 1С BSL (внешняя обработка, управляемая форма), COM `V83.COMConnector`, Python COM тесты (Rule #-1).

**Источник (эталон):** `_Rarzrabotki/Обработки/СинхронизироватьТовары/Ext/ObjectModule.bsl` (далее «И:строки»), его Form.xml и XML-описатель. Спека: `docs/superpowers/specs/2026-06-10-sinhronizirovat-dengi-design.md`.
