### Task 3: ObjectModule.bsl (полная замена)

Регистрация БСП (клон текущей, Наименование «Завантаження матеріалів у СС з двох файлів», версия 1.0) + движок:

```bsl
// Наборы - Массив структур {ИмяФайла, СырыеСтроки}, СырыеСтроки - как читает клиент.
Функция ЗагрузитьМатериалыИзНаборов(СтруктураСеб, Наборы) Экспорт
	// 1) per-файл ОтобратьМатериалы (через СоздатьЭлемент-движок), протокол отбора запоминаем;
	// 2) отобранные маскируем в сырые {Ряд, Тип:"Матеріал", Этап, ОбщееНазвание,
	//    Наименование:НоменклатураСС, Единица:ЕдиницаСС, Количество, Сумма} и копим общий массив
	//    + Σ Сумма и счётчики по файлу для протокола;
	// 3) внешняя транзакция: ОбъектСеб.ЗаполнитьКомплектующиеИзСырыхСтрок(ОбщийМассив);
	//    Результат.Ошибка → ВызватьИсключение; Записать(); СверитьЗаписанноеСБазой; фиксация;
	// 4) Результат.ПоФайлам - массив строк протокола per файл; Ошибка → откат, журнал
	//    "ЗагрузкаМатериаловССПоДвумФайлам.Ошибка".
КонецФункции
```

`СверитьЗаписанноеСБазой` — 1:1 из текущей обработки материалов (строк/ΣКол(окр3)/ΣСумма(окр2), допуск 0.005, запрос по `Справочник.СтруктураСебестоимости.Комплектующие`). Полный код пишется по образцу текущего `$СС\Загрузка материалов в СС\Ext\ObjectModule.bsl` (читается при реализации).
