**Goal:** Переписать внешнюю обработку `А_НачальнаяЗадолженностьПоЗарплатеФорма2` так, чтобы она грузила управленческие (Форма2) начальные остатки зарплаты из базы zup_2 по формуле **Форма2 = Общий(zup_2) − Форма1(док-источник)** и перезаписывала ими выбранный документ.

**Architecture:** 2-фазная обработка (превью-ТЧ + 2 кнопки). Фаза 1: COM→zup_2 (`ВзаиморасчетыСРаботниками.СуммаУпрОстаток` = Общий) → вычесть Форма1 из дока-реквизита `ДокНачальнаяЗадолженностьПоЗарплатеБух` → Форма2; подразделение = корень СтрПредпр первой кассовой выплаты (fallback Строительство) → реверс ПодрОрг. Фаза 2: очистка-перезапись дока-реквизита `ДокНачальнаяЗадолженностьПоЗарплатеФорма2`, ФормаPL=Форма2, проведение. Логика — в `Ext/ObjectModule.bsl`. TDD: Python COM pretest (RED) → BSL/сборка → headless verify (GREEN).

**Tech Stack:** 1С:Предприятие 8.3.20, BAS ERP 2.5, BSL, .epf, `V83.COMConnector`, Python 3.13 + pywin32, скилы `/epf-validate`, `/epf-build`, `mcp__python-runner__run_command`.

**Подтверждённые имена/грабли:**
- zup_2: регистр `ВзаиморасчетыСРаботниками` (Изм `Физлицо`, Рес `СуммаУпр`; в `.Остатки(…)` колонка = **`СуммаУпрОстаток`**). Строка подключения `Srvr="SQLSERVER";Ref="zup_2";Usr="cfo";Pwd="2442"`.
- ФизЛице zup_2↔ERP: по `КодПоДРФО`.
- `ВедомостьНаВыплатуЗарплатыВКассу`: шапочное `Подразделение` пустое → брать из ТЧ `А_РасшифровкаВыплатыЗарплатаПоФизлицам.Подразделение`.
- `СтруктураПредприятия` иерархична (Родитель); корни: Девелопмент/Логистика/Производство/Спецтехника/Строительство/ЦО.

- ГруппаУчетаНачислений (обязательна) — из источника Форма1, иначе «Зарплата (661)».
- **TZ-сдвиг** (memory feedback_balans_etalon_period_serverside): наивный Python datetime через COM сползает на день — в тестах даты литералом `ДАТАВРЕМЯ` / полдень.
- Зарезервированные алиасы: `ПО`, `В` (использовать `ПодрОрг`, `Вед`); переменную `Ссылка` не объявлять.
- Документ требует стандартный реквизит `Дата` (но шапку выбранного дока НЕ трогаем — она уже заполнена).

**Обработка — копия 661/663-варианта.** Метаданные уже содержат: реквизиты `ДатаОстатков`, `Организация`, `ДокНачальнаяЗадолженностьПоЗарплатеБух`, `ДокНачальнаяЗадолженностьПоЗарплатеФорма2`; ТЧ `Задолженность` (колонки Счет/ФизЛицоИмя/ФизическоеЛицо/Сотрудник/ПодразделениеОрг/Организация/ОрганизацияБухгалтерия/Сумма/Статус); форму с таблицей Задолженность + 2 команды (ЗаполнитьОС/СоздатьДокумент).
