# СС: оригинал по модулям, коэффициенты пересчёта, присоединённые файлы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, пользователь попросил «делай сам»). Шаги — чекбоксы.

**Goal:** Хранить оригинал Excel в `КомплектующиеПоМодульно` + сам файл как присоединённый к СС, вести коэффициенты пересчёта единиц (справочник правил в `ОбщиеНазванияНоменклатуры` + рабочая ТЧ в СС с ручной правкой), пересчитывать `Комплектующие` без изменения суммы.

**Architecture:** Метаданные BuhBud через meta-edit/meta-compile + клон типового `ДоговорыКонтрагентовПрисоединенныеФайлы`. Вся логика — общий модуль `А_СтруктураСебестоимостиСервер` (сервер); модуль объекта/форма тонкие. Разовые операции на живых СС — Python COM, вызывающий ТОТ ЖЕ общий модуль (одна реализация).

**Tech Stack:** 1С 8.3.20 / BAS Бухгалтерія (БСП «Работа с файлами»), Python 3 + win32com + openpyxl.

Спека: `docs/superpowers/specs/2026-09-27-ss-original-koeficienty-fajly-design.md`.

### Task 2: Общий модуль `А_СтруктураСебестоимостиСервер` (Server=true, ServerCall=false)

Программный интерфейс:
- `НормализоватьНаименование(Текст)` / `КлючНаименования(Текст)` (НРег от нормализованного) / `КлючЕдиницы(Текст)` (НРег+синонимы `СинонимЕдиницы`, перенесённые из модуля объекта).
- `КлючПозиции(Этап, ОбщееНазвание, НоменклатураСС)` — строка из UUID ссылок + ключа наименования (ключ сопоставления 4.3).
- `ПравилаКоэффициентов(МассивОН)` → Соответствие ОН → {Точные: Соответствие("ед|ном"→k), Общие: Соответствие("ед"→k), ЕдиницаКлюч} — один запрос по ТЧ ОН + единицы карточек.
- `НайтиКоэффициент(Правила, ОН, ЕдиницаСС, НоменклатураСС)` → Структура(Коэффициент, Источник) по 4.2.
- `ЗаполнитьКоэффициенты(СССсылкаИлиОбъект)` → протокол; строит/дополняет ТЧ `КоэффициентыПересчета` из свёртки `КомплектующиеПоМодульно`; не трогает `Вручную/ПодобранПоФакту`.
- `ПересчитатьКоличество(Объект)` → протокол; по 4.3 (ключ без единицы; распределение пропорционально Сумме; Σ Сумма до=после, иначе исключение); объект НЕ пишет.
- `ОтметитьДобавленныеВручную(Объект)` — 4.4.
- `ПодобратьКоэффициентыПоФакту(Объект)` — 5.2 (разовая операция для старых СС, но живёт в модуле — никаких «временных» дублей в Python).
- `ЗаписатьПравило(ОН, ЕдиницаСС, НоменклатураСС, Коэффициент, Комментарий)` — upsert в ТЧ ОН.
- `ПрисоединитьФайлОснования(Объект, ДвоичныеДанные, ИмяФайла, Модуль, КоличествоСтрок, СуммаИтого)` — `РаботаСФайлами.ДобавитьФайл` + замена строки `ФайлыОснования` модуля (объект уже записан — ссылка обязательна).

Код — в `WT\BUH\CommonModules\А_СтруктураСебестоимостиСервер\Ext\Module.bsl` (пишется в Task 2 целиком; все запросы предварительно проходят Python COM, Rule #-1: `_Rarzrabotki/Python/test/test_ss_koef_queries.py`).

Используется кнопкой загрузки для новых СС.
