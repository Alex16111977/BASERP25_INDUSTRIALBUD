> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Применить пересчитанные количества (колонка H файла «Список не співпадають одиниці.xlsx») к 98 строкам ТЧ Комплектующие СС «МД ООН Админ» в живой BaseERP, пересчитать цену, проставить ЕдиницаСС единицей 1С, снять флаг НеСовпадает — с бэкапом и контролем сумм.

**Architecture:** одноразовый Python COM скрипт: снапшот ТЧ «до» → чтение файла → транзакция (обновление строк по ключу N + контроль имени/суммы → Записать) → сверка запросом. Никаких изменений конфигурации/обработок.
