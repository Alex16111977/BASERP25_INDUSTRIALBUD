**Goal:** Добавить заполнение `А_ВзаиморасчетыССотрудниками` от документа `СписаниеБезналичныхДенежныхСредств` (СБДС) для **выплат зарплаты по зарплатному проекту/на лицевые счета**. Источник распределения по ФизЛицу — связанная Ведомость → `РегистрНакопления.ЗарплатаКВыплате`. Σ-инвариант: |Σ signed А_ВзСС| per (Орг, Подр) per Регистратор = |Σ signed ПАП(Статья=ОТ, Источник=Пуст)| per Регистратор.

**Architecture:**
- Точка интеграции: ОДНА строка вызова в конце `Documents/СписаниеБезналичныхДенежныхСредств/Ext/ObjectModule.bsl:1111-1124` после `ПровестиРегистрА_ДенежныеСредстваФинАгенты(Отказ);`
- Логика: новая процедура `ЗаполнитьИзСписанияБезнал(ДокОбъект)` в `AccumulationRegisters/А_ВзаиморасчетыССотрудниками/Ext/ManagerModule.bsl`
- Цепочка данных: СБДС.РасшифровкаПлатежа.**Ведомость** (поле в ТЧ) → ВедомостьНаВыплатуЗарплатыВБанк → `РегистрНакопления.ЗарплатаКВыплате(Регистратор=Ведомость, ВидДв=Расход)` → распределение СуммаКВыплате per ФизЛицо
- Подразделение: из шапки СБДС (`ДокОбъект.Подразделение`) — точно как в типовом запросе ПАП блока 1 (line 3910 типового ManagerModule СБДС)
- Знаки (финансистская семантика): выплата → **ВидДвижения=Расход** (долг работодателя перед физлицом уменьшается)

def стат(док):
    q = conn.NewObject("Запрос")
    q.Текст = """ВЫБРАТЬ Зап.Организация КАК Орг, Зап.Подразделение КАК Подр,

    ГДЕ Зап.Регистратор=&Док"""
    q.УстановитьПараметр("Док", док)
    t = q.Выполнить().Выгрузить()
    rows = t.Количество()
    с_фл = 0
    keys = Counter()
    for i in range(rows):
        e = t.Получить(i)

              conn.XMLСтрока(e.ВД))] += 1
    return rows, с_фл, {k: c for k, c in keys.items() if c > 1}
