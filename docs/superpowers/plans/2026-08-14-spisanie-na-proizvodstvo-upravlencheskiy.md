> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Внешний СКД-отчёт BaseERP «Списання на виробництво (управлінський)» — форма СС по факту списания: Етап → Загальна назва → Номенклатура, Кількість / Ціна з ПДВ / Сума з ПДВ.

**Architecture:** Клон движка `А_ОтчетПоСписаниюНаПроизводство` (программная компоновка: `ПолучитьДанные` → внешний набор «Детали» СКД), из которого убраны плановые строки; ТЧ `Комплектующие` активных СС драйвера дают только карту «назва → етап» (первое вхождение по `НомерСтроки`, разделы нумеруются «01. Каркас»…«99. Позапланово») и карту плановых цен «назва+одиниця» для fallback незакрытого месяца. Работы и табелирование не используются вообще.

**Tech Stack:** BSL (внешний отчёт, программная компоновка СКД), XML СКД, Python COM (`V83.COMConnector`, `C:\Python313\python.exe`) для Rule #-1 и приёмки, сборка `.erf` скиллом `erf-build` против BaseERPRazr.

print(f"ИТОГО факт: кол={итого_кол:.3f} сумма={итого_сумма:.2f}")

// Обе карты СС драйвера ОДНИМ упорядоченным обходом ТЧ Комплектующие
// (только материальная часть; ТЧ Работы не читается):
//   Этапы: ключ назвы -> {Этап, ЭтапНомер, ЭтапСтрока} — ПЕРВОЕ вхождение по
//     (Наименование СС, НомерСтроки); материал попадает ровно в один этап.
//     ЭтапНомер — порядковый номер появления этапа в обходе (порядок листа СС),
//     подпись раздела "01. Каркас" ... "99. Позапланово" сортируется строково.
//   Цены: ключ "назва|одиниця" -> {ПланКол, ПланГрн} — суммы ТЧ (с НДС) для fallback;
//     множитель КоличествоДомов на цену не влияет (сокращается в ПланГрн/ПланКол).
// Ключи нормализованы ВРег(СокрЛП()): в справочниках дубли карточек и «шт»/« шт».
Функция ПостроитьКартыСС(Драйвер)

	Запрос = Новый Запрос;
	Запрос.УстановитьПараметр("Драйвер", Драйвер);
	Запрос.Текст =
	"ВЫБРАТЬ
	|	К.Ссылка.Наименование КАК ИмяСС,
	|	К.НомерСтроки КАК НомерСтроки,
	|	ЕСТЬNULL(ВЫБОР
	|		КОГДА К.Номенклатура = ЗНАЧЕНИЕ(Справочник.Номенклатура.ПустаяСсылка)
	|			ТОГДА К.ОбщееНазвание.Наименование
	|		ИНАЧЕ К.Номенклатура.А_ОбщееНазваниеНоменклатуры.Наименование
	|	КОНЕЦ, """") КАК ИмяНазвы,
	|	К.Этап КАК Этап,
	|	ЕСТЬNULL(К.Единица.Наименование, """") КАК ИмяЕдиницы,
	|	К.Количество КАК Количество,
	|	К.Сумма КАК Сумма
	|ИЗ
	|	Справочник.А_СтруктураСебестоимости.Комплектующие КАК К
	|ГДЕ
	|	К.Ссылка.Активная
	|	И НЕ К.Ссылка.ЭтоГруппа
	|	И ВЫБОР
	|		КОГДА К.Ссылка.ПодразделениеОбъекта <> ЗНАЧЕНИЕ(Справочник.СтруктураПредприятия.ПустаяСсылка)
	|			ТОГДА К.Ссылка.ПодразделениеОбъекта
	|		ИНАЧЕ К.Ссылка.Подразделение
	|	КОНЕЦ = &Драйвер
	|УПОРЯДОЧИТЬ ПО
	|	ИмяСС,
	|	НомерСтроки";

	Этапы = Новый Соответствие;
	Цены = Новый Соответствие;
	НомераЭтапов = Новый Соответствие;
	СчетчикЭтапов = 0;

	Выборка = Запрос.Выполнить().Выбрать();
	Пока Выборка.Следующий() Цикл
		КлючНазвы = ВРег(СокрЛП(Выборка.ИмяНазвы));
		Если КлючНазвы = "" Тогда
			Продолжить;
		КонецЕсли;
		Если ЗначениеЗаполнено(Выборка.Этап) Тогда
			Если НомераЭтапов.Получить(Выборка.Этап) = Неопределено Тогда
				СчетчикЭтапов = СчетчикЭтапов + 1;
				НомераЭтапов.Вставить(Выборка.Этап, СчетчикЭтапов);
			КонецЕсли;
			Если Этапы.Получить(КлючНазвы) = Неопределено Тогда
				НомерЭтапа = НомераЭтапов.Получить(Выборка.Этап);
				Этапы.Вставить(КлючНазвы, Новый Структура("Этап, ЭтапНомер, ЭтапСтрока",
					Выборка.Этап, НомерЭтапа, ПодписьЭтапа(НомерЭтапа, Строка(Выборка.Этап))));
			КонецЕсли;
		КонецЕсли;
		КлючЦены = КлючНазвы + "|" + ВРег(СокрЛП(Выборка.ИмяЕдиницы));
		Группа = Цены.Получить(КлючЦены);
		Если Группа = Неопределено Тогда
			Группа = Новый Структура("ПланКол, ПланГрн", 0, 0);
			Цены.Вставить(КлючЦены, Группа);
		КонецЕсли;
		Группа.ПланКол = Группа.ПланКол + Выборка.Количество;
		Группа.ПланГрн = Группа.ПланГрн + Выборка.Сумма;
	КонецЦикла;

	Возврат Новый Структура("Этапы, Цены", Этапы, Цены);

// Деньги строки: СуммаСНДС = себестоимость (с НДС), при нуле (месяц не закрыт) —
// fallback Количество * плановая цена СС (ключ «назва+одиниця»). ИсточникЦены — прозрачность.
// ЦенаСНДС на детальной строке; на группах пересчитывается totalField схемы.
Процедура ЗаполнитьСуммыИЦены(ТЗ, КартаЦен)

	Для Каждого СтрокаТЗ Из ТЗ Цикл
		СуммаПлан = 0;
		Если ЗначениеЗаполнено(СтрокаТЗ.ОбщееНазвание) Тогда
			КлючЦены = ВРег(СокрЛП(СтрокаТЗ.ОбщееНазвание.Наименование)) + "|" + КлючЕдиницы(СтрокаТЗ.Единица);
			Группа = КартаЦен.Получить(КлючЦены);
			Если Группа <> Неопределено И Группа.ПланКол > 0 Тогда
				СуммаПлан = СтрокаТЗ.Количество * (Группа.ПланГрн / Группа.ПланКол);
			КонецЕсли;
		КонецЕсли;
		СтрокаТЗ.СуммаПлан = СуммаПлан;
		Если СтрокаТЗ.СуммаСоб <> 0 Тогда
			СтрокаТЗ.СуммаСНДС = СтрокаТЗ.СуммаСоб;
			СтрокаТЗ.ИсточникЦены = "Собівартість";
		ИначеЕсли СуммаПлан <> 0 Тогда
			СтрокаТЗ.СуммаСНДС = СуммаПлан;
			СтрокаТЗ.ИсточникЦены = "Планова ціна";
		Иначе
			СтрокаТЗ.СуммаСНДС = 0;
			СтрокаТЗ.ИсточникЦены = "Без ціни";
		КонецЕсли;
		СтрокаТЗ.ЦенаСНДС = ?(СтрокаТЗ.Количество = 0, 0, СтрокаТЗ.СуммаСНДС / СтрокаТЗ.Количество);
	КонецЦикла;
