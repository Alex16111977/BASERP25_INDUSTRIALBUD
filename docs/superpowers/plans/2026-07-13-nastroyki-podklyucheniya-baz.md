# А_НастройкиПодключенияБаз Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вынести захардкоженные строки COM-подключения (`Srvr="SQLSERVER";...`) из 17 мест в 14 объектах конфигурации в регистр сведений `А_НастройкиПодключенияБаз` с общей функцией `А_ПодключенияБазСервер.УстановитьСоединение(ИдентификаторБазы)`; сервер по умолчанию `localhost`, чтобы копия базы работала на любом сервере.

**Architecture:** Новый независимый непериодический регистр сведений (ключ — строковый идентификатор базы) + новый привилегированный серверный общий модуль, делегирующий COM-механику в БСП `ОбщегоНазначения.УстановитьВнешнееСоединениеСБазой()`. Спецификация: `docs/superpowers/specs/2026-07-13-nastroyki-podklyucheniya-baz-design.md`.

**Tech Stack:** BAS ERP 2.5 (XML-выгрузка конфигурации, BSL), Python COM (`V83.COMConnector`) для тестов, скилы `meta-compile`/`meta-validate`/`db-load-xml`/`db-update`.

**Факты, добытые при подготовке (НЕ перепроверять заново):**
- Структура результата БСП: `ОбщегоНазначенияСлужебныйКлиентСервер.УстановитьВнешнееСоединениеСБазой()` ([Module.bsl:374-380](../../CommonModules/ОбщегоНазначенияСлужебныйКлиентСервер/Ext/Module.bsl)) возвращает структуру с полями `Соединение`, `КраткоеОписаниеОшибки`, `ПодробноеОписаниеОшибки`, `ОшибкаПодключенияКомпоненты`.
- Конструктор параметров: `ОбщегоНазначенияКлиентСервер.СтруктураПараметровДляУстановкиВнешнегоСоединения()` ([Module.bsl:1915](../../CommonModules/ОбщегоНазначенияКлиентСервер/Ext/Module.bsl)) — поля `ВариантРаботыИнформационнойБазы` (1 = клиент-сервер), `КаталогИнформационнойБазы`, `ИмяСервера1СПредприятия`, `ИмяИнформационнойБазыНаСервере1СПредприятия`, `АутентификацияОперационнойСистемы`, `ИмяПользователя`, `ПарольПользователя`.
