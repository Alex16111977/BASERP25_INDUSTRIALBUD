# «Нарахування відсотків за кредитами» — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Новий документ BAS ERP 2.5 рахує відсотки за місяць по договорах «%% за использование от кредитора -- X» (за виплатою / за формулою / вручну) і створює під собою проведені «Приобретение товаров и услуг» зі статтею «Послуги банків».

**Architecture:** Метадані (перелік способів, регістр ставок, документ, реквізит зв'язку в ПТУ) + серверний загальний модуль `А_НачислениеПроцентовПоКредитамСервер` з усіма запитами і формулою (доступний з COM для тестів) + тонкий модуль об'єкта документа (заповнення, захист від дублів, генерація ПТУ за зразком ОУМП) + форми. Кожен запит і формула спершу перевіряються Python COM на BaseERP, потім переносяться в BSL 1:1.

**Tech Stack:** 1С:Підприємство 8.3.20 (BSL, XML-вивантаження конфігурації), Python 3 + `win32com` (V83.COMConnector), скіли проєкту `db-dump-xml`, `db-load-xml`, `db-update`, `bas-*`, `meta-*`, `form-*`.

**Spec:** `docs/superpowers/specs/2026-10-16-nachislenie-procentov-kredit-design.md` (рішення Р1–Р8, формула §5, побудова §6, приймання §7). Промт-обгортка: `prompts/prompt_nachislenie_procentov_kredit.md`.
