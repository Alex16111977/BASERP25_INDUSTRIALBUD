# А_ПланФактныйПроизводствоПолный: план из спецификации, факт из карточки — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Плановая ветка материалов берёт загальну назву, аналітику и одиницю только из табличной части `А_СтруктураСебестоимости.Комплектующие`; фактовая ветка отдаёт наименование карточки текстом в «Аналітику», а ссылку на карточку в новое измерение «Номенклатура».

**Architecture:** Программная компоновка СКД: BSL строит плоскую таблицу (`ПолучитьДанные` → цикл по подразделениям → UNION из 5 веток → 2 постобработки) и передаёт её схеме внешним набором «Детали». Меняются две ветки запроса, карта етапів, три постобработки, описание таблицы и схема. Спека: `docs/superpowers/specs/2026-09-04-pfpp-plan-bez-nomenklatury-design.md`.

**Tech Stack:** 1С:Предприятие 8.3.20, BSL, СКД (DataCompositionSchema XML), Python 3 + `win32com` (`V83.COMConnector`, `Srvr="localhost";Ref="BaseERP";Usr="Администратор";Pwd="24043"`), PowerShell `epf-build.ps1`, скилы `db-load-xml` / `db-update`.
