**Goal:** Создать типовые формы документу `А_ФинРез_Баланс` (форм нет вовсе), доретрофитить форму документа
`А_ПередачаНачислений` явными кнопками, задокументировать и дообучить скилы.

**Architecture:** Метод — **копия-адаптация рабочего эталона** (CLAUDE.md: «найди рабочий шаблон → скопируй →
меняй только контент»). Эталон формы документа простого типа = **`АмортизацияОС`** (уже содержит явный

формы списка = `А_ПередачаНачислений` (рабочий `CommandSet` + панель таблицы). Проведение/`ObjectModule` НЕ
трогаем (balance-класс).

**Tech Stack:** 1С BAS ERP 2.5 (Form.xml/BSL), скилы `form-validate`/`meta-edit`/`db-load-xml`/`db-update`,
Python COM (`V83.COMConnector`, `Srvr="SQLSERVER";Ref="BaseERP";Usr="Администратор";Pwd="24043"`).

**«Тест» в этом домене:** форма → `form-validate` (структура) + загрузка конфигурации + **smoke** (пользователь
открывает форму в 1С Enterprise и подтверждает вид); скил → приёмка свежим субагентом (дать скил чистому
агенту + задача, проверить вывод без выдумок).

**Ветка/копирование:** работаем в `claude/bas-doc-skills`, прямо в основной конфигурации (Конфигуратор грузит
оттуда, Rule #4). Формы документа/конфига коммитим; скилы (`.claude`) в git НЕ идут (gitignore) — живут на диске.
