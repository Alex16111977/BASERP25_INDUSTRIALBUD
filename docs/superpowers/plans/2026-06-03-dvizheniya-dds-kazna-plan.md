> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Самодостаточно для НОВОЙ ИИ-сессии** (нулевой контекст). Спека: `docs/superpowers/specs/2026-06-03-dvizheniya-dds-kazna-cherez-raspredeleniya-design.md`. База знаний: `_Rarzrabotki/notebook/knowledge_А_ОтражениеЗПпоКазне/` (KNOWLEDGE_MAP, 16_peredacha_nachisleniy.md, LESSONS).

**Goal:** Воспроизвести в ЕРП движения денег по выплате ЗП (которые в Казне идут через `БДДС`) — через новый `РегистрНакопления.А_ДвиженияДенегДоходыРасходы`, заполняя ТЧ `А_ДвижениеДДС` документов `А_РаспределениеЗаработнойПлаты` (Ф1/безнал) и `РаспределениеФ2` (Ф2/нал) из `А_ОтражениеЗПпоКазне.РаспределениеКазна`, затем проводя эти документы.

**Architecture:** Часть A — кнопка/метод на `А_ОтражениеЗПпоКазне` группирует `РаспределениеКазна` по `(ДокРаспределениеЗП, Подразделение, Статья)` → заливает в `А_ДвижениеДДС` целевого документа → проводит. Часть B — `ОбработкаПроведения` каждого документа-распределения пишет движения регистра, выводя ТипДС/Организация/ОргБух/БанкКассу из типа документа и реквизитов. Регистр = зеркало БДДС Казны (cash flow), Подразделение исходное.

**Tech Stack:** 1С BSL (8.3.20.1914), Python COM (pywin32, `V83.COMConnector`), MCP `1c-workerp`, навыки `/db-load-xml` + `/db-update`. RED = Python COM тест (CLAUDE.md Rule #-1), GREEN = BSL.
