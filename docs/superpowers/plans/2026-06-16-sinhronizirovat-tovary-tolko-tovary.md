# План реализации: обработка `СинхронизироватьТоварыТолькоТовары`

> **For agentic workers:** Реализовать по задачам. Шаги — чекбоксы `- [ ]`. Для 1С действует Rule #-1/#5: запрос сначала Python COM (RED), потом BSL (GREEN).

**Goal:** Получить из `СинхронизироватьТовары` односекционную обработку сверки ERP↔BuhBud только по товарам, с интерфейсом в стиле `СинхронизироватьДеньгиКасса`.

**Architecture:** Работаем поверх существующей побайтовой копии в основной конфигурации. ObjectModule: вырезаем разделы Гроші/Взаєморозрахунки, оставляем 3-фазную товарную ветку, достраиваем per-row методы (порт Кассы). Форму перестраиваем 1:1 по эталону Кассы, привязка к обобщённой модели (Измерение1=Номенклатура, Измерение2=Склад).

**Tech Stack:** 1С BSL, внешняя обработка (.epf), Python `win32com` (COM к BaseERP+BuhBud), skills `/epf-build` `/epf-validate` `/form-validate`.
