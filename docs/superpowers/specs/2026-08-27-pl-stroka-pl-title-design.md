# Отчёт А_ОтчетPL_ПолныйЕРП: подпись поля «Строка листа (PL как в Excel)» → «Строка PL»

Дата: 2026-08-27. Утверждено пользователем (вместе с загрузкой в конфигурацию).

## Решение

Подпись живёт в ОДНОЙ точке — `<title>` поля `СтрокаЛиста` в
`Templates/ОсновнаяСхемаКомпоновкиДанных/Ext/Template.xml`. Ни один из 15 пользовательских
вариантов в БД титул не переопределяет (проверено сериализацией настроек) — замена в схеме
отобразится во всех вариантах. Модуль не ссылается на текст; граница шапки в
`РусифицироватьСлужебныеТексты` и приёмках ищется по «Статья PL» — не затронута.
Параметр «PL как в Excel: строки листа» НЕ переименовывается (не просили).

Правка вносится в обе копии зеркала: `_Rarzrabotki` (наш формат) и `Reports/`
(канон БД после 27.08).

## Проверки

- Отчёт полным путём: «Строка PL» в шапке, старого текста нет, «Статья PL» на месте.
- Регрессия: `acceptance_russkie_nazvaniya` (28) + сверка док-код.
- `.erf` через BaseERPRazr, зеркала; частичная загрузка макета в BaseERP + UpdateDBCfg,
  контрольная выгрузка, смоук отчёта из конфигурации.
