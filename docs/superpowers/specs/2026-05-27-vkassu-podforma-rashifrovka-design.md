## 1. Цель

Создать в составе документа `ВедомостьНаВыплатуЗарплатыВКассу` локальную форму
для редактирования ТЧ `А_РасшифровкаВыплатыЗарплатаПоФизлицам` (с колонкой
`СтатьяДвиженияДенежныхСредств`), и заменить ею вызовы типовой подформы
`CommonForms.РедактированиеЗарплатыСтрокиВедомости` **только в форме документа
ВКассу** (двойной клик на ТЧ Состав + кнопка «Изменить зарплату»).

**Почему:** типовая подформа редактирует ТЧ `Зарплата`, в которой нет
реквизита `СтатьяДвиженияДенежныхСредств`. Пользователю нужно видеть и
редактировать статью ДДС из нашей кастомной ТЧ `А_Расшифровка` прямо при
двойном клике на сотруднике / по кнопке «Изменить зарплату».

---

## 2. Архитектурное решение — паттерн `ОтражениеЗарплатыВФинансовомУчете.ФормаСпискаФизическихЛиц`

Полностью копируем паттерн БСП: локальная форма документа с реквизитом-ТЧ,
передача данных через временное хранилище `ПоместитьВоВременноеХранилище` →
`ПолучитьИзВременногоХранилища`, возврат изменений через `ОписаниеОповещения` +
структуру результата (как в `CommonForms.РедактированиеЗарплатыСтрокиВедомости.ВыбратьИЗакрыть`).

**Не трогаем:**
- `CommonForms/РедактированиеЗарплатыСтрокиВедомости` — типовая БСП-форма
- `CommonModule.ВзаиморасчетыССотрудникамиКлиентРасширенный` — типовой клиентский код БСП
- `CommonModule.ВзаиморасчетыССотрудникамиКлиент` — типовой клиентский код БСП
- ТЧ `Зарплата` документа ВКассу — никаких новых реквизитов
- ТЧ `А_РасшифровкаВыплатыЗарплатаПоФизлицам` — структура остаётся как есть
- Формы документов `ВедомостьНаВыплатуЗарплатыПеречислением`, `ВедомостьНаВыплатуЗарплатыВБанк`,
  `ВедомостьНаВыплатуЗарплатыРаздатчиком` — типовая логика работает без изменений

## 3. Новая форма `Documents/ВедомостьНаВыплатуЗарплатыВКассу/Forms/А_ФормаСпискаРасшифровкиПоФЛ`

### 3.1 Реквизиты формы

| Имя | Тип | Назначение |
|---|---|---|
| `А_РасшифровкаВыплатыЗарплатаПоФизлицам` | `ТабличнаяЧасть.ВедомостьНаВыплатуЗарплатыВКассу.А_РасшифровкаВыплатыЗарплатаПоФизлицам` | Редактируемая копия фильтрованной части ТЧ документа |
| `ФизическоеЛицо` | `СправочникСсылка.ФизическиеЛица` | Контекст подформы (для нового добавления) |
| `Организация` | `СправочникСсылка.Организации` | Контекст подформы (для НаправлениеДеятельности) |

### 3.2 Структура формы (Form.xml)

- TableBox `А_РасшифровкаВыплатыЗарплатаПоФизлицам` с колонками (редактируемые):
  - `ФизическоеЛицо` (после открытия подставляется автоматически из контекста при добавлении новой строки)
  - `Сотрудник`
  - `Подразделение`
  - **`СтатьяДвиженияДенежныхСредств`** ← главная колонка задачи
  - `НаправлениеДеятельности`
  - `ОтработаноЧасов`
  - `Сумма`
- Командная панель TableBox — стандартные команды Add/Delete/Copy
- Командная панель формы — кнопки «ОК» и «Отмена»

### 3.3 Module.bsl — основные процедуры

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)

	Если Параметры.Свойство("АвтоТест") Тогда
		Возврат;
	КонецЕсли;

	Если Параметры.Свойство("Заголовок") Тогда
		Заголовок = Параметры.Заголовок;
	КонецЕсли;

	Если Параметры.Свойство("ФизическоеЛицо") Тогда
		ФизическоеЛицо = Параметры.ФизическоеЛицо;
	КонецЕсли;

	Если Параметры.Свойство("Организация") Тогда
		Организация = Параметры.Организация;
	КонецЕсли;

	Если Параметры.Свойство("АдресВХранилище") И ЗначениеЗаполнено(Параметры.АдресВХранилище) Тогда
		ТЗ = ПолучитьИзВременногоХранилища(Параметры.АдресВХранилище);
		А_РасшифровкаВыплатыЗарплатаПоФизлицам.Загрузить(ТЗ);
	КонецЕсли;

КонецПроцедуры

&НаКлиенте
Процедура А_РасшифровкаПриНачалеРедактирования(Элемент, НоваяСтрока, Копирование)
	// Для новой строки — подставить контекст (ФЛ + Организация)
	Если НоваяСтрока И НЕ Копирование Тогда
		Элемент.ТекущиеДанные.ФизическоеЛицо = ФизическоеЛицо;
		Элемент.ТекущиеДанные.ИдентификаторСтроки = Новый УникальныйИдентификатор();
	КонецЕсли;
КонецПроцедуры

&НаКлиенте
Процедура ОК(Команда)
	ВыбратьИЗакрыть();
КонецПроцедуры

&НаКлиенте
Процедура Отмена(Команда)
	Модифицированность = Ложь;
	Закрыть();
КонецПроцедуры

&НаКлиенте
Процедура ВыбратьИЗакрыть()
	Результат = Новый Структура;
	Результат.Вставить("Модифицированность", Модифицированность);
	Результат.Вставить("ФизическоеЛицо", ФизическоеЛицо);
	Результат.Вставить("АдресВХранилище", А_АдресВХранилище());
	Модифицированность = Ложь;
	Закрыть(Результат);
КонецПроцедуры

&НаСервере
Функция А_АдресВХранилище()
	ТЗ = А_РасшифровкаВыплатыЗарплатаПоФизлицам.Выгрузить();
	Возврат ПоместитьВоВременноеХранилище(ТЗ, УникальныйИдентификатор);
КонецФункции
```

## 4. Изменения в `Documents/ВедомостьНаВыплатуЗарплатыВКассу/Forms/ФормаДокумента/Ext/Form/Module.bsl`

### 4.1 Переопределение `СоставВыбор` (стр. 232-234)

Было:
```bsl
&НаКлиенте
Процедура СоставВыбор(Элемент, ВыбраннаяСтрока, Поле, СтандартнаяОбработка)
	ВзаиморасчетыССотрудникамиКлиентРасширенный.ВедомостьСоставВыбор(ЭтаФорма, Элемент, ВыбраннаяСтрока, Поле, СтандартнаяОбработка)
КонецПроцедуры
```

Стало:
```bsl
&НаКлиенте
Процедура СоставВыбор(Элемент, ВыбраннаяСтрока, Поле, СтандартнаяОбработка)
	СтандартнаяОбработка = Ложь;
	ФЛ = Объект.Состав.НайтиПоИдентификатору(ВыбраннаяСтрока).ФизическоеЛицо;
	А_ОткрытьРасшифровкуДляФЛ(ФЛ);
КонецПроцедуры
```

### 4.2 Переопределение `РедактироватьЗарплатуСтроки` (стр. 404-407)

Было:
```bsl
&НаКлиенте
Процедура РедактироватьЗарплатуСтроки(ДанныеСтроки) Экспорт
	ВзаиморасчетыССотрудникамиКлиент.ВедомостьРедактироватьЗарплатуСтроки(ЭтаФорма, ДанныеСтроки);
КонецПроцедуры
```

Стало:
```bsl
&НаКлиенте
Процедура РедактироватьЗарплатуСтроки(ДанныеСтроки) Экспорт
	Если ДанныеСтроки <> Неопределено И ЗначениеЗаполнено(ДанныеСтроки.ФизическоеЛицо) Тогда
		А_ОткрытьРасшифровкуДляФЛ(ДанныеСтроки.ФизическоеЛицо);
	КонецЕсли;
КонецПроцедуры
```

Связанная серверная процедура `РедактироватьЗарплатуСтрокиЗавершениеНаСервере` (стр. 410-412) — оставляем как есть (типовой обработчик для совместимости, наш обработчик вызывает другую процедуру).

### 4.3 Новые процедуры в форме ВКассу

```bsl
&НаКлиенте
Процедура А_ОткрытьРасшифровкуДляФЛ(ФЛ)

	ПарамФормы = А_ПодготовитьПараметрыНаСервере(ФЛ);
	ОткрытьФорму(
		"Документ.ВедомостьНаВыплатуЗарплатыВКассу.Форма.А_ФормаСпискаРасшифровкиПоФЛ",
		ПарамФормы, ЭтаФорма, , , ,
		Новый ОписаниеОповещения("А_РасшифровкаЗакрыта", ЭтотОбъект, Новый Структура("ФЛ", ФЛ)));

КонецПроцедуры

&НаСервере
Функция А_ПодготовитьПараметрыНаСервере(ФЛ)

	ТЗ = Объект.А_РасшифровкаВыплатыЗарплатаПоФизлицам.Выгрузить(
		Новый Структура("ФизическоеЛицо", ФЛ));

	АдрХр = ПоместитьВоВременноеХранилище(ТЗ, УникальныйИдентификатор);

	Парам = Новый Структура;
	Парам.Вставить("АдресВХранилище",  АдрХр);
	Парам.Вставить("ФизическоеЛицо",   ФЛ);
	Парам.Вставить("Организация",      Объект.Организация);
	Парам.Вставить("Заголовок",        Строка(ФЛ) + ": расшифровка по статье");

	Возврат Парам;

КонецФункции

&НаКлиенте
Процедура А_РасшифровкаЗакрыта(Результат, ДопПарам) Экспорт

	Если Результат = Неопределено Тогда
		Возврат;
	КонецЕсли;
	Если НЕ Результат.Модифицированность Тогда
		Возврат;
	КонецЕсли;

	А_РасшифровкаЗакрытаНаСервере(Результат.АдресВХранилище, ДопПарам.ФЛ);
	Модифицированность = Истина;

КонецПроцедуры

&НаСервере
Процедура А_РасшифровкаЗакрытаНаСервере(АдрХр, ФЛ)

	// Удалить старые строки этого ФЛ
	Удаляемые = Объект.А_РасшифровкаВыплатыЗарплатаПоФизлицам.НайтиСтроки(
		Новый Структура("ФизическоеЛицо", ФЛ));
	Для Каждого СтрУд Из Удаляемые Цикл
		Объект.А_РасшифровкаВыплатыЗарплатаПоФизлицам.Удалить(СтрУд);
	КонецЦикла;

	// Добавить новые из подформы
	НоваяТЗ = ПолучитьИзВременногоХранилища(АдрХр);
	Для Каждого СтрН Из НоваяТЗ Цикл
		НоваяСтр = Объект.А_РасшифровкаВыплатыЗарплатаПоФизлицам.Добавить();
		ЗаполнитьЗначенияСвойств(НоваяСтр, СтрН);
		// Если ИдентификаторСтроки пуст — поставить новый
		Если НЕ ЗначениеЗаполнено(НоваяСтр.ИдентификаторСтроки) Тогда
			НоваяСтр.ИдентификаторСтроки = Новый УникальныйИдентификатор();
		КонецЕсли;
	КонецЦикла;

КонецПроцедуры
```

## 5. Поведение

| Сценарий | Результат |
|---|---|
| Двойной клик на сотруднике в ТЧ Состав | Открывается **наша** локальная форма с А_Расшифровкой по этому ФЛ, редактируемая |
| Кнопка «Изменить зарплату» (на выделенной строке) | Открывает **нашу** форму вместо типовой |
| Пользователь редактирует / добавляет / удаляет строки | Изменения в реквизите формы (TZ) |
| ОК | Изменения записываются в ТЧ `Объект.А_РасшифровкаВыплатыЗарплатаПоФизлицам`. `Модифицированность = Истина` |
| Отмена | Изменения отбрасываются |
| Пустая А_Расшифровка для этого ФЛ | Форма открывается с пустой таблицей — пользователь может добавить строки |
| Другие документы (Перечислением, ВБанк, Раздатчиком) | Не задеты — у них свои формы документа с типовой логикой |
| ТЧ Зарплата | Не модифицируется через нашу форму. Если нужно изменить КВыплате — пользователь работает с ТЧ Зарплата напрямую через TableBox основной формы |

## 6. Out-of-scope

- Замена типовой формы в Перечислением / ВБанк / Раздатчиком
- Изменение типовой `CommonForms.РедактированиеЗарплатыСтрокиВедомости`
- Синхронизация ТЧ Зарплата ↔ А_Расшифровка (две независимые ТЧ)
- Перерасчёт СуммаПоДокументу от изменений в А_Расшифровке (СуммаПоДокументу = Итог(ТЧ.Зарплата.КВыплате))
- Открытие нашей формы из других мест (например при подборе сотрудника)

## 7. Тестирование

### 7.1 Python COM
Проверка структуры:
- Форма `Документ.ВедомостьНаВыплатуЗарплатыВКассу.Форма.А_ФормаСпискаРасшифровкиПоФЛ` зарегистрирована в метаданных
- Реквизит формы `А_РасшифровкаВыплатыЗарплатаПоФизлицам` существует и имеет правильный тип

### 7.2 Программный тест возврата изменений
Smoke через COM (имитация открытия+закрытия подформы вне UI невозможна, но можно протестировать
серверные процедуры `А_ПодготовитьПараметрыНаСервере` и `А_РасшифровкаЗакрытаНаСервере` если их сделать `Экспорт`).

Минимальный smoke:
- Подготовить ВКассу 000Ц-000009 с А_Расшифровкой для ФЛ «Васіліу Руслан»
- Программно вызвать `Объект.А_РасшифровкаВыплатыЗарплатаПоФизлицам.Выгрузить(Отбор)` — получить ТЗ для ФЛ
- Изменить одну строку (например `Сумма`)
- Программно записать обратно через паттерн «удалить старые + добавить новые»
- Проверить что изменение сохранилось в БД

### 7.3 Ручная UI-проверка (главная)
1. Открыть ВКассу 000Ц-000009
2. Двойной клик на «Васіліу Руслан Георгійович»
3. Должна открыться **наша** форма с **2 строками** и видимой колонкой «Статья ДДС» = «Зарплата механизаторов»
4. Изменить сумму в одной строке → ОК → проверить что в основной форме модифицированность установилась
5. Записать ВКассу → перепрочитать → значение сохранилось

## 8. Acceptance критерии

- ✅ В составе документа ВКассу появилась локальная форма `А_ФормаСпискаРасшифровкиПоФЛ`.
- ✅ В TableBox формы видны 7 колонок, включая редактируемую `СтатьяДвиженияДенежныхСредств`.
- ✅ Двойной клик на сотруднике в ТЧ Состав открывает нашу форму с фильтром по ФизЛицу.
- ✅ Кнопка «Изменить зарплату» открывает нашу форму вместо типовой.
- ✅ Пользователь может добавлять / удалять / редактировать строки.
- ✅ ОК сохраняет изменения в ТЧ документа; Отмена откатывает.
- ✅ Другие документы (Перечислением/ВБанк/Раздатчиком) не задеты.
- ✅ Регрессия Ф2/ОтражениеЗП тестов: PASS (косвенно — наши кнопки создания ВКассу не задеты).
