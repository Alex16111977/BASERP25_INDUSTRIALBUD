## 1. Задача

СКД-отчёт по ТЧ `Комплектующие` справочника `СтруктураСебестоимости`: разрезы
ОбщееНазвание / Номенклатура / Цена и все поля ТЧ.

## 2. СКД

Один набор данных — запрос (протестирован Python COM 1:1; контроль:
1228 строк, Σ Сумма = 15 247 859,11 на момент проектирования):

```
ВЫБРАТЬ
	К.Ссылка КАК Структура,
	К.Ссылка.Активная КАК Активная,
	К.Этап КАК Этап,
	К.ОбщееНазвание КАК ОбщееНазвание,
	К.Номенклатура КАК Номенклатура,
	К.НоменклатураСС КАК НоменклатураСС,
	К.Единица КАК Единица,
	К.ЕдиницаСС КАК ЕдиницаСС,
	К.Количество КАК Количество,
	К.Сумма КАК Сумма,
	ВЫБОР КОГДА К.Количество <> 0 ТОГДА К.Сумма / К.Количество ИНАЧЕ 0 КОНЕЦ КАК Цена
ИЗ
	Справочник.СтруктураСебестоимости.Комплектующие КАК К
```

- Поле «Цена» — вычисляемое (в ТЧ его нет).
- **Ресурсы:** `Количество` = Сумма(Количество); `Сумма` = Сумма(Сумма);
  `Цена` = средневзвешенная `ВЫБОР КОГДА Сумма(Количество) <> 0 ТОГДА
  Сумма(Сумма) / Сумма(Количество) ИНАЧЕ 0 КОНЕЦ` (НЕ среднее арифметическое).
- **Вариант по умолчанию:** группировки ОбщееНазвание → Номенклатура → детальные
  записи; выбранные поля: Структура, Этап, НоменклатураСС, ЕдиницаСС, Единица,
  Количество, Цена, Сумма.
- Отборы пользователю (СКД, доступные): Структура, Активная, ОбщееНазвание,
  Номенклатура, Этап.
- Формат Цена/Сумма: ЧЦ=15, ЧДЦ=2.
