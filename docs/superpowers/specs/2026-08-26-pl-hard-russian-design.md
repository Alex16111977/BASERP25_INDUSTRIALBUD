# Отчёт А_ОтчетPL_ПолныйЕРП: жёстко русский язык + орфография русских наименований

Дата: 2026-08-26. Утверждено пользователем (подход A, обе орфо-правки).

## Проблема

Отчёт, сформированный на другом сервере (украинский язык сеанса), выдал украинские
тексты — файл `_Rarzrabotki/Выгрузка отчета PL/PL по компании 07.2026.xlsx`:
«Липень 2026» в шапке колонок, «Параметри:», «Відбір:», «: Так»/«: Ні»,
«В групі зі списку». Статьи/водопад вышли русскими, но держатся на `НСтр("ru=…")` —
зависят от основного языка конфигурации сервера.

## Решение (подход A — три слоя в самом отчёте)

1. **Месяцы**: `Формат(ТекМесяц, "Л=ru_RU; ДФ='MMMM yyyy'")` — русская локаль жёстко,
   независимо от языка сеанса.
2. **НСтр → обычные строковые литералы** (33 вхождения) — нулевая зависимость от языка
   сеанса и основного языка конфигурации. Многострочные литералы сохраняют `|`-переносы.
3. **Пост-обработка** — новая ЭКСПОРТНАЯ процедура `РусифицироватьСлужебныеТексты(ТабДок)`,
   вызывается в `ПриКомпоновкеРезультата` после вывода. Обрабатывает служебную шапку
   (строки до заголовка таблицы «Статья PL» включительно):
   - ячейка целиком: «Параметри:» → «Параметры:», «Відбір:» → «Отбор:»;
   - суффиксы: «: Так» → «: Да», «: Ні» → «: Нет»;
   - подстроки: представления видов сравнения отбора («В групі зі списку» → «В группе
     из списка», «У списку» → «В списке», «В ієрархії» → «В иерархии», «Дорівнює» →
     «Равно» и др.) и украинские месяцы → русские (подстраховка).
   Экспортность — чтобы приёмка честно проверила замены на синтетическом табличном
   документе без украинского сервера.

## Орфография `НаименованиеДляОтчетаНаРусском` (только значения, `Наименование` НЕ трогать —
ключ синхронизации пользователя с Excel)

Аудит всех 71 статьи + 8 групп: 77 значений грамотны (чистились 21.08). Правки (утверждены):
- `000000059`: «Штраф/ мат помощь» → «Штраф / мат. помощь»
- `000000054`: «НДС/ Прочие налоги» → «НДС / прочие налоги»

Запись через `ОбменДанными.Загрузка = Истина` (`А_РучнаяКорректировка` блокирует запись).

## Проверки

- COM-механика: `Формат(дата, "Л=uk_UA; ДФ='MMMM yyyy'")` ↔ `Л=ru_RU` — доказать
  управление локалью.
- Новая приёмка: синтетический табличный документ с украинскими текстами из реального
  файла → `РусифицироватьСлужебныеТексты` → украинских токенов нет; отчёт строится,
  шапка колонок «Июль 2026».
- МАППИНГ приёмки русских названий дополнен двумя орфо-правками; все существующие
  приёмки зелёные (28/28, 42/42, 11/11, YTD 11/11) + сверка док-код.
- Финал: `.erf` через BaseERPRazr, зеркала, база знаний, память.
