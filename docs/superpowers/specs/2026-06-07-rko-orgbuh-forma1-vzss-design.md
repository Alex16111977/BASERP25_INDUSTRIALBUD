# Дизайн: РКО с А_ОрганизацияБухгалтерия → А_ВзСС как Форма1 + ОргБух

**Дата:** 2026-06-07
**Тип:** доработка `ЗаполнитьИзРКО` (продолжение [2026-06-07-rko-vyplata-rabotniku-filter-design](2026-06-07-rko-vyplata-rabotniku-filter-design.md))
**Подход:** A (условие в общем write-цикле, без правки запросов)

---

## 🎯 Бизнес-мета (CFO)

РКО с заполненным реквизитом `А_ОрганизацияБухгалтерия` (тип `СправочникСсылка.Организации`) — это **официальная** выплата зарплаты по конкретному юрлицу. Сейчас ветка ВКассу в `ЗаполнитьИзРКО` всегда пишет движения А_ВзСС как **Форма2** (управленческая) без `ОрганизацияБухгалтерия`. Нужно: для таких РКО писать **Форма1** + `ОрганизацияБухгалтерия = РКО.А_ОрганизацияБухгалтерия`.

Это соответствует архитектуре: измерение `ОрганизацияБухгалтерия` в А_ВзСС — «только Ф1» (официальный разрез по юрлицу), как уже сделано в `ЗаполнитьИзСписанияБезнал` (Форма1 + `Д.А_ОрганизацияБухгалтерия`).

**Данные (профиль на 2026-06-07):** 18 проведённых РКО с заполненным ОргБух — все ВКассу (16 «Выплата работнику» + 2 «через кассу»). У большинства ОргБух = ОргУпр («ТОВ ІНДАСТРІАЛБУД»), у **СТ00-000001/002 ОргБух = «ТОВ ІНДЕПТ СТІЛ»** (≠ ОргУпр) — ровно тот случай, ради которого нужен ОргБух-разрез.

---

## 📋 Цель

| | ДО | ПОСЛЕ (если ОргБух заполнен) |
|---|---|---|
| `ФормаPL` движений А_ВзСС | Форма2 | **Форма1** |
| `ОрганизацияБухгалтерия` | пусто | **= РКО.А_ОрганизацияБухгалтерия** |
| `Подразделение`/`ФизическоеЛицо`/`СуммаВзаиморасчетов`/`ВидДвижения` | — | **без изменений** |
| РКО без ОргБух | Форма2 / пусто | **Форма2 / пусто** (без изменений) |

Это **чистая ре-разметка** тех же движений (Σ и баланс не меняются). Σ-инвариант А_ВзСС + ПАП(ОТ) сохраняется (ПАП не имеет измерений ФормаPL/ОргБух).

## 🏗 Архитектура (Approach A)

**Единственная точка:** `AccumulationRegisters/А_ВзаиморасчетыССотрудниками/Ext/ManagerModule.bsl` → `ЗаполнитьИзРКО`, общий цикл записи (после `Результат = Запрос.Выполнить().Выгрузить()`).

```bsl
ОргБух = ДокОбъект.А_ОрганизацияБухгалтерия;   // реквизит шапки
ЭтоФорма1 = ЗначениеЗаполнено(ОргБух);
// в цикле:
Запись.ФормаPL              = ?(ЭтоФорма1, Перечисления.А_ФормыPL.Форма1, Перечисления.А_ФормыPL.Форма2);
Запись.ОрганизацияБухгалтерия = ОргБух;        // пусто при Форма2
```

**Свойства:**
- ОргБух — поле шапки → читается из `ДокОбъект`, запросы (ВКассу и старый) **не меняются**.
- Условие `ЗначениеЗаполнено(ОргБух)` — **независимо от ХозОп** и от ветки (ВКассу/старая): общий цикл покрывает оба случая.
- Только регистр **А_ВзСС** (ПАП/ДенежныеСредстваНаличные/ДСДохРасх не имеют измерений ФормаPL/ОргБух — не затрагиваются).
- Композиция с фиксом фильтра по работнику: ІБ00-000006 → 1 строка, Марчук, **Форма1**, ОргБух=ІНДАСТРІАЛБУД, 21 612,50.

## ✅ Верификация

1. BSL → копия в основную конфигурацию → `/db-load-xml -Mode Partial` + `/db-update -Dynamic+`.
2. Перепровести через COM: **ІБ00-000006** (ОргБух=ІНДАСТРІАЛБУД) и **СТ00-000001** (ОргБух=ІНДЕПТ СТІЛ ≠ ОргУпр).
3. Verify (Python COM):
   - оба → А_ВзСС: `ФормаPL = Форма1`, `ОрганизацияБухгалтерия` = соответствующий ОргБух;
   - контроль: РКО без ОргБух (напр. N0000053050) → остаётся Форма2 / ОргБух пусто;
   - Σ А_ВзСС по документу **не изменилась** (ре-разметка); регрессия фикса работника (1 ФЛ) сохраняется.
