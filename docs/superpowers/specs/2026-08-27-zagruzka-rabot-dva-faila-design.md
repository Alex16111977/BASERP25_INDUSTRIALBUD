# Спека: обработка «Загрузка работ в СС по двум файлам в одну СС» (BaseERP)

Дата: 2026-08-27. Статус: дизайн утверждён пользователем.

## Задача

Загрузить работы из ДВУХ Excel-файлов в ОДНУ структуру себестоимости (`Справочник.А_СтруктураСебестоимости`, база BaseERP), с указанием номера модуля для каждого файла:

- `_Rarzrabotki/Загрузка СС/СС ООН АДМИН/уніф СВ S1 Новий Шаблон 21.08.xlsx` → Модуль = 1
- `_Rarzrabotki/Загрузка СС/СС ООН АДМИН/уніф СВ S3 Новий Шаблон 21.08.xlsx` → Модуль = 3

Обработка — доработка заготовки `_Rarzrabotki/Загрузка СС/Загрузка работ в СС по двум файлам в одну СС.xml` (+ одноимённая папка исходников). Заготовка — копия старой BuhBud-версии «Загрузка работ в СС» с именем `ВнешняяОбработка1`; её модули заменяются движком «Загрузка работ в СС для базы ЕРП», который 1:1 подходит под новые шаблоны.

Материалы (ТЧ Комплектующие) НЕ трогаем — только работы.

## Проверенные факты (инспекция 2026-08-27)

- ТЧ `Работы` справочника `А_СтруктураСебестоимости` имеет поле **`Модуль` (Число)** — подтверждено `get_metadata_structure` по живой BaseERP.
- Оба файла содержат лист **«Проект СС»** со структурой существующего маппинга: C=«Робота» (фильтр), E=Тип робіт (Этап), G=Найменування робіт (Работа), I=Од. вим. (Единица), J=Кіль-кість (Количество), K=Вартість за од. (Цена), M=Вартість за повний обсяг (Сумма). Граница чтения — раздел «Загальновиробничі витрати» (S1: строка 357, S3: строка 399).
- Эталоны (строки «Робота» с непустой G до границы, суммы с Окр(,2)):
  - S1: **44 строки, ΣКоличество 1336.99, ΣСумма 328 530.00**
  - S3: **44 строки, ΣКоличество 1336.99, ΣСумма 326 230.00**
  - Вместе: 88 строк.

## Решения дизайна

**Режим перезаписи (выбор пользователя):** перед загрузкой из ТЧ Работы удаляются строки ТОЛЬКО тех модулей, которые присутствуют в таблице файлов. Строки других модулей сохраняются. Это позволяет перегружать один модуль отдельно.

## Метаданные обработки

- Внутреннее имя: `ЗагрузкаРаботВССПоДвумФайлам`, синоним «Загрузка работ в СС по двум файлам в одну СС» (переименование из `ВнешняяОбработка1`).
- UUID заготовки проверить на уникальность против обработки-источника «Загрузка работ в СС.xml»; при совпадении — регенерировать (см. память epf_clone_regen_internal_guids; ClassId не трогать).
- Реквизит `ДокСтруктураСебестоимости` (`CatalogRef.А_СтруктураСебестоимости`) — остаётся.
- Реквизит `ИмяФайла` — удалить.
- Новая ТЧ **`Файлы`**: `ИмяФайла` (Строка, переменная длина), `Модуль` (Число 10,0).

## Форма

- Поле выбора СС; таблица «Файлы»: колонка «Имя файла» (кнопка выбора — `ДиалогВыбораФайла`, фильтр *.xlsx), колонка «Модуль»; команда «Загрузить работы».
- Автоподстановка: при выборе файла, если имя содержит `S<цифры>` (регистронезависимо, напр. «уніф СВ S1 …»), Модуль = число; редактируемо.
- Валидации перед загрузкой (клиент): СС выбрана; таблица не пуста; в каждой строке файл указан и Модуль > 0; дубли модулей в таблице запрещены.

## Чтение Excel (клиент, COM `Excel.Application`, как в ЕРП-версии)

Для каждой строки ТЧ Файлы: открыть файл, лист «Проект СС» по имени, цикл со строки 2 до последней:
- стоп при E или G = «загальновиробничі витрати» (нормализовано, НРег);
- брать строки C = «Робота»; пустая G → пропуск (счётчик);
- структура строки: `{Этап←E, Работа←G, Единица←I, Количество←J (.Value), Цена←K (.Value), Сумма←M (.Value), Модуль←из ТЧ Файлы}`.
Все файлы → один общий массив структур. Ошибка чтения любого файла → загрузка не выполняется (Excel.Quit в Исключение).

## Движок (сервер, `Ext/ObjectModule.bsl`)

`ЗагрузитьРаботыИзМассива(СтруктураСеб, МассивСтрок) Экспорт` — одна транзакция:

1. Проверки: СС заполнена; группа `_Роботи` (код `0Ц-00000016`); образец работы (артикул `1.1.1` в иерархии группы). Кэши: этапы (`А_ЭтапыРабот`), работы группы `_Роботи`, базовые единицы (`УпаковкиЕдиницыИзмерения`, владелец `НаборыУпаковок.БазовыеЕдиницыИзмерения`, 4-приоритетные ключи) — всё как в ЕРП-версии, включая симметричную нормализацию (СокрЛП + схлоп двойных пробелов).
2. Множество модулей из МассивСтрок → удалить из ТЧ Работы строки этих модулей (обратный цикл по индексам); посчитать `СохраненоЧужихСтрок`.
3. Добавить строки: Этап/Работа — get-or-create; Единица — поиск по кэшу (не найдена → пустая + Инфо); Количество/Цена/Сумма — через `ПолучитьЧисло`; **`Модуль` = СтрокаДанных.Модуль**.
4. Записать объект.
5. **Контроль итогов в разрезе модуля** (запрос по ТЧ с `ГДЕ Ссылка = &Структура И Модуль В (&Модули)`, группировка по Модулю; и по Модулю+Этапу): для каждого загружаемого модуля сверить строк / ΣКоличество / ΣСумма / Σ по этапам с накопленными итогами Excel (Окр(,2), допуск 0.005). Дополнительно сверить общее число строк ТЧ = чужие + загруженные. Расхождение → исключение → откат всей транзакции.
6. Протокол (структура, без re-raise): Загружено, СозданоРабот, СозданоЭтапов, Пропущено, СохраненоЧужихСтрок, КонтрольПройден, Контроль[] (в разрезе модуля), Инфо[] (ненайденные единицы, уникальные работы, строки без этапа/работы/единицы), Ошибка, ТекстОшибки.

Квалификаторы ТЧ Работы (ERP): Количество 15,2; Цена 15,2; Сумма 10,2 — контрольные суммы через Окр(,2).
