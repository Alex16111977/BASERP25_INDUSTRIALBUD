## 🎯 Бизнес-мета

Обработка переносит входящие остатки расчётов с сотрудниками из **BuhBud** (BAS Бухгалтерія) в ЕРП-документ `НачальнаяЗадолженностьПоЗарплате` (Форма1 → регистр `А_ВзаиморасчетыССотрудниками`). Брала только счета **661/663**. Нужно — **все счета 66 В ИЕРАРХИИ** (`ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыПоОплатеТруда)`), выборкой как в отчёте сверки `А_СравнитьОстаткиВзаиморасчетыСотрудникиЕРПсBASБухгалтерия` (он уже использует В ИЕРАРХИИ).

**Discovery (BuhBud, 2026-06-07):** 66 = **661/662/663/665** (все пассивные); субконто1 у всех = `ФизическиеЛица` (гард `ССЫЛКА` ничего лишнего не режет); реквизит `А_ИдКод` заполнен у **813/813** ФЛ → надёжный ключ (лучше cross-base UUID). В `.Остатки` поле `СуммаОстатокДт`=0, `СуммаОстатокКт` знаковое → «Кт−Дт» = знаковое сальдо.

## 🏗 Изменения (Approach A) — `Ext/ObjectModule.bsl`

**`ПрочитатьОстаткиИзBuhBud`** — новый запрос (зеркало отчёта):
```
ВЫБРАТЬ
    ВЫРАЗИТЬ(Остатки.Субконто1 КАК Справочник.ФизическиеЛица).А_ИдКод КАК А_ИдКод,
    ВЫРАЗИТЬ(Остатки.Субконто1 КАК Справочник.ФизическиеЛица).Наименование КАК ИмяФЛ,
    Остатки.Организация.КодПоЕДРПОУ КАК ЕДРПОУ,
    СУММА(Остатки.СуммаОстатокКт) - СУММА(Остатки.СуммаОстатокДт) КАК Сумма
ИЗ РегистрБухгалтерии.Хозрасчетный.Остатки(&Дата,
       Счет В ИЕРАРХИИ(ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыПоОплатеТруда)), , ) КАК Остатки
ГДЕ Остатки.Субконто1 ССЫЛКА Справочник.ФизическиеЛица
    И Остатки.Организация.КодПоЕДРПОУ В (&масЕДРПОУ)
СГРУППИРОВАТЬ ПО <А_ИдКод, Наименование, ЕДРПОУ>
ИМЕЮЩИЕ СУММА(Остатки.СуммаОстатокКт) - СУММА(Остатки.СуммаОстатокДт) <> 0
```
- ТЗ-колонки `УИД/ДРФО` → `А_ИдКод` (+ ИмяФЛ, ЕДРПОУ, Сумма); чтение — только примитивы (нет COM-ссылок/UUID между базами).
- **`НайтиФизЛицо`** — поиск по `А_ИдКод` (`НайтиПоРеквизиту("А_ИдКод", …)`) вместо UUID/ДРФО.
- **`ЗаполнитьПревью`** — свёртка по `(А_ИдКод, ИмяФЛ, ЕДРПОУ)`; метка Счёт «661+663» → «66 (в иерархии)».
- Резолв ОргБух(ЕДРПОУ)/Сотрудник/Подразделение и создание/проведение `НачальнаяЗадолженностьПоЗарплате` (Форма1) — **без изменений** (знак <0 → Расход уже поддержан в `ЗаполнитьИзНачальнойЗадолженности`).
- Комментарии/текст диалога формы «661/663» → «66».

Отчёт сверки **не меняется** — он уже эталон с В ИЕРАРХИИ 66.
