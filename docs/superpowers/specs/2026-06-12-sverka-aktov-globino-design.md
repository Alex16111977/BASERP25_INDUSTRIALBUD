# Сверка актов списания стройматериалов Глобино: Бухгалтерия ↔ ЕРП

Дата: 2026-06-12. Статус: утверждён пользователем (подход A).

## Задача

Сверить два реестра расшифровки затрат по стройматериалам (объект Глобино):

- **Бухгалтерия**: `_Rarzrabotki/Реестры/Строительные материалы из Бухгалтерии.xlsx`,
  листы «Глобино-2» (счёт 205) и «Глобино-2051» (счёт 2051). Формат — карточка счёта:
  Період | Документ | Аналітика Дт | Аналітика Кт | Дебет(счёт, сумма) | Кредит(счёт, сумма) | сальдо.
- **ЕРП**: `_Rarzrabotki/Реестры/Строительные материалы ЕРП.xlsx`, лист «Лист2»,
  секция «Строительные материалы»: документы «Списание недостач товаров ВН-ІБ00-XXXXXX» + сумма.

Цель: таблица «номер акта → сумма в ЕРП / сумма в Бух / разница / статус», чтобы видеть,
какой акт получен в какой базе и где расходятся суммы.

## Решение (подход A)

Один Python-скрипт `_Rarzrabotki/Python/test/sverka_aktov_globino.py` (openpyxl, только чтение
исходников). Ключ сверки — номер `ІБ00-XXXXXX` с учётом типа:

- ЕРП: только секция «Строительные материалы», номер из `ВН-ІБ00-XXXXXX` (ВН = Вимога-накладна).
  Секция «Себестоимость реализации» (Астарта) — вне задачи, используется лишь для контроля итога листа.
- Бух: акты = типы «Вимога-накладна» и «Списання товарів»; сумма акта = кредитовый оборот
  (списание со счёта 205/2051), агрегация одного номера сквозь оба листа.
  Коллизия номера между разными типами актов — флагуется.
- Прочие типы (Переміщення, Комплектація, Надходження, Авансовий звіт, Закриття місяця)
  в сверку не входят, выводятся отдельным листом для контекста. «Закриття місяця: корректировка
  стоимости списания» показывается отдельно — объясняет мелкие расхождения по актам.

## Результат

`_Rarzrabotki/Реестры/Сверка актов Глобино.xlsx`:

1. **Сверка** — Номер | Дата | Документ ЕРП | Сумма ЕРП | Документ Бух | Бух 205 | Бух 2051 |
   Бух итого | Разница | Статус (`OK` / `Расхождение` / `Только в ЕРП` / `Только в Бух`), итоги.
2. **Бух прочие документы** — свод по (лист, тип, номер): суммы Дт/Кт.
3. **Контроль** — контрольные суммы: итог секции ЕРП против общего итога листа минус реализации;
   обороты Бух-листов = акты + прочие; суммы корректировок закрытия месяца.

Статус `OK` при |разница| < 0.01.

## Проверка

- Встроенные контрольные суммы (см. лист «Контроль») должны сойтись.
- Независимая перепроверка обеих сторон (отдельный пересчёт номеров и сумм) до выдачи результата.

- C: позиционная сверка по номенклатуре — избыточно для вопроса «какой акт получен».
