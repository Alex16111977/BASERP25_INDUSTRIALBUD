# Spec: Кнопка А_ОтражениеЗПпоКазне → N×ВКассу с СтатьёйДДС из шапки

> Дата: 2026-05-27
> Связан со spec: [2026-05-26-vedomost-vkassu-iz-raspredeleniyaf2-design.md](2026-05-26-vedomost-vkassu-iz-raspredeleniyaf2-design.md)
> Реализованная база: hotfix v3 (commit `71b6ee586`) — `СоздатьВедомостьНаВыплатуВКассуПоРаспределениюФ2()` в `Documents/РаспределениеФ2/Ext/ObjectModule.bsl`

---

## 1. Цель

Добавить в форму документа `А_ОтражениеЗПпоКазне` кнопку «Создать ведомости в кассу», которая:
1. Создаёт **по одной `ВедомостьНаВыплатуЗарплатыВКассу` на каждый уникальный `Документ.РаспределениеФ2`** из ТЧ `РаспределениеКазна` (по реквизиту строки `ДокРаспределениеЗП`).
2. **Использует `СтатьяДвиженияДенежныхСредств` из строк ТЧ `РаспределениеКазна`** (не из реквизита сотрудника) при заполнении ТЧ `А_РасшифровкаВыплатыЗарплатаПоФизлицам` ВКассу.
3. В шапку каждой созданной ВКассу записывает `А_ОтражениеЗПпоКазне = Ссылка` (родительский документ).

Свяжет родитель→дочка работает через шапочный реквизит ВКассу (поле уже есть: `ВКассу.А_ОтражениеЗПпоКазне` тип `Документ.А_ОтражениеЗПпоКазне`). Обратная связь не нужна — пользователь находит созданные ВКассу через стандартный механизм «Связанные документы» 1С.

---

## 2. Архитектурное решение — переиспользование

Существующая процедура `СоздатьВедомостьНаВыплатуВКассуПоРаспределениюФ2()` в `Documents/РаспределениеФ2/Ext/ObjectModule.bsl` уже умеет:
- Find-Or-Create по `ВКассу.А_РаспределениеФ2 = Ссылка Ф2`
- Cleanup (распровести → очистить ТЧ)
- Заполнение шапки + ТЧ Состав + ТЧ Зарплата + ТЧ А_Расшифровка
- Запись с проведением (hotfix v3)
- Обратную ссылку в Ф2

**Не дублируем эту логику.** Расширяем её **двумя опциональными параметрами**:

```bsl
Процедура СоздатьВедомостьНаВыплатуВКассуПоРаспределениюФ2(
    СтатьиДДСПоКлючу = Неопределено,
    СсылкаНаОтражениеЗП = Неопределено) Экспорт
```

- `СтатьиДДСПоКлючу` — `Соответствие` с ключом `"Сотр_UID|ПодрОрг_UID"` (строки UUID через `|`) → `Справочник.СтатьиДвиженияДенежныхСредств`. Если передан — используется как источник СтатьиДДС в А_Расшифровке вместо `Сотрудник.СтатьяЗарплата`.
- `СсылкаНаОтражениеЗП` — `Документ.А_ОтражениеЗПпоКазне`. Если передан — `ВыкВКассу.А_ОтражениеЗПпоКазне = СсылкаНаОтражениеЗП` в шапке.

Если оба параметра `Неопределено` — текущая Ф2-кнопка работает без изменений (обратная совместимость).

## 3. Алгоритм новой процедуры — `Documents/А_ОтражениеЗПпоКазне/Ext/ObjectModule.bsl`

Новая область `#Область ЕРП_СоздатьВедомостиВКассу`:

```
Процедура СоздатьВедомостиВКассуПоОтражениюЗП() Экспорт

  // 1. Guard: документ должен быть проведён (статьи и Ф2 должны быть актуальные)
  Если НЕ Проведен Тогда
    Сообщить("ОтражениеЗПпоКазне не проведено — операция отменена.");
    Возврат;
  КонецЕсли;

  // 2. Группировка ТЧ.РаспределениеКазна по ДокРаспределениеЗП
  //    + отбор только строк типа Документ.РаспределениеФ2
  //    + сбор справочника СтатьиДДС по ключу (Сотр_UID|ПодрОрг_UID)
  ГруппыПоФ2 = Новый Соответствие;  // Ф2.Ссылка → Соответствие(КлючСотрПодр → СтатьяДДС)
  ПропускТипов = 0;  // строки с А_РаспределениеЗаработнойПлаты — out of scope

  МасПодр = Новый Массив;  // для построения КешПодрОрг
  Для Каждого СтрРК Из РаспределениеКазна Цикл
    Если НЕ ЗначениеЗаполнено(СтрРК.ДокРаспределениеЗП) Тогда
      Продолжить;
    КонецЕсли;
    Если ТипЗнч(СтрРК.ДокРаспределениеЗП) <> Тип("ДокументСсылка.РаспределениеФ2") Тогда
      ПропускТипов = ПропускТипов + 1;
      Продолжить;
    КонецЕсли;
    Если ЗначениеЗаполнено(СтрРК.Подразделение) И МасПодр.Найти(СтрРК.Подразделение) = Неопределено Тогда
      МасПодр.Добавить(СтрРК.Подразделение);
    КонецЕсли;
  КонецЦикла;

  // Конвертация СтрПредпр → ПодрОрг (вызываем А_Привилегированный напрямую,
  // т.к. _ВЫК_ПостроитьКешПодрОрг в Ф2.ObjectModule неэкспортная)
  КешПодрОрг = Новый Соответствие;
  Для Каждого СтрПредпр Из МасПодр Цикл
    Попытка
      ПодрОрг = А_Привилегированный.ОбеспечитьПодразделенияОрганизацийПоПодразделению(СтрПредпр);
    Исключение
      ПодрОрг = Справочники.ПодразделенияОрганизаций.ПустаяСсылка();
    КонецПопытки;
    КешПодрОрг.Вставить(СтрПредпр, ПодрОрг);
  КонецЦикла;

  Для Каждого СтрРК Из РаспределениеКазна Цикл
    Если НЕ ЗначениеЗаполнено(СтрРК.ДокРаспределениеЗП) Тогда Продолжить КонецЕсли;
    Если ТипЗнч(СтрРК.ДокРаспределениеЗП) <> Тип("ДокументСсылка.РаспределениеФ2") Тогда Продолжить КонецЕсли;

    Ф2Ссылка = СтрРК.ДокРаспределениеЗП;
    ПодрОрг = ?(ЗначениеЗаполнено(СтрРК.Подразделение), КешПодрОрг[СтрРК.Подразделение],
                Справочники.ПодразделенияОрганизаций.ПустаяСсылка());
    Ключ = ?(ЗначениеЗаполнено(СтрРК.Сотрудник), Строка(СтрРК.Сотрудник.УникальныйИдентификатор()), "")
         + "|"
         + ?(ЗначениеЗаполнено(ПодрОрг), Строка(ПодрОрг.УникальныйИдентификатор()), "");

    Если ГруппыПоФ2.Получить(Ф2Ссылка) = Неопределено Тогда
      ГруппыПоФ2.Вставить(Ф2Ссылка, Новый Соответствие);
    КонецЕсли;
    ГруппыПоФ2[Ф2Ссылка].Вставить(Ключ, СтрРК.СтатьяДвиженияДенежныхСредств);
  КонецЦикла;

  // 3. Для каждой группы — вызвать процедуру создания ВКассу
  КолСоздано = 0;
  КолОшибок  = 0;
  Для Каждого КЗ Из ГруппыПоФ2 Цикл
    Ф2Ссылка = КЗ.Ключ;
    СловарьСтатей = КЗ.Значение;

    Ф2Объект = Ф2Ссылка.ПолучитьОбъект();
    Если Ф2Объект = Неопределено ИЛИ НЕ Ф2Объект.Проведен Тогда
      Сообщить("Ф2 " + Строка(Ф2Ссылка) + " не проведён — пропуск.");
      КолОшибок = КолОшибок + 1;
      Продолжить;
    КонецЕсли;
    Попытка
      Ф2Объект.СоздатьВедомостьНаВыплатуВКассуПоРаспределениюФ2(СловарьСтатей, Ссылка);
      КолСоздано = КолСоздано + 1;
    Исключение
      Сообщить("Ошибка создания ВКассу для " + Строка(Ф2Ссылка) + ": " + ОписаниеОшибки());
      КолОшибок = КолОшибок + 1;
    КонецПопытки;
  КонецЦикла;

  Сообщить("ОтражениеЗПпоКазне → ВКассу: создано/обновлено " + КолСоздано
    + ", ошибок " + КолОшибок + ?(ПропускТипов > 0,
    ", пропущено А_РаспределениеЗаработнойПлаты строк " + ПропускТипов, "") + ".");

КонецПроцедуры
```

> Псевдокод выше — для документации. Окончательная реализация выйдет в плане. Главное — структура и интерфейс.

## 4. Изменения в существующей Ф2-процедуре

Файл `Documents/РаспределениеФ2/Ext/ObjectModule.bsl`. Минимальные точечные правки:

### 4.1 Сигнатура

Было:
```bsl
Процедура СоздатьВедомостьНаВыплатуВКассуПоРаспределениюФ2() Экспорт
```

Стало:
```bsl
Процедура СоздатьВедомостьНаВыплатуВКассуПоРаспределениюФ2(
    СтатьиДДСПоКлючу = Неопределено,
    СсылкаНаОтражениеЗП = Неопределено) Экспорт
```

### 4.2 Шаг 4 (шапка)

Перед концом блока шапки добавить:
```bsl
Если СсылкаНаОтражениеЗП <> Неопределено Тогда
    ВыкВКассу.А_ОтражениеЗПпоКазне = СсылкаНаОтражениеЗП;
КонецЕсли;
```

### 4.3 Шаг 8 (заполнение А_Расшифровки) — СтатьяДДС

Было (псевдо):
```bsl
СтатьяДДС = СтрР.Сотрудник.СтатьяЗарплата;
Если НЕ ЗначениеЗаполнено(СтатьяДДС) Тогда
    Попытка СтатьяДДС = СтрР.Сотрудник.Родитель.СтатьяЗарплата;
    Исключение СтатьяДДС = ...ПустаяСсылка();
    КонецПопытки;
КонецЕсли;
```

Стало:
```bsl
Если СтатьиДДСПоКлючу <> Неопределено Тогда
    Ключ = ?(ЗначениеЗаполнено(СтрР.Сотрудник),
            Строка(СтрР.Сотрудник.УникальныйИдентификатор()), "")
         + "|"
         + ?(ЗначениеЗаполнено(ПодрОрг),
            Строка(ПодрОрг.УникальныйИдентификатор()), "");
    СтатьяДДС = СтатьиДДСПоКлючу.Получить(Ключ);
    Если СтатьяДДС = Неопределено ИЛИ НЕ ЗначениеЗаполнено(СтатьяДДС) Тогда
        СтатьяДДС = Справочники.СтатьиДвиженияДенежныхСредств.ПустаяСсылка();
        Сообщить("WARN: статья ДДС не найдена в ОтражениеЗПпоКазне для "
          + Строка(СтрР.Сотрудник) + " / " + Строка(ПодрОрг));
    КонецЕсли;
Иначе
    // ─ существующее поведение (Сотр.СтатьяЗарплата + Родитель fallback) ─
    СтатьяДДС = СтрР.Сотрудник.СтатьяЗарплата;
    Если НЕ ЗначениеЗаполнено(СтатьяДДС) Тогда
        Попытка
            СтатьяДДС = СтрР.Сотрудник.Родитель.СтатьяЗарплата;
        Исключение
            СтатьяДДС = Справочники.СтатьиДвиженияДенежныхСредств.ПустаяСсылка();
        КонецПопытки;
    КонецЕсли;
КонецЕсли;
```

### 4.4 Обратная совместимость

Все вызовы без параметров (старая Ф2-кнопка, ручной вызов) → ветка `Иначе` → старое поведение.

## 7. Out-of-scope

- Документы `А_РаспределениеЗаработнойПлаты` (безналичная выплата) — отдельная задача (ВКассу из ОтражениеЗПпоКазне делает только наличные через РаспределениеФ2).
- Автотриггер `ПриЗаписи` для `А_ОтражениеЗПпоКазне` — НЕ делаем (пользователь намеренно закомментировал автотриггер в Ф2 — кнопочная модель преферентна).
- Обратная связь ОтражениеЗПпоКазне → ВКассу (ТЧ или реквизит) — НЕ делаем, пользователь находит через «Связанные документы» 1С.
- Изменение логики Состав↔Зарплата ИдентификаторСтроки (hotfix v3) — не трогаем, работает корректно.

## 8. Acceptance критерии

- ✅ В форме `А_ОтражениеЗПпоКазне` появилась кнопка «Создать ведомости в кассу».
- ✅ По нажатию: создаётся N ВКассу, по одной на каждый уникальный Ф2 из ТЧ.РаспределениеКазна.
- ✅ Каждая ВКассу проведена, ТЧ Зарплата и А_Расшифровка заполнены.
- ✅ В А_Расшифровке `СтатьяДвиженияДенежныхСредств` берётся из ТЧ.РаспределениеКазна (а не из Сотрудник.СтатьяЗарплата).
- ✅ В шапке ВКассу заполнены `А_РаспределениеФ2` и `А_ОтражениеЗПпоКазне`.
- ✅ Идемпотентность: повторный вызов кнопки обновляет существующие ВКассу (Find-Or-Create по А_РаспределениеФ2), UUID не меняются.
- ✅ Старая Ф2-кнопка (без параметров) работает как раньше — регрессия отсутствует (smoke/idempotency/rashifrovka Ф2 продолжают PASS).
- ✅ Пользователь видит созданные ВКассу через «Связанные документы» 1С.

## 9. Эталонный документ для тестов

`А_ОтражениеЗПпоКазне №000000006 от 30.11.2025` (с скриншота) — связан с ВКассу `000Ц-000002 от 10.12.2025` через реквизит `А_ОтражениеЗПпоКазне`.

Структура (предположительно — preflight подтвердит):
- ТЧ.РаспределениеКазна: содержит строки с `ДокРаспределениеЗП = РаспределениеФ2 №000000026`
- Возможно содержит ещё Ф2-документы → N ВКассу будет создано
