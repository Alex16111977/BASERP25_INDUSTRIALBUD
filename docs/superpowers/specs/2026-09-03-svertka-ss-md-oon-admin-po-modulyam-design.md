# Спека: свёртка ТЧ Комплектующие СС «МД ООН Админ» по модулям (BuhBud)

Дата: 2026-09-03. Решения пользователя: свёртка — да; «По модульно» — оставить в оригинале (без исправления единиц).

## Задача (роль: бухгалтер)

В `Справочник.СтруктураСебестоимости` «МД ООН Админ» (bas_industrialbud):
- закладка **«Комплектуючі»** (ТЧ `Комплектующие`) = свод по модулям: одна строка на материал, Количество и Сумма — итог по модулям 1 и 3;
- поля `ЕдиницаСС_Оригинал` / `КоличествоСС_Оригинал` свода = то, что было в Excel (единица — в написании, к которому 1С привела при загрузке: «шт.»→«шт», «м²»→«м2», «м.»→«м»; количество — сумма исходных по модулям);
- закладка **«По модульно»** (ТЧ `КомплектующиеПоМодульно`, 325 строк, оригинал по модулям) содержательно НЕ меняется; только написание «м.»→«м» (13 строк) в `ЕдиницаСС`/`ЕдиницаСС_Оригинал` с пересчётом флага «Не совпадает» по правилу справочника;
- **Σ Сумма обеих закладок = 1 634 453.54** (неизменна).

## Факты (живая база, 2026-09-03)

- Основная ТЧ: 325 строк (исправленные единицы у 98 строк), Σ 1 634 453.54, НеСовпадает 4. «По модульно»: 325 строк (188 модуль 1 + 137 модуль 3), те же суммы.
- Ключ свёртки **Этап + ОбщееНазвание + НоменклатураСС (норм., без регистра) + ЕдиницаСС** → **216 групп**; более слабые ключи дают те же 216 — ключ однозначен. 108 групп из одной строки; 6 групп содержат дубли внутри одного модуля (Excel так составлен) — сворачиваются тоже; 12 групп с разной ценой в модулях → цена свода = Σ Сумма / Σ Количество.
- Исходные единицы (бэкап «ДО 2026-09-03»): 9 групп различаются только «м.»/«м» (канонизируется); **1 коллизия** — «Утеплювач базальтовий IZOVAT 100; стіни»: S1 7.733 м3, S3 66.6 м2 → `ЕдиницаСС_Оригинал` = «м3/м2», `КоличествоСС_Оригинал` = 0, предупреждение в протокол.
- `ПередЗаписью` справочника при записи пересчитывает у основной ТЧ ЕдиницаОбщееНазвание (из карточки), Цену и флаг НеСовпадает; ТЧ «По модульно» и поля `_Оригинал` не трогает.

## Правила свёртки (строка свода из группы строк основной ТЧ)

Порядок групп — по первому появлению. Ссылочные поля (Этап, ОбщееНазвание, Номенклатура, Единица, ЕдиницаОбщееНазвание), НоменклатураСС, ЕдиницаСС — из первой строки группы (внутри группы одинаковы по ключу). `Количество` = Σ (3 знака), `Сумма` = Σ (2 знака), `Цена` = Окр(Σ Сумма / Σ Количество, 2) (0 при нулевом количестве). `ЕдиницаСС_Оригинал` = единая исходная единица группы (канон) либо «u1/u2»; `КоличествоСС_Оригинал` = Σ исходных количеств при единой единице, иначе 0. `НеСовпадает` — пересчитает ПередЗаписью (ожидание вычисляется заранее по его правилу).

## Страховка и контроль

Бэкап обеих ТЧ «до» → `Единиці изммерения/Бекап МД ООН Админ ДО свёртки 2026-09-03.xlsx` (2 листа). Сухой прогон без записи; запись в COM-транзакции; после записи запросами: основная ТЧ 216 строк, Σ = 1 634 453.54; Σ «По модульно» = та же; погрупповая сверка (запрос с группировкой по ключу) с ожиданием Python по каждой группе (Кол/Сумма); флаги = ожиданию; «По модульно» — 325 строк, суммы по модулям без изменений. Любое расхождение → Rollback + exit 1.
