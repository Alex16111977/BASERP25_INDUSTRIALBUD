# Спека: исправление количеств/единиц в СС «МД ООН Админ» (BuhBud)

Дата: 2026-09-03. Повтор правки [2026-08-28 в BaseERP](2026-08-28-fix-edinicy-md-oon-admin-design.md) — той же СС в базе **bas_industrialbud** (`Справочник.СтруктураСебестоимости`, без префикса А_). Дизайн одобрен пользователем для ERP; мандат: «эту правку сделать в bas_industrialbud».

## Источник

`_Rarzrabotki/Загрузка СС/СС ООН АДМИН/Копия Список не співпадають одиниці.xlsx` (TDSheet, тот же формат: A=N, D=Номенклатура СС, H=«Кількість заг», I=Сумма). 98 строк с H, 2 без H (N=18, 203 «Заглушка ліва + права» — не трогать).

## Проверенные факты (2026-09-03, живая BuhBud)

- СС «МД ООН Админ»: 325 строк ТЧ Комплектующие, Σ Сумма 1 634 453.54, `НеСовпадает` = Истина у **102** строк (98 из файла + 2 «Заглушки» + 2 прочие).
- Сверка файл↔база по N + наименование + сумма: 98/98, 0 расхождений; у всех 98 строк `ЕдиницаОбщееНазвание` заполнена (напр. «м3»).
- Квалификатор Количество ТЧ Комплектующие BuhBud = **3 знака** — пересчитанные 0.045/0.216/0.103 и т.п. (10 строк) сохраняются точно, округления в цену НЕ требуется (отличие от ERP, где 2 знака).

## Правка (98 строк; уточнено по факту первого прогона)

Ключ `НомерСтроки=N` + контроль наименования (норм.) и суммы (0.01); расхождение = откат. По строке: `Количество` ← Окр(H,3); `Цена` ← Окр(Сумма/Количество, 2); `ЕдиницаСС` ← представление единицы **КАРТОЧКИ** общего названия `ОбщееНазвание.Единица` (через COM `buh.String()`, НЕ `str()`); `Единица` ← единица карточки при расхождении. Сумма строк неизменна.

**Критично (поймано контролем-с-откатом на первом прогоне):** `ПередЗаписью` справочника в BuhBud при КАЖДОЙ записи сам переустанавливает `ЕдиницаОбщееНазвание` из карточки, пересчитывает `Цена = Сумма/Количество` и `НеСовпадает = (представление единицы карточки <> ЕдиницаСС)` НА ВСЕХ строках. Поэтому: единицу брать из карточки (не из устаревшего поля строки ТЧ — 5 строк расходились), флаг вручную не выставлять, а ожидание числа флагов «после» вычислять по правилу ПередЗаписью на всех 325 строках до записи.

## Страховка и контроль

Бэкап всех 325 строк «до» → `Единиці изммерения/Бекап МД ООН Админ Комплектующие BuhBud ДО 2026-09-03.xlsx`. Пред-контроль: 325/1 634 453.54/НеСовпадает 102/правок 98. COM-транзакция; после записи запрос-сверка: строк 325, Σ прежняя, по правленым строкам Кол/Цена/ЕдиницаСС, НеСовпадает = вычисленному ожиданию. Любое расхождение → Rollback + exit 1.

## Факт выполнения (2026-09-03)

`FIX OK: обновлено 98, Σ Сумма 1 634 453.54 → 1 634 453.54, НеСовпадает 102 → 4` (остались N=18, 203 — «Заглушки» без единицы карточки, и N=59, 246 — вне файла). Количества с 3-м знаком (0.045/0.216/0.077/0.103/0.025) сохранены точно — квалификатор BuhBud 3 знака.
