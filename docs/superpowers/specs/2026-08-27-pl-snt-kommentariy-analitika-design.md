# Отчёт А_ОтчетPL_ПолныйЕРП: аналитика СписанияНедостачТоваров = Комментарий документа

Дата: 2026-08-27. Утверждено пользователем (вместе с загрузкой в конфигурацию).

## Проблема

У строк `ПрочиеРасходы` от `Документ.СписаниеНедостачТоваров` аналитика пуста — ветки
в CASE поля «Аналитика» нет вовсе (ИНАЧЕ NULL). Замер: июль-2026 — 174 документа
на 17,3 млн, из них 83 с комментарием («МД Вооз ЕМS Мала 2026», «Кривий Ріг
(сепараторна-8м) Акт №607/1…»).

## Решение (копия утверждённого паттерна РКО из v9, но проще)

В CASE поля «Аналитика» `втЕРП_Расх_Детали` (ВЫБРАТЬ + копия в СГРУППИРОВАТЬ ПО, сразу
после ветки РКО) добавляется ветка:

    КОГДА Р.Регистратор ССЫЛКА Документ.СписаниеНедостачТоваров
        ТОГДА ВЫРАЗИТЬ(ВЫРАЗИТЬ(… КАК Документ.СписаниеНедостачТоваров).Комментарий КАК Строка(200))

Условия по операции нет; пустой комментарий даёт пустую строку — поведение как сейчас.
CASE поля «Контрагент» не трогается. Запрос — `v10_full.sql`, суммы не меняются.

## Проверки

- RED (`test_otchetpl_v10_snt_analitika_2026-08-27.py`): v10 == v9 построчно по ключу
  без аналитики; строковая аналитика только у РКО и СписанияНедостач; все июльские пары
  (документ, комментарий) на месте (сверка прямым запросом).
- Регрессия: `acceptance_russkie_nazvaniya` (28) + `acceptance_rko_analitika` (3) +
  сверка док-код (перенацелить на v10).
