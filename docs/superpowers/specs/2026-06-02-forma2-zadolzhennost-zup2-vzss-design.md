## 📋 Бизнес-цель

Обработка `_Rarzrabotki/Обработки/А_НачальнаяЗадолженностьПоЗарплатеФорма2` (сейчас — копия 661/663-обработки, грузит из BuhBud) переписывается под загрузку **управленческих (Форма2) начальных остатков зарплаты из базы zup_2**.

В zup_2 остаток «Общий» = **Форма1 + Форма2** (полное управленческое обязательство перед ФЛ). Из документа-источника `ДокНачальнаяЗадолженностьПоЗарплатеБух` берётся **Форма1**, и вычисляется **Форма2 = Общий − Форма1**. Создаётся (перезаписывается) документ из реквизита `ДокНачальнаяЗадолженностьПоЗарплатеФорма2` **только управленческим остатком** (ФормаPL=Форма2).

**Инвариант (бухгалтерская сверка):** `Форма1 + Форма2 = Общий` per ФизЛице. Подтверждается отчётом «Взаиморасчёты с сотрудниками для баланса».

> **⚠️ ПОПРАВКА 2026-06-02 (подтверждено пользователем + verify PASS):** «Общий» — НЕ голое сальдо
> `ВзаиморасчетыСРаботниками.Остатки(КонецДня)` (оно даёт ВСЁ накопленное управленческое сальдо: Буша −35153, а не −93).
> **Правильная формула:** `Общий = Остатки(КонецДня(ДатаОстатков)).СуммаУпрОстаток + Σ(Начисления.Результат − Удержания.Результат_ВСЕ) за месяц(ДатаОстатков)` из `Документ.НачислениеЗарплатыРаботникам` (zup_2; источник чтения как в `А_ОтражениеЗПпоКазне`). Смысл: управленческое сальдо МИНУС свежее начисление месяца = начальная (перенесённая) задолженность. Эталон Буша: −35153 + (52000 − 16940) = **−93,00**. Источник истины — `Ext/ObjectModule.bsl::ПрочитатьОбщийИзZup2`. Таблица «Заземление» ниже сохранена как было (значение −93 верно, способ его получения — исправлен выше).

### Фаза 1 — `ЗагрузитьИзZup2()` (переписать `ЗагрузитьИзBuhBud`)
1. Проверка `ДатаОстатков`. Дата-первой-кассы `Д0 = ДатаОстатков + 1 день`.
2. **COM zup_2** → запрос примитивов:
```
ВЫБРАТЬ
    О.Физлицо.КодПоДРФО КАК ДРФО, О.Физлицо.Наименование КАК ИмяФЛ,
    СУММА(О.СуммаУпрОстаток) КАК Общий
ИЗ РегистрНакопления.ВзаиморасчетыСРаботниками.Остатки(&Дата, ) КАК О
СГРУППИРОВАТЬ ПО О.Физлицо.КодПоДРФО, О.Физлицо.Наименование
ИМЕЮЩИЕ СУММА(О.СуммаУпрОстаток) <> 0
```
`&Дата = КонецДня(ДатаОстатков)`. Закрыть COM, перенести ТЗ примитивов.
3. Для каждого ФЛ (ERP-контекст):
   - `ФизическоеЛицо` = `НайтиПоРеквизиту("КодПоДРФО", ДРФО)` (иначе Статус="Нет ФЛ");
   - `Сотрудник` = первый по `ФизическоеЛицо` (приоритет ГоловнаяОрганизация=упр.орг);
   - **Форма1** = запрос Σ строк `ДокНачальнаяЗадолженностьПоЗарплатеБух.ЗадолженностьПоЗарплате` где `Сотрудник.ФизическоеЛицо=ФЛ` И (`ФормаPL=Форма1` ИЛИ ФормаPL пусто);
   - **Сумма (Форма2) = Общий − Форма1**; если =0 → пропустить (не в превью или Статус);
   - **Подразделение**: `НайтиПодразделениеПоПервойКассе(ФЛ, Д0)` (см. ниже); fallback корень «Строительство»; затем реверс ПодрОрг;
   - `ГруппаУчетаНачислений` = из строки источника Форма1 (если ФЛ там есть), иначе `Справочники.ГруппыУчетаНачисленийИУдержаний.НайтиПоНаименованию("Зарплата (661)")`;
   - `Организация`=упр.орг (информационно — шапку дока не трогаем); **`ОрганизацияБухгалтерия` = ПУСТО** (Форма2 — управленческая; бух.орг заполняется только у Форма1, в эталоне 000Ц-000002 пусто);
   - Статус="OK".

**`НайтиПодразделениеПоПервойКассе(ФЛ, Д0)`** (вернуть КОРНЕВОЙ СтрПредпр):
```
ВЫБРАТЬ ПЕРВЫЕ 1 Рш.Подразделение КАК Подр
ИЗ Документ.ВедомостьНаВыплатуЗарплатыВКассу.А_РасшифровкаВыплатыЗарплатаПоФизлицам КАК Рш
    ВНУТРЕННЕЕ СОЕДИНЕНИЕ Документ.ВедомостьНаВыплатуЗарплатыВКассу КАК Вед ПО Вед.Ссылка = Рш.Ссылка
ГДЕ Рш.ФизическоеЛицо = &ФЛ И Вед.Дата >= &Д0 И Вед.Проведен
УПОРЯДОЧИТЬ ПО Вед.Дата
```
→ Подр(ПодрОрг).А_Подразделение → подъём по Родитель до корня; если ничего → корень «Строительство». Реверс: ПодрОрг где Владелец=упр.орг И `.А_Подразделение`=корень.
