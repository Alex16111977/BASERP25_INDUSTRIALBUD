## 1. Цель (бухгалтер)

По каждой карточке «Общего названия» видеть рядом ПЛАН (строки СС: в каких единицах
планировалось) и ФАКТ (приходные накладные: в каких единицах реально закупалось,
суммы С НДС — сопоставимо с СС), с расшифровкой до документов поступления и до самой
структуры себестоимости — чтобы выбрать правильную `ОбщиеНазванияНоменклатуры.Единица`.

## 2. СКД — один набор, пакетный запрос (протестирован 1:1 на живой BuhBud:
план 952 строки / Σ 10 842 173,71; факт 27 955 строк / Σ 302 545 499,52)

- ВТ `АктивныеОН`: РАЗЛИЧНЫЕ ОбщееНазвание из ТЧ Комплектующие структур с
  `Активная И НЕ ПометкаУдаления` (фильтр «только активные» жёстко в запросе;
  факт показывается только по карточкам, используемым в активных СС).
- ОБЪЕДИНИТЬ ВСЕ:
  - **«План СС»**: ТЧ Комплектующие активных структур — ВидСтроки, ОбщееНазвание,
    ЕдиницаОбщая = `К.ОбщееНазвание.Единица`, Номенклатура, Единица (ТЧ), ЕдиницаСС,
    Этап, НоменклатураСС, Документ = `К.Ссылка` (Структура — расшифровка до СС),
    КоличествоПлан, СуммаПлан; факт-поля NULL.
  - **«Факт закупки»**: `Документ.ПоступлениеТоваровУслуг.Товары`, `Ссылка.Проведен`,
    `Номенклатура.ОбщееНазваниеНоменклатуры В (ВТ)` — ОбщееНазвание из привязки,
    Единица = `Т.ЕдиницаИзмерения` (фактическая единица строки поступления!),
    Документ = `Т.Ссылка` (расшифровка до накладной), КоличествоФакт,
    **СуммаФакт = `ВЫБОР КОГДА Т.Ссылка.СуммаВключаетНДС ТОГДА Т.Сумма
    ИНАЧЕ Т.Сумма + Т.СуммаНДС КОНЕЦ`** (НДС-синхронизация с СС-суммами; оба
    случая в базе: 35777 док. без включённого НДС, 12670 с включённым);
    план-поля NULL. Точный текст запроса — в
    `scratchpad\test_zakupki_query.py` контроллера, НЕ менять ни символа.

## 3. Ресурсы и вариант

- Ресурсы: КоличествоПлан, СуммаПлан, КоличествоФакт, СуммаФакт — Σ. Формат сумм ЧЦ=15; ЧДЦ=2.
- Вариант «Основной»: группировки **ОбщееНазвание → Номенклатура → детальные записи**;
  в выбранных полях группировки ОбщееНазвание добавить **ЕдиницаОбщая** (вывод «единица
  общий»); детали: ВидСтроки, Этап, НоменклатураСС, Единица, ЕдиницаСС, Документ,
  4 ресурса. Сортировка деталей: ВидСтроки УБЫВ («План СС» раньше «Факт закупки»).
- Роли полей/отборы доступные: ОбщееНазвание, Номенклатура, Этап, ВидСтроки, Документ.
