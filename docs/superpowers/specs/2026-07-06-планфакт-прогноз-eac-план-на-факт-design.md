## «План на факт / Прогноз» — модель (EAC / cost-control forecast)

Финансовый смысл: **EAC = AC + (BAC − EV)** — прогноз = фактические затраты + остаток бюджета,
когда остаток ожидается по плану. «План на факт» = ETC (estimate-to-complete).

Только по материалам (блок «2. Матеріали»). Праця без изменений.

### Формулы (на уровне «Загальна назва» = ОбщееНазвание)
- `ПланЦена = ПланГрн / ПланКол` (средняя плановая цена по общей назве)
- `Залишок = max(0, ПланКол − ФактКол)`
- **`ПланНаФактГрн = Залишок × ПланЦена`** (ETC)
- **`ПрогнозГрн = Σ(ФактГрн) + Σ(ПланНаФактГрн)`** (EAC)
- **`ОтклонениеПрогнозГрн = ПрогнозГрн − Σ(ПланГрн)`** (+ = перевитрата)
- **`ПроцентПрогнозГрн = ПрогнозГрн / Σ(ПланГрн) × 100`** (>100% = перерасход)

Overrun (ФактКол>ПланКол) → Залишок=0 → ПланНаФакт=0 → Прогноз=Факт.

### Валидация COM (тест-СС ОРІЛЬ)
План 1 918 598 / Факт 1 617 249 / ПланНаФакт 625 675 / Прогноз 2 242 924 / Виконання 116.9%.

## Реализация

**Ресурс `ПланНаФактГрн`** — единственный хранимый; Прогноз/Відхилення/% — totalField-выражения.

**BSL (`ПолучитьДанные`):**
- Грейн ВТ_Детали: +колонка `ПланНаФактГрн` (0 во всех 5 ветках).
- Финальный SELECT: `СУММА(ПланНаФактГрн)`; `ПрогнозГрн = СУММА(ФактГрн)+СУММА(ПланНаФактГрн)`;
  `ОтклонениеПрогнозГрн = …−СУММА(ПланГрн)`; `ПроцентПрогнозГрн = ВЫБОР … КОНЕЦ`.
- `СоздатьПустуюТаблицу`: +4 колонки.
- **Новая постобработка `ЗаполнитьПланНаФакт(ТЗ, СС)`** (после `ЗаполнитьЭтапФактМатериалов`):
  агрегирует материалы по `(Подразделение, Категория, Этап, ОбщееНазвание)` → нетто ПланКол/ФактКол/ПланГрн;
  считает ETC; **вставляет синтетическую строку «залишок плану»** на уровень ОбщееНазвание
  (Аналитика/Единица/Документ пусты) с `ПланНаФактГрн` (и `ПрогнозГрн=ПланНаФакт`). Только если ETC>0.

**Template.xml:** +4 поля (decimal, ресурсы); +4 totalField; +selection (после грн-блока);
`ПроцентПрогнозГрн` в условное оформление ЧДЦ=1. Ресурсы рендерятся колонками (не dimension-питфол).

**Допущение:** нетто ПланКол−ФактКол корректно при единой единице «Загальна назва»
(`Номенклатура.ЕдиницаИзмерения`).
