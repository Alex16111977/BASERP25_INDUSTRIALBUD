# Дизайн: master‑промт «Изучить типовую конфигурацию BAS ERP 2.5 → создать набор скилов по созданию объектов в типовом стиле»

- **Дата:** 2026-05-30
- **Статус:** утверждён (v2)
- **Артефакт‑результат:** `_Rarzrabotki/prompts/master_prompt_typovye_skills.md`

---

## 1. Цель

Получить **переиспользуемый master‑промт (текст)**, который в свежей сессии ИИ:
1. изучает **только типовые** (без префикса `А_`) объекты конфигурации `C:\Configuration_downloads\BASERP25`;
2. извлекает их конвенции (стиль форм, общие процедуры, движения, проведение, стандартные реквизиты);
3. генерирует набор скилов в `.claude/skills/`, по которым ИИ создаёт новые объекты, отвечающие требованиям конфигурации «как другие документы»;
4. проверяет результат (Python COM + `*-validate` + BSL review + свежий агент).

## 2. Зафиксированные решения

| # | Вопрос | Решение |
|---|--------|---------|
| Q1 | Что значит «создавать документ» | **Полный жизненный цикл**: от нового объекта‑документа до программного заполнения/проведения |
| Q2 | Форма результата | **Master‑промт (текст)**, который пользователь вставляет в новую сессию |
| Q3 | Что изучать | **Только типовые** объекты (без `А_`); кастомные `А_*` как эталон НЕ используются |
| Q4 | Охват | **Документы + справочники + регистры** |
| Q5 | Имя новых объектов | Структура/вид копируют типовой стиль, **имя получает проект‑префикс `А_`** (жёсткое правило `CLAUDE.md`) |

## 3. Структура master‑промта (7 блоков)

0. **Роль и контекст** — рабочий каталог, цель, доступные инструменты (MCP `1c-workerp`, cc‑1c‑skills, Python COM).
1. **Жёсткие правила** — Rule #‑1 (тест запросов в Python COM до BSL); изучать только типовое; не выдумывать поля; копировать конвенции, не изобретать.
2. **Фаза 0 — Изучение (обязательна до генерации)** — эталоны по типам + как изучать + база знаний + кирпичи‑скилы.
3. **Фаза 1 — Зафиксировать конвенции** — reference‑чек‑листы (именование, синонимы, стандартные реквизиты, состав формы, общие модули, движения, проведение).
4. **Фаза 2 — Сгенерировать скилы** — целевой набор (см. §4).
5. **Контракт формата скилов** — frontmatter `name`+`description`; `description` = «Используй когда…» (триггеры, без пересказа workflow, достаточно «pushy»); тело <500 строк; progressive disclosure (детали в `reference/*.md`, один уровень); язык русский; привязка к реальным эталонам.
6. **Фаза 3 — Верификация** — Rule #‑1; `meta-validate`/`form-validate`; `1c-bsl-review`; прогон свежим агентом по тест‑заданию; цикл правок.
7. **Anti‑patterns / Red flags** — что НЕ делать.

## 4. Целевой набор скилов (создаёт промт)

| Скил | Тип | Роль |
|------|-----|------|
| `bas-house-style` | reference | Как устроены типовые объекты: стиль форм, общие процедуры, движения, проведение |
| `bas-doc-new` | technique | Новый Документ в типовом стиле: метаданные + ТЧ + форма + модули |
| `bas-catalog-new` | technique | Новый Справочник в типовом стиле |
| `bas-register-new` | technique | Новый регистр (накопления/сведений) + привязка движений документа |
| `bas-doc-fill` | technique | Программное создание записей типовых документов (обяз. поля, `Курс/Кратность`, взаиморасчёты) |
| `bas-verify` | technique | Гейт проверки (Python COM + `meta-validate`/`form-validate` + `1c-bsl-review`) |

> Число/группировку скилов промт может уточнить после изучения (например, объединить `*-new`), но по умолчанию — этот набор.

## 5. Эталоны для изучения (только типовое)

- **Документы:** `ПриобретениеТоваровУслуг`, `РеализацияТоваровУслуг`, `ПоступлениеТоваровУслуг`, `ПеремещениеТоваров`.
- **Справочники:** `Номенклатура`, `Контрагенты`, `ДоговорыКонтрагентов`, `Склады`.
- **Регистры:** `ТоварыНаСкладах` (накопления), `ЦеныНоменклатуры` (сведений) + движения изучаемых документов.

## 6. Критерии приёмки

- [ ] Скилы из §4 созданы в `.claude/skills/`, проходят `meta-validate`/`form-validate` (где применимо).
- [ ] Каждый `description` написан как триггер («Используй когда…»), без пересказа процесса.
- [ ] Тело каждого `SKILL.md` < 500 строк, тяжёлые детали — в `reference/`.
- [ ] **Тест свежим агентом:** агент без контекста по скилу создаёт новый документ в типовом стиле без дополнительных подсказок.
- [ ] Все запросы 1С в скилах прошли Python COM (Rule #‑1).
