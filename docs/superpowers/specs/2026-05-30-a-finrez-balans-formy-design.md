## 3. ЖЁСТКОЕ ПРАВИЛО (вносится в скил + гейт)

**Каждая форма документа ОБЯЗАНА** содержать 3 команды формы и их кнопки командной панели:

| Команда формы (`<Command>`) | Action | Picture (StdPicture) | Shortcut | Кнопка (`<Button>`): Representation |
|---|---|---|---|---|
| `ПровестиИЗакрыть` | ПровестиИЗакрыть | WriteAndClose | — | **Text + DefaultButton=true** (красивая) |
| `ЗаписатьДокумент` | ЗаписатьДокумент | Write | **Ctrl+S** | Picture (иконка) |
| `ПровестиДокумент` | ПровестиДокумент | Post | — | Picture (иконка) |

Плюс `УстановитьПометкуУдаленияДокумента` (Picture MarkToDelete, кнопка `LocationInCommandBar=InAdditionalSubmenu`),
`<CommandSet>` исключает `Post`/`PostAndClose`/`SetDeletionMark`/`Write`, `Autofill=false`. **Это не autofill и
не опция** — обязательно для НОВОЙ и СТАРОЙ формы. Полный вербатим — `bas-bsp-form/reference/document-contract.md §1.1`.

## 4. Фаза 1 — `А_ФинРез_Баланс`: создать обе формы (эталон `АмортизацияОС`)

- **1.1** Зарегистрировать `ФормаДокумента` + `ФормаСписка` в метаданных документа + заполнить
  `DefaultObjectForm`/`DefaultListForm`.
- **1.2 ФормаДокумента** (Уровень 1, §3): `CommandSet` + 3 команды + кнопки (красивая «Провести и закрыть»,
  иконки Записать/Провести, Пометка в «Ещё») + подменю `СоздатьНаОсновании`/`Печать`/`Отчёты`/`Заполнить` +
  `ФормаГруппаКомандыФормы` + `ФормаСправка`; шапка без зазора (группы `Representation=None`+`ShowTitle=false`,
  поля `Объект.Number`/`Объект.Date` + Организация/ВключатьДочерние/Ответственный/Комментарий); модуль —
  `ПодключаемыеКоманды.ПриСозданииНаСервере` + 4 обработчика `Подключаемый_*` (источник `Объект`).
- **1.3 ФормаСписка** (адаптировать рабочую `А_ПередачаНачислений` ФормаСписка): `CommandSet`(26) +
  форменная панель `Autofill=false` + панель **таблицы**-списка (Autofill по умолчанию) с подменю
  `СоздатьНаОсновании`/`Отчёты` + `ГруппаГлобальныеКоманды`→`ПодменюПечать` + `ГруппаКомандыФормы`;
  реквизит `Список` + колонки (Организация, Месяц, Ответственный, Комментарий); модуль — `ПодключаемыеКоманды`
  + обработчики (источник `Элементы.Список`) → «Движения документа»/«Связанные документы».
- **1.4** Проверка (см. §8).
