## 1. Контрольные записи (блокирующие)

Движок `ЗагрузитьМатериалыИзМассива` при заполнении ТЧ копит «Excel-итоги»:
- СтрокЭ (=Загружено), ΣКоличество (по строкам `Окр(Количество, 3)` — квалификатор ТЧ
  Число(15,3)), ΣСумма (по строкам `Окр(Сумма, 2)` — Число(10,2)), Соответствие
  Этап → ΣСумма (окр. 2).
  Округление построчно обязательно: сырые Excel-дроби (13.714285…, 3021.705) иначе
  дают ложные расхождения.

После `ОбъектСеб.Записать()`, ДО `ЗафиксироватьТранзакцию()` — независимые запросы к БД
(транзакция видит свои изменения; запросы протестированы Python COM 1:1):
- итоги: `КОЛИЧЕСТВО(*), СУММА(Количество), СУММА(Сумма) ... ГДЕ К.Ссылка = &Структура`;
- по этапам: `Этап, СУММА(Сумма) ... СГРУППИРОВАТЬ ПО К.Этап`.

Сверка (допуск 0.005 на плавучку): строк, ΣКоличество, ΣСумма, Σ по каждому этапу
(в обе стороны: этапы Excel⊆1С и 1С⊆Excel). Расхождение →
`ВызватьИсключение "КОНТРОЛЬ ЗАГРУЗКИ НЕ ПРОЙДЕН: <критерий: Excel=…, 1С=…, дельта=…>"`
→ существующий обработчик откатывает транзакцию, протокол возвращает Ошибка+текст.
Битая загрузка не фиксируется.

## 2. Протокол

Новые поля протокола: `КонтрольПройден` (Булево), `Контроль` (массив строк готового
текста: строки/ΣКол/ΣСумма/по этапам, Excel vs 1С), `Инфо` (массив строк):
- уникальных наименований (`КОЛИЧЕСТВО(РАЗЛИЧНЫЕ НоменклатураСС)`) Excel vs 1С;
- строк без ОбщегоНазвания / без Единицы / без Номенклатуры (запрос протестирован) —
  качество связок, не блокирует.

Форма выводит: вердикт «КОНТРОЛЬ ЗАГРУЗКИ: ПРОЙДЕН», блок Контроль, блок Инфо.

## 3. Клиент

`ПрочитатьExcelВМассив` дополнительно считает и сообщает: строк «Матеріал» в файле
всего / взято / пропущено (пустое наименование G) — контроль полноты чтения файла.
(Итоговой строки в листе нет — «Разом по розділу» = 0, критерий недоступен.
В хвосте листа колонки съезжают (админ-блок), но там C≠«Матеріал» — фильтр отсекает.)
