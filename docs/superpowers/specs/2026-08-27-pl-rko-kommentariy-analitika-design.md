# Отчёт А_ОтчетPL_ПолныйЕРП: аналитика РКО «Прочий расход» = Комментарий документа

Дата: 2026-08-27. Утверждено пользователем (вариант «Комментарий, пустой → контрагент»).

## Проблема (глазами финансиста)

В расшифровке «Аналитика» строки от `РасходныйКассовыйОрдер` с операцией «Прочий расход ДС»
безлики: аналитика берётся из Контрагента, а у таких РКО он пуст. Замер июль-2026:
49 РКО на 10 439 130,38 грн — контрагент пуст у ВСЕХ, комментарий заполнен у ВСЕХ
(«ЗП акты по реестру», «Оплата за землю Шаранда И», «%% за июнь = 197 500»…).

## Решение

В `втЕРП_Расх_Детали` (регистр `ПрочиеРасходы`) ветка РКО в CASE поля `Аналитика`
(и его копии в `СГРУППИРОВАТЬ ПО`) заменяется вложенным ВЫБОР:

- операция = `ЗНАЧЕНИЕ(Перечисление.ХозяйственныеОперации.ПрочаяВыдачаДенежныхСредств)`
  (представление «Прочий расход ДС» — имя значения проверено на живой базе)
  И `ВЫРАЗИТЬ(Комментарий КАК Строка(200)) <> ""` → **комментарий** (обрезка 200);
- иначе → **Контрагент**, как сейчас (пустой комментарий и все прочие операции РКО
  ничего не теряют).

`Комментарий` — строка неограниченной длины: в ВЫБОР/ГРУППИРОВАТЬ только через
`ВЫРАЗИТЬ(… КАК Строка(200))`. Поле «Аналитика» становится составным (ссылки + строка) —
`Аналитика1` в BSL уже строит `Строка(Стр.Аналитика)`, для строки это она сама.
Разные комментарии = отдельные строки расшифровки (группировка по аналитике).

Не затрагивается: доходная ветка (РКО там нет), CASE поля `Контрагент`, документные
месяцы из `А_ОтчетPL` (там аналитика — комментарий финансиста из документа PL).
Запрос — новая версия `v9_full.sql`.
