# Дизайн: А_ПланФактныйПроизводствоПолный — количество + разрезы по материалам

Дата: 2026-06-30
Отчёт: `_Rarzrabotki/Отчеты/А_ПланФактныйПроизводствоПолный` (внешний `.erf`, программная компоновка СКД)

## Цель

Расширить отчёт по блоку «2. Матеріали»:
1. Добавить **количество** (план/факт/відхилення/%) по материалам.
2. Группировать материалы по **Етап → ОбщееНазвание → Аналітика(Номенклатура)**.
3. Добавить разрез **Документ** (как в `А_ПланФактныйАнализСебестоимости`).

## Решения (утверждено)

- **Количество:** 4 колонки `ПланКол/ФактКол/ОтклонениеКол/ПроцентКол`. План = `Комплектующие.Количество`,
  факт = `СебестоимостьТоваров.Количество` (закупки). У праці = 0 (там количество — это часы).
- **ОбщееНазвание:** группировка по **ссылке** `СправочникСсылка.А_ОбщиеНазванияНоменклатуры`
  (probe: для тест-СС 97 имён, 0 дублей ссылок — план/факт сходятся по ссылке).
- **Документ:** составной тип. План → карточка СС (`Комплектующие.Ссылка`,
  `СправочникСсылка.А_СтруктураСебестоимости`), факт → `ДокументСсылка.ПриобретениеТоваровУслуг`.

## Архитектура (подход A — расширение программного СКД)

Отчёт остаётся программной компоновкой (`ПриКомпоновкеРезультата` → внешний набор «Детали»).
Меняется BSL (`ПолучитьДанные`, `СоздатьПустуюТаблицу`) + схема СКД (`Template.xml`).
Постобработка `ЗаполнитьЭтапФактМатериалов` (Етап+Категорія факта) — без изменений.

### Грейн ВТ_Детали (13 колонок, было 9)

Измерения (7): `Подразделение, Блок, Категория, Этап, ОбщееНазвание, Аналитика, Документ`
Ресурсы-сырьё (6): `ПланЧасы, ФактЧасы, ПланКол, ФактКол, ПланГрн, ФактГрн`

| Ветка | ОбщееНазвание | Документ | ПланКол | ФактКол |
|---|---|---|---|---|
| Роботи-план | пусто (типизир. ПустаяСсылка) | НЕОПРЕДЕЛЕНО | 0 | 0 |
| Матеріали-план | `К.Номенклатура.А_ОбщееНазваниеНоменклатуры` | `К.Ссылка` (СС) | `К.Количество` | 0 |
| Табель-факт | пусто | НЕОПРЕДЕЛЕНО | 0 | 0 |
| ЗП-факт | пусто | НЕОПРЕДЕЛЕНО | 0 | 0 |
| Матеріали-факт-закупки | `СТ…Номенклатура.А_ОбщееНазваниеНоменклатуры` | `ВЫРАЗИТЬ(СТ.Регистратор КАК Документ.ПриобретениеТоваровУслуг)` | 0 | `СТ.Количество` |

Финальная группировка по 7 измерениям; считает `Отклонение/Процент` для часов, количества, грн.

### Схема СКД (Template.xml)

- +поля: `ОбщееНазвание` (dim, CatalogRef.А_ОбщиеНазванияНоменклатуры), `Документ`
  (dim, composite DocumentRef.ПриобретениеТоваровУслуг + CatalogRef.А_СтруктураСебестоимости),
  `ПланКол/ФактКол/ОтклонениеКол/ПроцентКол` (resource, decimal 18.2).
- +totalField для 4 ресурсов количества (Сумма / разность / %).
- +селект 4 ресурсов количества; формат `ЧДЦ=1` для `ПроцентКол`.
- Структура группировок: `Підрозділ → Блок → Категорія → Етап → ОбщееНазвание → Аналітика → Документ`.
  У праці уровни `ОбщееНазвание`/`Документ` схлопываются в пустые узлы.

### Выравнивание план/факт

План и факт материалов сходятся на уровне `ОбщееНазвание` (ссылки совпадают по probe).
Ниже, на `Номенклатура`, план-карточка и факт-карточка могут разойтись (разные карточки одной
«общей» номенклатуры) — это ожидаемо и для этого нужен уровень `ОбщееНазвание`.
