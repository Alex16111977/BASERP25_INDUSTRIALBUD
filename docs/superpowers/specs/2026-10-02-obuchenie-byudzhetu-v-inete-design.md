## Процесс (Workflow)

1. **Исследование**: 18 треков (M02–M05 — по два: международные основы EN и практика RU/UA; остальные — по одному);
   агент читает уже имеющуюся заметку 01–06 из `knowledge_ПредварительныйРасчет_БюджетированияИ_PL/research`
   и идёт глубже, пишет заметки с URL.
2. **Написание модуля** по шаблону из заметок трека(ов).
3. **Проверка** модуля скептиком: факты против источников, формулы и арифметика примеров, применимость.
4. **Правка** модуля по замечаниям.
5. **Синтез** (барьер — нужны все модули): карта, инструкция ИИ, применение к нашему бюджету, формулы, глоссарий, вопросы.
6. **Критик полноты** → до 3 дополнительных тем → исследование + модуль → обновление карты.

Агенты пишут в worktree (хук запрещает запись в основной каталог), затем папка копируется в основной каталог (Rule #4).
Язык материала — русский, термины с украинскими и английскими эквивалентами.
