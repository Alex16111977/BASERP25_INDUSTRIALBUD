### 1. Метаданные обработки
Объект → `А_ПереносОстатков661663` (синоним «Перенос начальной задолженности по зарплате»).
- **Реквизит:** `ДатаОстатков` (Date) — период остатка; `Месяц = НачалоМесяца(ДатаОстатков)`.
- **ТЧ-превью `Задолженность`:** `Счет`(Строка 3), `ФизЛицоИмя`(Строка 200), `ФизическоеЛицо`(СправочникСсылка.ФизическиеЛица), `Сотрудник`(СправочникСсылка.Сотрудники), `ПодразделениеОрг`(СправочникСсылка.ПодразделенияОрганизаций), `Организация`(СправочникСсылка.Организации), `ОрганизацияБухгалтерия`(СправочникСсылка.Организации), `Сумма`(Число 15,2), `Статус`(Строка).
- **Форма `Форма`:** командная панель с 2 кнопками + поле `ДатаОстатков`; таблица превью (поиск, правка, подвал-итог по `Сумма`). XML по правилам CLAUDE.md: у `Command` есть `id`, у `Action` нет `xsi:type`, все id уникальны. Логика — в **`Ext/ObjectModule.bsl`** (экспортные процедуры), модуль формы — тонкие обёртчики (как в эталонах «денег»/«РасчетыСПартнерами»).

### 2. Поток данных
- **Фаза 1 «Заполнить из BuhBud»** (`ОбъектОбработки.ЗагрузитьИзBuhBud()` Экспорт): COM→BuhBud → запрос остатков 661/663 по ЕДРПОУ орг-в-балансе → резолв ссылок → заполнение превью + пометка несопоставленных.
- **Фаза 2 «Создать документы»** (`ОбъектОбработки.СоздатьДокументы()` Экспорт): группировка превью по `Организация` → `find-or-create` `НачальнаяЗадолженностьПоЗарплате` (Месяц + Организация) → очистка ТЧ → заполнение → `Записать(Проведение)`.

### 3. Запрос к BuhBud (заземлён; выполнять в контексте BuhBud-соединения `V83`)
```
ВЫБРАТЬ
    Остатки.Счет.Код КАК Счет,
    Остатки.Субконто1 КАК ФЛ,                 // Справочник.ФизическиеЛица (BuhBud)
    Остатки.СуммаОстатокКт КАК Сумма,         // пассив = долг перед ФЛ
    Остатки.Организация.КодПоЕДРПОУ КАК ЕДРПОУ
ИЗ РегистрБухгалтерии.Хозрасчетный.Остатки(&Дата, Счет.Код В ("661", "663"), , ) КАК Остатки
ГДЕ Остатки.СуммаОстатокКт <> 0
    И Остатки.Организация.КодПоЕДРПОУ В (&масЕДРПОУ)
```
`&масЕДРПОУ` — `Массив` ЕДРПОУ организаций ERP с `А_ВБалансе=Истина И КодПоЕДРПОУ<>""` (собрать в ERP-контексте, передать в запрос BuhBud). **Счета держим литералом в условии виртуальной таблицы, а фильтр ЕДРПОУ — во внешнем `ГДЕ`** (проверенный паттерн обработки ОС; массив-параметр внутри условия ВТ ненадёжен). `&Дата = КонецДня(ДатаОстатков)`. Сериализация ТЗ через `V83.ЗначениеВСтрокуВнутр` → закрыть COM → `ЗначениеИзСтрокиВнутр` (как в эталонах). **UUID ФЛ доставать в цикле по ТЗ в контексте V83**: `V83.string(СтрТЗ.ФЛ.УникальныйИдентификатор())` + `СтрТЗ.ФЛ.КодПоДРФО` — сериализовать вместе с суммами строкой/таблицей примитивов (НЕ переносить COM-ссылки ФЛ в ERP — они невалидны между базами).

### 4. Правила резолва (в Фазе 1, ERP-контекст)
| Поле ТЧ-превью | Правило | Fallback / Статус |
|---|---|---|
| `ФизическоеЛицо` | по UUID: `Справочники.ФизическиеЛица.ПолучитьСсылку(Новый УникальныйИдентификатор(UUID))`, проверить `ПолучитьОбъект()<>Неопределено` | по `КодПоДРФО` (`НайтиПоРеквизиту`) → иначе Статус="Нет ФЛ" |
| `Сотрудник` | первый `Справочник.Сотрудники` по `ФизическоеЛицо` с **приоритетом Организация=орг по ЕДРПОУ**, не помеченный на удаление | первый любой активный → иначе "Нет сотрудника" |
| `Организация` | `Справочники.Организации.НайтиПоРеквизиту("КодПоЕДРПОУ", ЕДРПОУ)` | — |
| `ПодразделениеОрг` | реверс: `ПодразделенияОрганизаций` где `.А_Подразделение = Организация.А_ПодразделениеЗарплатаБух` И `Организация=орг`, первый | пусто → Статус="Нет подразделения" |
| `ОрганизацияБухгалтерия` | = `Организация` | — |
| `ФормаPL` (при создании) | `Перечисления.А_ФормыPL.Форма1` | — |
| **661+663** | **суммируются в ОДНУ строку** per (Сотрудник, ПодразделениеОрг, Организация) | — |

### 5. Создание документа (Фаза 2)
- **Ключ find-or-create:** `Организация` + `Месяц`(=`НачалоМесяца(ДатаОстатков)`). Один документ на организацию. Если найден — `Записать(ОтменаПроведения)` + `ЗадолженностьПоЗарплате.Очистить()`; иначе `Документы.НачальнаяЗадолженностьПоЗарплате.СоздатьДокумент()`.
- **Шапка:** `Месяц`, `Организация`, `Ответственный`, `Комментарий`("Сформировано переносом 661/663 на " + ДатаОстатков).
- **Строки ТЧ:** `Сотрудник`, `Подразделение`(=ПодразделениеОрг), `Сумма`, `ФормаPL=Форма1`, `ОрганизацияБухгалтерия`. (`СтатьяФинансирования/СтатьяРасходов/ГруппаУчетаНачислений` — пусто.)
- **Проведение:** `Записать(РежимЗаписиДокумента.Проведение)` в `Попытка/Исключение`. Спец-флаги обмена не нужны.

### 6. Обработка ошибок
Строки со Статусом ≠ "OK" в документ **не попадают** (остаются в превью с подсветкой). Счётчики в сообщениях: загружено строк, сопоставлено/не сопоставлено (с разбивкой ФЛ/Сотрудник/Подр), создано/обновлено документов, Σ по организациям. Несопоставленные ФЛ/подразделения — явный список (не теряем молча).
